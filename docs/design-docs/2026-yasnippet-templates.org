#+TITLE: Migrate AI Block Templates to yasnippet
#+DATE: 2026-03-17
#+STATUS: draft

* Goals

- Replace =claude-org-templates.el= alist system entirely with yasnippet
- Use =yas-expand-snippet= for interactive tab-stop navigation
- Support static text, dynamic elisp, and user-editable fields in a single template
- Keep the =completing-read= menu (=C-c C-/ t=) as the entry point
- Make yasnippet a required dependency (already installed in user's Emacs)
- Remove =claude-org-templates.el=, =claude-org--load-templates-from-file=,
  =claude-org-templates-file= customization, and all related loader code

* Non-Goals

- Requiring TAB-trigger expansion (we invoke from a command, not by typing a key)
- Supporting users who don't have yasnippet installed
- Maintaining backward compatibility with =claude-org-templates-file=

* Background

** Current System

=claude-org-templates.el= is an alist of =(NAME . VALUE)= pairs read from disk on
every invocation. 9 of 10 templates are static strings. 1 is a function reference.
The entry point =claude-org-insert-template= uses =completing-read= then =(insert content)=.

** What yasnippet Adds

| Capability | Current | yasnippet |
|------------+---------+-----------|
| Static text | ✅ =(insert "...")= | ✅ Same text in body |
| User-editable fields | ❌ None | ✅ =$1=, =${1:default}=, =$0= |
| Context-aware defaults | ⚠ Function must return whole string | ✅ =`(elisp)`= inline anywhere |
| Mirrors (repeat field) | ❌ | ✅ =$1= repeated = auto-mirror |
| Tab navigation | ❌ | ✅ TAB moves between fields |
| Completing-read menu | ✅ | ✅ =yas-expand-snippet= after selection |

* Technical Design

** Approach: Pure yasnippet — snippet files in =snippets/org-mode/=

Ship snippet files as part of the package. yasnippet manages everything:
loading, TAB expansion, =yas-insert-snippet= menu. The =insert-template=
command becomes a one-liner calling =yas-insert-snippet=. No custom
template loader code at all.

** Migration: Template-by-Template

*** Static templates (no change needed — work as-is with yas-expand-snippet)

| Template | Change | Reason |
|----------+--------+--------|
| Code Review | None | One-liner, no fields needed |
| continue | None | One-liner |
| Git Commit and Push | None | Fixed instruction |
| Enter Worktree | None | Fixed instruction |
| Exit Worktree (keep) | None | Fixed instruction |
| Exit Worktree (remove) | None | Fixed instruction |

*** Templates with natural tab stops

*Fix Error* — scaffold with blank fields:

#+begin_example
;; Before:
"Please help fix this error:\n\nError:\n\nContext:\n\n"

;; After:
"Please help fix this error:\n\nError:\n${1:paste error here}\n\nContext:\n${2:describe context}\n$0"
#+end_example

*Merge Worktree* — has =<branch-name>= placeholder:

#+begin_example
;; Before:
"... git merge --squash <branch-name> ..."

;; After:
"... git merge --squash ${1:branch-name} ...
6. Clean up: git worktree remove .claude/worktrees/$1 && git branch -d $1
$0"
#+end_example

=$1= mirrors — the branch name typed once appears in all 3 locations.

*** Templates with context-aware defaults

*Debug with Phoenix Traces* — could inject live Phoenix URL:

#+begin_example
"1. Query recent spans from the emacs-agent project:
   curl -s -X POST http://localhost:`(or (getenv \"PHOENIX_PORT\") \"6006\")`/graphql ..."
#+end_example

*Explain Code* — could inject the current file context:

#+begin_example
"Please explain the code in `(file-name-nondirectory (or buffer-file-name \"\"))`:\n$0"
#+end_example

*** Function-based template (Analyze Backtrace)

This stays as a function — yasnippet handles it via embedded elisp:

#+begin_example
"Please analyze this Emacs backtrace:\n\n\\=`\\=`\\=`\n`(claude-org-template--backtrace-text)`\n\\=`\\=`\\=`\n\n$0"
#+end_example

Where =claude-org-template--backtrace-text= is a helper that reads the
=*Backtrace*= buffer content (the existing function minus the prompt wrapper).

*** Step 2: Load snippets at package init

In =claude-org.org=, add snippet directory to yasnippet:

#+begin_src elisp
(require 'yasnippet)

(defun claude-org--setup-yasnippet ()
  "Load claude-org snippet directory into yasnippet."
  (let ((snippets-dir (expand-file-name
                       "snippets"
                       (or (bound-and-true-p claude-code-directory)
                           (file-name-directory
                            (or load-file-name buffer-file-name))))))
    (when (file-directory-p snippets-dir)
      (add-to-list 'yas-snippet-dirs snippets-dir t)
      (yas-load-directory snippets-dir))))

(with-eval-after-load 'yasnippet
  (claude-org--setup-yasnippet))
#+end_src

*** Step 3: Rewrite =insert-template= as thin wrapper

#+begin_src elisp
(defun claude-org-insert-template ()
  "Select and expand a Claude AI template into the current AI block.
Uses yasnippet for interactive field navigation and TAB completion."
  (interactive)
  (unless (claude-org--in-ai-block-p)
    (claude-org--do-insert-block nil)
    (forward-line -1)
    (end-of-line))
  (unless yas-minor-mode (yas-minor-mode 1))
  ;; Filter to only "Claude AI" group snippets
  (let* ((templates (cl-remove-if-not
                     (lambda (tmpl)
                       (equal "Claude AI" (yas--template-group tmpl)))
                     (yas--all-templates (yas--get-snippet-tables 'org-mode))))
         (names (mapcar #'yas--template-name templates))
         (selected (completing-read "Template: " names nil t))
         (tmpl (cl-find selected templates
                        :key #'yas--template-name :test #'equal)))
    (when tmpl
      (yas-expand-snippet (yas--template-content tmpl)))))
#+end_src

*** Step 4: Enable =yas-minor-mode= in =claude-org-mode=

#+begin_src elisp
;; In claude-org-mode enable hook:
(yas-minor-mode 1)
#+end_src

This gives users two ways to insert templates:
- =C-c C-/ t= → =completing-read= → expand (the menu way)
- Type =fe= + TAB inside an AI block → expand (the keyboard way, via =# condition:=)

*** Step 6: Keep =backtrace-text= helper

#+begin_src elisp
(defun claude-org-template--backtrace-text ()
  "Return the current Emacs backtrace as a string.
Called by the Analyze Backtrace yasnippet via embedded elisp."
  (let ((buf (or (and (eq major-mode 'debugger-mode) (current-buffer))
                 (get-buffer "*Backtrace*"))))
    (if buf
        (with-current-buffer buf (buffer-string))
      "(No backtrace found — open *Backtrace* buffer first)")))
#+end_src

** User Setup in =.emacs= / =init.el=

#+begin_src elisp
;; 1. Install yasnippet (if not already)
(use-package yasnippet
  :ensure t
  :config
  (yas-global-mode 1))    ;; enables yas-minor-mode in all buffers

;; 2. Install claude-code (which ships the snippets)
(use-package claude-code
  :load-path "~/projects/claude-agent"
  :config
  ;; claude-org-mode enables yas-minor-mode automatically
  ;; Snippets are loaded from claude-agent/snippets/org-mode/ automatically
  )

;; That's it! Templates are available via:
;;   C-c C-/ t  →  completing-read menu  →  expand with TAB stops
;;   Type "fe" + TAB inside #+begin_src ai block → expand Fix Error
;;   Type "mw" + TAB → expand Merge Worktree (with mirror fields)
#+end_src

For users who already have =yas-global-mode= enabled, no additional
setup is needed. The snippets load automatically when =claude-org.org=
loads via =with-eval-after-load 'yasnippet=.

For users who don't want =yas-global-mode=, =claude-org-mode= enables
=yas-minor-mode= in its hook, so snippets work in org files with
=claude-org-mode= active.

** yasnippet Gotchas for org-mode

| Issue | Solution |
|-------+---------|
| Indentation mangling | Use =(yas-indent-line 'fixed)= in expand-env |
| TAB conflict with =org-cycle= | =yas-maybe-expand= conditional binding handles this |
| Literal =$= in templates | Escape as =\$= |
| Literal backtick in templates | Escape as =\`= |
| =yas-minor-mode= required | Enable in =claude-org-mode= hook |

** Two Ways to Use Templates

| Method | How | When |
|--------+-----+------|
| Menu | =C-c C-/ t= → =completing-read= → select → expand | Always works, discoverable |
| Keyboard | Type =fe= + TAB inside AI block | Fast for frequent users |

Both produce identical results. The keyboard method only triggers when
=# condition: (claude-org--in-ai-block-p)= is true (inside an AI block),
so keys like =fe= don't interfere with normal typing.
