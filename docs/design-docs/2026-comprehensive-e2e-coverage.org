* Reality check (2026-04-27)
The shipped form is `tests/e2e/E2E_TASKS.org` — 32 tasks under Sections
A (cmux workflows), B (tmux primitives), C (bridge driving), D (cross-cutting),
E (tmux full-stack gaps now closed).  Driven by the `/loop` skill one task
per iteration; results are written back inline as PASS/FAIL/BLOCKED-ENV/
GAP-CONFIRMED.  See also `2026-e2e-test-strategy.org` for the strategy doc.

* Motivation

From Anthropic's "Harness Design for Long-Running Application Development":
- "Sprint contracts" -- define success criteria before implementation
- "QA agent tuning" -- evaluator must actively test, not just read diffs
- "Criteria-based evaluation" -- transform quality into gradable measures

Our E2E tests cover only the happy path (execute ai block -> response). 20+
cmux and org-mode features have zero E2E coverage. The evaluator should test
like a user: execute commands, check cmux state, verify org properties.

* Test Story Structure

Each test follows the established T1-T15 pattern:

#+begin_example
,** T<N>: <Feature Under Test>
:PROPERTIES:
:STATUS: UNTESTED
:TESTED:
:PRIORITY: HIGH|MEDIUM|LOW
:DEPENDS: T<M>
:END:

,*** Setup
<preconditions: org property changes, cmux state>

,*** Command
evalElisp:
<exact Elisp to execute via MCP>

,*** Expected
<behavioral expectations, observable side effects>

,*** Trace Assertions (optional, from trace-evaluator design)
<expected Phoenix spans>

,*** Teardown (optional)
<cleanup: remove properties, close workspaces>
#+end_example

=:DEPENDS:= enables skip logic when prerequisites fail.

* HIGH Risk Test Details

** T16: Cancel active query

*** Setup
Execute ai block with slow prompt. Wait 3s for Claude Code to start.

*** Command
=(claude-org-cancel)= from workspace buffer.

*** Expected
- Escape key sent to cmux surface
- Session =:busy= cleared within 5s
- Mode-line updated
- No error heading inserted in org

** T17: Permission needed notification

*** Command
=(claude-org-cmux--permission-needed "sdd-e2e-test-005" "Bash(rm -rf /)")=

*** Expected
- Mode-line shows orange permission alert
- cmux workspace focused
- macOS notification fires

*** Teardown
=(claude-org-cmux--permission-resolved "sdd-e2e-test-005")=

** T18: Session recovery after restart

*** Setup
Clear all hash tables to simulate Emacs restart:
=(clrhash claude-org-terminal--workspace-to-session-key)= etc.

*** Command
=(claude-org-cmux--recover-session "sdd-e2e-test-005")=

*** Expected
- Returns non-nil session-key
- Hash tables repopulated from org properties
- Subsequent execute works without new workspace

** T19: Status detection

*** Command
=(claude-org-cmux--get-status "sdd-e2e-test-005" surface-id)=

*** Expected
- Returns ="ready"= when Claude Code idle
- Returns ="busy"= during active query

** T20: Workspace resolution by name after cmux restart

*** Setup
Rename the heading to a title no cmux workspace has, e.g. "Nonexistent Workspace".

*** Command
=(claude-org-cmux-open-tab)=

*** Expected
- =find-workspace-by-name= returns nil -> =ensure-session= launches fresh
- New workspace created with heading title as name
- =CMUX_SURFACE_ID= property refreshed to new surface
- Restore path (not launch) when heading title matches a live cmux workspace

** T21: Story switching

*** Setup
Add second story to workspace-test.org with its own ai block.

*** Command
Execute ai block in second story.

*** Expected
- ACTIVE_STORY changes to second story name
- cmux tab renamed
- =claude-org-active-story-changed-hook= fires

** T22: --resume uses CLAUDE_CLI_SESSION

*** Command
=(claude-org-cmux--build-launch-command buf session-id dir)=

*** Expected
- Result contains ="--resume"= and the CLAUDE_CLI_SESSION UUID

** T23: Cancel all queries

*** Command
=(claude-org-cancel-all)=

*** Expected
- All active sessions' =:busy= cleared
- All cmux surfaces receive escape

** T24: Query completed cleanup

*** Command
=(claude-org-cmux--query-completed "sdd-e2e-test-005")=

*** Expected
- Session =:busy= set to nil
- Active query unregistered
- Workspace mappings NOT cleared (persist)

* Execution Model

Tests run by Claude Code or human operator using evalElisp MCP + cmux CLI.
NOT mock tests -- real Emacs, real cmux, real Claude Code.

Prerequisites (same as T1-T15):
1. Emacs with =claude-org-mode= loaded
2. MCP server running
3. cmux running
4. Phoenix + OTel bridge (for trace assertions)
