* Introduction

Claude Org Integration is a minor mode for org-mode that enables interactive
streaming AI queries directly within org files using ~#+begin_src ai~ blocks.

This package depends on ~claude-agent~ for Claude communication and provides
org-specific features on top of it.

** Features

- *Token-by-token streaming*: Responses stream token-by-token with debounced
  font-lock for smooth rendering.

- *Multi-session support*: Multiple queries with different CLAUDE_SESSION_ID
  values can run concurrently.

- *Session recovery*: When backend sessions expire, context is collected from
  the org file and rebuilt automatically.

- *Project support*: PROJECT_ROOT property sets cwd; :system_prompt: tagged
  sections provide project guidelines.

** Usage Example

#+BEGIN_SRC org :load no
,#+PROPERTY: PROJECT_ROOT /path/to/project

,* Project Guidelines :system_prompt:
This project uses Python 3.11.
Always use absolute imports.

,* Tasks

,** Instruction 1 :claude_chat:

,#+begin_src ai
How do I read a JSON file in Python?
,#+end_src

Response will appear here after pressing C-c C-c inside the ai block.
#+END_SRC

;; Load extracted modules (literate-elisp .org files, not .el packages)
(let ((module-dir (file-name-directory (or load-file-name buffer-file-name ""))))
  (dolist (module '("code-agent-org-session" "code-agent-org-queue"
                    "code-agent-org-response"
                    "code-agent-org-scheduled"))
    (unless (featurep (intern module))
      (literate-elisp-load
       (expand-file-name (concat module ".org") module-dir))))
  ;; Load ACP backend (our own JSON-RPC transport, no external deps)
  (dolist (module '("claude-agent-jsonrpc"
                    "claude-agent-acp"
                    "claude-agent-acp-opencode"
                    "claude-agent-acp-gemini"
                    "claude-agent-acp-codex"))
    (unless (featurep (intern module))
      (let ((path (expand-file-name (concat module ".org") module-dir)))
        (when (file-exists-p path)
          (literate-elisp-load path)))))
  ;; Load claude-ide conditionally (requires websocket package)
  (when (require 'websocket nil t)
    (unless (featurep 'claude-ide)
      (literate-elisp-load
       (expand-file-name "claude-ide.org" module-dir)))))

(declare-function code-agent-org-cmux-open-tab "code-agent-org-cmux" ())
(defvar code-agent-org-terminal--workspace-to-session-key)

** macOS Notifications

Send a desktop notification with sound when a query completes, pulling
the user back even when looking at another app. Hooking
=code-agent-org-complete-hook= rather than each backend means every
backend (JSON stream, cmux, tmux) gets notifications for free with no
per-backend wiring.

One =osascript= call delivers both banner + sound, non-blocking via
=start-process=. Two non-goals accepted: the banner always shows
"Script Editor" as the sender (osascript's identity; would need a
bundled .app to override), and only the completion event is surfaced
— intermediate streaming/tool-use/permission would be noise. Linux /
Windows users get the same =complete-hook= and can layer their own
notifier. The defcustoms above gate behaviour and pick from the
standard macOS sound set (Basso / Blow / Bottle / … / Tink).

#+BEGIN_SRC elisp
(defun code-agent-org--notify (title message &optional sound)
  "Send a macOS desktop notification with optional SOUND. Non-blocking."
  (when (eq system-type 'darwin)
    (let* ((sound-clause (if sound
                             (format " sound name %S" sound)
                           ""))
           (script (format "display notification %S with title %S%s"
                           message title sound-clause)))
      (start-process "claude-notify" nil "osascript" "-e" script))))

(defun code-agent-org--notify-on-complete (session-key _result status)
  "Send macOS notification on query completion.
STATUS is `completed' or `error'.  Added to `code-agent-org-complete-hook'."
  (when code-agent-org-notify-on-complete
    (let* ((title (if (eq status 'error)
                      "Claude: Error"
                    "Claude: Complete"))
           (message (format "%s" (or (buffer-name) "query"))))
      (code-agent-org--notify title message code-agent-org-notify-sound))))

(add-hook 'code-agent-org-complete-hook #'code-agent-org--notify-on-complete)
#+END_SRC

*** Loop Detection Utilities

Helper functions for the loop iteration hook system. These are building
blocks that hook functions can use — no detection logic runs by default.

#+BEGIN_SRC elisp
(defun code-agent-org--record-tool-call (session-key tool-name tool-input)
  "Record a tool call in the session's :tool-call-history.
Appends (TOOL-NAME . ARGS-HASH) to the history list."
  (let* ((args-hash (sxhash tool-input))
         (entry (cons tool-name args-hash))
         (history (code-agent-org--session-get session-key :tool-call-history)))
    (code-agent-org--session-put session-key :tool-call-history
                             (append history (list entry)))))

(defun code-agent-org-loop-inject-warning (session-key message)
  "Inject a warning MESSAGE into the next loop iteration for SESSION-KEY.
The warning will be included in the system prompt and cleared after use."
  (code-agent-org--session-put session-key :loop-warning message))

(defun code-agent-org--consume-loop-warning (session-key)
  "Read and clear the :loop-warning from SESSION-KEY.
Returns the warning string, or nil if none."
  (let ((warning (code-agent-org--session-get session-key :loop-warning)))
    (when warning
      (code-agent-org--session-put session-key :loop-warning nil))
    warning))
#+END_SRC

*** Autonomous Mode — TODO-Driven Future Design

The loop primitive above (=:loop N :interval S= header arg, plus the
=loop-iteration-hook= and =loop-inject-warning= helpers) covers the
"single block iterates N times" case. The next design step — *not yet
shipped* — promotes this from "fixed iteration count" to *"run until an
acceptance criterion is met or a circuit breaker trips"*. The notes here
capture the agreed shape so the eventual implementation has a target.

**** What the user writes

A regular org TODO heading with checkboxes, executed via =C-c C-c=:

#+begin_example
,** TODO Refactor session management
- [ ] Extract shared code into base module
- [ ] Update tests
- [ ] Run make check
#+end_example

System detects checkboxes → launches autonomous loop → agent works for
minutes-to-hours → notification when done → review buffer.

**** Mode selection

The same =C-c C-c= chord routes to interactive or autonomous mode based
on what point is on:

| Point is on | Mode |
|-------------+------|
| AI block without checkboxes | Interactive (current behaviour) |
| AI block with checkboxes | Autonomous |
| TODO heading with checkboxes | Autonomous |
| TODO heading without checkboxes | Interactive |

Differences a user notices:

| Aspect | Interactive | Autonomous |
|--------+-------------+------------|
| Trigger | =ai= block | TODO + checkboxes |
| Runs for | seconds | minutes–hours |
| User waits? | yes (streaming) | no |
| Feedback | inline response | review buffer at end |
| Permission mode | normal | =acceptEdits= (permissive) |

**** Loop engine — which side runs the loop?

*Option A — Claude Code's built-in loop* (preferred). Claude Code already
runs autonomously; we send the TODO + checkboxes as one prompt with
permissive settings, and let Claude Code iterate internally. Emacs's
role shrinks to: send the spec, set the permission mode, monitor the
verbose buffer for completion or stall, surface the review buffer.

*Option B — Emacs-driven loop.* Emacs sends prompt → waits for response →
parses checkbox state → sends "continue, these items still unchecked: …"
→ repeats. More control but more code. Defer until Option A proves
insufficient.

**** Circuit breaker — three states

Borrowed from the distributed-systems pattern; goal is to prevent
runaway agents.

- *CLOSED* (normal): agent making progress, let it continue.
- *OPEN* (halted): agent stuck, stop the loop, notify the user.
- *HALF-OPEN* (probe): after the user gives feedback, try one more
  iteration before deciding whether to re-open or close.

Default thresholds (configurable):

| Threshold | Default | Trip condition |
|-----------+---------+----------------|
| no-progress | 3 | iterations with no file changes |
| same-error | 5 | iterations producing the same error string |
| max-iterations | 10 | hard cap on total iterations |
| token-budget | TBD | max tokens consumed before halt |

For Option A, the detector tails the verbose buffer: no edits in N
captures = no progress; same error string repeated N times = same error;
process exit = completion or crash.

**** Review buffer

When an autonomous task ends (success *or* circuit-break), Emacs renders
a single review buffer summarizing diff, test results, and per-checkbox
acceptance:

#+begin_example
╔══════════════════════════════════════════╗
║  Autonomous Task Review                  ║
║  Story: Refactor session management      ║
║  Status: Completed (7 iterations)        ║
╚══════════════════════════════════════════╝

## Changes
[git diff since task started]

## Test Results
✓ 650 passed, ✗ 2 failed, ○ 6 skipped

## Acceptance Criteria

*** External Pattern Studies — Ralph and Atomic

Two outside methodologies were studied before settling on the shape of
the loop primitive and the autonomous-mode design above. The notes here
record what we adopted and what we deliberately did not, so future
contributors do not have to re-derive the rejections.

**** Ralph (overnight loop method)

Source: Geoffrey Huntley's "Ralph Wiggum" technique
([[https://ghuntley.com/ralph/]]) plus the production-grade
=frankbria/ralph-claude-code= shell harness. The simplest form is
literally =while :; do cat PROMPT.md | claude ; done=, with a circuit
breaker and a structured-status protocol layered on top to keep it from
running forever.

*Adopted*:

- *Three-state circuit breaker* (CLOSED / HALF-OPEN / OPEN). Designed
  into the autonomous-mode subsection above; built on top of the
  shipped =:loop= primitive.
- *Loop iteration hook + warning injection* (=loop-iteration-hook=,
  =loop-inject-warning=) — the building blocks a Ralph-style harness
  would attach to. Already in this file (see Loop Detection Utilities).

*Not adopted*:

- The structured =---RALPH_STATUS---= block with =STATUS= /
  =EXIT_SIGNAL= / =RECOMMENDATION= fields in the model output. Phoenix
  spans carry the same completion-detection signal with less prompt
  surface area and generalise to non-Ralph flows.
- Geoffrey Huntley's iteration-section-per-loop org layout
  (=Iteration 1 :ralph_iter:=, =Iteration 2 :ralph_iter:=, …). The
  =:loop= header arg appends responses with =(N/M)= suffixes inside one
  response section, which keeps the file flatter and folds cleanly.

References to revisit when implementing the Future Design:
=https://github.com/frankbria/ralph-claude-code=,
=https://github.com/mikeyobrien/ralph-orchestrator=,
=https://anandchowdhary.com/blog/2025/running-claude-code-in-a-loop=.

**** Atomic (SDLC-style harness, flora131/agent-instructions)

Source: =flora131/agent-instructions=
([[https://github.com/flora131/agent-instructions]]), documented case study
at [[https://alexlavaee.me/blog/ai-coding-infrastructure/]] ("100k LOC in two
weeks"). Atomic separates *commands* (orchestration:
=/research-codebase=, =/create-spec=, =/implement-feature=, …), *agents*
(specialised executors: locator, analyzer, pattern-finder), and *skills*
(domain knowledge injection).

*Adopted*:

- *Slash command discovery and completion* in AI blocks (see "Slash
  Command Completion" later in this file). The mechanism is exposed;
  the catalog is the user's, not a fixed Atomic one.
- *yasnippet templates as the prompt-template surface* ("Template
  Insertion (yasnippet)" later in this file). Functionally equivalent
  to Atomic's static-prompt commands, with TAB-stop fields for the
  parts a human must fill in.
- *Specialised sub-agents via Claude Code's subagent mechanism* —
  codebase-locator, codebase-analyzer, etc. are first-class skills the
  user invokes; the project does not redefine them.

*Not adopted*:

- =feature-list.json= as the ground-truth task ledger. Org checkboxes
  on a =** TODO= heading serve the same role natively; the autonomous-
  mode design above builds on that.
- =progress.txt= as a separate handoff document. Org properties on the
  story heading (=:CLAUDE_SESSION_ID:=, =:CLAUDE_BACKEND:=, …) already
  carry the equivalent state.
- The "competing agents" psychological framing in prompts. Not used —
  no measurable win observed, and it complicates prompt audit.

The fuller comparison-and-recommendation matrix is preserved in git
history; the lessons that mattered are folded into the autonomous-mode
design above and the shipped =:loop= primitive.

(defun code-agent-org-append-to-response (session-key query-id text)
  "Append TEXT to the response section identified by QUERY-ID.
Finds the response heading with matching :QUERY_ID: property,
navigates to the end of its subtree, and inserts TEXT.
Preserves window-start (scroll position)."
  (let ((ws (window-start)))

          (condition-case nil
              (when (re-search-forward
                     (format ":QUERY_ID: %s" (regexp-quote query-id)) nil t)

            (error nil)))

** File-Level Property Lookup

File-level properties (=#+ PROPERTY:=) require different lookup logic than
section properties. This function searches only the file header area (before
the first heading) to avoid matching properties inside headings.

#+NAME: session-file-level-property
#+BEGIN_SRC elisp
(defun code-agent-org--get-file-level-property (property)
  "Get PROPERTY value from file-level #+PROPERTY keyword.
Only searches in the file header area (before first heading).
Returns nil if not found."
  (save-excursion
    (save-restriction
      (widen)
      (goto-char (point-min))
      ;; Limit search to before first heading (file header area)
      (let ((limit (save-excursion
                     (if (re-search-forward "^\\*+ " nil t)
                         (line-beginning-position)
                       (point-max)))))
        (when (re-search-forward
               (format "^#\\+PROPERTY:[ \t]+%s[ \t]+\\(.+\\)$"
                       (regexp-quote property))
               limit t)
          (string-trim (match-string-no-properties 1)))))))
#+END_SRC

** Session Scope Detection

Session scope determines how conversation context is shared. The =:claude_session:=
tag creates a section-scoped session (isolated subtree). Without it, the whole
file shares one conversation context.

#+NAME: session-scope-detection
#+BEGIN_SRC elisp
(defun code-agent-org--has-session-tag-p ()
  "Check if current section has the session tag.
Returns non-nil if current heading has :claude_session: tag.
Returns nil safely if not in org-mode context."
  (ignore-errors
    (save-excursion
      (when (org-at-heading-p)
        (let ((tags (org-get-tags nil t)))
          (member code-agent-org-session-tag tags))))))

(defun code-agent-org--find-session-scope-heading ()
  "Find the heading that defines the session scope.
Walks up the heading tree looking for :claude_session: tag or CLAUDE_SESSION_ID.
Checks current heading first, then walks upward.
Returns the heading position or nil if at file scope.
Returns nil safely if not in org-mode context."
  (ignore-errors
    (save-excursion
      (catch 'found
        ;; First check current heading (if at one)
        (when (org-at-heading-p)
          (when (or (code-agent-org--has-session-tag-p)
                    (org-entry-get nil "CLAUDE_SESSION_ID" nil))
            (throw 'found (point))))
        ;; Then walk up the tree
        (while (org-up-heading-safe)
          (when (or (code-agent-org--has-session-tag-p)
                    (org-entry-get nil "CLAUDE_SESSION_ID" nil))
            (throw 'found (point))))
        nil))))
#+END_SRC

** SDK UUID Management

The SDK UUID is the session identifier returned by Claude Code CLI. It's stored
as an org property to enable session resumption across Emacs restarts.

#+BEGIN_SRC elisp
(defun code-agent-org--get-sdk-uuid ()
  "Get SDK UUID from org properties for current session.
Only retrieves UUID from the same scope where CLAUDE_SESSION_ID is defined:
- If session ID is in a heading, gets UUID from that heading's property drawer
- If no session ID in headings, gets UUID from file-level #+PROPERTY
Returns nil if not set."
  (let ((session-heading (code-agent-org--find-session-scope-heading)))
    (if session-heading
        ;; Section-level: get UUID from the heading that defines the session
        (save-excursion
          (goto-char session-heading)
          (org-entry-get nil code-agent-org-sdk-uuid-property nil))  ;; nil = no inheritance
      ;; File-level: get from #+PROPERTY keyword
      (code-agent-org--get-file-level-property code-agent-org-sdk-uuid-property))))

(defun code-agent-org--set-sdk-uuid (uuid)
  "Set SDK UUID in org property.
Stores at the appropriate scope based on where CLAUDE_SESSION_ID is defined:
- If session ID is in a heading (current or parent), stores in that heading's property drawer
- Otherwise stores at file level."
  (let ((session-heading (code-agent-org--find-session-scope-heading)))
    (if session-heading
        ;; Section-level: set in the heading that defines the session
        (save-excursion
          (goto-char session-heading)
          (org-set-property code-agent-org-sdk-uuid-property uuid))
      ;; File-level: use #+PROPERTY keyword
      (save-excursion
        (goto-char (point-min))
        (if (re-search-forward
             (format "^#\\+PROPERTY:[ \t]+%s[ \t]+.+$" code-agent-org-sdk-uuid-property)
             nil t)
            ;; Update existing
            (replace-match (format "#+PROPERTY: %s %s"
                                   code-agent-org-sdk-uuid-property uuid))
          ;; Insert new after other properties
          (goto-char (point-min))
          (if (re-search-forward "^#\\+PROPERTY:" nil t)
              (progn
                (end-of-line)
                (insert (format "\n#+PROPERTY: %s %s"
                                code-agent-org-sdk-uuid-property uuid)))
            ;; No properties, insert after title or at beginning
            (if (re-search-forward "^#\\+TITLE:" nil t)
                (progn
                  (end-of-line)
                  (insert (format "\n#+PROPERTY: %s %s"
                                  code-agent-org-sdk-uuid-property uuid)))
              (insert (format "#+PROPERTY: %s %s\n" code-agent-org-sdk-uuid-property uuid)))))))))

(defun code-agent-org--clear-sdk-uuid ()
  "Clear SDK UUID from org properties.
Removes the property from the appropriate scope based on where CLAUDE_SESSION_ID is defined."
  (let ((session-heading (code-agent-org--find-session-scope-heading)))
    (if session-heading
        ;; Section-level: remove from property drawer
        (save-excursion
          (goto-char session-heading)
          (org-delete-property code-agent-org-sdk-uuid-property))
      ;; File-level: remove #+PROPERTY line
      (save-excursion
        (goto-char (point-min))
        (when (re-search-forward
               (format "^#\\+PROPERTY:[ \t]+%s[ \t]+.+\n?"
                       code-agent-org-sdk-uuid-property)
               nil t)
          (replace-match ""))))))

** Session Recovery

#+BEGIN_SRC elisp
(defun code-agent-org--section-has-archive-tag-p ()
  "Check if current heading has :ARCHIVE: tag.
Point must be at a heading."
  (when (org-at-heading-p)
    (member "ARCHIVE" (org-get-tags nil t))))

(defun code-agent-org--collect-ai-blocks-in-section ()
  "Collect AI blocks in current section (not including subsections).
Returns list of (question . response) pairs.
Point must be at a heading, or before first heading for top-level content."
  (let ((conversations '())
        (section-start (if (org-at-heading-p)
                           ;; Start after the heading line
                           (save-excursion
                             (forward-line 1)
                             (point))
                         ;; Before first heading: start from current point
                         (point)))
        (section-end (save-excursion
                       (if (org-at-heading-p)
                           ;; End is before next same-level heading
                           (progn
                             (org-end-of-subtree t t)
                             (point))
                         ;; Before first heading: search until first heading
                         (if (re-search-forward "^\\*+ " nil t)
                             (line-beginning-position)
                           (point-max))))))
    (save-excursion
      (save-restriction
        (narrow-to-region section-start section-end)
        ;; Find all ai blocks in this section only (not subsections)
        (goto-char (point-min))
        (while (re-search-forward "^[ \t]*#\\+begin_src[ \t]+ai" nil t)
          ;; Make sure we're not in a subsection
          (let ((block-pos (point)))
            (save-excursion
              (beginning-of-line)
              ;; Check if there's a heading between section start and block
              (goto-char (point-min))
              (unless (re-search-forward "^\\*+ " block-pos t)
                ;; No heading found, this block is in current section
                (goto-char block-pos)
                (let* ((q-start (progn (forward-line 1) (point)))
                       (q-end (progn (re-search-forward "^[ \t]*#\\+end_src" nil t)
                                     (line-beginning-position)))
                       (question (string-trim (buffer-substring-no-properties q-start q-end)))
                       ;; Response is content after #+end_src until next heading or ai block
                       (r-start (progn (forward-line 1) (point)))
                       (r-end (save-excursion
                                (if (re-search-forward "^\\(\\*+ \\|[ \t]*#\\+begin_src\\)" nil t)
                                    (line-beginning-position)
                                  (point-max))))
                       (response (string-trim (buffer-substring-no-properties r-start r-end))))
                  (when (not (string-empty-p question))
                    (push (cons question response) conversations)))))))))
    (nreverse conversations)))

(defun code-agent-org--collect-session-context ()
  "Collect conversation history from current session scope.
If CLAUDE_SESSION_ID is defined in a section, narrows to that subtree.
Otherwise, collects from the entire file.
Skips sections tagged with :ARCHIVE: for better performance with large files.
Returns list of (question . response) pairs for recovery."
  (claude-agent-with-span "collect-session-context" nil nil
  (let ((conversations '())
        (scope (code-agent-org--get-session-scope)))
    (save-excursion
      (save-restriction
        ;; Narrow to section scope if session ID is defined locally
        (when (eq scope 'section)
          (unless (org-at-heading-p)
            (org-back-to-heading t))
          (org-narrow-to-subtree))

        ;; Collect blocks from before first heading
        (goto-char (point-min))
        (unless (org-at-heading-p)
          (setq conversations (append conversations (code-agent-org--collect-ai-blocks-in-section))))

        ;; Iterate through top-level sections, skipping archived ones
        (goto-char (point-min))
        (when (re-search-forward "^\\*+ " nil t)
          (beginning-of-line)
          (while (not (eobp))
            (if (code-agent-org--section-has-archive-tag-p)
                ;; Skip entire archived subtree
                (org-end-of-subtree t t)
              ;; Collect blocks from this section
              (setq conversations (append conversations (code-agent-org--collect-ai-blocks-in-section)))
              ;; Move to next same-level heading
              (org-end-of-subtree t t))
            ;; Move to next top-level heading
            (unless (re-search-forward "^\\*+ " nil t)
              (goto-char (point-max)))
            (beginning-of-line)))))
    conversations)))

(defun code-agent-org--build-recovery-prompt (context original-prompt)
  "Build recovery prompt with CONTEXT history and ORIGINAL-PROMPT."
  (let ((scope (code-agent-org--get-session-scope)))
    (concat
     "<session_recovery>\n"
     "The previous session expired. Here is the conversation history from this "
     (if (eq scope 'section) "section" "file")
     ":\n\n"
     (mapconcat
      (lambda (pair)
        (format "**User:** %s\n\n**Assistant:** %s\n\n---\n"
                (car pair) (cdr pair)))
      context "")
     "</session_recovery>\n\n"
     "Please continue the conversation. The user's current question is:\n\n"
     original-prompt)))

(defun code-agent-org--recover-session (session-key &optional reason)
  "Recover session for SESSION-KEY by creating a new response section.
REASON can be 'context-limit or 'expired (default).

Uses query-id based recovery:
1. Find current response section by query-id
2. Create NEW recovery response section after it
3. Generate new query-id for recovery query
4. Old query's callbacks will be ignored (query-id mismatch)

Recovery is limited to `code-agent-org-max-recovery-attempts' consecutive
attempts.  The counter resets on each new query."
  (claude-agent-with-span "recover-session"
      (list :custom-id (code-agent-org--session-get session-key :custom-id)
            :reason (format "%s" reason))
    nil
  ;; Guard: check recovery count against limit
  (let ((count (or (code-agent-org--session-get session-key :recovery-count) 0)))
    (if (>= count code-agent-org-max-recovery-attempts)
        ;; insert-error calls cleanup-session internally — no need for
        ;; redundant reset-session-state, stop-spinner, refresh-header-line
        (code-agent-org--insert-error
         session-key
         (format "Recovery limit reached (%d attempts). Please retry manually."
                 count))
      ;; Normal recovery path — increment counter before attempting
      (code-agent-org--session-put session-key :recovery-count (1+ count))
      (code-agent-org--session-put session-key :recovering t)
      (let* ((old-query-id (code-agent-org--session-get session-key :query-id))
             (reason-str (pcase reason
                           ('context-limit "context_limit")
                           (_ "session_expired"))))
        ;; Try to find response section by query-id (marker-free approach)
        (let ((response-pos (code-agent-org--find-response-by-query-id old-query-id)))
          (if (not response-pos)
              ;; Can't find response section - full cleanup via centralized function
              (progn
                (message "Claude: Cannot recover session - response section not found")
                (code-agent-org--cleanup-session session-key "error" t))
            ;; Found response section - create recovery section
            (save-excursion
              (goto-char response-pos)
              ;; Move to end of current response section
              (org-end-of-subtree t)
              ;; Insert newlines and create NEW recovery response section
              (insert "\n\n")
              ;; Generate new query-id for recovery
              (let ((new-query-id (code-agent-org--generate-query-id)))
                ;; Update session with new query-id BEFORE creating section
                (code-agent-org--session-put session-key :query-id new-query-id)
                ;; Create recovery response section with parent reference
                (code-agent-org--create-response-section
                 session-key new-query-id 'recovery old-query-id reason-str)
                ;; Insert recovery message in the new section
                (let ((recovery-msg (pcase reason
                                      ('context-limit "/Context limit reached, recovering with history.../")
                                      (_ "/Session expired, recovering with context.../"))))
                  (insert recovery-msg "\n\n"))))
            ;; Clear old session UUID from org property
            (code-agent-org--clear-sdk-uuid)
            ;; Collect context and send recovery request
            (let* ((context (code-agent-org--collect-session-context))
                   (original-prompt (code-agent-org--session-get session-key :original-prompt))
                   (recovery-prompt (code-agent-org--build-recovery-prompt context original-prompt)))
              ;; Clear recovering flag - the new query-id protects us now
              (code-agent-org--session-put session-key :recovering nil)
              ;; Send recovery request with new query-id already in session
              (code-agent-org--send-request recovery-prompt nil session-key)))))))))

#+BEGIN_SRC elisp
(cl-defun code-agent-org--parse-env (source &key from-string)
  "Parse .env content and return alist of (VAR . VALUE).
SOURCE is either a file path or a string of env content.
When FROM-STRING is non-nil, SOURCE is treated as a string.
When FROM-STRING is nil, SOURCE is treated as a file path.

Supports standard .env syntax:
  KEY=value
  KEY=\"value with spaces\"
  KEY='single quoted'
  # Comments (ignored)
  export KEY=value (export prefix ignored)
  Values containing = (only first = is split point)

Returns nil for nonexistent files. Safe parser — no Elisp execution."
  (let ((env-alist '()))
    (if from-string
        ;; Parse from string content
        (with-temp-buffer
          (insert source)
          (goto-char (point-min))
          (setq env-alist (code-agent-org--parse-env-lines)))
      ;; Parse from file path
      (let ((expanded-path (expand-file-name source)))
        (when (file-exists-p expanded-path)
          (with-temp-buffer
            (insert-file-contents expanded-path)
            (goto-char (point-min))
            (setq env-alist (code-agent-org--parse-env-lines))))))
    env-alist))

(defun code-agent-org--parse-env-lines ()
  "Parse env lines from current buffer position to end.
Returns alist of (KEY . VALUE). Internal helper for `code-agent-org--parse-env'."
  (let ((env-alist '()))
    (while (not (eobp))
      (let ((line (string-trim (buffer-substring-no-properties
                                (line-beginning-position)
                                (line-end-position)))))
        ;; Skip empty lines and comments
        (unless (or (string-empty-p line)
                    (string-prefix-p "#" line))
          ;; Remove optional "export " prefix
          (when (string-match "^\\s-*export[ \t]+" line)
            (setq line (substring line (match-end 0))))
          ;; Parse KEY=VALUE (value may contain =)
          (when (string-match "^\\([A-Za-z_][A-Za-z0-9_]*\\)=\\(.*\\)$" line)
            (let* ((key (match-string 1 line))
                   (value (match-string 2 line))
                   ;; Remove surrounding quotes if present
                   (unquoted-value (if (and (>= (length value) 2)
                                            (or (and (string-prefix-p "\"" value)
                                                     (string-suffix-p "\"" value))
                                                (and (string-prefix-p "'" value)
                                                     (string-suffix-p "'" value))))
                                       (substring value 1 -1)
                                     value)))
              (push (cons key unquoted-value) env-alist)))))
      (forward-line 1))
    (nreverse env-alist)))

(defun code-agent-org--get-env-file-path ()
  "Get ENV_FILE path from org properties.
Returns nil if not set. Supports tilde expansion."
  (when-let* ((env-file (code-agent-org--get-org-property "ENV_FILE" t))) ; no-expand=t
    (expand-file-name env-file)))

(defun code-agent-org--load-env-file ()
  "Load environment variables from ENV_FILE property.
Returns alist of (VAR . VALUE), or nil if no ENV_FILE is set."
  (when-let* ((env-file-path (code-agent-org--get-env-file-path)))
    (if (file-exists-p env-file-path)
        (code-agent-org--parse-env env-file-path)
      (message "Warning: ENV_FILE not found: %s" env-file-path)
      nil)))

#+BEGIN_SRC elisp
(defun code-agent-org--expand-env-vars (value env-alist)
  "Expand ${VAR} references in VALUE using ENV-ALIST.
ENV-ALIST is an alist of (VAR-NAME . VAR-VALUE).
Also expands environment variables from process-environment.

Examples:
  \"${HOME}/projects\"     -> \"/Users/user/projects\"
  \"token=${API_TOKEN}\"   -> \"token=sk-abc123\"
  \"${VAR:-default}\"      -> Uses default if VAR not set (bash syntax)"
  (when value
    (let ((result value))
      ;; Replace ${VAR} with values from env-alist or process-environment
      (while (string-match "\\${\\([A-Za-z_][A-Za-z0-9_]*\\)\\(:-\\([^}]*\\)\\)?}" result)
        (let* ((var-name (match-string 1 result))
               (default-value (match-string 3 result))
               ;; Look up in env-alist first, then process-environment
               (var-value (or (cdr (assoc var-name env-alist))
                              (getenv var-name)
                              default-value
                              "")))
          (setq result (replace-match var-value t t result))))
      result)))

(defun code-agent-org--collect-system-prompts ()
  "Collect content from all org sections tagged :system_prompt:.
Returns concatenated string of heading + body for each section, or nil if none.

Usage in org file:
  * Project Guidelines :system_prompt:
  This project uses Python 3.11 with Django.
  Always use absolute imports."
  (save-excursion
    (save-restriction
      (widen)
      (goto-char (point-min))
      (let ((prompts '())
            (heading-re "^\\(\\*+\\) +\\(.*\\):system_prompt:"))
        ;; Use regex search instead of org-map-entries to avoid cache issues
        (while (re-search-forward heading-re nil t)
          (let* ((stars (match-string 1))
                 (heading-text (match-string 2))
                 (heading (string-trim (replace-regexp-in-string ":.*$" "" heading-text)))
                 (beg (save-excursion
                        (forward-line 1)
                        ;; Skip property drawers and planning lines
                        (while (and (not (eobp))
                                    (looking-at "^[ \t]*\\(:\\|DEADLINE:\\|SCHEDULED:\\|CLOSED:\\)"))
                          (forward-line 1))
                        (point)))
                 (end (save-excursion
                        (beginning-of-line)
                        (org-end-of-subtree t t)
                        (point)))
                 (body (when (< beg end)
                         (string-trim (buffer-substring-no-properties beg end)))))
            (when (and heading (not (string-empty-p heading)))
              (push (concat "* " heading
                            (when (and body (not (string-empty-p body)))
                              (concat "\n" body)))
                    prompts))))
        (when prompts
          (mapconcat #'identity (nreverse prompts) "\n\n"))))))

* Process Management

Multi-session process management allowing concurrent queries.

** Session State Cross-Reference

The per-query session struct, registry, and accessors live in
=code-agent-org-session.org= (composed =cl-defstruct=​s with a routing
table over four sub-structs).  They're loaded in the Dependencies

** Persistent Client Registry

Long-running Claude clients keyed by session-key.  Unlike
=code-agent-org--sessions= (buffer-local, per-query state), this registry
owns live processes that survive across multiple queries.  Earlier
versions kept state in a bare hash table plus seven free functions —
the classic "wrap the hash in a class" smell that
=.claude/rules/oop-smalltalk-protocols.md= calls out.  The registry
is now an explicit coordinator: one =code-agent-org-persistent-registry=
struct, one singleton, generics for every verb callers need.

*** The Entry Class

One session's persistent-client state.  =cl-defstruct= with typed
slots replaces the previous untyped =:client= / =:buffer= / =:heading-pos=
plists so accessors are discoverable and refactors are compiler-checked.

#+BEGIN_SRC elisp
(cl-defstruct (code-agent-org-persistent-entry
               (:constructor code-agent-org-persistent-entry--create)
               (:copier nil))
  "One persistent-client entry held by `code-agent-org-persistent-registry'."
  (client nil
          :documentation "`claude-agent-client' struct — the live process handle.")
  (buffer nil

*** Disconnection

Two verbs: one-session and all-for-buffer.  The single-session path
emits a user-facing message; the buffer-sweep path delegates to the
single-session path so the message format stays consistent.

#+BEGIN_SRC elisp
(cl-defgeneric code-agent-org-persistent-registry-disconnect
    (registry session-key &optional reason)
  "Disconnect and remove the entry for SESSION-KEY from REGISTRY.
REASON (optional string) is shown in the user-facing message.")

(cl-defmethod code-agent-org-persistent-registry-disconnect
    ((registry code-agent-org-persistent-registry) session-key &optional reason)
  "Default implementation: tear down the client then remove the entry."
  (when-let* ((entry (code-agent-org-persistent-registry-get-entry
                      registry session-key)))
    (when-let* ((client (code-agent-org-persistent-entry-client entry)))
      (when (claude-agent-client-alive-p client)
        (claude-agent-client-disconnect client)))
    (remhash session-key
             (code-agent-org-persistent-registry-entries registry))
    (message "Claude: Disconnected session %s%s"
             (code-agent-org--session-display-name session-key)
             (if reason (format " (%s)" reason) ""))))

(cl-defgeneric code-agent-org-persistent-registry-disconnect-buffer
    (registry buffer)
  "Disconnect every entry whose `buffer' slot matches BUFFER.")

(cl-defmethod code-agent-org-persistent-registry-disconnect-buffer
    ((registry code-agent-org-persistent-registry) buffer)
  "Default implementation: collect keys first, then dispatch one-by-one."
  (let ((to-remove nil))
    (maphash (lambda (key entry)
               (when (eq (code-agent-org-persistent-entry-buffer entry) buffer)
                 (push key to-remove)))
             (code-agent-org-persistent-registry-entries registry))
    (dolist (key to-remove)
      (code-agent-org-persistent-registry-disconnect registry key "buffer killed"))))

*** Backend Registry Dispatch

The backend registry maps CLAUDE_BACKEND property strings to
constructor lambdas.  It's wired to the persistent registry only
indirectly — ACP constructors use =code-agent-org--acp-session-persistence=
to set up session-id auto-save on the returned backend.

#+BEGIN_SRC elisp
(defun code-agent-org--acp-session-persistence ()
  "Read the stored ACP_SESSION_ID and return a (INITIAL-ID . SAVE-FN) pair.
SAVE-FN writes the new session id back to the org entry at point.
Captures the current marker so the save is bound to the block's heading
even if point moves later.  `lexical-let' is required because literate-elisp
does not honour the file header's lexical-binding directive — without it,
`marker' would be looked up dynamically at callback time and trigger a
void-variable error."
  (let ((initial (code-agent-org--get-org-property "ACP_SESSION_ID" t)))
    (lexical-let ((marker (point-marker)))
      (cons initial
            (lambda (session-id)
              (when (and session-id (marker-buffer marker))
                (condition-case err
                    (with-current-buffer (marker-buffer marker)
                      (save-excursion
                        (goto-char marker)
                        (org-entry-put nil "ACP_SESSION_ID" session-id)
                        (save-buffer)))
                  (error
                   (message "code-agent-org: failed to persist ACP_SESSION_ID: %s"
                            (error-message-string err))))))))))

** Query-ID System

Query-IDs provide reliable, marker-free response tracking. Each query gets a
unique ID stored as an org property, enabling:
- Race-free callback validation (old queries ignored)
- Persistent response location (survives buffer kill/Emacs restart)
- Clear audit trail (every response traceable to its query)

*** Query-ID Generation (see code-agent-org-response.org)

*** Response Section Creation

#+BEGIN_SRC elisp
(defun code-agent-org--create-response-section (session-key query-id query-type
                                            &optional parent-query-id recovery-reason
                                            loop-info)
  "Create a response section for SESSION-KEY with QUERY-ID.
QUERY-TYPE is 'normal or 'recovery.
For recovery queries, PARENT-QUERY-ID and RECOVERY-REASON should be provided.
LOOP-INFO is (ITERATION . MAX) for loop iterations, or nil.

Returns the position where content should be inserted (after properties)."
  (claude-agent-with-span "create-response-section"
      (list :query-id query-id :query-type (symbol-name query-type)) nil
  (let* ((section-level (code-agent-org--effective-section-level session-key))
         ;; Response should be at SAME level as instruction (sibling), not child
         ;; section-level is the instruction heading level, so use it directly
         (response-level section-level)
         (stars (make-string response-level ?*))
         ;; Get instruction number from session or find by :claude_chat: tag
         ;; Note: code-agent-org--find-instruction-number returns nil if no :claude_chat: heading found
         (instr-num (or (code-agent-org--session-get session-key :instruction-num)
                        (code-agent-org--find-instruction-number)))
         (timestamp (format-time-string "%Y-%m-%d %H:%M"))
         ;; Build loop suffix for iteration numbering
         (loop-suffix (if loop-info
                          (format "(%d/%d)" (car loop-info) (cdr loop-info))
                        ""))
         ;; For recovery, use N.M numbering; for normal, just the number
         ;; If no instruction number found, omit the number from heading
         (response-num (cond
                        ((null instr-num)
                         ;; No instruction found - use timestamp-based identifier
                         (format-time-string "%H%M%S"))
                        ((eq query-type 'recovery)
                         (let ((recovery-count (or (code-agent-org--session-get session-key :recovery-count) 0)))
                           (code-agent-org--session-put session-key :recovery-count (1+ recovery-count))
                           (format "%s.%d" instr-num (1+ recovery-count))))
                        (t
                         (number-to-string instr-num))))
         (tags (if (eq query-type 'recovery)
                   ":ai_output:recovery:"
                 ":ai_output:"))
         (heading (format "%s Response %s%s (%s) %s" stars response-num loop-suffix timestamp tags)))
    (save-excursion
      ;; Insert heading
      (insert heading "\n")
      ;; Insert properties
      (insert ":PROPERTIES:\n")
      (insert (format ":QUERY_ID: %s\n" query-id))
      (insert (format ":QUERY_TYPE: %s\n" (symbol-name query-type)))
      (when (and (eq query-type 'recovery) parent-query-id)
        (insert (format ":PARENT_QUERY_ID: %s\n" parent-query-id)))
      (when (and (eq query-type 'recovery) recovery-reason)
        (insert (format ":RECOVERY_REASON: %s\n" recovery-reason)))
      (insert ":END:\n\n")
      ;; Reset content flag so first-token newline stripping works
      (code-agent-org--session-put session-key :response-has-content nil)
      ;; Return current position (where content will be inserted)
      (point)))))

*** Marker-Free Token Insertion

#+BEGIN_SRC elisp
(defun code-agent-org--insert-at-response (session-key text)
  "Insert TEXT at end of response section for SESSION-KEY.
Uses query-id property lookup instead of marker.
Returns t if insertion succeeded, nil otherwise.
Uses `save-restriction'/`widen' so it works even when buffer is narrowed (F20)."
  (let ((query-id (code-agent-org--session-get session-key :query-id)))
    (when query-id
      (save-excursion
        (save-restriction
          (widen)
          (let ((heading-pos (code-agent-org--find-response-by-query-id query-id)))
            (when heading-pos
              (goto-char heading-pos)
            ;; Capture response section level for level-aware stop pattern
            (let* ((response-level (org-current-level))
                   ;; Only stop at headings at SAME or SHALLOWER level than
                   ;; the response section; deeper headings are content within it
                   (stop-pattern (format "^\\*\\{1,%d\\} " response-level)))
              (if (re-search-forward "^:END:" nil t)
                  (progn
                    ;; Skip past :END: to the blank line after it
                    (forward-line 1)
                    ;; Skip ONE blank line if present (the standard separator)
                    (when (looking-at "^$")
                      (forward-line 1))
                    ;; If we're now at a same-or-shallower heading, insert BEFORE it
                    (if (looking-at stop-pattern)
                        (progn
                          (forward-line -1)
                          (end-of-line)
                          (insert text)
                          t)
                      ;; Otherwise, find the end of content in this section
                      (let ((insert-pos (line-end-position)))
                        ;; Search forward for same-or-shallower heading or end of buffer
                        (while (and (not (eobp))
                                    (not (looking-at stop-pattern)))
                          (setq insert-pos (line-end-position))
                          (forward-line 1))
                        ;; insert-pos now points to end of last content line
                        (goto-char insert-pos)
                        (insert text)
                        t)))
                ;; No :END: found, fall back to end of heading line
                (end-of-line)
                (insert "\n" text)
                t)))))))))

(defun code-agent-org--handle-token-v2 (session-key text)
  "Handle incoming TEXT token for SESSION-KEY using query-id lookup.
Normalizes org headers, auto-breaks long lines, and inserts at response section.
This is the marker-free version using query-id."
  (let ((query-id (code-agent-org--session-get session-key :query-id)))
    (if (not query-id)
        ;; B1/F18: Warn instead of silently dropping tokens
        (message "Claude: token dropped for %s — nil query-id (recovery race?)" session-key)
      (let* ((target-level (1+ (code-agent-org--effective-section-level session-key)))
             (normalized-text (code-agent-org--normalize-headers-in-text text target-level))
             ;; Auto-break long lines
             (current-line-len (or (code-agent-org--session-get session-key :current-line-length) 0))
             (break-result (code-agent-org--auto-break-lines normalized-text current-line-len))
             (final-text (car break-result))
             (new-line-len (cdr break-result)))
        ;; Update line length state
        (code-agent-org--session-put session-key :current-line-length new-line-len)
        ;; Strip leading newlines from the very first token of a new response.
        ;; Claude's model often starts assistant text with "\n\n" which creates
        ;; unwanted blank lines after the :END: property drawer.
        (unless (code-agent-org--session-get session-key :response-has-content)
          (when (> (length final-text) 0)
            (setq final-text (string-trim-left final-text "\n+"))
            (when (> (length final-text) 0)
              (code-agent-org--session-put session-key :response-has-content t))))
        ;; Prepend newline separator between consecutive assistant messages.
        ;; :last-assistant-query-id stores the query-id of the most recent
        ;; assistant message's on-message callback.  When we see the SAME
        ;; query-id here it means a previous assistant message already
        ;; produced output in this query, so we insert a blank-line separator.
        ;; Cross-query stale values are harmless: different query-ids won't match.
        (let ((last-asst-qid (code-agent-org--session-get session-key :last-assistant-query-id)))
          (when (and (> (length final-text) 0)
                     last-asst-qid
                     (equal last-asst-qid query-id))
            ;; Clear so we only insert one separator per assistant message boundary
            (code-agent-org--session-put session-key :last-assistant-query-id nil)
            (setq final-text (concat "\n\n" final-text))))
        ;; Insert processed text using query-id lookup
        (when (> (length final-text) 0)
          (code-agent-org--insert-at-response session-key final-text))
        ;; Schedule fontification
        (code-agent-org--schedule-fontlock)))))

** Marker Lifecycle Management

Robust marker validation to prevent crashes when markers become invalid
during async operations. Markers can become invalid when their buffer is
killed or when they haven't been set to a position.

#+BEGIN_SRC elisp
(defun code-agent-org--marker-valid-p (marker)
  "Check if MARKER is still valid for use.
Returns non-nil if MARKER is:
- An actual marker object (not nil or other type)
- Associated with a buffer (not just created with `make-marker')
- Its buffer is still live (not killed)
- Has a valid position (not nil)

This should be called before any operation that uses a marker,
especially in async contexts where the buffer may have been killed."
  (and marker
       (markerp marker)
       (marker-buffer marker)
       (buffer-live-p (marker-buffer marker))
       (marker-position marker)))

(defmacro code-agent-org--with-session-marker (marker &rest body)
  "Execute BODY in the buffer of MARKER if it is valid, else return nil.
Switches to the marker's buffer using `with-current-buffer', so BODY
runs with the marker's buffer current.  If MARKER is nil, not a marker,
or its buffer has been killed, BODY is silently skipped and nil is returned."
  (declare (indent 1) (debug t))
  (let ((m (make-symbol "marker")))
    `(let ((,m ,marker))
       (when (code-agent-org--marker-valid-p ,m)
         (with-current-buffer (marker-buffer ,m)
           ,@body)))))

* Behavior Prompts

Workspace-related context detection functions.

** The Living Workspace Model

Mental model that shaped the workspace / story / =ACTIVE_STORY= machinery
in this section: the org file is a *Lisp image*. A workspace is a
persistent process that outlives any individual story; stories are
incremental modifications under the workspace heading; =C-c C-c= is the
REPL =eval=, always available. You don't restart Claude Code between
stories — you switch =ACTIVE_STORY= and the same session keeps going.

#+begin_example
,* claude-agent-dev                        ← workspace heading
:PROPERTIES:
:CMUX_WORKSPACE: claude-agent-dev          ← user-set: human-readable name
:CLAUDE_SESSION_ID: sdd-20260326-dev       ← session identity
:CLAUDE_CLI_SESSION: abc-def-123           ← auto-set: for --resume
:CMUX_SURFACE_ID: surface:5                ← auto: cached surface ref
:ACTIVE_STORY: Fix parser bug              ← auto: persists after completion
:END:

,** Fix parser bug                         ← story (lightweight, no properties)
,*** System Prompt                         ← optional, sent on story switch
,*** Workflow                              ← all prompts + responses go here
,#+begin_src ai
…
,#+end_src

,** Add new API endpoint                   ← another story, same workspace
#+end_example

| Property | Who Sets | Purpose |
|----------+----------+---------|
| =CMUX_WORKSPACE= | User | Human-readable workspace name; binds to the cmux pane |
| =CLAUDE_SESSION_ID= | User or auto | Session identity for routing and inheritance |
| =CLAUDE_CLI_SESSION= | Auto | Claude Code SDK UUID for =--resume= |
| =CMUX_SURFACE_ID= | Auto | Cached surface ID, avoids re-detection |
| =ACTIVE_STORY= | Auto | Current story heading, *persists after completion* |

Stories themselves have *zero required properties* — everything
inherits from the workspace heading.

*** Two Channels, Same Session

Both routes through the same workspace's Claude Code:

| Channel | Trigger | Routing |
|---------+---------+---------|
| A — ai block | =C-c C-c= inside an =ai= block | Auto-selects nearest ancestor =CMUX_WORKSPACE=; per-session =:marker= identifies insert point |
| B — direct cmux input | User types in the cmux terminal directly | =workspace-bridge= reads =ACTIVE_STORY= via MCP, navigates to that story's =Workflow= subsection, inserts at end |

If =ACTIVE_STORY= is nil, Channel B has no org routing — terminal-only
interaction.

*** =ACTIVE_STORY= Lifecycle

The property *persists* across the busy → ready transition. It only
changes on:

- A =C-c C-c= execution from a /different/ story under the same
  workspace → auto-switch (fires =active-story-changed-hook=).
- =org-archive-subtree= on the active story → cleared.
- Manual user clear.

Concurrency is handled by the busy-state machine: =C-c C-c= on a
*different* story while the workspace is busy raises a wait/queue/
interrupt prompt rather than silently switching mid-flight.

*** Per-Story System Prompt

When =ACTIVE_STORY= changes, =active-story-changed-hook= runs. The
default handlers (1) inject the new story's =System Prompt= subsection
into the workspace's Claude Code as the next message, and (2) rename
the cmux pane to =workspace: story=. The injection happens *once* on
story switch — not on every ai block — so per-story context loads at
the natural seam without repeating it on each prompt.

  "Collect story headings under workspace at WORKSPACE-POS.
Stories are direct children (level = workspace-level + 1).
Returns list of (NAME POS) ordered by position."
  (save-excursion
    (save-restriction
      (widen)
      (goto-char workspace-pos)
      (let* ((ws-level (org-current-level))
             (story-level (1+ ws-level))
             (ws-end (save-excursion (org-end-of-subtree t t) (point)))
             result)
        (while (and (outline-next-heading)
                    (< (point) ws-end))
          (when (= (org-current-level) story-level)
            (push (list (org-get-heading t t t t) (point)) result)))
        (nreverse result)))))

      (goto-char subtree-pos)

        (while (re-search-forward "^[ \t]*#\\+begin_src[ \t]+ai\\b" subtree-end t)
          (setq last-pos (1+ (line-end-position))))

(defun code-agent-org--goto-story-make-key (index)
  "Generate a single-key binding for INDEX (0-based). Uses 1-9 then a-z, skips q."
  (if (< index 9)
      (char-to-string (+ ?1 index))
    (let ((c (+ ?a (- index 9))))
      (when (>= c ?q) (setq c (1+ c)))  ; skip q (used for quit)
      (char-to-string c))))

(defun code-agent-org--goto-story-make-action (fn pos)
  "Create a transient action that calls FN with POS."
  (lexical-let ((f fn) (p pos))
    (lambda () (interactive) (funcall f p))))

(defun code-agent-org--goto-story-build-items (entries jump-fn)
  "Build transient suffix specs from ENTRIES.
ENTRIES is a list of (NAME POS ...).  JUMP-FN is the function to call with POS."
  (apply #'vector
         (cl-loop for (name pos) in entries
                  for i from 0
                  collect (list (code-agent-org--goto-story-make-key i)
                                (code-agent-org--goto-story-make-action jump-fn pos)
                                :description (truncate-string-to-width
                                              (substring-no-properties name) 50)))))

(defun code-agent-org-goto-story ()

Auto-skips workspace/story selection when only one candidate exists.
Shows single-key transient menu when multiple candidates."
  (interactive)
  (let ((workspaces (code-agent-org--collect-workspaces)))

     ((null workspaces)

     ;; Multiple → show workspace picker

       workspaces
       #'code-agent-org--goto-story-select)))))

     ((null stories)
      (message "No stories found in workspace"))
     ;; One story → jump directly
     ((= 1 (length stories))
      (code-agent-org--goto-story-jump (cadr (car stories))))
     ;; Multiple → show story picker
     (t
      (code-agent-org--goto-story-show-menu
       "Select Story"
       stories
       #'code-agent-org--goto-story-jump)))))

       :setup-children
       (lambda (_)
         (mapcar (lambda (item)
                   (transient-parse-suffix
                    (oref transient--prefix command)

Merges heading tags with CLAUDE_TAGS property, deduplicating.
Heading tags take priority (appear first in list)."
  (let* ((heading-tags (code-agent-org--get-heading-tags))

(defun code-agent-org--get-block-header-args ()
  "Get header arguments from current ai block.
Returns plist of header arguments, e.g. (:phase \"code\" :tests t)."
  (save-excursion
    (let ((case-fold-search t))
      (when (re-search-backward "^[ \t]*#\\+begin_src[ \t]+ai\\b" nil t)
        (let ((line (buffer-substring-no-properties (point) (line-end-position))))
          (when (string-match "#\\+begin_src[ \t]+ai\\b[ \t]*\\(.*\\)" line)
            (let ((args-str (match-string 1 line))
                  (result nil))
              (when (and args-str (not (string-empty-p args-str)))
                ;; Parse header args: :key value :key2 value2
                (with-temp-buffer
                  (insert args-str)
                  (goto-char (point-min))
                  (while (re-search-forward ":\\([a-zA-Z_-]+\\)\\(?:[ \t]+\\([^ \t\n:]+\\)\\)?" nil t)
                    (let ((key (intern (concat ":" (match-string 1))))
                          (val (match-string 2)))
                      ;; Build plist: push value first, then key (reversed later)
                      (push key result)
                      (push (or val t) result)))))
              ;; Result is (val2 key2 val1 key1), reverse to get (key1 val1 key2 val2)
              (nreverse result))))))))

* Block Detection

Block detection answers the fundamental question: "Where am I in the document?"
These functions determine the execution context for AI blocks by examining:

1. *Section hierarchy* - What level heading contains the cursor?
2. *Block boundaries* - Is point inside a =#+begin_src ai= block?
3. *Output sections* - Is this an AI response area (tagged with =:ai_output:=)?
4. *Instruction numbering* - Which instruction number does this belong to?

The detection logic supports both complete blocks (with =#+end_src=) and incomplete
blocks (still being edited), allowing execution during composition.

** AI Block Boundary Detection

These functions detect whether point is inside an AI block and extract its boundaries.
The key insight: an incomplete block (no =#+end_src= yet) is valid for execution,
enabling users to run queries while still composing them.

#+NAME: block-detect-boundaries
#+BEGIN_SRC elisp
(defun code-agent-org--in-ai-block-p ()
  "Return t if point is inside a #+begin_src ai block."
  (save-excursion
    (let ((case-fold-search t)
          (pos (point)))
      (when (re-search-backward "^[ \t]*#\\+begin_src[ \t]+ai\\b" nil t)
        (let ((block-start (point)))
          ;; If we find end_src, check we're between begin and end
          ;; If no end_src found, assume we're still inside the block (incomplete block)
          (if (re-search-forward "^[ \t]*#\\+end_src" nil t)
              (and (>= pos block-start)
                   (<= pos (point)))
            ;; No end found, we're in an incomplete block - that's OK
            (>= pos block-start)))))))

(defun code-agent-org--get-block-content ()
  "Get content of the ai block at point."
  (save-excursion
    (let ((case-fold-search t))
      (when (re-search-backward "^[ \t]*#\\+begin_src[ \t]+ai\\b" nil t)
        (forward-line 1)
        (let ((start (point)))
          (when (re-search-forward "^[ \t]*#\\+end_src" nil t)
            (forward-line 0)
            (string-trim (buffer-substring-no-properties start (point)))))))))

(defun code-agent-org--find-block-end ()
  "Find position at end of #+end_src line."
  (save-excursion
    (let ((case-fold-search t))
      (when (re-search-forward "^[ \t]*#\\+end_src" nil t)
        (line-end-position)))))

** Output Section and Instruction Detection

Output sections (tagged =:ai_output:=) contain Claude's responses.
Instruction detection finds which numbered instruction contains the cursor,
used for maintaining conversation context and navigation.

*** Design Note: Instruction Identification

*IMPORTANT*: Instruction sections are identified by the =:claude_chat:= tag,
NOT by heading text patterns like "Instruction N".

Users may rename instruction headings to descriptive titles like
"Fix Authentication Bug" or "Implement User Dashboard". The system must
work correctly regardless of heading text.

| Identifier | Used For | Example |
|--------------+-------------------------------+-----------------------------------|
| =:claude_chat:= | Finding instruction heading | =** My Task :claude_chat:= |
| =:ai_output:= | Finding response sections | =** Response 1 :ai_output:= |

All functions that need to find instruction sections MUST use
=code-agent-org--find-instruction-heading= which searches by tag.

#+NAME: block-detect-output-instruction
#+BEGIN_SRC elisp
(defun code-agent-org--in-output-section-p ()
  "Check if cursor is inside an :ai_output: tagged section.
Returns non-nil if current heading or any parent heading has the output tag."
  (save-excursion
    (let ((tags (org-get-tags nil t)))
      (member code-agent-org-output-tag tags))))

(defun code-agent-org--find-instruction-heading ()
  "Find the instruction heading for point.
Instruction headings are identified by the :claude_chat: tag.

Search order:
1. Current heading (if it has :claude_chat: tag)
2. Parent headings (walk up the hierarchy, checking each for tag)
3. At each level, also check previous siblings for the tag

Returns the position of the instruction heading, or nil if not found.

NOTE: This function identifies instructions by TAG, not by heading text.
Headings like \"Fix Bug :claude_chat:\" and \"Instruction 1 :claude_chat:\"
are both valid instruction headings."
  (save-excursion
    (when (ignore-errors (org-back-to-heading t))
      (let ((found nil)
            (done nil))
        ;; Search current heading and all ancestors
        (while (and (not found) (not done))
          ;; Check current heading
          (when (member code-agent-org-heading-tag (org-get-tags nil t))
            (setq found (point)))
          ;; If not found, check previous siblings at this level
          (unless found
            (let ((current-level (org-current-level))
                  (search-pos (point)))
              (save-excursion
                (while (and (not found)
                            (org-get-previous-sibling))
                  (when (and (= (org-current-level) current-level)
                             (member code-agent-org-heading-tag (org-get-tags nil t)))
                    (setq found (point)))))
              ;; If still not found, go up one level
              (unless found
                (goto-char search-pos)
                (unless (org-up-heading-safe)
                  ;; Can't go up further, exit loop
                  (setq done t))))))
        found))))

(defun code-agent-org--find-instruction-number ()
  "Find the next response number for the current instruction section.
Uses `code-agent-org--find-instruction-heading' to locate the instruction
by its :claude_chat: tag, then counts existing Response N siblings.

Returns the next available response number (max existing + 1).
Returns nil if no instruction heading is found (caller must handle this)."
  (save-excursion
    (let ((instr-pos (code-agent-org--find-instruction-heading)))
      (when instr-pos
        (goto-char instr-pos)
        (let ((instruction-level (org-current-level))
              (max-response-num 0))
          ;; Search forward for Response N siblings at same level
          (save-excursion
            (while (org-get-next-sibling)
              (when (and (= (org-current-level) instruction-level)
                         (looking-at "^\\*+ Response \\([0-9]+\\)"))
                (let ((num (string-to-number (match-string 1))))
                  (when (> num max-response-num)
                    (setq max-response-num num))))))
          ;; Return next number (max + 1), or 1 if no responses found
          (1+ max-response-num))))))

(defun code-agent-org--skip-to-after-output-section ()
  "Skip to after the current :ai_output: section.
Moves point to after the output section's subtree, ready to insert sibling."
  (when (code-agent-org--in-output-section-p)
    (org-back-to-heading t)
    ;; Move to the end of this subtree
    (org-end-of-subtree t t)))

(defun code-agent-org--heading-matches-auto-title-pattern-p ()
  "Check if current heading matches the auto-title pattern.
Returns the heading text (without stars and tags) if it matches, nil otherwise."
  (save-excursion
    (when (ignore-errors (org-back-to-heading t))
      (let ((heading (org-get-heading t t t t)))  ; no tags, no todo, no priority, no comment
        (when (and heading
                   (string-match-p code-agent-org-auto-title-heading-pattern heading))
          heading)))))

(defun code-agent-org--replace-heading-at-marker (marker new-title)
  "Replace heading text at MARKER with NEW-TITLE.
Preserves heading level (stars), tags, and properties.
Frees MARKER after use to prevent leak (F23)."
  (when (and marker (markerp marker) (marker-buffer marker) (buffer-live-p (marker-buffer marker)))
    (with-current-buffer (marker-buffer marker)
      (save-excursion
        (goto-char marker)
        (when (ignore-errors (org-back-to-heading t))
          (let* ((tags (org-get-tags nil t))
                 (level (org-current-level))
                 (stars (make-string level ?*))
                 ;; Build tag string manually
                 (tag-str (if tags
                              (concat " :" (mapconcat #'identity tags ":") ":")
                            "")))
            ;; Delete the current heading line (including newline)
            (beginning-of-line)
            (let ((line-start (point)))
              (forward-line 1)
              (delete-region line-start (point)))
            ;; Insert new heading with title and tags on same line
            (insert stars " " new-title tag-str "\n"))))))
    ;; Free marker after use to prevent leak (F23)
    (when (markerp marker)
      (set-marker marker nil)))

(defun code-agent-org--clean-title (title max-chars)
  "Clean up a generated TITLE string, truncating to MAX-CHARS.
Strips surrounding quotes and truncates with ellipsis if needed.
Returns cleaned title or nil if empty."
  (let ((cleaned (string-trim title)))
    (when (and (>= (length cleaned) 2)
               (string-match-p "^[\"'].*[\"']$" cleaned))
      (setq cleaned (substring cleaned 1 -1)))
    (when (string-match "^\\(?:Title:\\s-*\\|Here's\\s-*\\(?:a\\|the\\)\\s-*title:\\s-*\\)" cleaned)
      (setq cleaned (substring cleaned (match-end 0))))
    (when (> (length cleaned) max-chars)
      (setq cleaned (concat (substring cleaned 0 (- max-chars 3)) "...")))
    (unless (string-empty-p cleaned)
      cleaned)))

*** Copilot Title Generator Class

The copilot backend reuses one ~copilot-chat~ instance across every
title request — spinning up a fresh instance per call would be
wasteful and would scatter state across call frames.  Previously the
instance was held in a bare ~defvar~ with three free
setq/memq/copilot-chat--create lines inline in the request
function.  Promoting to an explicit singleton class makes the lifecycle
obvious and mirrors the rest of the codebase.

#+BEGIN_SRC elisp
(cl-defstruct (code-agent-org-copilot-title-generator
               (:constructor code-agent-org-copilot-title-generator--create)
               (:copier nil))
  "Reusable copilot-chat instance used to generate headings for new queries."
  (instance nil
            :documentation "copilot-chat instance, created on first use."))

(defvar code-agent-org--title-generator
  (code-agent-org-copilot-title-generator--create)
  "Module-wide singleton copilot title generator.
One per Emacs — creating a fresh copilot-chat instance per query
has no benefit and wastes the underlying HTTP session.")

(cl-defgeneric code-agent-org-copilot-title-generator-ensure-instance
    (generator)
  "Return GENERATOR's copilot-chat instance, creating one if needed.
Also re-creates when the stored instance has been evicted from
`copilot-chat--instances' (e.g. by the user clearing chat state).")

(cl-defmethod code-agent-org-copilot-title-generator-ensure-instance
    ((generator code-agent-org-copilot-title-generator))
  "Default implementation: lazy-init + staleness check."
  (let ((current (code-agent-org-copilot-title-generator-instance generator)))
    (unless (and current (memq current copilot-chat--instances))
      (setf (code-agent-org-copilot-title-generator-instance generator)
            (copilot-chat--create default-directory))))
  (code-agent-org-copilot-title-generator-instance generator))

(cl-defgeneric code-agent-org-copilot-title-generator-generate
    (generator query on-title on-error)
  "Ask GENERATOR's copilot instance to summarise QUERY as a short title.
ON-TITLE is invoked with the cleaned title string when generation
completes; ON-ERROR is invoked with an explanation string on any
failure (missing copilot-chat, streaming error, empty response).")

(cl-defmethod code-agent-org-copilot-title-generator-generate
    ((generator code-agent-org-copilot-title-generator) query on-title on-error)
  "Default implementation: stream tokens through copilot-chat--ask."
  (condition-case err
      (progn
        (require 'copilot-chat)
        (require 'copilot-chat-copilot)
        (require 'copilot-chat-common)
        (let ((instance (code-agent-org-copilot-title-generator-ensure-instance
                         generator)))
          (lexical-let ((accumulated "")
                        (on-title-cb on-title)
                        (on-error-cb on-error)
                        (max-chars claude-agent-title-max-chars)
                        (fired nil))
            (copilot-chat--ask
             instance
             (format "Generate a short title (5-8 words, max %d chars) for this text. Output ONLY the title, no quotes, no explanation:\n\n%s"
                     max-chars
                     (truncate-string-to-width query 500))
             (lambda (_inst content)
               (condition-case err
                   (if (string= content copilot-chat--magic)
                       (unless fired
                         (setq fired t)
                         (let ((title (code-agent-org--clean-title
                                       accumulated max-chars)))
                           (if title
                               (funcall on-title-cb title)
                             (funcall on-error-cb
                                      "Copilot returned empty title"))))
                     (setq accumulated (concat accumulated content)))
                 (error (funcall on-error-cb (error-message-string err)))))
             t))))  ; out-of-context = t
    (error
     (funcall on-error (error-message-string err)))))

* Block Insertion

Block insertion creates new AI query blocks with proper structure and numbering.
The insertion logic is "smart" - it understands the document's flat pattern where
Instruction N and Response N are siblings, not parent-child.

** Instruction Numbering

Each instruction gets a unique sequential number. This function scans all existing
instruction headings and returns the next available number, ensuring no duplicates.

#+NAME: block-insert-numbering
#+BEGIN_SRC elisp
(defun code-agent-org--next-instruction-number ()
  "Find the next available instruction number within current session scope.
Counts headings with :claude_chat: tag within the session scope.
Does not depend on heading titles (which may be renamed by users)."
  (save-excursion
    (let ((count 0)
          (session-pos (code-agent-org--find-session-scope-heading)))
      ;; Try to find session scope and count chat headings within it
      (when session-pos
        (goto-char session-pos)
        (let ((scope-end (save-excursion (org-end-of-subtree t) (point))))
          ;; Only search forward if scope-end is after current position
          (when (> scope-end session-pos)
            ;; Count all headings with claude_chat tag in this scope
            (while (re-search-forward "^\\*+ " scope-end t)
              (when (member code-agent-org-heading-tag (org-get-tags nil t))
                (setq count (1+ count)))))))
      ;; Return next number (at least 1)
      (max 1 (1+ count)))))
#+END_SRC

** Standard Block Insertion

The primary insertion command. Key behaviors:
- Skips past output sections to maintain the flat Instruction/Response pattern
- Matches heading level of existing instructions (or uses current level)
- Auto-generates the next instruction number
- Tags the heading with =code-agent-org-heading-tag=
*** Core Block Insertion

**** Finding Previous Chat / Workspace Level

To insert a new AI block at the correct level, we have to find an enclosing
*chat* heading (any with =:claude_chat:= tag) or *workspace* heading (any
with a =CLAUDE_SESSION_ID= property starting with =sdd-=). The two scans
share a shape: =save-excursion + widen=, scan backward through headings,
test a predicate at each candidate, return its level. The workspace case
also falls back to a forward scan from =point-min= so the very first
workspace in a buffer is reachable when point precedes it.

=code-agent-org--find-heading-level-matching= captures that shared shape;
each named finder becomes a thin wrapper that supplies its predicate.
Removed a third sibling (=--find-previous-story-level=) that had no
callers anywhere in the repo — pure scaffolding.

#+NAME: block-find-heading-level
#+BEGIN_SRC elisp
(defun code-agent-org--find-heading-level-matching (predicate &optional bidirectional)
  "Return the org level of the nearest backward heading where PREDICATE holds.
PREDICATE is called at each heading line and must return non-nil to match.
If BIDIRECTIONAL is non-nil and the backward scan finds nothing, also scan
forward from `point-min' up to the original point. Returns an integer
level or nil."
  (save-excursion
    (save-restriction
      (widen)
      (let ((start-pos (point))
            (found-level nil))
        (while (and (not found-level)
                    (re-search-backward "^\\*+ " nil t))
          (when (funcall predicate)
            (setq found-level (org-current-level))))
        (when (and bidirectional (not found-level))
          (goto-char (point-min))
          (while (and (not found-level)
                      (re-search-forward "^\\*+ " start-pos t))
            (when (funcall predicate)
              (setq found-level (org-current-level)))))
        found-level))))

(defun code-agent-org--find-previous-chat-level ()
  "Find the level of the nearest :claude_chat:-tagged heading before point.
Returns the level (integer) or nil if not found."
  (let ((tag-pattern (format ":%s:" code-agent-org-heading-tag)))
    (code-agent-org--find-heading-level-matching
     (lambda ()
       (string-match-p tag-pattern
                       (buffer-substring-no-properties
                        (point) (line-end-position)))))))

**** Inserting the Block

#+NAME: block-insert-standard
#+BEGIN_SRC elisp
(defun code-agent-org--do-insert-block (_workflow-tags)
  "Insert an AI block at point.
_WORKFLOW-TAGS is ignored (kept for call-site compatibility).
Automatically generates a CUSTOM_ID for stable navigation."
  ;; If inside an output section, skip to after it
  (code-agent-org--skip-to-after-output-section)
  ;; Find the level by looking for the last chat section (heading with :claude_chat: tag)
  (let* ((level (or (code-agent-org--find-previous-chat-level)
                    (org-current-level)
                    1))
         (stars (make-string level ?*))
         (num (code-agent-org--next-instruction-number))
         (tag-string code-agent-org-heading-tag)
         (tag-str (concat ":" tag-string ":"))
         ;; Generate CUSTOM_ID for stable navigation
         (file-base (when buffer-file-name (file-name-base buffer-file-name)))
         ;; Wrap session-id lookup to handle edge cases in batch testing
         (session-id (ignore-errors (code-agent-org--get-session-id)))
         (custom-id (code-agent-org--generate-instruction-custom-id file-base num session-id)))
    (insert stars " Instruction " (number-to-string num) " " tag-str "\n")
    ;; Add PROPERTIES drawer with CUSTOM_ID
    (when custom-id
      (insert ":PROPERTIES:\n")
      (insert ":CUSTOM_ID: " custom-id "\n")
      (insert ":END:\n"))
    (insert "\n#+begin_src ai\n\n#+end_src\n")
    (forward-line -2)))

(defun code-agent-org--generate-instruction-custom-id (file-base num session-id)
  "Generate a unique CUSTOM_ID for an instruction block.
FILE-BASE is the org file name without extension.
NUM is the instruction number.
SESSION-ID is the parent section's CLAUDE_SESSION_ID (can be nil).

Returns a string like \"file-instruction-N-session-id-HHMMSS\" with timestamp.
If that ID already exists in the buffer, appends -2, -3, etc. until unique."
  (let ((timestamp (format-time-string "%H%M%S")))
    (when file-base
      (let* ((base-id (if session-id
                          (format "%s-instruction-%d-%s-%s" file-base num session-id timestamp)
                        (format "%s-instruction-%d-%s" file-base num timestamp)))
             (candidate base-id)
             (counter 2))
        ;; Check if ID exists and add -N suffix until unique
        (while (code-agent-org--custom-id-exists-p candidate)
          (setq candidate (format "%s-%d" base-id counter))
          (setq counter (1+ counter)))
        candidate))))

(defun code-agent-org-insert-block ()
  "Insert a new AI block at point."
  (interactive)
  (code-agent-org--do-insert-block nil))

** Session and Story Blocks

These create blocks with isolated conversation context. Session blocks use the
=:claude_session:= tag for section-scoped isolation. Story blocks use
=CLAUDE_SESSION_ID= property for named, persistent sessions.

| Command | Keybinding | Level Behavior |
|---------+------------+----------------|
| =code-agent-org-insert-session-block= | | Uses current section level |
| =code-agent-org-insert-story= | =C-c C-s= | Aligns with previous story, or top level if none |

Story level alignment: When inserting a new story, the function searches backwards
for an existing story section (heading with =CLAUDE_SESSION_ID= starting with "story-").
If found, the new story uses the same level. If no previous story exists, it defaults
to top level (=*=), keeping stories at a consistent hierarchy.

#+NAME: block-insert-session-story
#+BEGIN_SRC elisp
(defun code-agent-org-insert-session-block ()
  "Insert an AI query block with independent section-scoped session.
The :claude_session: tag creates a new conversation context for this subtree."
  (interactive)
  (let* ((level (or (org-current-level) 1))
         (stars (make-string level ?*))
         (num (code-agent-org--next-instruction-number)))
    (insert stars " Session " (number-to-string num) " :" code-agent-org-session-tag ":\n\n")
    (insert "#+begin_src ai\n\n#+end_src")
    (forward-line -1)))

(defun code-agent-org-insert-story ()
  "Insert a new story under the current workspace.
Prompts for story title and creates a sub-heading with Workflow and
an empty ai block. The story inherits CLAUDE_SESSION_ID from the
workspace heading — no per-story session ID needed.
Sets ACTIVE_STORY on the workspace heading."
  (interactive)
  (let ((ws (code-agent-org--find-workspace-heading)))
    (unless ws
      (user-error "Not inside a workspace. Create one first with code-agent-org-insert-workspace"))
    (let* ((title (read-string "Story title: "))
           (ws-level (save-excursion
                       (goto-char (cdr ws))
                       (org-current-level)))
           (story-level (1+ ws-level))
           (wf-level (1+ story-level))
           (instr-level (1+ wf-level))
           (stars-story (make-string story-level ?*))
           (stars-wf (make-string wf-level ?*))
           (stars-instr (make-string instr-level ?*))
           (file-base (when buffer-file-name (file-name-base buffer-file-name)))
           (session-id (save-excursion
                         (goto-char (cdr ws))
                         (or (org-entry-get nil "CLAUDE_SESSION_ID") "new"))))
      ;; Go to end of workspace subtree to insert new story
      (save-excursion
        (goto-char (cdr ws))
        (org-end-of-subtree t t)
        (insert "\n" stars-story " " title "\n")
        (insert stars-wf " Workflow :sdd:\n")
        (insert ":PROPERTIES:\n")
        (insert ":CUSTOM_ID: " (code-agent-org--generate-custom-id session-id "Workflow" file-base) "\n")
        (insert ":END:\n\n")
        (insert stars-instr " Instruction 1 :" code-agent-org-heading-tag ":\n")
        (insert ":PROPERTIES:\n")
        (insert ":CUSTOM_ID: " (code-agent-org--generate-instruction-custom-id file-base 1 session-id) "\n")
        (insert ":END:\n\n")
        (insert "#+begin_src ai\n\n#+end_src\n"))
      ;; Set ACTIVE_STORY
      (code-agent-org--set-active-story title)
      ;; Jump to the new ai block
      (goto-char (cdr ws))
      (org-end-of-subtree t t)
      (re-search-backward "^#\\+begin_src ai" nil t)
      (forward-line 1)
      (message "Created story '%s' under workspace '%s'" title (car ws)))))

(defun code-agent-org--find-previous-workspace-level ()
  "Find the level of the nearest workspace heading (CLAUDE_SESSION_ID starts
with \"sdd-\"). Falls back to a forward scan from buffer start so a
workspace placed after point is still reachable. Returns the level
(integer) or nil if not found."
  (code-agent-org--find-heading-level-matching
   (lambda ()
     (string-prefix-p "sdd-" (or (org-entry-get nil "CLAUDE_SESSION_ID") "")))
   t))

(defun code-agent-org-insert-workspace ()
  "Insert a workspace with one default story.
Structure:
  * Workspace Name          (workspace heading with CMUX_WORKSPACE)
  ** First Story            (story sub-heading, name = workspace name)
  *** System Prompt         (story-specific AI guidance)
  *** Workflow :sdd:        (contains AI blocks and responses)
  **** Instruction 1        (empty AI block, cursor positioned here)

    (insert ":ACTIVE_STORY: First Story\n")

      (insert ":CLAUDE_BACKEND: " code-agent-org-workspace-default-backend "\n"))
    (insert ":END:\n\n")

    (insert stars2 " First Story\n")

    (insert stars3 " System Prompt :system_prompt:\n")
    (insert ":PROPERTIES:\n")
    (insert ":CUSTOM_ID: " (code-agent-org--generate-custom-id session-id "System Prompt" file-base) "\n")
    (insert ":END:\n\n")
    (insert (format "The current workspace story is \"%s\"\n\n" name))

    ;; 4. Workflow under story
    (insert stars3 " Workflow :sdd:\n")
    (insert ":PROPERTIES:\n")
    (insert ":CUSTOM_ID: " (code-agent-org--generate-custom-id session-id "Workflow" file-base) "\n")

    (re-search-backward "^#\\+begin_src ai")
    (forward-line 1)
    (message "Created workspace '%s' with session ID: %s" name session-id)))

(defun code-agent-org-workspace-archive-workflow ()
  "Archive the current Workflow via `org-archive-subtree' and create a fresh one.
Uses the buffer's #+ARCHIVE: property to determine the archive location.
Inserts a new Workflow at the same position and level with an empty AI block.

Archive folds the previous transcript into the archive file but is NOT a
session reset: the workspace's CLAUDE_CLI_SESSION (and Copilot's) are
preserved so the next \"Open terminal\" still resumes the same agent
conversation. To start a brand-new chat instead, clear the property
manually with `org-delete-property' before launching the terminal."
  (interactive)
  (save-excursion
    (org-back-to-heading t)
    ;; Walk up to find the workspace top-level heading with CLAUDE_SESSION_ID
    (let ((workspace-pos nil)
          (session-id nil))
      (save-excursion
        (while (and (not session-id) (org-up-heading-safe))
          (setq session-id (org-entry-get nil "CLAUDE_SESSION_ID"))
          (when session-id (setq workspace-pos (point)))))
      (unless session-id
        (setq session-id (org-entry-get nil "CLAUDE_SESSION_ID"))
        (when session-id (setq workspace-pos (point))))
      (unless session-id
        (user-error "Not inside a workspace section (no CLAUDE_SESSION_ID found)"))
      ;; Find the active Workflow heading under this workspace
      (goto-char workspace-pos)
      (let* ((workspace-end (save-excursion (org-end-of-subtree t t) (point)))
             (workflow-pos nil))
        (save-excursion
          (while (and (not workflow-pos)
                      (re-search-forward "^\\*+ +Workflow\\b.*:sdd:" workspace-end t))
            (unless (member "ARCHIVE" (org-get-tags nil t))
              (setq workflow-pos (line-beginning-position)))))
        (unless workflow-pos
          (user-error "No active Workflow section found under this workspace"))
        (goto-char workflow-pos)
        (let* ((wf-level (org-current-level))
               (stars (make-string wf-level ?*))
               (stars-instr (make-string (1+ wf-level) ?*))
               (file-base (when buffer-file-name (file-name-base buffer-file-name))))
          ;; Archive the workflow subtree using org's native archive
          (org-archive-subtree)
          ;; Point is now where the workflow was — insert new one
          (insert stars " Workflow :sdd:\n")
          (insert ":PROPERTIES:\n")
          (insert ":CUSTOM_ID: " (code-agent-org--generate-custom-id session-id "Workflow" file-base) "\n")
          (insert ":END:\n\n")
          (insert stars-instr " Instruction 1 :" code-agent-org-heading-tag ":\n")
          (insert ":PROPERTIES:\n")
          (let ((instr-id (code-agent-org--generate-instruction-custom-id file-base 1 session-id)))
            (when instr-id
              (insert ":CUSTOM_ID: " instr-id "\n")))
          (insert ":END:\n\n")
          (insert "#+begin_src ai\n\n#+end_src\n")
          ;; CLAUDE_CLI_SESSION (and Copilot's) are intentionally NOT
          ;; cleared — archiving the transcript should not break
          ;; resume on the next "Open terminal".
          (save-buffer)
          ;; Position cursor inside the new AI block
          (re-search-backward "^#\\+begin_src ai")
          (forward-line 1)
          (message "Archived workflow to archive file, created fresh Workflow section"))))))

** Prompt Refinement

Refine the current AI block prompt using Claude's assistance.

#+NAME: block-refine-prompt
#+BEGIN_SRC elisp
(defun code-agent-org-refine-prompt ()
  "Refine the AI prompt in the current block.
Prompts for refinement intent, then calls Claude to improve the prompt.
Result directly replaces block content. Use \\[undo] to revert."
  (interactive)
  (unless (code-agent-org--in-ai-block-p)
    (user-error "Not inside an AI block"))
  (let* ((content (code-agent-org--get-block-content))
         intent)
    (unless content
      (user-error "Could not extract block content (missing #+end_src?)"))
    ;; Empty content is allowed - user can describe what they want to write
    (setq intent (read-string "How to refine the prompt? "))
    (when (string-empty-p intent)
      (user-error "Refinement intent cannot be empty"))
    (message "Refining prompt...")
    ;; Use lexical-let to capture buffer/marker for async callback
    ;; (literate-elisp uses dynamic binding; plain let variables go void)
    (lexical-let ((source-buffer (current-buffer))
                  (source-marker (point-marker)))
      (claude-agent-refine-prompt
       content intent
       :on-result (lambda (refined)
                    (if (buffer-live-p source-buffer)
                        (with-current-buffer source-buffer
                          (save-excursion
                            (goto-char source-marker)
                            (if (code-agent-org--replace-block-content refined)
                                (message "Prompt refined. Use C-/ to undo if needed.")
                              (message "Failed to replace block content"))))
                      (message "Source buffer no longer exists")))
       :on-error (lambda (err) (message "Refinement failed: %s" err))))))

* Template Insertion (yasnippet)

AI block templates are yasnippet snippets in =snippets/org-mode/=.
Supports static text, tab stops (=$1=, =${1:default}=), mirrors,
embedded elisp (=`(elisp)`=), and =$0= exit points.

The previous template system was a hand-rolled alist
(=claude-org-templates.el=) that read =(NAME . VALUE)= pairs from disk on
every invocation. 9 of 10 templates were static strings; the 10th was a
function reference that returned a whole string. Migrating to yasnippet
deleted the loader code (~75 lines) and bought four capabilities the
alist could not express: user-editable fields (=$1=, =${1:default}=, =$0=),
auto-mirroring (the same =$1= repeated produces synchronized fields),
inline elisp evaluation anywhere in the body via =`(form)`=, and TAB
navigation between fields. yasnippet became a hard requirement of the
package — not an optional integration — because every existing template
relies on it. Backward compatibility with the old alist file was an
explicit non-goal; the migration was a one-shot replacement.

** Snippet File Conventions

Each snippet file in =snippets/org-mode/= uses standard yasnippet syntax
plus four conventions this package relies on:

| Header | Purpose |
|--------+---------|
| =# name:= | Human label shown in =completing-read= and =yas-insert-snippet= menus |
| =# key:= | Two- or three-letter trigger for =KEY + TAB= expansion inside an AI block |
| =# group: Claude AI= | All bundled snippets use this group; =insert-template= filters by it so user snippets in other groups are not mixed in |
| =# condition:= | =(code-agent-org--in-ai-block-p)= for AI-block-only snippets, or =(get-buffer "*Backtrace*")= for ones that need a specific buffer present |
| =# expand-env: ((yas-indent-line 'fixed))= | Stops yasnippet from re-indenting the body — org-mode auto-indent disagrees with template literal whitespace |

A typical snippet — =ai-fix-error= — has two free-text fields and an exit
point:

#+begin_example
,# -*- mode: snippet -*-
,# name: Fix Error
,# key: fe
,# group: Claude AI
,# condition: (code-agent-org--in-ai-block-p)
,# expand-env: ((yas-indent-line 'fixed))
,# --
Please help fix this error:

Error:
${1:paste error here}

Context:
${2:describe what you were doing}

$0
#+end_example

A snippet with a *mirror field* — =ai-merge-worktree= — types the branch
name once and replays it everywhere the same =$1= appears:

#+begin_example
Please merge the worktree branch into master:
1. Exit the worktree if still inside
2. git checkout master
3. git merge --squash ${1:branch-name}
4. Run make check
5. If tests pass, commit with a descriptive message
6. Clean up: git worktree remove .claude/worktrees/$1 && git branch -d $1
$0
#+end_example

A snippet with *embedded elisp* — =ai-analyze-backtrace= — runs Lisp at
expansion time to inject context the user shouldn't have to paste:

#+begin_example
Please analyze this Emacs backtrace:

\`\`\`
,`(code-agent-org-template--backtrace-text)`
\`\`\`

Provide:
1. Root cause
2. Which function failed and why
3. Suggested fix
4. How to prevent it
$0
#+end_example

The companion helper (=code-agent-org-template--backtrace-text=, defined
below) reads the =*Backtrace*= buffer.

** Template Insertion Command

There are two ways to invoke a template, both producing the same result —
the choice is discoverability vs speed:

| Method | How | Best for |
|--------+-----+----------|
| Menu | =C-c C-/ t= → =completing-read= → select → expand | discovering what's available; works regardless of context |
| Keyboard | inside an AI block, type the snippet =# key:= (e.g. =fe=) + =TAB= | fast for the templates a user uses daily |

The keyboard method only triggers when the snippet's =# condition:= is
true (almost always =(code-agent-org--in-ai-block-p)=), so two-letter
keys like =fe= or =mw= don't fire on ordinary prose typing.

A few yasnippet pitfalls in org-mode are worth knowing about; the
snippet conventions above already mitigate them, but understanding them
helps when authoring new snippets:

| Issue | What goes wrong | Mitigation already applied |
|-------+-----------------+----------------------------|
| Indent mangling | yasnippet re-indents the body to match surrounding code, breaking literal whitespace inside =ai= blocks | =# expand-env: ((yas-indent-line 'fixed))= in every snippet |
| =TAB= conflict with =org-cycle= | TAB normally folds the heading instead of advancing fields | =yas-maybe-expand= conditional binding handles this — yasnippet wins inside an active expansion, =org-cycle= wins otherwise |
| Literal =$= in body | yasnippet treats =$N= as a field marker | Escape as =\$= |
| Literal backtick | Backticks delimit embedded elisp | Escape as =\`= |
| =yas-minor-mode= must be on | Otherwise =yas-expand-snippet= silently does nothing | =insert-template= flips it on if needed; users with =yas-global-mode= already pay no attention |

#+BEGIN_SRC elisp
;;;###autoload
(defun code-agent-org-insert-template ()
  "Select and expand a Claude AI template into the current AI block.
Uses yasnippet for interactive field navigation and TAB completion.
If not inside an AI block, creates one first."
  (interactive)
  (unless (code-agent-org--in-ai-block-p)
    (code-agent-org--do-insert-block nil)
    (forward-line -1)
    (end-of-line))
  (unless (bound-and-true-p yas-minor-mode)
    (yas-minor-mode 1))
  ;; Ensure extra snippet dirs are loaded (handles late setq timing)
  (code-agent-org--ensure-extra-snippet-dirs)
  ;; Get all Claude AI snippets from the org-mode table
  (let* ((table (yas--table-get-create 'org-mode))
         (all-templates '())
         (_ (maphash (lambda (_k v)
                       (maphash (lambda (_k2 tmpl) (push tmpl all-templates)) v))
                     (yas--table-hash table)))
         (ai-templates (cl-remove-if-not
                        (lambda (tmpl)
                          (let ((g (yas--template-group tmpl)))
                            (or (equal "Claude AI" g)
                                (equal '("Claude AI") g))))
                        all-templates))
         (names (mapcar #'yas--template-name ai-templates))
         (selected (completing-read "Template: " (sort names #'string<) nil t))
         (tmpl (cl-find selected ai-templates
                        :key #'yas--template-name :test #'equal)))
    (when tmpl
      (yas-expand-snippet (yas--template-content tmpl))
      (message "Inserted template: %s" selected))))

* Slash Command Completion

Auto-completion for Claude Code slash commands in AI blocks.

** Command Discovery

#+BEGIN_SRC elisp
(defun code-agent-org--scan-command-dir (dir)
  "Scan DIR for .md files and return list of slash commands.
Subdirectories create namespaced commands with : separator.
Example: dir/custom/test.md becomes /custom:test"
  (when (file-directory-p dir)
    (let ((commands nil))
      (dolist (file (directory-files-recursively dir "\\.md$"))
        (let* ((relative (file-relative-name file dir))
               (parts (split-string relative "/"))
               (name (file-name-sans-extension (car (last parts))))
               (namespace (butlast parts)))
          (push (if namespace
                    (concat "/" (mapconcat #'identity namespace ":") ":" name)
                  (concat "/" name))
                commands)))
      commands)))

(defun code-agent-org--scan-plugin-commands ()
  "Scan plugin commands from ~/.claude/plugins/marketplaces/*/plugins/*/commands/*.md.
Returns list of slash commands with plugin namespace.
Example: /plugin-name:command"
  (let ((commands nil)
        (plugins-dir (expand-file-name "~/.claude/plugins")))
    (when (file-directory-p plugins-dir)
      ;; Scan both direct plugins and marketplace plugins
      (dolist (search-pattern (list (expand-file-name "*/commands" plugins-dir)
                                     (expand-file-name "marketplaces/*/plugins/*/commands" plugins-dir)))
        (dolist (commands-dir (file-expand-wildcards search-pattern))
          (when (file-directory-p commands-dir)
            (let* ((plugin-dir (file-name-directory (directory-file-name commands-dir)))
                   (plugin-name (file-name-nondirectory (directory-file-name plugin-dir))))
              ;; Only scan root of commands/ (flat, no recursion)
              (dolist (file (directory-files commands-dir nil "\\.md$"))
                (let ((cmd-name (file-name-sans-extension file)))
                  (push (concat "/" plugin-name ":" cmd-name) commands))))))))
    commands))

(defun code-agent-org--discover-slash-commands ()
  "Discover all available slash commands from user, project, and plugins.
Returns list of command strings with / prefix."
  (let ((commands (copy-sequence code-agent-org-builtin-slash-commands))
        (user-dir (expand-file-name "~/.claude/commands"))
        (project-root (code-agent-org--get-project-root)))
    ;; Add user commands
    (setq commands (append commands (code-agent-org--scan-command-dir user-dir)))
    ;; Add project commands if PROJECT_ROOT is set
    (when project-root
      (let ((project-dir (expand-file-name ".claude/commands" project-root)))
        (setq commands (append commands (code-agent-org--scan-command-dir project-dir)))))
    ;; Add plugin commands
    (setq commands (append commands (code-agent-org--scan-plugin-commands)))
    ;; Remove duplicates (first match wins)
    (delete-dups commands)
    commands))

** Response Section Boundary Detection

Since Instruction and Response sections are siblings at the same level,
=org-end-of-subtree= doesn't include Response sections. We need custom
boundary detection to find where to insert new responses.

#+BEGIN_SRC elisp
(defun code-agent-org--find-response-boundary ()
  "Find the boundary for searching response sections.
Returns point of next non-:ai_output: sibling at same level,
or next heading at higher level (parent boundary), or point-max.

This is needed because Instruction and Response are SIBLINGS,
not parent-child, so `org-end-of-subtree' doesn't include responses."
  (save-excursion
    (let ((current-level (org-current-level)))
      (org-end-of-subtree t)  ; Move past current heading's content
      (let ((found nil))
        (while (and (not found)
                    (re-search-forward "^\\*+ " nil t))
          (let ((heading-level (1- (- (match-end 0) (match-beginning 0)))))
            (cond
             ;; Higher level (less stars) = parent boundary
             ((< heading-level current-level)
              (setq found (match-beginning 0)))
             ;; Same level = check if :ai_output: sibling
             ((= heading-level current-level)
              (save-excursion
                (goto-char (match-beginning 0))
                (unless (looking-at (format ".*:%s:" code-agent-org-output-tag))
                  ;; Not an output section = boundary
                  (setq found (match-beginning 0))))))))
        (or found (point-max))))))

(defun code-agent-org--find-last-ai-output-sibling ()
  "Find the last :ai_output: sibling section.
Returns point at END of that section, or nil if none found."
  (save-excursion
    (let* ((current-level (org-current-level))
           (block-end (code-agent-org--find-block-end))
           (boundary (code-agent-org--find-response-boundary))
           (last-output-end nil)
           (output-pattern (format "^\\*\\{%d\\} .*:%s:"
                                   current-level code-agent-org-output-tag)))
      (when block-end
        (goto-char block-end)
        (while (re-search-forward output-pattern boundary t)
          (setq last-output-end
                (save-excursion (org-end-of-subtree t) (point)))))
      last-output-end)))

(defun code-agent-org--find-response-insert-point ()
  "Find insertion point for new response section.
Returns point after last :ai_output: sibling, or after #+end_src."
  (or (code-agent-org--find-last-ai-output-sibling)
      (code-agent-org--find-block-end)))

(defun code-agent-org--create-response-section-header (instr-num timestamp &optional loop-info section-level)
  "Create response section header string.
INSTR-NUM is the instruction number (can be nil for non-Instruction headings).
TIMESTAMP is from LAST_AI_EXECUTED property (YYYY-MM-DD HH:MM:SS format).
LOOP-INFO is (CURRENT . MAX) for loop iterations, or nil.
SECTION-LEVEL is the heading level for the Response section.

Returns a string like: \"** Response 1 (2025-01-13 08:00) :ai_output:\""
  (let* ((level (code-agent-org--ensure-positive-level
                  (or section-level (code-agent-org--get-section-level))))
         (stars (make-string level ?*))
         ;; Trim seconds for cleaner display: "2025-01-13 08:00:15" -> "2025-01-13 08:00"
         (display-time (if (and timestamp (> (length timestamp) 16))
                           (substring timestamp 0 16)
                         (or timestamp (format-time-string "%Y-%m-%d %H:%M"))))
         (loop-suffix (if loop-info
                          (format "(%d/%d)" (car loop-info) (cdr loop-info))
                        ""))
         (instr-part (if instr-num
                         (format " %d" instr-num)
                       "")))
    (format "%s Response%s%s (%s) :%s:\n\n"
            stars instr-part loop-suffix display-time code-agent-org-output-tag)))

(defun code-agent-org--format-todo-item (todo)
  "Format a single TODO item as org checkbox.
TODO is a plist with :content, :status, and :activeForm.
When status is in_progress, show activeForm instead of content
since activeForm is the present continuous form of the same task."
  (let* ((content (plist-get todo :content))
         (status (plist-get todo :status))
         (active-form (plist-get todo :activeForm))
         (checkbox (cond
                    ((equal status "completed") "[X]")
                    ((equal status "in_progress") "[-]")
                    (t "[ ]")))
         ;; Use activeForm for in_progress, content otherwise
         (display-text (if (and (string= status "in_progress") active-form)
                           active-form
                         content)))
    (format "- %s %s" checkbox display-text)))

(defun code-agent-org--find-instruction-heading-for-session (session-key)
  "Find the instruction heading position for SESSION-KEY.
Uses the stored custom-id to locate the heading.
Returns marker position or nil if not found."
  (let ((custom-id (code-agent-org--session-get session-key :custom-id)))
    (when custom-id
      (save-excursion
        (goto-char (point-min))
        (when (re-search-forward
               (format ":CUSTOM_ID: %s" (regexp-quote custom-id)) nil t)
          (org-back-to-heading t)
          (point))))))

(defun code-agent-org--find-todo-region (heading-pos)
  "Find existing todo list region after HEADING-POS.
Looks for checkbox list between #+end_src and the next heading or marker.
Returns (BEG . END) of the region, or nil if no todos found."
  (save-excursion
    (goto-char heading-pos)
    ;; Find the #+end_src of the ai block
    (when (re-search-forward "^#\\+end_src" nil t)
      (forward-line 1)
      (let ((search-start (point))
            (search-end (save-excursion
                          ;; Find next heading or end of buffer
                          (if (re-search-forward "^\\*+ " nil t)
                              (line-beginning-position)
                            (point-max)))))
        ;; Look for checkbox list in this region
        (when (re-search-forward "^- \\[[ X-]\\]" search-end t)
          (goto-char (line-beginning-position))
          (let ((beg (point)))
            ;; Find end of checkbox list
            (while (and (< (point) search-end)
                        (looking-at "^- \\[[ X-]\\]"))
              (forward-line 1))
            ;; Include trailing blank line if present
            (when (and (< (point) search-end)
                       (looking-at "^$"))
              (forward-line 1))
            (cons beg (point))))))))

(defun code-agent-org--compute-todo-cookie (todos)
  "Compute statistics cookie string from TODOS list.
Returns string like \"[2/5]\" showing completed/total."
  (let ((total (length todos))
        (completed (cl-count-if
                    (lambda (todo)
                      (string= (plist-get todo :status) "completed"))
                    todos)))
    (format "[%d/%d]" completed total)))

(defun code-agent-org--update-heading-cookie (heading-pos cookie-str)
  "Update or add statistics cookie in heading at HEADING-POS.
COOKIE-STR is like \"[2/5]\". Replaces existing cookie or adds before tags."
  (save-excursion
    (goto-char heading-pos)
    (let ((line-end (line-end-position)))
      ;; Check if there's already a cookie [N/M] or [N%]
      (if (re-search-forward "\\[\\([0-9]+/[0-9]+\\|[0-9]+%\\)\\]" line-end t)
          ;; Replace existing cookie
          (replace-match cookie-str t t)
        ;; No cookie - add before tags or at end of heading text
        (goto-char heading-pos)
        ;; Skip past the stars and heading text to find insertion point
        (if (re-search-forward "[ \t]+\\(:[^ \t\n:]+:\\)+[ \t]*$" line-end t)
            ;; Has tags - insert before the space+tags
            (progn
              (goto-char (match-beginning 0))
              (insert " " cookie-str))
          ;; No tags - insert at end of line
          (end-of-line)
          (insert " " cookie-str))))))

(defun code-agent-org--update-todos-in-place (session-key todos)
  "Update todo list in place for SESSION-KEY with TODOS.
Finds the instruction heading via custom-id, updates the checkbox list
between #+end_src and Response section, and updates the heading cookie."
  (let ((heading-pos (code-agent-org--find-instruction-heading-for-session session-key)))
    (when heading-pos
      (save-excursion
        ;; Update heading cookie
        (code-agent-org--update-heading-cookie
         heading-pos
         (code-agent-org--compute-todo-cookie todos))
        ;; Format the new todo list (with trailing newline for spacing)
        (let ((new-todos-text (concat (mapconcat #'code-agent-org--format-todo-item todos "\n") "\n\n"))
              (existing-region (code-agent-org--find-todo-region heading-pos)))
          (if existing-region
              ;; Replace existing todo list
              (progn
                (delete-region (car existing-region) (cdr existing-region))
                (goto-char (car existing-region))
                (insert new-todos-text))
            ;; No existing todos - insert after #+end_src
            (goto-char heading-pos)
            (when (re-search-forward "^#\\+end_src" nil t)
              (forward-line 1)
              ;; Skip any blank lines
              (while (looking-at "^$")
                (forward-line 1))
              ;; Insert before current position (which might be Response heading)
              (insert "\n" new-todos-text))))))))

(defun code-agent-org--handle-tool-use (session-key tool-name tool-input)
  "Handle special TOOL-NAME with TOOL-INPUT for SESSION-KEY.
For TodoWrite: updates in-place under instruction heading, returns nil.
For other tools: returns formatted string to insert, or nil if not special."
  (cond
   ((equal tool-name "TodoWrite")
    (let ((todos (plist-get tool-input :todos)))
      ;; Update todos in-place under instruction heading (not at marker)
      (code-agent-org--update-todos-in-place session-key todos)
      ;; Return nil so nothing is inserted at streaming marker
      nil))
   (t nil)))

(defun code-agent-org--handle-message (session-key msg)
  "Handle incoming MSG for SESSION-KEY.
Extracts session ID from result messages and stores it."
  ;; Store SDK UUID to org property when we get a result message
  (when (claude-agent-result-message-p msg)
    (let ((sdk-uuid (claude-agent-result-message-session-id msg))
          (marker (code-agent-org--session-get session-key :marker)))
      (when (and sdk-uuid marker (marker-buffer marker))
        ;; Store in session state for extraction to use
        (code-agent-org--session-put session-key :sdk-uuid sdk-uuid)
        (with-current-buffer (marker-buffer marker)
          (save-excursion
            (goto-char marker)
            (code-agent-org--set-sdk-uuid sdk-uuid))))))
  ;; Handle special tool uses in assistant messages
  (when (claude-agent-assistant-message-p msg)
    ;; Store query-id that produced this assistant message.
    ;; In handle-token-v2, we insert a newline separator only when the
    ;; current query-id matches this stored id — meaning a previous
    ;; assistant message already produced output in this same query.
    ;; Using query-id instead of a boolean avoids stale-flag issues across
    ;; queries: a leftover value from query N cannot affect query N+1
    ;; because their query-ids differ.
    (code-agent-org--session-put session-key :last-assistant-query-id
                             (code-agent-org--session-get session-key :query-id))
    (let ((marker (code-agent-org--session-get session-key :marker)))
      (when (and marker (marker-buffer marker))
        (dolist (block (claude-agent-assistant-message-content msg))
          (when (claude-agent-tool-use-block-p block)
            (let* ((tool-name (claude-agent-tool-use-block-name block))
                   (tool-input (claude-agent-tool-use-block-input block))
                   (formatted (code-agent-org--handle-tool-use session-key tool-name tool-input)))
              ;; F3/F5: Record tool call for history and increment count
              (code-agent-org--record-tool-call session-key tool-name tool-input)
              (code-agent-org--session-put session-key :tool-call-count
                                       (1+ (or (code-agent-org--session-get session-key :tool-call-count) 0)))
              (when formatted
                (with-current-buffer (marker-buffer marker)
                  (save-excursion
                    (goto-char marker)
                    (insert formatted)
                    (set-marker marker (point)))))))))))
  ;; Display system messages if enabled
  (when (and code-agent-org-show-system-messages
             (claude-agent-system-message-p msg))
    (let ((marker (code-agent-org--session-get session-key :marker)))
      (when (and marker (marker-buffer marker))
        (with-current-buffer (marker-buffer marker)
          (save-excursion
            (goto-char marker)
            (insert (format "\n[System: %s]\n"
                            (claude-agent-system-message-subtype msg)))
            (set-marker marker (point))))))))

(defun code-agent-org--maybe-continue-loop (session-key)
  "Continue loop execution by starting the next iteration.
Called from handle-complete only when loop-current < loop-max (caller
already verified continuation is needed).  Increments the loop counter
and either schedules delayed execution or runs immediately."
  (let* ((loop-current (or (code-agent-org--session-get session-key :loop-current) 1))
         (loop-max (or (code-agent-org--session-get session-key :loop-max) 1))
         (loop-interval (or (code-agent-org--session-get session-key :loop-interval) 0))
         (original-prompt (code-agent-org--session-get session-key :original-prompt))
         (instr-num (code-agent-org--session-get session-key :instruction-num))
         (custom-id (code-agent-org--session-get session-key :custom-id))
         (next-iteration (1+ loop-current)))
    ;; Increment loop counter
    (code-agent-org--session-put session-key :loop-current next-iteration)
    ;; Schedule next iteration
    (if (> loop-interval 0)
        ;; Delayed execution — store timer for cancellation (F22)
        (let ((timer (run-at-time loop-interval nil
                       #'code-agent-org--execute-loop-iteration
                       session-key next-iteration loop-max original-prompt
                       instr-num custom-id loop-interval)))
          (code-agent-org--session-put session-key :loop-timer timer))
      ;; Immediate execution
      (code-agent-org--execute-loop-iteration
       session-key next-iteration loop-max original-prompt
       instr-num custom-id loop-interval))))

(defun code-agent-org--execute-loop-iteration (session-key iteration max prompt instr-num custom-id interval)
  "Execute a single loop iteration.
SESSION-KEY identifies the session.
ITERATION is current iteration number (1-based).
MAX is total iterations.
PROMPT is the original query.
INSTR-NUM and CUSTOM-ID are for session manager display.
INTERVAL is delay between iterations (for display).

Creates a proper response section with :QUERY_ID: property at the correct
position (after the previous iteration's response section, found via query-id
lookup).  This ensures tokens are routed to the new section, not the old one."
  (cl-block code-agent-org--execute-loop-iteration
  ;; Clear loop timer reference — timer has fired (F22)
  (code-agent-org--session-put session-key :loop-timer nil)
  ;; Guard: skip iteration if session was cancelled or errored
  (let ((exec-status (code-agent-org--get-exec-status-for-session session-key)))
    (when (member exec-status '("cancelled" "error"))
      (message "Claude loop: skipping iteration %d — session %s is %s"
               iteration session-key exec-status)
      (cl-return-from code-agent-org--execute-loop-iteration nil)))
  ;; Get buffer from session marker (needed when called via run-at-time)
  (let ((marker (code-agent-org--session-get session-key :marker)))
    (when (and marker (marker-buffer marker))
      (with-current-buffer (marker-buffer marker)
        ;; Set busy state
        (code-agent-org--session-put session-key :busy t)
        (code-agent-org--session-put session-key :start-time (float-time))
        ;; Run loop iteration hook (F3: empty by default, user opts in)
        (run-hook-with-args 'code-agent-org-loop-iteration-hook session-key iteration)
        ;; Start spinner
        (code-agent-org--start-spinner session-key)
        ;; Generate new query-id for this iteration (tokens route via query-id)
        (let* ((old-query-id (code-agent-org--session-get session-key :query-id))
               (new-query-id (code-agent-org--generate-query-id))
               ;; Find end of previous response section by old query-id
               (insert-pos (code-agent-org--find-response-end-by-query-id old-query-id)))
          ;; Store new query-id BEFORE creating section (callbacks read it)
          (code-agent-org--session-put session-key :query-id new-query-id)
          ;; Create response section at correct position (after previous response)
          ;; If insert-pos is nil (e.g. response section deleted), abort iteration
          (if (not insert-pos)
              (progn
                (message "Claude loop: cannot find previous response section, aborting iteration %d" iteration)
                (code-agent-org--cleanup-session session-key "error"))
            (save-excursion
              (goto-char insert-pos)
              (insert "\n\n")
              (code-agent-org--create-response-section
               session-key new-query-id 'normal
               nil nil (cons iteration max)))
            ;; Build query-context with updated iteration
            (let ((query-ctx (when instr-num
                               (claude-agent-make-query-context
                                :instruction-num instr-num
                                :loop-current iteration
                                :loop-max max
                                :custom-id custom-id))))
              ;; Send request (uses continue-conversation for context)
              (code-agent-org--send-request prompt query-ctx session-key)))))))))

(defun code-agent-org--free-marker (session-key)
  "Free marker for SESSION-KEY to prevent memory leak.
Markers hold references to buffers; must be explicitly freed."
  (when-let* ((marker (code-agent-org--session-get session-key :marker)))
    (when (markerp marker)
      (set-marker marker nil))
    (code-agent-org--session-put session-key :marker nil)))

(defun code-agent-org--unregister-active-query (session-key)
  "Dispatch a backend cancel for SESSION-KEY's in-flight query.

CALL THIS FROM CANCEL OR ERROR PATHS ONLY, never from a normal
\"completed\" path.  On agent-family backends this kills any
in-flight CLI subprocess so the mode-line spinner stops without
waiting for the process to exit.  On multiplexer-family backends
the override sends cancel keys (Escape / C-c) to the persistent
pane.

After a NORMAL Stop hook (status \"completed\") the prompt has
already been delivered and the response inserted; calling this on
that path on a multiplexer would ESC any follow-up sub-agent work
on the same surface (the bug fixed by gating in
`code-agent-org--cleanup-session').  For agent-family the call is a
no-op on completion because the SDK subprocess already exited."
  (when-let* ((backend (code-agent-org--session-get session-key :backend)))
    ;; Dispatch via Protocol 3 `cancel-from-org' — multiplexer backends
    ;; override to send cancel keys (Escape / C-c) to the pane; agent
    ;; backends delegate to `claude-agent-backend-cancel'.
    (ignore-errors (claude-org-backend-cancel-from-org backend session-key))))

(defun code-agent-org--cleanup-queued-blocks (session-key)
  "Clear pending queue for SESSION-KEY, reset exec-status on queued blocks, free markers.
Extracted from insert-error for reuse by cleanup-session."
  (let ((queue (code-agent-org--session-get session-key :pending-queue)))
    (when queue
      (dolist (block-info queue)
        (when-let* ((queued-marker (plist-get block-info :marker)))
          (when (and queued-marker (marker-buffer queued-marker))
            (with-current-buffer (marker-buffer queued-marker)
              (save-excursion
                (goto-char queued-marker)
                (code-agent-org--set-exec-status nil))))  ; Clear scheduled status
          ;; Free the queued marker to prevent leak
          (when (markerp queued-marker)
            (set-marker queued-marker nil))))
      (code-agent-org--clear-queue session-key))))

(defun code-agent-org--cleanup-session (session-key status &optional clear-queue-p)
  "Clean up SESSION-KEY to terminal state.  Centralized cleanup function.
STATUS is \"completed\", \"cancelled\", or \"error\".
CLEAR-QUEUE-P when non-nil clears the pending queue with status cleanup.

This is the SINGLE cleanup function that all termination paths should call.
Operations are performed in a fixed, canonical order."
  ;; 1. Stop spinner
  (code-agent-org--stop-spinner session-key)
  ;; 1.5 Cancel loop timer if pending (F22: prevents orphaned timers)
  (when-let* ((timer (code-agent-org--session-get session-key :loop-timer)))
    (when (timerp timer)
      (cancel-timer timer))
    (code-agent-org--session-put session-key :loop-timer nil))
  ;; 2. Set exec-status (preserve existing 'cancelled' — user intent)
  (unless (equal (code-agent-org--get-exec-status-for-session session-key) "cancelled")
    (code-agent-org--set-exec-status-for-session session-key status))
  ;; 3. Reset transient state (:busy, :recovering, :last-assistant-query-id)
  (code-agent-org--reset-session-state session-key)
  ;; 4. Free marker
  (code-agent-org--free-marker session-key)
  ;; 5. Clear queue with status cleanup on queued blocks
  (when clear-queue-p
    (code-agent-org--cleanup-queued-blocks session-key))
  ;; 6. Unregister from active queries (mode-line/queries buffer)
  ;;
  ;; --unregister-active-query dispatches `claude-org-backend-cancel-from-org'
  ;; which on multiplexer-family backends (cmux/tmux) sends a real ESC keypress
  ;; to the surface.  That's correct on cancel/error paths, but on a NORMAL
  ;; "completed" Stop hook the prompt has been delivered, response inserted,
  ;; and the surface is already idle (or running follow-up sub-agents on the
  ;; user's behalf).  Sending ESC there interrupts that follow-up work — the
  ;; reproduced bug: workspace_bridge.handle_response → workspace-insert-response
  ;; → cleanup-session → ESC → sub-agents cancelled, next response empty.
  ;; For agent-family backends the cancel is a no-op after a completed query
  ;; (the SDK subprocess already exited), so gating on status doesn't regress.
  (unless (equal status "completed")
    (code-agent-org--unregister-active-query session-key))
  ;; 7. Refresh header line
  (code-agent-org--refresh-header-line))

(defun code-agent-org--handle-complete (session-key result)
  "Handle query completion for SESSION-KEY with RESULT.
Uses query-id based architecture with marker for queue duplicate detection.

IMPORTANT: Loop continuation check must happen BEFORE freeing the marker,
because execute-loop-iteration needs the marker to find the buffer.
When the loop continues, :busy and :marker are kept alive for the next
iteration (including across run-at-time delays for :interval)."
  (let ((trace-ctx (code-agent-org--session-get session-key :trace-ctx)))
  (claude-agent-with-span "handle-complete"
      (list :custom-id (code-agent-org--session-get session-key :custom-id)
            :result (if result "error" "ok")
            :error-message (when (and result (plist-get (cdr result) :message))
                             (plist-get (cdr result) :message))
            :tool-call-count (code-agent-org--session-get session-key :tool-call-count)
            :duration-sec (when (code-agent-org--session-get session-key :start-time)
                            (format "%.1f" (- (float-time)
                                              (code-agent-org--session-get session-key :start-time))))
            :loop-current (code-agent-org--session-get session-key :loop-current)
            :loop-max (code-agent-org--session-get session-key :loop-max))
      trace-ctx
  (code-agent-org--stop-spinner session-key)
  ;; Add newline after response using query-id lookup (marker-free)
  (let ((query-id (code-agent-org--session-get session-key :query-id)))
    (when query-id
      (code-agent-org--insert-at-response session-key "\n")))
  ;; Update header line
  (code-agent-org--refresh-header-line)
  ;; Run completion hook (no marker to pass - we're marker-free)
  (run-hook-with-args 'code-agent-org-complete-hook session-key result 'completed)
  ;; Run user query-complete hook (F4: empty by default, user opts in)
  (let ((query-id (code-agent-org--session-get session-key :query-id)))
    (when query-id
      (run-hook-with-args 'code-agent-org-query-complete-hook session-key query-id)))
  ;; Persist telemetry (F5: duration, tool count)
  (condition-case nil
      (progn
        (code-agent-org--persist-duration session-key)
        (code-agent-org--persist-tool-count session-key))
    (error nil))
  ;; Check loop state BEFORE any cleanup - execute-loop-iteration needs :marker
  (let* ((loop-current (or (code-agent-org--session-get session-key :loop-current) 1))
         (loop-max (or (code-agent-org--session-get session-key :loop-max) 1))
         (should-continue (< loop-current loop-max)))
    (if should-continue
        ;; Loop has more iterations: keep :busy and :marker alive,
        ;; clear only transient flags, then trigger next iteration
        (progn
          (code-agent-org--session-put session-key :recovering nil)
          (code-agent-org--session-put session-key :last-assistant-query-id nil)
          (code-agent-org--maybe-continue-loop session-key))
      ;; Loop complete (or single-shot) - full cleanup
      (unless (equal (code-agent-org--get-exec-status-for-session session-key) "cancelled")
        (code-agent-org--set-exec-status-for-session session-key "completed"))
      (code-agent-org--reset-session-state session-key)
      (code-agent-org--free-marker session-key)
      ;; Process pending queue
      (let ((next-block (code-agent-org--dequeue-block session-key)))
        (if next-block
            (code-agent-org--execute-queued-block session-key next-block)
          ;; Truly done — no follow-up call to --unregister-active-query.
          ;; Mode-line + *Claude Queries* buffer already reflect terminal
          ;; state via --reset-session-state (step 3) + --refresh-header-line
          ;; (step 7) above.  --unregister-active-query only adds a backend
          ;; cancel-from-org dispatch, which on multiplexer-family backends
          ;; sends ESC to the persistent surface and cancels follow-up
          ;; sub-agent work; on agent-family backends it's a no-op since the
          ;; SDK subprocess already exited.  See the gating in --cleanup-session
          ;; for the same rationale on the cancel/error paths.
          )))))))

** Error Handling

#+BEGIN_SRC elisp
(defun code-agent-org--handle-error (session-key error)
  "Handle error ERROR for SESSION-KEY.
Attempts session recovery if error indicates expired session or context too long.
If already recovering and another error occurs, give up and show error to user."
  (let ((error-msg (claude-agent--extract-error-message error))
        (is-recovering (code-agent-org--session-get session-key :recovering))
        (backend (code-agent-org--session-get session-key :backend)))
    (cond
     ;; Already recovering and hit another error - give up to prevent infinite loop
     (is-recovering
      (message "Claude: Recovery failed with error: %s" error-msg)
      (code-agent-org--insert-error session-key
                                (format "Recovery failed: %s" error-msg)))
     ;; Use backend protocol for error classification (backend-agnostic)
     (t
      (pcase (if backend
                 (claude-agent-backend-classify-error backend error-msg)
               'unknown)
        ('context-limit
         (message "Claude context limit reached, starting fresh session with history...")
         (code-agent-org--recover-session session-key 'context-limit))
        ('session-expired
         (message "Claude session expired, starting new session...")
         (code-agent-org--recover-session session-key 'expired))
        (_
         (code-agent-org--insert-error session-key error-msg)))))))

(defun code-agent-org--insert-error (session-key error-msg)
  "Insert ERROR-MSG in response section and clean up via centralized cleanup.
Uses `insert-at-response' (query-id lookup) for correct placement in the
response section.  Falls back to inserting after #+end_src if no response
section exists yet (same pattern as cancel)."
  ;; Insert error text at the response section (F16: unified insertion)
  (let ((error-text (format "\n[Error: %s]\n" error-msg)))
    (or (code-agent-org--insert-at-response session-key error-text)
        ;; Fallback: if no response section, insert after #+end_src
        (let ((marker (code-agent-org--session-get session-key :marker)))
          (when (and marker (markerp marker) (marker-buffer marker))
            (with-current-buffer (marker-buffer marker)
              (save-excursion
                (goto-char marker)
                (when (re-search-forward "^#\\+end_src" nil t)
                  (end-of-line)
                  (insert error-text))))))))
  ;; Count queued blocks before cleanup clears them
  (let ((queue-count (length (or (code-agent-org--session-get session-key :pending-queue) nil))))
    ;; Centralized cleanup: stop-spinner, set exec-status, reset-state,
    ;; free-marker, clear-queue, unregister, refresh-header-line
    (code-agent-org--cleanup-session session-key "error" t)
    (when (> queue-count 0)
      (message "Cleared %d queued block(s) due to error" queue-count)))
  ;; Run completion hook with error status
  (run-hook-with-args 'code-agent-org-complete-hook session-key error-msg 'error))

* Execution

Execution and request handling.

** Execute Command

Every AI-block execution is a unit of work with the same seven
inputs: the session it belongs to, the prompt text, the heading
level used when creating the response section, the instruction's
CUSTOM_ID for navigation, the loop max/interval, and an optional
marker on the heading for async title generation.  Two code paths
deliver these inputs — ~code-agent-org-execute~ for a block at point,
~--execute-queued-block~ for a block that was deferred because the
session was busy — and both previously reassembled the same
arguments into the same shared function (~--execute-core~).

Promoting the input bundle to a ~cl-defstruct~ ensures the two
factories (from-point / from-block-info) produce the same shape,
makes the slot set discoverable, and gives the core method a
single typed parameter instead of seven positional/keyword args.

*** Run Method

The body that was ~--execute-core~ moves onto a ~cl-defgeneric~
dispatched on the command class.  It still does one coherent
thing: initialise the session, create the response section,
start the spinner, dispatch through the backend, fire the
after-hook — but now every read comes from a typed accessor
instead of a positional/keyword argument.

#+BEGIN_SRC elisp
(cl-defgeneric code-agent-org-execute-command-run (command)
  "Execute COMMAND: seed session state, build the response section,
kick off the spinner, dispatch through the backend, and run the
after-hook.  Returns nil.")

(cl-defmethod code-agent-org-execute-command-run
    ((cmd code-agent-org-execute-command))
  "Default implementation."
  (let ((session-key (code-agent-org-execute-command-session-key cmd))
        (content (code-agent-org-execute-command-content cmd))
        (section-level (code-agent-org-execute-command-section-level cmd))
        (custom-id (code-agent-org-execute-command-custom-id cmd))
        (loop-max (code-agent-org-execute-command-loop-max cmd))
        (loop-interval (code-agent-org-execute-command-loop-interval cmd)))
    (claude-agent-with-span "execute-core"
        (list :custom-id custom-id :loop-max loop-max
              :input (truncate-string-to-width (or content "") 2000)
              :session-id (ignore-errors (code-agent-org--get-session-id)))
      nil
      (code-agent-org--set-exec-status "executing")
      (let ((timestamp (format-time-string "%Y-%m-%d %H:%M:%S")))
        (save-excursion
          (org-back-to-heading t)
          (org-entry-put nil "LAST_AI_EXECUTED" timestamp))
        (let ((insert-point (code-agent-org--find-response-insert-point))
              (instr-num (code-agent-org--find-instruction-number)))
          (unless insert-point
            (user-error "Cannot find block end"))
          (let ((query-id (code-agent-org--generate-query-id))
                (block-marker (copy-marker (point))))
            (code-agent-org--session-put session-key :query-id query-id)
            (code-agent-org--session-put session-key :marker block-marker)
            (code-agent-org--session-put session-key :original-prompt content)
            (code-agent-org--session-put session-key :section-level section-level)
            (code-agent-org--session-put session-key :start-time (float-time))
            (code-agent-org--session-put session-key :busy t)
            (code-agent-org--session-put session-key :loop-max loop-max)
            (code-agent-org--session-put session-key :loop-current 1)
            (code-agent-org--session-put session-key :loop-interval loop-interval)
            (code-agent-org--session-put session-key :instruction-num instr-num)
            (code-agent-org--session-put session-key :custom-id custom-id)
            (code-agent-org--session-put session-key :recovery-count 0)
            (save-excursion
              (goto-char insert-point)
              (insert "\n\n")
              (when code-agent-org-auto-create-response-section
                (code-agent-org--create-response-section session-key query-id 'normal)))
            (code-agent-org--start-spinner session-key)
            (let ((query-ctx (when instr-num
                               (claude-agent-make-query-context
                                :instruction-num instr-num
                                :loop-current 1
                                :loop-max loop-max
                                :custom-id custom-id))))
              (code-agent-org--send-request content query-ctx session-key))
            (run-hook-with-args 'code-agent-org-execute-after-hook
                                session-key content nil)))))))

(defun code-agent-org-execute ()
  "Execute the AI query at point.
Must be called when point is inside a #+begin_src ai block.
Sends the query to Claude and streams the response below the block.

Supports loop execution via header arguments:
  :loop N     - Execute N iterations (default 1)
  :interval N - Wait N seconds between iterations (default 0)

When `code-agent-org-auto-create-response-section' is non-nil, creates a Response
section with :ai_output: tag for flat pattern organization.
When `code-agent-org-auto-generate-title' is non-nil, generates a title for
headings matching `code-agent-org-auto-title-heading-pattern' (see `code-agent-org-title-backend').

If the session is busy, queues the block for execution when current query completes."
  (interactive)
  (claude-agent-with-trace "execute-ai-block"
      (list :oi-kind "CHAIN"
            :session-id (ignore-errors (code-agent-org--get-session-id))
            :custom-id (ignore-errors (code-agent-org--find-instruction-custom-id))
            :backend (or (code-agent-org--get-org-property "CLAUDE_BACKEND" t) "claude-code"))
  (cl-block code-agent-org-execute
  (unless (code-agent-org--in-ai-block-p)
    (user-error "Not inside an ai block. Use #+begin_src ai ... #+end_src"))
  (let* ((content (code-agent-org--get-block-content))
         (session-key (code-agent-org--current-session-key))
         ;; Get header args for loop support
         (header-args (code-agent-org--get-block-header-args))
         (loop-max (or (plist-get header-args :loop) 1))
         (loop-interval (or (plist-get header-args :interval) 0))
         ;; Convert string values to numbers if needed
         (loop-max (if (stringp loop-max) (string-to-number loop-max) loop-max))
         (loop-interval (if (stringp loop-interval) (string-to-number loop-interval) loop-interval))
         ;; Get CUSTOM_ID for session manager navigation (before buffer changes)
         (custom-id (code-agent-org--find-instruction-custom-id))
         ;; Capture section level at AI block position BEFORE any buffer modifications
         ;; This ensures loop iterations use the correct level even if AI generates nested headings
         (section-level (code-agent-org--get-section-level))
         ;; Check for auto-title BEFORE any buffer modifications
         (should-auto-title (and code-agent-org-auto-generate-title
                                 (code-agent-org--heading-matches-auto-title-pattern-p)))
         ;; Create marker at heading position for title update
         (heading-marker (when should-auto-title
                           (save-excursion
                             (org-back-to-heading t)
                             (copy-marker (point))))))
    (unless content
      (user-error "Empty ai block"))
    ;; Record execution for all backends (history, jump-to-block)
    (run-hook-with-args 'code-agent-org-execute-hook session-key content nil)
    ;; Auto-generate title for all backends
    (when heading-marker
      (code-agent-org--maybe-auto-generate-title content heading-marker))
    ;; Initialize loop state for ALL backends (before backend-specific early returns)
    (code-agent-org--session-put session-key :loop-max loop-max)
    (code-agent-org--session-put session-key :loop-current 1)
    (code-agent-org--session-put session-key :loop-interval loop-interval)
    (code-agent-org--session-put session-key :original-prompt content)
    ;; Multiplexer-family backends (cmux, tmux) have a different execution
    ;; shape from agent-family backends: the response arrives asynchronously
    ;; via the Python workspace-bridge rather than through streaming
    ;; callbacks.  Dispatch through Protocol 3 `execute-block' on the backend
    ;; instance (Smalltalk style — dispatch on receiver class, no string
    ;; discriminators).  The backend's `execute-block' method handles the
    ;; full launch/send/register dance and returns; response delivery is
    ;; the bridge's job.
    (let* ((mux-options (list :cwd default-directory))
           (mux-backend (or (code-agent-org--session-get session-key :backend)
                            (code-agent-org--make-default-backend
                             session-key mux-options))))
      (when (cl-typep mux-backend 'claude-agent-multiplexer-backend)
        (code-agent-org--session-put session-key :backend mux-backend)
        ;; If multiplexer session is already busy, queue this block instead
        ;; of firing a second prompt in parallel.  Mux dispatch had been
        ;; placed BEFORE the queue check, so two C-c C-c invocations would
        ;; both go to cmux unconditionally — A6 caught this regression.
        (when (code-agent-org--session-get session-key :busy)
          (let* ((block-info (list :custom-id custom-id
                                   :content content
                                   :marker (copy-marker (point))
                                   :loop-max loop-max
                                   :loop-interval loop-interval
                                   :section-level section-level
                                   :should-auto-title should-auto-title
                                   :heading-marker heading-marker))
                 (result (code-agent-org--queue-block session-key block-info)))
            (pcase result
              ('queued
               (code-agent-org--set-exec-status "scheduled")
               (message "Scheduled [%d]. Will run after current query completes."
                        (code-agent-org--queue-count session-key)))
              ('running
               (message "This block is already running. Wait for it to complete."))
              ('in-queue
               (message "This block is already scheduled [%d in queue]."
                        (code-agent-org--queue-count session-key))))
            (cl-return-from code-agent-org-execute nil)))
        (claude-org-backend-execute-block
         mux-backend
         (list :prompt content
               :session-key session-key
               :custom-id custom-id
               :loop-max loop-max
               :loop-interval loop-interval
               :section-level section-level))
        (cl-return-from code-agent-org-execute nil)))
    ;; If session is busy, queue the block instead of erroring
    (when (code-agent-org--session-get session-key :busy)
      (let* ((block-info (list :custom-id custom-id
                               :content content
                               :marker (copy-marker (point))
                               :loop-max loop-max
                               :loop-interval loop-interval
                               :section-level section-level
                               :should-auto-title should-auto-title
                               :heading-marker heading-marker))
             (result (code-agent-org--queue-block session-key block-info)))
        (pcase result
          ('queued
           ;; Set status to scheduled
           (code-agent-org--set-exec-status "scheduled")
           (message "Scheduled [%d]. Will run after current query completes."
                    (code-agent-org--queue-count session-key)))
          ('running
           (message "This block is already running. Wait for it to complete."))
          ('in-queue
           (message "This block is already scheduled [%d in queue]."
                    (code-agent-org--queue-count session-key))))
        (cl-return-from code-agent-org-execute nil)))
    ;; Bundle inputs + dispatch through the command class.
    (code-agent-org-execute-command-run
     (code-agent-org-execute-command--create
      :session-key session-key
      :content content
      :section-level section-level
      :custom-id custom-id
      :loop-max loop-max
      :loop-interval loop-interval
      :heading-marker heading-marker))))))

*** Response Stream Class

Every backend query returns four streaming callbacks —
=:on-token=, =:on-message=, =:on-error=, =:on-complete=.  Previously
each was hand-wrapped by =code-agent-org--make-guarded-callback= into a
closure that validated the query-id + source buffer before
dispatching to a bare ~defun~.  That is precisely the shape the
Smalltalk rule points at: several functions sharing identical
dispatch state (session-key, source-buffer, query-id) glued
together by closures.

Promoting to a ~cl-defstruct~ + ~cl-defgeneric~ verbs makes the state
carrier explicit and the dispatch symmetric.  The actual handler
bodies (=--handle-token-v2=, =--handle-message=, =--handle-error=,
=--handle-complete=) remain as free functions — they're the
procedural "how"; the stream class is the "who" that owns the
validation.

#+BEGIN_SRC elisp
(cl-defstruct (code-agent-org-response-stream
               (:constructor code-agent-org-response-stream--create)
               (:copier nil))
  "Per-query streaming state.
A stream instance is created in `code-agent-org--send-request' and
lives only as long as the backend query it serves; the four
methods below validate that the stream is still current before
dispatching to the buffer-mutating handlers."
  (session-key nil
               :documentation "Session key identifying the owning org section.")
  (source-buffer nil
                 :documentation "Originating org buffer — handlers no-op if it's been killed.")
  (query-id nil
            :documentation "Query id frozen at stream creation; handlers no-op when the session's current query-id has moved on (new query or cancel)."))

(defun code-agent-org-response-stream--current-p (stream)
  "Return non-nil if STREAM is still the active one for its session.
Called by every handler before dispatching to the bare `--handle-*'
function: it short-circuits stale callbacks from superseded queries."
  (and (buffer-live-p (code-agent-org-response-stream-source-buffer stream))
       (with-current-buffer (code-agent-org-response-stream-source-buffer stream)
         (equal (code-agent-org-response-stream-query-id stream)
                (code-agent-org--session-get
                 (code-agent-org-response-stream-session-key stream)
                 :query-id)))))

(defun code-agent-org-response-stream--dispatch (stream handler arg)
  "Call HANDLER on ARG inside STREAM's source buffer if STREAM is current.
HANDLER is one of the bare `--handle-*' functions."
  (when (code-agent-org-response-stream--current-p stream)
    (with-current-buffer (code-agent-org-response-stream-source-buffer stream)
      (funcall handler
               (code-agent-org-response-stream-session-key stream)
               arg))))

  "Deliver TEXT token to STREAM (no-op on stale streams).")

(cl-defmethod code-agent-org-response-stream-handle-message

(defun code-agent-org--dispatch-query (session-key full-prompt callbacks
                                    &rest props)
  "Dispatch FULL-PROMPT through the backend for SESSION-KEY.
CALLBACKS is a plist of :on-token, :on-message, :on-error, :on-complete.
PROPS are keyword args passed through to the backend.
SESSION-KEY is automatically injected into PROPS.

The dispatch goes through Protocol 3
(`claude-org-backend-execute-block') so the frontend dispatches on
the backend instance rather than branching on backend type.  The
default method on `claude-agent-backend' shims to
`claude-agent-backend-query' — unchanged behaviour for existing
JSON/ACP backends.  Concrete agent and multiplexer backends
introduced in later phases override `execute-block' with their own
orchestration.

Stores the resulting backend and query handle in the session."
  (claude-agent-with-span "dispatch-query"
      (list :input (truncate-string-to-width (or full-prompt "") 2000)
            :session-key session-key) nil
  (let* ((props (plist-put props :session-key session-key))
         (options (plist-get props :options))
         (backend (or (code-agent-org--session-get session-key :backend)
                      (code-agent-org--make-default-backend session-key options)))
         ;; Protocol 3 dispatch — see claude-agent-backend.org
         ;; §Org-Integration Protocol.  `block-info' is the plist the
         ;; generic contract expects; the default method unpacks it
         ;; back into a `backend-query' call so behaviour stays
         ;; identical until concrete backends start overriding.
         (block-info (list :prompt full-prompt
                           :callbacks callbacks
                           :props props
                           :session-key session-key))
         (handle (claude-org-backend-execute-block backend block-info)))
    ;; Store backend and handle in session
    (code-agent-org--session-put session-key :backend backend)
    (code-agent-org--session-put session-key :query-handle handle)
    ;; Update persistent client activity if applicable
    (when (claude-agent-backend-supports-p backend :persistent-client)
      (code-agent-org-persistent-registry-update-activity
       code-agent-org--persistent-registry session-key)))))

(defun code-agent-org--send-request (prompt &optional query-context session-key-override)
  "Send PROMPT to Claude via claude-agent.
QUERY-CONTEXT is a claude-agent-query-context struct for Session Manager display.
SESSION-KEY-OVERRIDE if provided, uses this session-key instead of calculating from
current buffer position. Essential for loop iterations where cursor may have moved.

When Docker mode is active (CLAUDE_CODE_PATH contains 'docker'), this function
passes :cli-path and :path-mappings to claude-agent-query for automatic path
translation between host (PROJECT_ROOT) and container (CLAUDE_CONTAINER_PATH)."
  (claude-agent-with-span "send-request"
      (list :span-kind "CLIENT"
            :custom-id (when query-context
                          (claude-agent-query-context-custom-id query-context))
            :input prompt)
    nil
  (let* ((session-key (or session-key-override (code-agent-org--current-session-key)))
         (sdk-uuid (code-agent-org--get-sdk-uuid))
         (project-root (code-agent-org--get-project-root))
         (system-prompt (code-agent-org--build-system-prompt))
         ;; Docker configuration from org properties
         (cli-path (code-agent-org--get-cli-path))
         (path-mappings (code-agent-org--get-path-mappings))
         ;; Build IDE context reminder and query options using helpers
         (system-reminder (code-agent-org--build-ide-context-reminder project-root))
         (options (code-agent-org--build-query-options project-root system-prompt sdk-uuid))
         ;; Build full prompt with system reminder
         (full-prompt (code-agent-org--build-full-prompt prompt system-reminder))
         ;; Capture source context for session manager display
         (source-buf (current-buffer))
         (custom-id (when query-context (claude-agent-query-context-custom-id query-context))))
    ;; Store trace context for async callbacks
    (code-agent-org--session-put session-key :trace-ctx (claude-agent-trace-context))
    ;; Get session heading name for permission prompts
    ;; Need to position at heading first since we might be inside a src block
    (let ((org-section-name
           (save-excursion
             (ignore-errors (org-back-to-heading t))
             (when-let* ((heading-pos (code-agent-org--find-session-scope-heading)))
               (goto-char heading-pos)
               (substring-no-properties (org-get-heading t t t t))))))
      ;; Build the streaming state carrier; its methods validate the
      ;; query-id + source buffer before dispatching to handler bodies.
      (let* ((query-id (code-agent-org--session-get session-key :query-id))
             (stream (code-agent-org-response-stream--create
                      :session-key session-key
                      :source-buffer source-buf
                      :query-id query-id))
             (callbacks (code-agent-org-response-stream-callbacks stream)))
        ;; Dispatch through backend
        (code-agent-org--dispatch-query session-key full-prompt callbacks
          :options options
          :source-buffer source-buf
          :query-context query-context
          :source-location-fn (when custom-id 'code-agent-org-goto-custom-id)
          :source-location-args (when custom-id (list custom-id))
          :cli-path cli-path
          :path-mappings path-mappings
          :project-root project-root
          :context-label org-section-name))))))

(defun code-agent-org--execute-queued-block (session-key block-info)
  "Execute a queued BLOCK-INFO for SESSION-KEY.
BLOCK-INFO is a plist with :custom-id, :content, :marker, :loop-max, etc."
  (claude-agent-with-trace "execute-queued-block"
      (list :span-kind "CONSUMER" :oi-kind "CHAIN"
            :session-id (ignore-errors (code-agent-org--get-session-id))
            :custom-id (plist-get block-info :custom-id))
  (cl-block code-agent-org--execute-queued-block
  (let ((custom-id (plist-get block-info :custom-id))
        (content (plist-get block-info :content))
        (orig-marker (plist-get block-info :marker))
        (loop-max (plist-get block-info :loop-max))
        (loop-interval (plist-get block-info :loop-interval))
        (section-level (plist-get block-info :section-level))
        (heading-marker (plist-get block-info :heading-marker)))
    ;; Check if marker is still valid (block not deleted)
    (unless (and orig-marker (marker-buffer orig-marker))
      (message "Skipping queued block - marker invalid (block deleted?)")
      ;; Free dead marker to prevent leak (F23)
      (when (markerp orig-marker)
        (set-marker orig-marker nil))
      ;; Try next in queue
      (when-let* ((next (code-agent-org--dequeue-block session-key)))
        (code-agent-org--execute-queued-block session-key next))
      (cl-return-from code-agent-org--execute-queued-block nil))
    ;; Navigate to the original position and delegate through the command class.
    (with-current-buffer (marker-buffer orig-marker)
      (save-excursion
        (goto-char orig-marker)
        (code-agent-org-execute-command-run
         (code-agent-org-execute-command-from-block-info session-key block-info))))
    ;; Free original marker
    (set-marker orig-marker nil)))))

  "Ensure header refresh timer is running."

  "Refresh header line in all code-agent-org buffers."
  (dolist (buf (buffer-list))
    (when (buffer-live-p buf)
      (with-current-buffer buf
        (when (bound-and-true-p code-agent-org-mode)

          ;; These can cause "Invalid search bound" errors when org-entry-get
          ;; tries to parse with inheritance across buffer boundaries
          (unless (buffer-base-buffer)
            (code-agent-org--refresh-header-line)

            (when (hash-table-p code-agent-org--sessions)
              (maphash (lambda (_key state)
                         (when (and (code-agent-org--session-state-p state)
                                    (code-agent-org--session-state-get state :busy))
                           (let* ((frame (or (code-agent-org--session-state-get state :spinner) 0))
                                  (next-frame (mod (1+ frame) 4)))
                             (code-agent-org--session-state-set state :spinner next-frame))))
                       code-agent-org--sessions))))))))

** Cursor-Position Tracking

The header line shows which workspace and story the cursor is in.
These update on a 0.2-second debounce after cursor movement — fast
enough to feel responsive, slow enough to avoid unnecessary org tree
walks on every keystroke.

#+BEGIN_SRC elisp
(defun code-agent-org--schedule-cursor-header-update ()
  "Schedule a debounced header update after cursor movement.
Added to `post-command-hook' by `code-agent-org-mode'."
  (when code-agent-org--header-cursor-timer
    (cancel-timer code-agent-org--header-cursor-timer))
  (setq code-agent-org--header-cursor-timer
        (run-at-time 0.2 nil #'code-agent-org--update-cursor-header

  (when (buffer-live-p buf)

      (setq code-agent-org--header-cursor-timer nil)

        (let ((ws (ignore-errors (code-agent-org--find-workspace-heading)))

                         (equal new-story code-agent-org--header-story-name))

                    code-agent-org--header-story-name new-story)

* Cancel Support

Interactive cancellation for the active query in the current
session.  Delegates the heavy lifting to
=code-agent-org--cleanup-session= so the same teardown path runs
whether the cancel came from the user (here) or from an error path
elsewhere.  A short-lived trace span wraps the request so the
cancel itself shows up in Phoenix next to the query it aborted.

#+BEGIN_SRC elisp
(defun code-agent-org-cancel ()
  "Cancel the current session's active query, stop any loop, and clear queue.
Uses centralized `code-agent-org--cleanup-session' for complete cleanup (F19)."
  (interactive)
  (claude-agent-with-span "cancel"
      (list :custom-id (ignore-errors (code-agent-org--find-instruction-custom-id))) nil
  (let* ((session-key (code-agent-org--current-session-key))
         (backend (code-agent-org--session-get session-key :backend))
         (query-handle (code-agent-org--session-get session-key :query-handle))
         (loop-current (code-agent-org--session-get session-key :loop-current))
         (loop-max (code-agent-org--session-get session-key :loop-max))
         (queue-count (code-agent-org--queue-count session-key)))
    (if (and backend (code-agent-org--session-get session-key :busy))
        (progn
          ;; Stop loop by setting current = max
          (when (and loop-max (> loop-max 1))
            (code-agent-org--session-put session-key :loop-current loop-max))
          ;; Protocol 3 dispatch — mux backends send cancel keys, agent
          ;; backends delegate to `claude-agent-backend-cancel'.  No more
          ;; string-matching on `backend' slot value.
          (claude-org-backend-cancel-from-org backend session-key)
          ;; Insert cancellation message BEFORE cleanup (needs :query-id and :marker)
          (let ((cancel-text (if (and loop-max (> loop-max 1))
                                 (format "\n[Cancelled at iteration %d/%d]\n"
                                         (or loop-current 1) loop-max)
                               "\n[Cancelled]\n")))
            (or (code-agent-org--insert-at-response session-key cancel-text)
                ;; Fallback: if no response section found (e.g., cancelled
                ;; before response section was created), use marker
                (let ((marker (code-agent-org--session-get session-key :marker)))
                  (when (and marker (marker-buffer marker))
                    (with-current-buffer (marker-buffer marker)
                      (save-excursion
                        (goto-char marker)
                        (when (re-search-forward "^#\\+end_src" nil t)
                          (end-of-line)
                          (insert cancel-text))))))))
          ;; Full cleanup via centralized function (F19: replaces 7 manual ops)
          ;; Handles: stop-spinner, set-exec-status, reset-session-state
          ;; (clears :busy, :recovering, :last-assistant-query-id),
          ;; free-marker, cleanup-queued-blocks (frees queued markers +
          ;; resets exec-status), unregister-active-query, refresh-header-line
          (code-agent-org--cleanup-session session-key "cancelled" t)
          (if (> queue-count 0)
              (message "Query cancelled, cleared %d queued block(s)" queue-count)
            (message "Query cancelled")))
      (message "No active query to cancel")))))

(defun code-agent-org-cancel-all ()
  "Cancel all active queries in this buffer and clear all queues.
Uses centralized `code-agent-org--cleanup-session' for complete cleanup."
  (interactive)
  (let ((cancelled 0)
        (queued-cleared 0))
    (maphash (lambda (key state)
               (when (code-agent-org--session-state-p state)
                 ;; Count queued blocks before clearing
                 (let ((q-count (length (code-agent-org--session-state-get state :pending-queue))))
                   (when (> q-count 0)
                     (cl-incf queued-cleared q-count)))
                 ;; Only cleanup sessions that are busy or have queued blocks;
                 ;; skip idle sessions to avoid overwriting "completed"/"error" status
                 (when (or (code-agent-org--session-state-get state :busy)
                           (> (length (code-agent-org--session-state-get state :pending-queue)) 0))
                   ;; Protocol 3 dispatch — same as single-session cancel.
                   (when (code-agent-org--session-state-get state :busy)
                     (when-let* ((backend (code-agent-org--session-state-get state :backend)))
                       (ignore-errors
                         (claude-org-backend-cancel-from-org backend key)))
                     (cl-incf cancelled))
                   ;; Full cleanup via centralized function
                   (code-agent-org--cleanup-session key "cancelled" t))))
             code-agent-org--sessions)
    (if (> queued-cleared 0)
        (message "Cancelled %d queries, cleared %d queued blocks" cancelled queued-cleared)
      (message "Cancelled %d queries" cancelled))))

(defun code-agent-org-cancel-queue ()
  "Cancel only queued blocks, leaving the running query intact.
Uses `cleanup-queued-blocks' to properly free markers and reset exec-status."
  (interactive)
  (let* ((session-key (code-agent-org--current-session-key))
         (queue-count (code-agent-org--queue-count session-key)))
    (if (> queue-count 0)
        (progn
          (code-agent-org--cleanup-queued-blocks session-key)
          (code-agent-org--refresh-header-line)
          (message "Cleared %d queued block(s), running query continues" queue-count))
      (message "No queued blocks to cancel"))))

*** Unified Terminal Dispatchers

Dispatchers called by workspace_bridge.py to route events to the correct
terminal backend. All use the same pattern: check if the session is
known to cmux, then dispatch accordingly.

#+BEGIN_SRC elisp
(defun code-agent-org--terminal-query-completed (workspace-session-id)
  "Dispatch query-completed to the correct terminal backend.
WORKSPACE-SESSION-ID identifies the session whose query just finished.
Tries cmux (checks hash table, then falls back to request-id file)."
  (cond
   ;; cmux: session-key in hash table (normal path)
   ((and (fboundp 'code-agent-org-cmux--query-completed)
         (gethash workspace-session-id code-agent-org-terminal--workspace-to-session-key))
    (code-agent-org-cmux--query-completed workspace-session-id))
   ;; cmux: hash table empty but request-id file exists (module reload / race)
   ((and (fboundp 'code-agent-org-cmux--query-completed)
         (code-agent-org-terminal--read-request-id workspace-session-id))
    (code-agent-org-cmux--query-completed workspace-session-id))
   (t (message "code-agent-org: no terminal backend loaded for query-completed"))))

(defun code-agent-org--terminal-permission-needed (workspace-session-id tool-name)
  "Dispatch permission notification to the correct terminal backend."
  (cond
   ((and (fboundp 'code-agent-org-cmux--permission-needed)
         (boundp 'code-agent-org-terminal--workspace-to-session-key)
         (gethash workspace-session-id code-agent-org-terminal--workspace-to-session-key))
    (code-agent-org-cmux--permission-needed workspace-session-id tool-name))
   (t (message "code-agent-org: no terminal backend loaded for permission-needed"))))

(defun code-agent-org--terminal-permission-resolved (workspace-session-id)
  "Dispatch permission resolution to the correct terminal backend."
  (cond
   ((and (fboundp 'code-agent-org-cmux--permission-resolved)
         (boundp 'code-agent-org-terminal--workspace-to-session-key)
         (gethash workspace-session-id code-agent-org-terminal--workspace-to-session-key))
    (code-agent-org-cmux--permission-resolved workspace-session-id))
   (t (message "code-agent-org: no terminal backend loaded for permission-resolved"))))

* Org File Protection Hook

*NOTE: This hook does NOT work as intended.* It is kept for documentation purposes
and potential future use if Claude Code CLI changes its architecture.

** How Permission Functions Work

When Claude Code CLI is in =acceptEdits= mode, it sends =can_use_tool= control
requests to Emacs before executing Edit/Write tools. The
=claude-agent-permission-functions= hook processes these requests:

| Permission Mode | Edit/Write Flow | Protection? |
|-----------------+-----------------+-------------|
| bypassPermissions | CLI auto-approves | ❌ No prompts |
| acceptEdits | CLI → can_use_tool → Emacs | ✅ Permission functions run |
| default | CLI prompts user | ⚠️ CLI UI (not Emacs) |

To protect org files, add =code-agent-org-permission-protect-org= to
=claude-agent-permission-functions=. This only works in =acceptEdits= mode.

** Org File Protection (Permission Function)

This permission function protects .org files from modifications via:
1. Edit/Write tools directly targeting .org files
2. Bash commands that would modify .org files (sed -i, redirects, cp, mv, etc.)

Add it to =claude-agent-permission-functions= to enable protection.

*** Bash Command Detection

Detect if a bash command would modify an .org file.

#+NAME: org-protect-bash-detect
#+BEGIN_SRC elisp
(defun code-agent-org--bash-modifies-org-p (command)
  "Return non-nil if COMMAND would modify an .org file.
Checks for:
- In-place edit commands (sed -i, perl -i) referencing .org
- Output redirection (>, >>) to .org files
- File operations (cp, mv, install, tee) targeting .org files
- Temp file swap patterns (cmd > tmp && mv tmp file.org)"
  (when (and command (stringp command) (string-match-p "\\.org\\b" command))
    (or
     ;; In-place edit commands: sed -i, perl -i, ruby -i
     (and (string-match-p "\\b\\(sed\\|perl\\|ruby\\)\\b" command)
          (string-match-p " -[^ ]*i" command))
     ;; Output redirection to .org: > file.org, >> file.org, 2> file.org
     ;; Match > or >> followed by anything then .org (but not | or ; before .org)
     (string-match-p ">[>&]?[^|;]*\\.org" command)
     ;; File operations with .org as target at end of command
     (string-match-p "\\b\\(cp\\|mv\\|install\\)\\b.*\\.org[ \t]*$" command)
     ;; File operations with .org in quotes
     (string-match-p "\\b\\(cp\\|mv\\|install\\)\\b.*\\.org['\"]" command)
     ;; tee to .org file
     (string-match-p "\\btee\\b.*\\.org" command)
     ;; Temp file swap pattern: ... && mv ... .org
     (string-match-p "&&.*\\bmv\\b.*\\.org" command))))
#+END_SRC

*** Main Protection Function

#+NAME: org-protect-permission
#+BEGIN_SRC elisp
(defun code-agent-org-permission-protect-org (tool-name tool-input _context)
  "Permission function to protect .org files from modifications.

TOOL-NAME: string like \"Edit\", \"Write\", \"Bash\"
TOOL-INPUT: plist with tool-specific parameters
CONTEXT: plist with :session-id, :context-label

Blocks:
1. Edit/Write tools on .org files
2. Bash commands that would modify .org files

Returns nil to pass through, or permission result to deny.
Should be added to `claude-agent-permission-functions'."
  (let ((file-path (plist-get tool-input :file_path))
        (command (plist-get tool-input :command)))
    (cond
     ;; Layer 1: Block Edit/Write on .org files
     ((and (member tool-name '("Edit" "Write"))
           file-path
           (string-match-p "\\.org$" file-path))
      (code-agent-org--deny-org-modification tool-name))
     ;; Layer 2-4: Block Bash commands modifying .org files
     ((and (string= tool-name "Bash")
           command
           (code-agent-org--bash-modifies-org-p command))
      (code-agent-org--deny-org-modification "Bash")))))
#+END_SRC

** Protection Installation

Install/remove org protection in the permission hook.

(defun code-agent-org--install-protection ()
  "Install org file protection in permission functions.
The protection must be global because it runs in process filter context."
  (add-hook 'claude-agent-permission-functions
            #'code-agent-org-permission-protect-org))

(defun code-agent-org--remove-protection ()
  "Remove org file protection if no code-agent-org buffers remain."
  (unless (cl-some (lambda (buf)
                     (and (not (eq buf (current-buffer)))
                          (buffer-live-p buf)
                          (with-current-buffer buf
                            code-agent-org-mode)))
                   (buffer-list))
    (setq claude-agent-permission-functions
          (delq #'code-agent-org-permission-protect-org
                claude-agent-permission-functions))))
