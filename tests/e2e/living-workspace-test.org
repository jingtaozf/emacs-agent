** T12: Tab name uses ACTIVE_STORY, not workspace heading
:PROPERTIES:
:STATUS: PASS
:TESTED: 2026-03-26
:NOTE: Bug found and fixed — tab-title now reads ACTIVE_STORY property
:END:

*** Setup

Test fixture must have workspace heading name DIFFERENT from ACTIVE_STORY:
- Workspace heading: "Test Dev Workspace"
- ACTIVE_STORY: "study code patterns"
- Story sub-heading: "** study code patterns"

*** Command
#+begin_example
evalElisp:
;; 1. Execute ai block
(with-current-buffer (find-buffer-visiting ".../workspace-test.org")
  (save-excursion
    (goto-char (point-min))
    (re-search-forward "hello tab name test" nil t)
    (claude-org-execute)))

;; 2. Check tab name in cmux tree
(claude-org-cmux--call "tree" "--workspace" "<CMUX_WORKSPACE_ID>")
#+end_example

*** Expected
Surface line shows ACTIVE_STORY name: ="study code patterns [sdd-e2e-test-002]"=
NOT the workspace heading: ="Test Dev Workspace [sdd-e2e-test-002]"=

*** Bug found
=claude-org-terminal--tab-title= used =(org-get-heading)= which returns the
workspace heading name, not the story name. Fixed to use =(org-entry-get nil "ACTIVE_STORY")=
with fallback to heading name.

File: =claude-org-terminal-base.org:88=
