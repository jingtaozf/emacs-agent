#+TITLE: Pi Backend Multi-Block Same-Workspace E2E Fixture

* Pi Multi-Block Workspace
:PROPERTIES:
:CUSTOM_ID: pi-mb-workspace
:CLAUDE_BACKEND: pi
:CLAUDE_SESSION_ID: pi-mb-e2e
:END:

Three AI blocks under the SAME workspace heading.  Together they
prove three invariants:

1. *Same Pi subprocess across blocks 1+2* — same PID, block 2 recalls
   the number set by block 1 (in-process conversation context).

2. *Session does NOT get stuck :busy t after agent_end* — historically
   block 1's =agent_end= fired its =:on-complete= callback but the
   chain that clears =:busy= never reached its destination, so block
   2 got queued instead of dispatched.  (Fixed in 5226db7 + 1c35417.)

3. *Cross-process session persistence* — between blocks 2 and 3 the
   runner kills the Pi subprocess; block 3 must respawn under the
   same session-key, READ =:PI_SESSION_ID:= from the workspace
   heading, pass =--session <id>= to the new =pi --mode rpc=, and
   STILL recall the number from block 1.  Different Pi PID, same
   Pi-side conversation.

** Workflow :sdd:

*** Instruction 1 — establish context :claude_chat:pi-mb-e2e:
:PROPERTIES:
:CUSTOM_ID: pi-mb-1
:EXPECTED: ACK_ONE
:TIMEOUT: 60
:END:

#+begin_src ai
Remember this number for the rest of our conversation: 4242.
Reply with exactly the text ACK_ONE and nothing else. No punctuation, no quotes.
#+end_src

*** Instruction 2 — same Pi process, recall context :claude_chat:pi-mb-e2e:
:PROPERTIES:
:CUSTOM_ID: pi-mb-2
:EXPECTED: 4242
:TIMEOUT: 60
:END:

#+begin_src ai
What number did I just ask you to remember? Reply with just the number, no other text.
#+end_src

*** Instruction 3 — AFTER Pi kill, session must persist :claude_chat:pi-mb-e2e:
:PROPERTIES:
:CUSTOM_ID: pi-mb-3
:EXPECTED: 4242
:TIMEOUT: 60
:END:

Between block 2 and this block the test runner explicitly kills the
Pi subprocess.  This block reuses the same session-key on the Emacs
side; the backend reads =:PI_SESSION_ID:= (written by block 1's
=get_state= handshake response) and passes =--session <id>= to the
respawned =pi --mode rpc=.  If persistence works, Pi reloads the
prior conversation from =~/.pi/agent/sessions/= and recalls the
number.

What number did I ask you to remember at the start of this conversation? Reply with just the number, no other text.
#+end_src
