** Root cause (verified by source reading)

| Symptom | Code path |
|---------+-----------|
| Tool inline in response | =lp/backend/code-agent-pi-backend.org=: =code-agent-pi--handle-tool-start/end= calls =--render-tool-text= → =on-token= callback → response section.  Default =code-agent-pi-show-tool-calls t=. |
| No verbose buffer | =lp/sdk/code-agent-backend.org=: =code-agent-verbose-insert= only =gethash=, never creates.  =code-agent--get-session-verbose-buffer= (creator) is internal + uncalled by the Pi path.  =code-agent-backend-verbose-buffer= on Pi returns nil. |

** Fix plan

1. Default =code-agent-pi-show-tool-calls= → =nil= (clean response;
   tool events go to verbose buffer only).  User who wants the old
   inline-render flips back with =M-x customize=.
2. =code-agent-verbose-insert= auto-creates the session buffer (via
   =code-agent--get-session-verbose-buffer=) if missing — closes
   the gap that left Pi's =--verbose-log= no-oping.
3. Pi's =code-agent-backend-verbose-buffer= returns the buffer
   (created on demand) instead of =nil= so the
   =code-agent-org-show-verbose= fallback chain finds it.
