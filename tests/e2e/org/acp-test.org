* Gemini ACP Test
:PROPERTIES:
:CLAUDE_BACKEND: gemini-acp
:CLAUDE_SESSION_ID: acp-e2e-gemini
:END:

Before running, pick an auth method and set the env var:
- ~GEMINI_API_KEY~ for ~gemini-api-key~ method (default)
- GCP credentials for ~vertex-ai~
- Google OAuth for ~oauth-personal~

Configure with:
#+begin_src elisp :load no
(setq code-agent-acp-gemini-auth-method 'gemini-api-key)
(setq code-agent-acp-gemini-environment
      (list (format "GEMINI_API_KEY=%s" (getenv "GEMINI_API_KEY"))))
#+end_src
