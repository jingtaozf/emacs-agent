#+TITLE: Major Features — End-to-End Verification Checklist
#+DATE: 2026-04-25

* Overview

This file is the executable end-to-end verification checklist for
the *user-visible features* of the code-agent SDK after the
tri-protocol backend refactor (2026-04-24).

Unlike =make test-unit= which exercises Elisp paths in isolation,
the tasks here drive the *real stack*:

- Real Emacs (=evalElisp= against the running session)
- Real cmux app (workspaces, surfaces, send / read-screen, sidebar)
- Real tmux binary (=tmux new-session=, =send-keys=, =capture-pane=)
- Real agent CLIs (Claude Code, OpenCode if installed)
- Real Python bridge subprocess (=workspace-bridge.py= invoked by
  claude-code hooks)

*No mocks at this layer.*  Tasks that can't be driven without manual
human action are marked =[manual]= and explicit.

A =/loop= driver reads this file, picks the first task with
checkbox =[ ]=, executes it, marks =[X]= on pass, attempts a
mechanical fix on failure, and stops if the same task fails twice.

* Loop driver instructions

Each iteration:

1. *Find* the first task heading with =[ ]= under any =* Section=.
2. *Execute* the =Action= block — it is a sequence of real
   invocations: =evalElisp= forms, =cmux= / =tmux= / =bash= shell
   commands, all run for real.
3. *Verify* the predicates in =Verify=.  Each predicate is a single
   bash- or evalElisp-evaluable test.  All must hold.
4. *On pass*: change =[ ]= to =[X]=, set =:STATUS: PASS= and
   =:LAST_RUN:= timestamp, run the =Cleanup= block.
5. *On failure*: read =Common failures=.  If a hint applies, apply
   the mechanical fix described, re-run.  If still failing or no
   hint applies, set =:STATUS: FAIL= with the diagnostic,
   *don't* mark =[X]=, advance to next task.
6. After 3 consecutive =FAIL= results, stop and surface to user.

When all tasks under a section are =[X]=, mark the section heading
itself with a leading =DONE = label.

** Cleanup hygiene

After completing a task — and especially when crossing a section boundary — release transient resources that are no longer needed:

- *Per-task tmux sessions* (Section B's =claude-test-bN= sessions) — explicitly kill in each task's Cleanup block; verify with =tmux ls= after.
- *cmux workspaces created by tests* — close via =cmux close-workspace --workspace <ref>= when no later task in the loop will reuse them.  Test Dev Workspace (sdd-e2e-test-005) is shared by ALL Section A tasks — close it after A15 succeeds, not earlier.  Other test workspaces (e.g. tmux-test) close when their section ends.
- *Status files* under =/tmp/code-agent-status/= — leave intact; they're shared with the bridge and useful for debugging.  Only the test fixtures' =.from-emacs= files should be cleaned up by individual task Cleanup blocks.
- *Temporary org files* under =/tmp= (e.g. =/tmp/e2e-c1.org=) — delete in the task's Cleanup block.
- *Verbose buffers* (=*cmux: <id>*=) — let them die naturally with their workspace; don't manually kill (that's tested in A8 anyway).

Do NOT close the Test Dev Workspace mid-Section-A run, even if a task fails — Section A's tasks share state.  When a Section A task FAILs, mark FAIL but leave the workspace; the next [ ] task may resume successfully against the same session.

* Pre-flight gates

Before any task runs, verify and surface a stop-the-loop error if
any of these are missing.  These are *not* tasks themselves; they
are pre-conditions checked once per loop start.
