* Gemini ACP Profile

Per-agent configuration for Google's Gemini CLI.  Gemini speaks ACP
natively via the experimental flag =--experimental-acp=.  Three auth
methods are supported (per the ACP spec):

| Method         | How                                            |
|----------------+------------------------------------------------|
| gemini-api-key | Set GEMINI_API_KEY, sent via authenticate RPC  |
| vertex-ai      | Uses ambient Google Cloud credentials          |
| oauth-personal | Google OAuth (personal account)                |

References:
- https://github.com/google-gemini/gemini-cli
- reference/agent-shell/agent-shell-google.el

Note: =--experimental-acp= is explicitly experimental; if Gemini CLI
changes the flag in a future release, update
=claude-agent-acp-gemini-command=.

** Dependencies

#+BEGIN_SRC elisp
(require 'claude-agent-acp)
#+END_SRC

** Customization

#+BEGIN_SRC elisp
(defgroup claude-agent-acp-gemini nil
  "Gemini ACP profile."
  :group 'claude-agent-acp
  :prefix "claude-agent-acp-gemini-")

(defcustom claude-agent-acp-gemini-command '("gemini" "--experimental-acp")
  "Command and args to launch Gemini CLI in ACP mode."
  :type '(repeat string)
  :group 'claude-agent-acp-gemini)

(defcustom claude-agent-acp-gemini-auth-method 'gemini-api-key
  "Which authenticate method to advertise during the ACP handshake.
- `gemini-api-key': sends GEMINI_API_KEY (must be in environment)
- `vertex-ai': uses ambient Google Cloud credentials
- `oauth-personal': Google OAuth for a personal account"
  :type '(choice (const gemini-api-key)
                 (const vertex-ai)
                 (const oauth-personal))
  :group 'claude-agent-acp-gemini)

(defcustom claude-agent-acp-gemini-environment nil
  "Extra environment variables for the Gemini subprocess.
List of \"NAME=VALUE\" strings.  Typical entries:
  \"GEMINI_API_KEY=...\" when `claude-agent-acp-gemini-auth-method' is
  `gemini-api-key'.
  \"GOOGLE_APPLICATION_CREDENTIALS=...\" for vertex-ai auth."
  :type '(repeat string)
  :group 'claude-agent-acp-gemini)
#+END_SRC

** Auth Request Maker

#+BEGIN_SRC elisp
(defun claude-agent-acp-gemini--auth-request ()
  "Build authenticate RPC params using `claude-agent-acp-gemini-auth-method'."
  `((methodId . ,(symbol-name claude-agent-acp-gemini-auth-method))))
#+END_SRC

** Class

Concrete subclass of =claude-agent-acp-backend= for Gemini.  Gemini
does require =authenticate= (unlike OpenCode), but that variation
lives on the struct slot =needs-authenticate=, not in methods.  The
subclass exists mainly so future Gemini-specific methods
(e.g. model-ID extraction, Gemini-only capability quirks) can
dispatch on the type without string-matching =agent-name=.

#+BEGIN_SRC elisp
(cl-defstruct (claude-agent-gemini-backend
               (:include claude-agent-acp-backend (type :gemini))
               (:constructor claude-agent-gemini-backend--create)
               (:copier nil))
  "ACP backend specialised for Google Gemini CLI.")
#+END_SRC

** Constructor

#+BEGIN_SRC elisp
(defun claude-agent-acp-gemini-create (&rest args)
  "Create an ACP backend configured for Google Gemini CLI.
ARGS are forwarded to `claude-agent-gemini-backend--create' after the
gemini-specific defaults.  Typical usage:

  (claude-agent-acp-gemini-create :cwd \"/path\" :session-key \"sdd-...\")"
  (apply #'claude-agent-gemini-backend--create
         :agent-name "gemini"
         :spawn-args claude-agent-acp-gemini-command
         :environment claude-agent-acp-gemini-environment
         :needs-authenticate t
         :auth-request-maker #'claude-agent-acp-gemini--auth-request
         args))
#+END_SRC
