* OpenCode ACP Profile

Per-agent configuration for OpenCode.  Provides a thin constructor
that presets =spawn-args=, auth handling, and environment for the
generic =claude-agent-acp= backend.

OpenCode speaks ACP natively via =opencode acp= on stdio.  It uses
its own credentials from =opencode auth login=, so no ACP-level
=authenticate= RPC is needed.

References:
- https://opencode.ai
- reference/agent-shell/agent-shell-opencode.el

** Dependencies

#+BEGIN_SRC elisp
(require 'claude-agent-acp)
#+END_SRC

** Customization

#+BEGIN_SRC elisp
(defgroup claude-agent-acp-opencode nil
  "OpenCode ACP profile."
  :group 'claude-agent-acp
  :prefix "claude-agent-acp-opencode-")

(defcustom claude-agent-acp-opencode-command '("opencode" "acp")
  "Command and args to launch OpenCode as an ACP server."
  :type '(repeat string)
  :group 'claude-agent-acp-opencode)

(defcustom claude-agent-acp-opencode-environment nil
  "Extra environment variables for the OpenCode subprocess.
List of \"NAME=VALUE\" strings.  Typical entries:
  \"OPENCODE_API_KEY=...\" if you use API-key auth instead of CLI login."
  :type '(repeat string)
  :group 'claude-agent-acp-opencode)
#+END_SRC

** Class

Concrete subclass of =claude-agent-acp-backend= for OpenCode.
Adding this as a formal =cl-defstruct= — rather than using the base
class directly with agent-specific slot values — follows the
Smalltalk-flavoured protocol style: dispatch on the receiver's class
rather than on an =agent-name= string.  Currently OpenCode shares
all methods with the abstract base; adding =cl-defmethod=
specialisations later (e.g. an OpenCode-only capability check)
requires no call-site changes.

#+BEGIN_SRC elisp
(cl-defstruct (claude-agent-opencode-backend
               (:include claude-agent-acp-backend (type :opencode))
               (:constructor claude-agent-opencode-backend--create)
               (:copier nil))
  "ACP backend specialised for OpenCode.")
#+END_SRC

** Constructor

#+BEGIN_SRC elisp
(defun claude-agent-acp-opencode-create (&rest args)
  "Create an ACP backend configured for OpenCode.
ARGS are passed to `claude-agent-opencode-backend--create' after the
opencode-specific defaults.  Typical usage:

  (claude-agent-acp-opencode-create :cwd \"/path\" :session-key \"sdd-...\")"
  (apply #'claude-agent-opencode-backend--create
         :agent-name "opencode"
         :spawn-args claude-agent-acp-opencode-command
         :environment claude-agent-acp-opencode-environment
         :needs-authenticate nil
         :auth-request-maker nil
         args))
#+END_SRC
