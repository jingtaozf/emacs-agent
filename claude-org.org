* Introduction

Claude Org Integration is a minor mode for org-mode that enables interactive
streaming AI queries directly within org files using ~#+begin_src ai~ blocks.

This package depends on ~claude-agent~ for Claude communication and provides
org-specific features on top of it.

** Features

- *Token-by-token streaming*: Responses stream token-by-token with debounced
  font-lock for smooth rendering.

- *Multi-session support*: Multiple queries with different CLAUDE_SESSION_ID
  values can run concurrently.

- *Session recovery*: When backend sessions expire, context is collected from
  the org file and rebuilt automatically.

- *Project support*: PROJECT_ROOT property sets cwd; :system_prompt: tagged
  sections provide project guidelines.

** Usage Example

#+BEGIN_SRC org :load no
,#+PROPERTY: PROJECT_ROOT /path/to/project

,* Project Guidelines :system_prompt:
This project uses Python 3.11.
Always use absolute imports.

,* Tasks

,** Instruction 1 :claude_chat:

,#+begin_src ai
How do I read a JSON file in Python?
,#+end_src

Response will appear here after pressing C-c C-c inside the ai block.
#+END_SRC

*** Prompt File Loader

#+NAME: prompt-file-loader
#+BEGIN_SRC elisp
(defun claude-org--load-prompt-file (file)
  "Load prompt content from FILE.
Returns file content as trimmed string, or nil if file doesn't exist."
  (when (file-readable-p file)
    (with-temp-buffer
      (insert-file-contents file)
      (string-trim (buffer-string)))))

(defun claude-org--extract-summary-section (file)
  "Extract only the * Summary section from FILE.
Returns content of Summary section if found, otherwise returns full file content.
This enables progressive disclosure: system prompt loads only summaries,
Claude reads full file via org link when tag is active.

Summary section format:
  * Summary
  :PROPERTIES:
  :CUSTOM_ID: tags-TAG-summary
  :END:
  [brief content with link to Details]

If no Summary section exists (backward compat), returns full file content."
  (when (file-readable-p file)
    (with-temp-buffer
      (insert-file-contents file)
      (goto-char (point-min))
      ;; Look for "* Summary" at beginning of line
      (if (re-search-forward "^\\* Summary[ \t]*$" nil t)
          (let ((start (line-beginning-position)))
            ;; Find end: next level-1 heading or end of file
            (if (re-search-forward "^\\* " nil t)
                (string-trim (buffer-substring-no-properties start (line-beginning-position)))
              (string-trim (buffer-substring-no-properties start (point-max)))))
        ;; No Summary section: return full content (backward compat)
        (string-trim (buffer-string))))))

(defun claude-org--load-system-prompts ()
  "Load all system prompts from system/ directory.
Files are loaded in sorted order (use numeric prefix for ordering).
Returns list of prompt strings."
  (let ((dir (expand-file-name "system" claude-org-prompts-directory)))
    (when (file-directory-p dir)
      (let ((files (directory-files dir t "\\.org\\'" t)))
        (delq nil (mapcar #'claude-org--load-prompt-file (sort files #'string<)))))))
#+END_SRC

* Session Management

Session identity is determined by file path + optional CLAUDE_SESSION_ID property.

** Helper Functions

File-level properties (=#+ PROPERTY:=) require different lookup logic than
section properties. This function searches only the file header area (before
the first heading) to avoid matching properties inside headings.

#+NAME: session-file-level-property
#+BEGIN_SRC elisp
(defun claude-org--get-file-level-property (property)
  "Get PROPERTY value from file-level #+PROPERTY keyword.
Only searches in the file header area (before first heading).
Returns nil if not found."
  (save-excursion
    (save-restriction
      (widen)
      (goto-char (point-min))
      ;; Limit search to before first heading (file header area)
      (let ((limit (save-excursion
                     (if (re-search-forward "^\\*+ " nil t)
                         (line-beginning-position)
                       (point-max)))))
        (when (re-search-forward
               (format "^#\\+PROPERTY:[ \t]+%s[ \t]+\\(.+\\)$"
                       (regexp-quote property))
               limit t)
          (string-trim (match-string-no-properties 1)))))))
#+END_SRC

** Session ID Functions

These functions retrieve and interpret the =CLAUDE_SESSION_ID= property.
Session IDs enable multiple independent conversations within a single org file.

#+NAME: session-id-functions
#+BEGIN_SRC elisp
(defun claude-org--get-session-id ()
  "Get user-defined CLAUDE_SESSION_ID from org properties.
Searches section property drawer first, then file-level #+PROPERTY.
Returns nil if no session ID is defined (file path will be used alone).
Returns nil safely if not in org-mode context."
  (ignore-errors
    (save-excursion
      ;; org-entry-get with t enables inheritance up the heading tree
      (org-entry-get nil "CLAUDE_SESSION_ID" t))))

(defun claude-org--get-session-scope ()
  "Determine the scope of the current CLAUDE_SESSION_ID.
Returns `section' if defined in a property drawer, `file' if defined
at file level, or nil if no session ID is defined.
Returns nil safely if not in org-mode context."
  (ignore-errors
    (save-excursion

  (ignore-errors

(defun claude-org--find-session-scope-heading ()
  "Find the heading that defines the session scope.

Returns nil safely if not in org-mode context."
  (ignore-errors

            (if (re-search-forward "^#\\+TITLE:" nil t)
                (progn
                  (end-of-line)
                  (insert (format "\n#+PROPERTY: %s %s"

** Session Recovery

#+BEGIN_SRC elisp
(defun claude-org--section-has-archive-tag-p ()
  "Check if current heading has :ARCHIVE: tag.
Point must be at a heading."
  (when (org-at-heading-p)
    (member "ARCHIVE" (org-get-tags nil t))))

(defun claude-org--collect-ai-blocks-in-section ()
  "Collect AI blocks in current section (not including subsections).
Returns list of (question . response) pairs.
Point must be at a heading, or before first heading for top-level content."
  (let ((conversations '())
        (section-start (if (org-at-heading-p)
                           ;; Start after the heading line
                           (save-excursion
                             (forward-line 1)
                             (point))
                         ;; Before first heading: start from current point
                         (point)))
        (section-end (save-excursion
                       (if (org-at-heading-p)
                           ;; End is before next same-level heading
                           (progn
                             (org-end-of-subtree t t)
                             (point))
                         ;; Before first heading: search until first heading
                         (if (re-search-forward "^\\*+ " nil t)
                             (line-beginning-position)
                           (point-max))))))
    (save-excursion
      (save-restriction
        (narrow-to-region section-start section-end)
        ;; Find all ai blocks in this section only (not subsections)
        (goto-char (point-min))
        (while (re-search-forward "^[ \t]*#\\+begin_src[ \t]+ai" nil t)
          ;; Make sure we're not in a subsection
          (let ((block-pos (point)))
            (save-excursion
              (beginning-of-line)
              ;; Check if there's a heading between section start and block
              (goto-char (point-min))
              (unless (re-search-forward "^\\*+ " block-pos t)
                ;; No heading found, this block is in current section
                (goto-char block-pos)
                (let* ((q-start (progn (forward-line 1) (point)))
                       (q-end (progn (re-search-forward "^[ \t]*#\\+end_src" nil t)
                                     (line-beginning-position)))
                       (question (string-trim (buffer-substring-no-properties q-start q-end)))
                       ;; Response is content after #+end_src until next heading or ai block
                       (r-start (progn (forward-line 1) (point)))
                       (r-end (save-excursion
                                (if (re-search-forward "^\\(\\*+ \\|[ \t]*#\\+begin_src\\)" nil t)
                                    (line-beginning-position)
                                  (point-max))))
                       (response (string-trim (buffer-substring-no-properties r-start r-end))))
                  (when (not (string-empty-p question))
                    (push (cons question response) conversations)))))))))
    (nreverse conversations)))

(defun claude-org--collect-session-context ()
  "Collect conversation history from current session scope.
If CLAUDE_SESSION_ID is defined in a section, narrows to that subtree.
Otherwise, collects from the entire file.
Skips sections tagged with :ARCHIVE: for better performance with large files.
Returns list of (question . response) pairs for recovery."
  (let ((conversations '())
        (scope (claude-org--get-session-scope)))
    (save-excursion
      (save-restriction
        ;; Narrow to section scope if session ID is defined locally
        (when (eq scope 'section)
          (unless (org-at-heading-p)
            (org-back-to-heading t))
          (org-narrow-to-subtree))

        ;; Collect blocks from before first heading
        (goto-char (point-min))
        (unless (org-at-heading-p)
          (setq conversations (append conversations (claude-org--collect-ai-blocks-in-section))))

        ;; Iterate through top-level sections, skipping archived ones
        (goto-char (point-min))
        (when (re-search-forward "^\\*+ " nil t)
          (beginning-of-line)
          (while (not (eobp))
            (if (claude-org--section-has-archive-tag-p)
                ;; Skip entire archived subtree
                (org-end-of-subtree t t)
              ;; Collect blocks from this section
              (setq conversations (append conversations (claude-org--collect-ai-blocks-in-section)))
              ;; Move to next same-level heading
              (org-end-of-subtree t t))
            ;; Move to next top-level heading
            (unless (re-search-forward "^\\*+ " nil t)
              (goto-char (point-max)))
            (beginning-of-line)))))
    conversations))

(defun claude-org--build-recovery-prompt (context original-prompt)
  "Build recovery prompt with CONTEXT history and ORIGINAL-PROMPT."
  (let ((scope (claude-org--get-session-scope)))
    (concat
     "<session_recovery>\n"
     "The previous session expired. Here is the conversation history from this "
     (if (eq scope 'section) "section" "file")
     ":\n\n"
     (mapconcat
      (lambda (pair)
        (format "**User:** %s\n\n**Assistant:** %s\n\n---\n"
                (car pair) (cdr pair)))
      context "")
     "</session_recovery>\n\n"
     "Please continue the conversation. The user's current question is:\n\n"
     original-prompt)))

(defun claude-org--recover-session (session-key &optional reason)
  "Recover session for SESSION-KEY by creating a new response section.
REASON can be 'context-limit or 'expired (default).

Uses query-id based recovery:
1. Find current response section by query-id
2. Create NEW recovery response section after it
3. Generate new query-id for recovery query
4. Old query's callbacks will be ignored (query-id mismatch)

Recovery is limited to `claude-org-max-recovery-attempts' consecutive
attempts.  The counter resets on each new query."
  ;; Guard: check recovery count against limit
  (let ((count (or (claude-org--session-get session-key :recovery-count) 0)))
    (if (>= count claude-org-max-recovery-attempts)
        (progn
          (claude-org--insert-error
           session-key
           (format "Recovery limit reached (%d attempts). Please retry manually."
                   count))
          (claude-org--reset-session-state session-key)
          (claude-org--stop-spinner session-key)
          (claude-org--refresh-header-line))
      ;; Normal recovery path — increment counter before attempting
      (claude-org--session-put session-key :recovery-count (1+ count))
      (claude-org--session-put session-key :recovering t)
      (let* ((old-query-id (claude-org--session-get session-key :query-id))
             (reason-str (pcase reason
                           ('context-limit "context_limit")
                           (_ "session_expired"))))
        ;; Try to find response section by query-id (marker-free approach)
        (let ((response-pos (claude-org--find-response-by-query-id old-query-id)))
          (if (not response-pos)
              ;; Can't find response section - fail gracefully
              (progn
                (message "Claude: Cannot recover session - response section not found")
                (claude-org--reset-session-state session-key)
                (claude-org--stop-spinner session-key)
                (claude-org--refresh-header-line))
            ;; Found response section - create recovery section
            (save-excursion
              (goto-char response-pos)
              ;; Move to end of current response section
              (org-end-of-subtree t)
              ;; Insert newlines and create NEW recovery response section
              (insert "\n\n")
              ;; Generate new query-id for recovery
              (let ((new-query-id (claude-org--generate-query-id)))
                ;; Update session with new query-id BEFORE creating section
                (claude-org--session-put session-key :query-id new-query-id)
                ;; Create recovery response section with parent reference
                (claude-org--create-response-section
                 session-key new-query-id 'recovery old-query-id reason-str)
                ;; Insert recovery message in the new section
                (let ((recovery-msg (pcase reason
                                      ('context-limit "/Context limit reached, recovering with history.../")
                                      (_ "/Session expired, recovering with context.../"))))
                  (insert recovery-msg "\n\n"))))
            ;; Clear old session UUID from org property
            (claude-org--clear-sdk-uuid)
            ;; Collect context and send recovery request
            (let* ((context (claude-org--collect-session-context))
                   (original-prompt (claude-org--session-get session-key :original-prompt))
                   (recovery-prompt (claude-org--build-recovery-prompt context original-prompt)))
              ;; Clear recovering flag - the new query-id protects us now
              (claude-org--session-put session-key :recovering nil)
              ;; Send recovery request with new query-id already in session
              (claude-org--send-request recovery-prompt nil session-key))))))))
#+END_SRC

* Environment Variable Loading

Load environment variables from `.env` files with variable substitution support.

** ENV File Loading

#+BEGIN_SRC elisp
(defun claude-org--parse-env-file (file-path)
  "Parse .env FILE-PATH and return alist of (VAR . VALUE).
Supports standard .env syntax:
  KEY=value
  KEY=\"value with spaces\"
  # Comments
  export KEY=value (export prefix ignored)

Performs tilde expansion on file-path."
  (let ((expanded-path (expand-file-name file-path))
        (env-alist '()))
    (when (file-exists-p expanded-path)
      (with-temp-buffer
        (insert-file-contents expanded-path)
        (goto-char (point-min))
        (while (not (eobp))
          (let ((line (string-trim (buffer-substring-no-properties
                                    (line-beginning-position)
                                    (line-end-position)))))
            ;; Skip empty lines and comments
            (unless (or (string-empty-p line)
                        (string-prefix-p "#" line))
              ;; Remove optional "export " prefix
              (when (string-match "^export[ \t]+" line)
                (setq line (substring line (match-end 0))))
              ;; Parse KEY=VALUE
              (when (string-match "^\\([A-Za-z_][A-Za-z0-9_]*\\)=\\(.*\\)$" line)
                (let* ((key (match-string 1 line))
                       (value (match-string 2 line))
                       ;; Remove surrounding quotes if present
                       (unquoted-value (if (and (>= (length value) 2)
                                                (or (and (string-prefix-p "\"" value)
                                                         (string-suffix-p "\"" value))
                                                    (and (string-prefix-p "'" value)
                                                         (string-suffix-p "'" value))))
                                           (substring value 1 -1)
                                         value)))
                  (push (cons key unquoted-value) env-alist)))))
          (forward-line 1))))
    (nreverse env-alist)))

(defun claude-org--parse-env-file-safe (content)
  "Parse env file CONTENT string safely without using (read).
Returns alist of (KEY . VALUE). This is a safe parser that treats
all values as literal strings - no Elisp execution possible.

Supports:
- KEY=value
- KEY=\"value\" (double quotes stripped)
- KEY='value' (single quotes stripped)
- # comments
- export KEY=value (export prefix ignored)
- Blank lines (skipped)
- Values containing = (only first = is split point)"
  (let ((env-alist '()))
    (with-temp-buffer
      (insert content)
      (goto-char (point-min))
      (while (not (eobp))
        (let ((line (string-trim (buffer-substring-no-properties
                                  (line-beginning-position)
                                  (line-end-position)))))
          ;; Skip empty lines and comments
          (unless (or (string-empty-p line)
                      (string-prefix-p "#" line))
            ;; Remove optional "export " prefix
            (when (string-match "^\\s-*export[ \t]+" line)
              (setq line (substring line (match-end 0))))
            ;; Parse KEY=VALUE (value may contain =)
            (when (string-match "^\\([A-Za-z_][A-Za-z0-9_]*\\)=\\(.*\\)$" line)
              (let* ((key (match-string 1 line))
                     (value (match-string 2 line))
                     ;; Remove surrounding quotes if present
                     (unquoted-value (if (and (>= (length value) 2)
                                              (or (and (string-prefix-p "\"" value)
                                                       (string-suffix-p "\"" value))
                                                  (and (string-prefix-p "'" value)
                                                       (string-suffix-p "'" value))))
                                         (substring value 1 -1)
                                       value)))
                (push (cons key unquoted-value) env-alist)))))
        (forward-line 1)))
    (nreverse env-alist)))

(defun claude-org--get-env-file-path ()

Returns nil if not set. Supports tilde expansion."

(defun claude-org--load-env-file ()
  "Load environment variables from ENV_FILE property.
Returns alist of (VAR . VALUE), or nil if no ENV_FILE is set."
  (when-let ((env-file-path (claude-org--get-env-file-path)))
    (if (file-exists-p env-file-path)

#+BEGIN_SRC elisp
(defun claude-org--expand-env-vars (value env-alist)
  "Expand ${VAR} references in VALUE using ENV-ALIST.
ENV-ALIST is an alist of (VAR-NAME . VAR-VALUE).
Also expands environment variables from process-environment.

Examples:
  \"${HOME}/projects\"     -> \"/Users/user/projects\"
  \"token=${API_TOKEN}\"   -> \"token=sk-abc123\"
  \"${VAR:-default}\"      -> Uses default if VAR not set (bash syntax)"
  (when value
    (let ((result value))
      ;; Replace ${VAR} with values from env-alist or process-environment
      (while (string-match "\\${\\([A-Za-z_][A-Za-z0-9_]*\\)\\(:-\\([^}]*\\)\\)?}" result)
        (let* ((var-name (match-string 1 result))
               (default-value (match-string 3 result))
               ;; Look up in env-alist first, then process-environment
               (var-value (or (cdr (assoc var-name env-alist))
                              (getenv var-name)
                              default-value
                              "")))
          (setq result (replace-match var-value t t result))))
      result)))

(defun claude-org--collect-system-prompts ()
  "Collect content from all org sections tagged :system_prompt:.
Returns concatenated string of heading + body for each section, or nil if none.

Usage in org file:
  * Project Guidelines :system_prompt:
  This project uses Python 3.11 with Django.
  Always use absolute imports."
  (save-excursion
    (save-restriction
      (widen)
      (goto-char (point-min))
      (let ((prompts '())
            (heading-re "^\\(\\*+\\) +\\(.*\\):system_prompt:"))
        ;; Use regex search instead of org-map-entries to avoid cache issues
        (while (re-search-forward heading-re nil t)
          (let* ((stars (match-string 1))
                 (heading-text (match-string 2))
                 (heading (string-trim (replace-regexp-in-string ":.*$" "" heading-text)))
                 (beg (save-excursion
                        (forward-line 1)
                        ;; Skip property drawers and planning lines
                        (while (and (not (eobp))
                                    (looking-at "^[ \t]*\\(:\\|DEADLINE:\\|SCHEDULED:\\|CLOSED:\\)"))
                          (forward-line 1))
                        (point)))
                 (end (save-excursion
                        (beginning-of-line)
                        (org-end-of-subtree t t)
                        (point)))
                 (body (when (< beg end)
                         (string-trim (buffer-substring-no-properties beg end)))))
            (when (and heading (not (string-empty-p heading)))
              (push (concat "* " heading
                            (when (and body (not (string-empty-p body)))
                              (concat "\n" body)))
                    prompts))))
        (when prompts
          (mapconcat #'identity (nreverse prompts) "\n\n"))))))

(defun claude-org--build-system-prompt ()
  "Build complete system prompt from file-based templates and org sections.
Combines:
1. System prompts from prompts/system/*.org (loaded in sorted order)
2. :system_prompt: tagged org sections in the current file
3. Behavior prompts from tags and header arguments

** Persistent Client Registry

Global registry of persistent Claude clients, keyed by session-key.
This enables long-running Claude processes that stay alive across multiple queries.

#+BEGIN_SRC elisp
(defvar claude-org--persistent-clients (make-hash-table :test 'equal)
  "Global hash table mapping session-key -> persistent client state.

Each entry contains:
  :client       - claude-agent-client struct
  :buffer       - source org buffer (for cleanup on buffer kill)
  :heading-pos  - position of session-defining heading (for TODO state changes)
  :last-activity - timestamp of last query/response
  :query-count  - number of queries sent through this client

Unlike `claude-org--sessions' which is buffer-local and tracks per-query state,
this registry tracks long-running processes that persist across queries.")

(defcustom claude-org-persistent-sessions nil
  "When non-nil, use persistent process pool for sessions.
When nil, spawn a new process for each query (legacy behavior).

Persistent sessions reduce latency and allow Claude to maintain
conversation context internally."
  :type 'boolean
  :group 'claude-org)

(defcustom claude-org-backend-type 'json-stream
  "Backend type for Claude CLI communication.
Selects which backend implementation to use for new sessions.

  - `json-stream': JSON streaming via subprocess (default, backward compatible).
    Uses --output-format stream-json with structured messages.
  - `claude-cli': Interactive terminal via eat terminal emulator.
    Runs Claude CLI as long-lived TUI process. Requires the `eat' package."
  :type '(radio (const :tag "JSON stream (default)" json-stream)
                (const :tag "Claude CLI terminal (requires eat)" claude-cli))
  :group 'claude-org)

(defcustom claude-org-session-idle-timeout nil
  "Seconds of inactivity before auto-closing idle persistent sessions.
When nil, sessions remain connected until explicitly closed."
  :type '(choice (const :tag "Never timeout" nil)
                 (integer :tag "Seconds"))
  :group 'claude-org)

(defun claude-org--get-persistent-client (session-key)
  "Get persistent client for SESSION-KEY, or nil if none exists."
  (when-let ((entry (gethash session-key claude-org--persistent-clients)))
    (plist-get entry :client)))

(defun claude-org--persistent-client-alive-p (session-key)
  "Return non-nil if persistent client for SESSION-KEY is alive."
  (when-let ((client (claude-org--get-persistent-client session-key)))
    (claude-agent-client-alive-p client)))

(defun claude-org--register-persistent-client (session-key client buffer heading-pos)
  "Register CLIENT as persistent client for SESSION-KEY.
BUFFER is the org buffer that owns this client.
HEADING-POS is the position of the session-defining heading."
  (puthash session-key
           (list :client client
                 :buffer buffer
                 :heading-pos heading-pos
                 :last-activity (float-time)
                 :query-count 0)
           claude-org--persistent-clients))

(defun claude-org--update-persistent-client-activity (session-key)
  "Update last activity timestamp for SESSION-KEY."
  (when-let ((entry (gethash session-key claude-org--persistent-clients)))
    (plist-put entry :last-activity (float-time))
    (plist-put entry :query-count (1+ (or (plist-get entry :query-count) 0)))
    (puthash session-key entry claude-org--persistent-clients)))

(defun claude-org--disconnect-persistent-client (session-key &optional reason)
  "Disconnect persistent client for SESSION-KEY.
REASON is an optional string explaining why (for logging)."
  (when-let ((entry (gethash session-key claude-org--persistent-clients)))
    (when-let ((client (plist-get entry :client)))
      (when (claude-agent-client-alive-p client)
        (claude-agent-client-disconnect client)))
    (remhash session-key claude-org--persistent-clients)
    (message "Claude: Disconnected session %s%s"
             (claude-org--session-display-name session-key)
             (if reason (format " (%s)" reason) ""))))

(defun claude-org--disconnect-all-clients-for-buffer (buffer)
  "Disconnect all persistent clients associated with BUFFER."
  (let ((to-remove nil))
    (maphash (lambda (key entry)
               (when (eq (plist-get entry :buffer) buffer)
                 (push key to-remove)))
             claude-org--persistent-clients)
    (dolist (key to-remove)
      (claude-org--disconnect-persistent-client key "buffer killed"))))

(defun claude-org--list-persistent-clients ()
  "Return list of (session-key . info-plist) for all persistent clients."
  (let ((clients nil))
    (maphash (lambda (key entry)
               (push (cons key entry) clients))
             claude-org--persistent-clients)
    (nreverse clients)))

(defun claude-org--persistent-client-count ()
  "Return count of active persistent clients."
  (hash-table-count claude-org--persistent-clients))

(defun claude-org--make-default-backend (session-key options)
  "Create the default backend for SESSION-KEY with OPTIONS.
Dispatches on CLAUDE_BACKEND org property (if set) or `claude-org-backend-type'.
Returns a backend struct (json-backend or claude-backend)."
  (let* ((prop-value (claude-org--get-org-property "CLAUDE_BACKEND" t))
         (backend-type (or (cond
                             ((equal prop-value "claude-cli") 'claude-cli)
                             ((equal prop-value "json-stream") 'json-stream)
                             (t nil))
                           claude-org-backend-type)))
    (pcase backend-type
    ('claude-cli
     (unless (featurep 'eat)
       (user-error "The `eat' package is required for claude-cli backend. \
Install with: M-x package-install RET eat RET"))
     (claude-agent-claude-backend--create
      :session-key session-key
      :cwd (or (claude-org--get-project-root) default-directory)
      :options options))
    (_ ; json-stream (default)
     (claude-agent-json-backend--create
      :session-key session-key
      :persistent-p claude-org-persistent-sessions)))))

(defun claude-org--get-or-create-persistent-client (session-key options)
  "Get or create a persistent client for SESSION-KEY.
OPTIONS is a plist of claude-agent options.
Returns the client struct, creating and connecting a new one if needed."
  (let ((existing (claude-org--get-persistent-client session-key)))
    (if (and existing (claude-agent-client-alive-p existing))
        ;; Return existing alive client
        existing
      ;; Create new client
      (let* ((buffer (current-buffer))
             (heading-pos (save-excursion
                           (ignore-errors (org-back-to-heading t))
                           (claude-org--find-session-scope-heading)))
             (client (claude-agent-client-create
                      :options options
                      :session-key session-key
                      :on-disconnect
                      (lambda (c)
                        (let ((key (claude-agent-client-session-key c)))
                          (remhash key claude-org--persistent-clients)
                          (message "Claude: Session %s disconnected"
                                   (claude-org--session-display-name key)))))))
        ;; Connect the client (without initial prompt - we'll send messages later)
        (claude-agent-client-connect client "")
        ;; Register in persistent clients registry
        (claude-org--register-persistent-client session-key client buffer heading-pos)
        client))))

** Query-ID System

Query-IDs provide reliable, marker-free response tracking. Each query gets a
unique ID stored as an org property, enabling:
- Race-free callback validation (old queries ignored)
- Persistent response location (survives buffer kill/Emacs restart)
- Clear audit trail (every response traceable to its query)

*** Query-ID Generation

#+BEGIN_SRC elisp
(defun claude-org--generate-query-id ()
  "Generate a unique query ID.
Format: YYYYMMDD-HHMMSS-XXXX where XXXX is a 4-char random suffix.
Example: 20260204-103025-a7f3"
  (let* ((timestamp (format-time-string "%Y%m%d-%H%M%S"))
         (random-suffix (substring (md5 (format "%s%s" (random) (current-time))) 0 4)))
    (format "%s-%s" timestamp random-suffix)))

#+BEGIN_SRC elisp
(defun claude-org--create-response-section (session-key query-id query-type
                                            &optional parent-query-id recovery-reason
                                            loop-info)
  "Create a response section for SESSION-KEY with QUERY-ID.
QUERY-TYPE is 'normal or 'recovery.
For recovery queries, PARENT-QUERY-ID and RECOVERY-REASON should be provided.
LOOP-INFO is (ITERATION . MAX) for loop iterations, or nil.

Returns the position where content should be inserted (after properties)."
  (let* ((section-level (or (claude-org--session-get session-key :section-level) 1))
         ;; Response should be at SAME level as instruction (sibling), not child
         ;; section-level is the instruction heading level, so use it directly
         (response-level section-level)
         (stars (make-string response-level ?*))
         ;; Get instruction number from session or find by :claude_chat: tag
         ;; Note: claude-org--find-instruction-number returns nil if no :claude_chat: heading found
         (instr-num (or (claude-org--session-get session-key :instruction-num)
                        (claude-org--find-instruction-number)))
         (timestamp (format-time-string "%Y-%m-%d %H:%M"))
         ;; Build loop suffix for iteration numbering
         (loop-suffix (if loop-info
                          (format "(%d/%d)" (car loop-info) (cdr loop-info))
                        ""))
         ;; For recovery, use N.M numbering; for normal, just the number
         ;; If no instruction number found, omit the number from heading
         (response-num (cond
                        ((null instr-num)
                         ;; No instruction found - use timestamp-based identifier
                         (format-time-string "%H%M%S"))
                        ((eq query-type 'recovery)
                         (let ((recovery-count (or (claude-org--session-get session-key :recovery-count) 0)))
                           (claude-org--session-put session-key :recovery-count (1+ recovery-count))
                           (format "%s.%d" instr-num (1+ recovery-count))))
                        (t
                         (number-to-string instr-num))))
         (tags (if (eq query-type 'recovery)
                   ":ai_output:recovery:"
                 ":ai_output:"))
         (heading (format "%s Response %s%s (%s) %s" stars response-num loop-suffix timestamp tags)))
    (save-excursion
      ;; Insert heading
      (insert heading "\n")
      ;; Insert properties
      (insert ":PROPERTIES:\n")
      (insert (format ":QUERY_ID: %s\n" query-id))
      (insert (format ":QUERY_TYPE: %s\n" (symbol-name query-type)))
      (when (and (eq query-type 'recovery) parent-query-id)
        (insert (format ":PARENT_QUERY_ID: %s\n" parent-query-id)))
      (when (and (eq query-type 'recovery) recovery-reason)
        (insert (format ":RECOVERY_REASON: %s\n" recovery-reason)))
      (insert ":END:\n\n")
      ;; Reset content flag so first-token newline stripping works
      (claude-org--session-put session-key :response-has-content nil)
      ;; Return current position (where content will be inserted)
      (point))))

*** Marker-Free Token Insertion

#+BEGIN_SRC elisp
(defun claude-org--insert-at-response (session-key text)
  "Insert TEXT at end of response section for SESSION-KEY.
Uses query-id property lookup instead of marker.
Returns t if insertion succeeded, nil otherwise."
  (let ((query-id (claude-org--session-get session-key :query-id)))
    (when query-id
      (save-excursion
        (let ((heading-pos (claude-org--find-response-by-query-id query-id)))
          (when heading-pos
            (goto-char heading-pos)
            ;; Find the :END: of the PROPERTIES drawer
            (if (re-search-forward "^:END:" nil t)
                (progn
                  ;; Skip past :END: to the blank line after it
                  (forward-line 1)
                  ;; Skip ONE blank line if present (the standard separator)
                  (when (looking-at "^$")
                    (forward-line 1))
                  ;; If we're now at a heading, insert BEFORE it (go back to blank line)
                  (if (looking-at "^\\*+ ")
                      (progn
                        (forward-line -1)
                        (end-of-line)
                        (insert text)
                        t)
                    ;; Otherwise, find the end of content in this section
                    (let ((insert-pos (line-end-position)))
                      ;; Search forward for next heading or end of buffer
                      (while (and (not (eobp))
                                  (not (looking-at "^\\*+ ")))
                        (setq insert-pos (line-end-position))
                        (forward-line 1))
                      ;; insert-pos now points to end of last content line
                      (goto-char insert-pos)
                      (insert text)
                      t)))
              ;; No :END: found, fall back to end of heading line
              (end-of-line)
              (insert "\n" text)
              t)))))))

(defun claude-org--handle-token-v2 (session-key text)
  "Handle incoming TEXT token for SESSION-KEY using query-id lookup.
Normalizes org headers, auto-breaks long lines, and inserts at response section.
This is the marker-free version using query-id."
  (let ((query-id (claude-org--session-get session-key :query-id)))
    (when query-id
      (let* ((target-level (1+ (or (claude-org--session-get session-key :section-level) 0)))
             (normalized-text (claude-org--normalize-headers-in-text text target-level))
             ;; Auto-break long lines
             (current-line-len (or (claude-org--session-get session-key :current-line-length) 0))
             (break-result (claude-org--auto-break-lines normalized-text current-line-len))
             (final-text (car break-result))
             (new-line-len (cdr break-result)))
        ;; Update line length state
        (claude-org--session-put session-key :current-line-length new-line-len)
        ;; Strip leading newlines from the very first token of a new response.
        ;; Claude's model often starts assistant text with "\n\n" which creates
        ;; unwanted blank lines after the :END: property drawer.
        (unless (claude-org--session-get session-key :response-has-content)
          (when (> (length final-text) 0)
            (setq final-text (string-trim-left final-text "\n+"))
            (when (> (length final-text) 0)
              (claude-org--session-put session-key :response-has-content t))))
        ;; Prepend newline separator between consecutive assistant messages.
        ;; :last-assistant-query-id stores the query-id of the most recent
        ;; assistant message's on-message callback.  When we see the SAME
        ;; query-id here it means a previous assistant message already
        ;; produced output in this query, so we insert a blank-line separator.
        ;; Cross-query stale values are harmless: different query-ids won't match.
        (let ((last-asst-qid (claude-org--session-get session-key :last-assistant-query-id)))
          (when (and (> (length final-text) 0)
                     last-asst-qid
                     (equal last-asst-qid query-id))
            ;; Clear so we only insert one separator per assistant message boundary
            (claude-org--session-put session-key :last-assistant-query-id nil)
            (setq final-text (concat "\n\n" final-text))))
        ;; Insert processed text using query-id lookup
        (when (> (length final-text) 0)
          (claude-org--insert-at-response session-key final-text))
        ;; Schedule fontification
        (claude-org--schedule-fontlock)))))
#+END_SRC

** Marker Lifecycle Management

Robust marker validation to prevent crashes when markers become invalid
during async operations. Markers can become invalid when their buffer is
killed or when they haven't been set to a position.

#+BEGIN_SRC elisp
(defun claude-org--marker-valid-p (marker)
  "Check if MARKER is still valid for use.
Returns non-nil if MARKER is:
- An actual marker object (not nil or other type)
- Associated with a buffer (not just created with `make-marker')
- Its buffer is still live (not killed)
- Has a valid position (not nil)

This should be called before any operation that uses a marker,
especially in async contexts where the buffer may have been killed."
  (and marker
       (markerp marker)
       (marker-buffer marker)
       (buffer-live-p (marker-buffer marker))
       (marker-position marker)))

(defmacro claude-org--with-session-marker (marker &rest body)
  "Execute BODY in the buffer of MARKER if it is valid, else return nil.
Switches to the marker's buffer using `with-current-buffer', so BODY
runs with the marker's buffer current.  If MARKER is nil, not a marker,
or its buffer has been killed, BODY is silently skipped and nil is returned."
  (declare (indent 1) (debug t))
  (let ((m (make-symbol "marker")))
    `(let ((,m ,marker))
       (when (claude-org--marker-valid-p ,m)
         (with-current-buffer (marker-buffer ,m)
           ,@body)))))

** Pending Block Queue

Functions for managing queued blocks that execute when session becomes free.

#+BEGIN_SRC elisp
(defun claude-org--same-block-p (id-a marker-a id-b marker-b)
  "Return non-nil if block A and block B refer to the same block.
Compares by custom-id when both are non-nil, otherwise by marker position."
  (if (and id-a id-b)
      (equal id-a id-b)
    (let ((pos-a (and (claude-org--marker-valid-p marker-a)
                      (marker-position marker-a)))
          (pos-b (and (claude-org--marker-valid-p marker-b)
                      (marker-position marker-b))))
      (and pos-a pos-b (= pos-a pos-b)))))

(defun claude-org--queue-block (session-key block-info)
  "Add BLOCK-INFO to pending queue for SESSION-KEY.
BLOCK-INFO is a plist with :custom-id, :content, :marker, :instr-num.
Duplicate detection uses custom-id.  When custom-id is unavailable on
either side, marker position is compared instead.
Returns:
  'queued    - block was successfully added to queue
  'running   - block is already running (cannot queue)
  'in-queue  - block is already in the queue"
  (let* ((queue (claude-org--session-get session-key :pending-queue))
         (new-custom-id (plist-get block-info :custom-id))
         (running-custom-id (claude-org--session-get session-key :custom-id))
         (new-marker (plist-get block-info :marker))
         (running-marker (claude-org--session-get session-key :marker))
         ;; Determine if the new block matches the running block
         (is-running
          (and (claude-org--session-get session-key :busy)
               (claude-org--same-block-p new-custom-id new-marker
                                         running-custom-id running-marker)))
         ;; Determine if the new block is already in queue
         (in-queue
          (cl-some (lambda (queued)
                     (claude-org--same-block-p
                      new-custom-id new-marker
                      (plist-get queued :custom-id) (plist-get queued :marker)))
                   queue)))
    (cond
     (is-running 'running)   ; Cannot queue the running block
     (in-queue 'in-queue)    ; Already queued
     ((>= (length queue) claude-org-max-queue-depth)
      (message "Claude: Queue full (%d blocks). Cannot queue more."
               (length queue))
      'queue-full)
     (t
      (claude-org--session-put session-key :pending-queue
                               (append queue (list block-info)))
      'queued))))

(defun claude-org--dequeue-block (session-key)
  "Remove and return next block from SESSION-KEY queue.
Returns nil if queue is empty."
  (let ((queue (claude-org--session-get session-key :pending-queue)))
    (when queue
      (claude-org--session-put session-key :pending-queue (cdr queue))
      (car queue))))

(defun claude-org--clear-queue (session-key)
  "Clear all pending blocks for SESSION-KEY."
  (claude-org--session-put session-key :pending-queue nil))

(defun claude-org--queue-count (session-key)
  "Return number of queued blocks for SESSION-KEY."
  (length (claude-org--session-get session-key :pending-queue)))

(defun claude-org--total-queue-count ()
  "Return total number of queued blocks across all sessions in current buffer."
  (let ((total 0))
    (when (hash-table-p claude-org--sessions)
      (maphash (lambda (_key state)
                 (when (claude-org--session-state-p state)
                   (cl-incf total (length (claude-org--session-state-pending-queue state)))))
               claude-org--sessions))
    total))

*** SDD Subsection Update Helper

Helper function for updating SDD subsections without creating duplicates.
When updating Spec, Research Output, or Features sections, AI should use this
to *replace* existing subsections rather than appending new ones.

#+BEGIN_SRC elisp
(defun claude-org--adjust-heading-levels (content target-level)
  "Adjust all heading levels in CONTENT to be relative to TARGET-LEVEL.
The first heading in CONTENT becomes TARGET-LEVEL, and all other headings
are adjusted proportionally.

For example, if CONTENT starts with '*** Foo' and TARGET-LEVEL is 4,
'*** Foo' becomes '**** Foo' and '**** Bar' becomes '***** Bar'.

This ensures correct hierarchy regardless of what level Claude uses in examples."
  (if (string-match "^\\(\\*+\\) " content)
      (let* ((content-level (length (match-string 1 content)))
             (level-diff (- target-level content-level)))
        (if (= level-diff 0)
            content  ; Already correct
          ;; Adjust all heading lines
          (with-temp-buffer
            (insert content)
            (goto-char (point-min))
            (while (re-search-forward "^\\(\\*+\\) " nil t)
              (let* ((stars (match-string 1))
                     (old-level (length stars))
                     (new-level (max 1 (+ old-level level-diff)))  ; Ensure at least level 1
                     (new-stars (make-string new-level ?*)))
                (replace-match (concat new-stars " "))))
            (buffer-string))))
    ;; No heading found, return as-is
    content))

(defun claude-org-update-or-create-subsection (parent-id subsection-name content)
  "Update existing subsection or create new one under PARENT-ID.
PARENT-ID is the CUSTOM_ID of the parent section (e.g., Spec section).
SUBSECTION-NAME is the heading text (e.g., \"Goals\", \"Non-Goals\").
CONTENT is the full content including heading.  The heading level will be
automatically adjusted to be one level below the parent, so callers don't
need to know the exact level.

This function prevents duplicate subsections when AI updates SDD sections
multiple times. It searches for existing subsection and replaces it,
or creates new one at end if not found.

Returns t on success, nil on failure.

Example usage in AI prompt:
  (claude-org-update-or-create-subsection
    \"myproject-spec-sdd-20260115-123456\"
    \"Goals\"
    \"*** Goals\\n\\n- Goal 1\\n- Goal 2\")

Note: The '***' will be auto-adjusted to match parent+1 level."
  (save-excursion
    (condition-case err
        (progn
          ;; Navigate to parent section by CUSTOM_ID
          (org-link-open-from-string (format "[[#%s]]" parent-id))
          (let* ((parent-level (org-outline-level))
                 (child-level (1+ parent-level))
                 ;; Auto-adjust heading levels in content
                 (adjusted-content (claude-org--adjust-heading-levels content child-level))
                 (subtree-end (save-excursion (org-end-of-subtree t) (point)))
                 ;; Match heading at exact child level with subsection name
                 (search-pattern (format "^%s %s\\([ \t]\\|$\\)"
                                         (regexp-quote (make-string child-level ?*))
                                         (regexp-quote subsection-name))))
            (if (re-search-forward search-pattern subtree-end t)
                ;; Found existing subsection - replace it
                (progn
                  (beginning-of-line)
                  (let ((section-start (point))
                        section-end)
                    ;; Find end of this subsection (next sibling or parent end)
                    ;; Use org-end-of-subtree for reliability
                    (save-excursion
                      (org-end-of-subtree t)
                      (setq section-end (point)))
                    ;; Delete old content
                    (delete-region section-start section-end)
                    ;; Insert new content at current position (after delete, point is at section-start)
                    (insert adjusted-content)
                    (unless (bolp) (insert "\n"))
                    t))
              ;; Not found - create at end of parent
              (goto-char subtree-end)
              ;; Ensure we're on a new line with blank line before
              (unless (bolp) (insert "\n"))
              (unless (save-excursion (forward-line -1) (looking-at-p "^[ \t]*$"))
                (insert "\n"))
              (insert adjusted-content)
              (unless (bolp) (insert "\n"))
              t)))
      (error
       (message "claude-org-update-or-create-subsection error: %s" (error-message-string err))
       nil))))
#+END_SRC

** Header Prompt Lookup

Loads prompt from =prompts/headers/=. Supports:
- Enum-style: =headers/phase/code.org= for =:phase code=
- Template-style: =headers/coverage.org= with =%s= placeholder

#+BEGIN_SRC elisp
(defun claude-org--header-prompt (header value)
  "Get behavior prompt for HEADER keyword with VALUE.
Loads from prompts/headers/ at runtime.

Supports two patterns:
- Enum: headers/HEADER/VALUE.org (e.g., headers/phase/code.org)
- Template: headers/HEADER.org with %s placeholder"
  (when value
    (let* ((name (substring (symbol-name header) 1))  ; strip leading :
           (dir (expand-file-name "headers" claude-org-prompts-directory))
           ;; Try enum-style first: headers/phase/code.org
           (enum-file (expand-file-name (format "%s/%s.org" name value) dir))
           ;; Fallback to template: headers/coverage.org
           (template-file (expand-file-name (format "%s.org" name) dir)))
      (cond
       ;; Enum-style: subdirectory with value files
       ((file-readable-p enum-file)
        (claude-org--load-prompt-file enum-file))
       ;; Template-style: single file with %s placeholder
       ((file-readable-p template-file)
        (let ((tpl (claude-org--load-prompt-file template-file)))
          (if (and tpl (string-match-p "%s" tpl))
              (format tpl value)
            tpl)))))))

** Collect Current Context

#+BEGIN_SRC elisp
(defun claude-org--get-heading-tags ()
  "Get list of tag strings from current section headings (inherited).
Uses org-get-tags with LOCAL=nil to include inherited tags from ancestors."
  (when-let* ((tags (org-get-tags nil nil)))  ; nil = include inherited tags
    (mapcar #'downcase tags)))

(defun claude-org--get-property-tags ()
  "Get list of tag strings from CLAUDE_TAGS property (with inheritance).
Property value is space-separated list of tag names."
  (when-let* ((prop-value (org-entry-get nil "CLAUDE_TAGS" t)))  ; t = inherit
    (split-string prop-value "[ \t]+" t)))

(defun claude-org--get-current-tags ()
  "Get effective list of tag strings for current context.
Merges heading tags with CLAUDE_TAGS property, deduplicating.
Heading tags take priority (appear first in list)."
  (let* ((heading-tags (claude-org--get-heading-tags))
         (property-tags (claude-org--get-property-tags))
         (all-tags heading-tags))
    ;; Add property tags that aren't already in heading tags
    (dolist (tag property-tags)
      (unless (member (downcase tag) (mapcar #'downcase all-tags))
        (push (downcase tag) all-tags)))
    (nreverse all-tags)))

(defun claude-org--get-block-header-args ()
  "Get header arguments from current ai block.
Returns plist of header arguments, e.g. (:phase \"code\" :tests t)."
  (save-excursion
    (let ((case-fold-search t))
      (when (re-search-backward "^[ \t]*#\\+begin_src[ \t]+ai\\b" nil t)
        (let ((line (buffer-substring-no-properties (point) (line-end-position))))
          (when (string-match "#\\+begin_src[ \t]+ai\\b[ \t]*\\(.*\\)" line)
            (let ((args-str (match-string 1 line))
                  (result nil))
              (when (and args-str (not (string-empty-p args-str)))
                ;; Parse header args: :key value :key2 value2
                (with-temp-buffer
                  (insert args-str)
                  (goto-char (point-min))
                  (while (re-search-forward ":\\([a-zA-Z_-]+\\)\\(?:[ \t]+\\([^ \t\n:]+\\)\\)?" nil t)
                    (let ((key (intern (concat ":" (match-string 1))))
                          (val (match-string 2)))
                      ;; Build plist: push value first, then key (reversed later)
                      (push key result)
                      (push (or val t) result)))))
              ;; Result is (val2 key2 val1 key1), reverse to get (key1 val1 key2 val2)
              (nreverse result))))))))

#+BEGIN_SRC elisp

Returns plist with :tags and :header-args."

(defun claude-org--sdd-tag-priority (tag)
  "Return priority for TAG in SDD workflow (lower = first).
Container tags come before phase tags."
  (pcase tag
    ("sdd" 0)        ; Container first
    ("spec" 1)       ; Documentation sections
    ("features" 2)
    ("research" 10)  ; Phases in order
    ("design" 11)
    ("planning" 12)
    ("implementation" 13)
    (_ 50)))          ; Other tags last

Returns plist with :file-path, :sdd-root, :session-id, :current-tags."
  (list :file-path (buffer-file-name)

        :session-id (claude-org--get-session-id)
        :current-tags (claude-org--get-current-tags)))

(defun claude-org--build-behavior-prompt ()
  "Build behavior prompt from current tags and header arguments.
Returns combined prompt string or nil if no behaviors active.

For SDD workflow, tags are ordered: container (sdd) first, then phase tags.
This ensures the workflow context is established before phase-specific behavior.
Context is passed to tag methods for dynamic prompt generation (e.g., SDD links)."
  (let* ((config (claude-org--collect-behavior-config))
         (tags (plist-get config :tags))
         (header-args (plist-get config :header-args))
         (context (claude-org--build-behavior-context))
         (parts '()))
    ;; Collect tag prompts (ordered by SDD priority for proper context)
    (dolist (tag-str (sort (copy-sequence tags)
                           (lambda (a b)
                             (< (claude-org--sdd-tag-priority a)
                                (claude-org--sdd-tag-priority b)))))
      (when-let ((prompt (claude-org-tag-prompt (intern tag-str) context)))
        (push prompt parts)))
    ;; Collect header argument prompts
    (cl-loop for (header value) on header-args by #'cddr
             when (keywordp header)
             do (when-let ((prompt (claude-org--header-prompt header value)))
                  (push prompt parts)))
    ;; Combine (reverse to maintain order: tags first, then headers)
    (when parts
      (string-join (nreverse parts) "\n\n"))))

* Block Detection

Block detection answers the fundamental question: "Where am I in the document?"
These functions determine the execution context for AI blocks by examining:

1. *Section hierarchy* - What level heading contains the cursor?
2. *Block boundaries* - Is point inside a =#+begin_src ai= block?
3. *Output sections* - Is this an AI response area (tagged with =:ai_output:=)?
4. *Instruction numbering* - Which instruction number does this belong to?

The detection logic supports both complete blocks (with =#+end_src=) and incomplete
blocks (still being edited), allowing execution during composition.

** AI Block Boundary Detection

These functions detect whether point is inside an AI block and extract its boundaries.
The key insight: an incomplete block (no =#+end_src= yet) is valid for execution,
enabling users to run queries while still composing them.

#+NAME: block-detect-boundaries
#+BEGIN_SRC elisp
(defun claude-org--in-ai-block-p ()
  "Return t if point is inside a #+begin_src ai block."
  (save-excursion
    (let ((case-fold-search t)
          (pos (point)))
      (when (re-search-backward "^[ \t]*#\\+begin_src[ \t]+ai\\b" nil t)
        (let ((block-start (point)))
          ;; If we find end_src, check we're between begin and end
          ;; If no end_src found, assume we're still inside the block (incomplete block)
          (if (re-search-forward "^[ \t]*#\\+end_src" nil t)
              (and (>= pos block-start)
                   (<= pos (point)))
            ;; No end found, we're in an incomplete block - that's OK
            (>= pos block-start)))))))

(defun claude-org--get-block-content ()
  "Get content of the ai block at point."
  (save-excursion
    (let ((case-fold-search t))
      (when (re-search-backward "^[ \t]*#\\+begin_src[ \t]+ai\\b" nil t)
        (forward-line 1)
        (let ((start (point)))
          (when (re-search-forward "^[ \t]*#\\+end_src" nil t)
            (forward-line 0)
            (string-trim (buffer-substring-no-properties start (point)))))))))

(defun claude-org--find-block-end ()
  "Find position at end of #+end_src line."
  (save-excursion
    (let ((case-fold-search t))
      (when (re-search-forward "^[ \t]*#\\+end_src" nil t)
        (line-end-position)))))

#+END_SRC

Replace the content inside an AI block, preserving the begin/end markers.

** Output Section and Instruction Detection

Output sections (tagged =:ai_output:=) contain Claude's responses.
Instruction detection finds which numbered instruction contains the cursor,
used for maintaining conversation context and navigation.

*** Design Note: Instruction Identification

*IMPORTANT*: Instruction sections are identified by the =:claude_chat:= tag,
NOT by heading text patterns like "Instruction N".

Users may rename instruction headings to descriptive titles like
"Fix Authentication Bug" or "Implement User Dashboard". The system must
work correctly regardless of heading text.

| Identifier | Used For | Example |
|--------------+-------------------------------+-----------------------------------|
| =:claude_chat:= | Finding instruction heading | =** My Task :claude_chat:= |
| =:ai_output:= | Finding response sections | =** Response 1 :ai_output:= |

All functions that need to find instruction sections MUST use
=claude-org--find-instruction-heading= which searches by tag.

#+NAME: block-detect-output-instruction
#+BEGIN_SRC elisp
(defun claude-org--in-output-section-p ()
  "Check if cursor is inside an :ai_output: tagged section.
Returns non-nil if current heading or any parent heading has the output tag."
  (save-excursion
    (let ((tags (org-get-tags nil t)))
      (member claude-org-output-tag tags))))

(defun claude-org--find-instruction-heading ()
  "Find the instruction heading for point.
Instruction headings are identified by the :claude_chat: tag.

Search order:
1. Current heading (if it has :claude_chat: tag)
2. Parent headings (walk up the hierarchy, checking each for tag)
3. At each level, also check previous siblings for the tag

Returns the position of the instruction heading, or nil if not found.

NOTE: This function identifies instructions by TAG, not by heading text.
Headings like \"Fix Bug :claude_chat:\" and \"Instruction 1 :claude_chat:\"
are both valid instruction headings."
  (save-excursion
    (when (ignore-errors (org-back-to-heading t))
      (let ((found nil)
            (done nil))
        ;; Search current heading and all ancestors
        (while (and (not found) (not done))
          ;; Check current heading
          (when (member claude-org-heading-tag (org-get-tags nil t))
            (setq found (point)))
          ;; If not found, check previous siblings at this level
          (unless found
            (let ((current-level (org-current-level))
                  (search-pos (point)))
              (save-excursion
                (while (and (not found)
                            (org-get-previous-sibling))
                  (when (and (= (org-current-level) current-level)
                             (member claude-org-heading-tag (org-get-tags nil t)))
                    (setq found (point)))))
              ;; If still not found, go up one level
              (unless found
                (goto-char search-pos)
                (unless (org-up-heading-safe)
                  ;; Can't go up further, exit loop
                  (setq done t))))))
        found))))

(defun claude-org--find-instruction-number ()
  "Find the next response number for the current instruction section.
Uses `claude-org--find-instruction-heading' to locate the instruction
by its :claude_chat: tag, then counts existing Response N siblings.

Returns the next available response number (max existing + 1).
Returns nil if no instruction heading is found (caller must handle this)."
  (save-excursion
    (let ((instr-pos (claude-org--find-instruction-heading)))
      (when instr-pos
        (goto-char instr-pos)
        (let ((instruction-level (org-current-level))
              (max-response-num 0))
          ;; Search forward for Response N siblings at same level
          (save-excursion
            (while (org-get-next-sibling)
              (when (and (= (org-current-level) instruction-level)
                         (looking-at "^\\*+ Response \\([0-9]+\\)"))
                (let ((num (string-to-number (match-string 1))))
                  (when (> num max-response-num)
                    (setq max-response-num num))))))
          ;; Return next number (max + 1), or 1 if no responses found
          (1+ max-response-num))))))

(defun claude-org--skip-to-after-output-section ()
  "Skip to after the current :ai_output: section.
Moves point to after the output section's subtree, ready to insert sibling."
  (when (claude-org--in-output-section-p)
    (org-back-to-heading t)
    ;; Move to the end of this subtree
    (org-end-of-subtree t t)))

(defun claude-org--heading-matches-auto-title-pattern-p ()
  "Check if current heading matches the auto-title pattern.
Returns the heading text (without stars and tags) if it matches, nil otherwise."
  (save-excursion
    (when (ignore-errors (org-back-to-heading t))
      (let ((heading (org-get-heading t t t t)))  ; no tags, no todo, no priority, no comment
        (when (and heading
                   (string-match-p claude-org-auto-title-heading-pattern heading))
          heading)))))

(defun claude-org--replace-heading-at-marker (marker new-title)
  "Replace heading text at MARKER with NEW-TITLE.
Preserves heading level (stars), tags, and properties."
  (when (and marker (marker-buffer marker) (buffer-live-p (marker-buffer marker)))
    (with-current-buffer (marker-buffer marker)
      (save-excursion
        (goto-char marker)
        (when (ignore-errors (org-back-to-heading t))
          (let* ((tags (org-get-tags nil t))
                 (level (org-current-level))
                 (stars (make-string level ?*))
                 ;; Build tag string manually
                 (tag-str (if tags
                              (concat " :" (mapconcat #'identity tags ":") ":")
                            "")))
            ;; Delete the current heading line (including newline)
            (beginning-of-line)
            (let ((line-start (point)))
              (forward-line 1)
              (delete-region line-start (point)))
            ;; Insert new heading with title and tags on same line
            (insert stars " " new-title tag-str "\n")))))))

(defun claude-org--maybe-auto-generate-title (query heading-marker)
  "Generate title for QUERY and update heading at HEADING-MARKER.
Only runs if `claude-org-auto-generate-title' is non-nil."
  (when claude-org-auto-generate-title
    (lexical-let ((marker heading-marker))
      (claude-agent-generate-title
       `((user . ,query))
       :on-title (lambda (title)
                   (claude-org--replace-heading-at-marker marker title))
       :on-error (lambda (err)
                   (message "Auto-title generation failed: %s" err))))))

(defun claude-org--next-instruction-number ()

*** Tag Selection State

#+NAME: block-insert-tag-state
#+BEGIN_SRC elisp
(defvar claude-org--selected-tags nil
  "Currently selected workflow tags for block insertion.")

(defvar claude-org--discovered-tags-cache nil
  "Cache of discovered tags: (timestamp . tag-list).
Each tag is (key tag description).")

(defconst claude-org--discovered-tags-cache-ttl 5
  "Seconds to cache discovered tags before re-scanning.")

(defun claude-org--discover-tags ()
  "Discover available tags from prompts/tags/ directory.
Returns list of (key tag description) for each tag file.
Results are cached for `claude-org--discovered-tags-cache-ttl' seconds."
  (let* ((now (float-time))
         (cache-time (car claude-org--discovered-tags-cache))
         (cached-tags (cdr claude-org--discovered-tags-cache)))
    (if (and cache-time
             (< (- now cache-time) claude-org--discovered-tags-cache-ttl))
        cached-tags
      ;; Rebuild cache
      (let* ((tag-dir (expand-file-name "tags" claude-org-prompts-directory))
             (files (when (file-directory-p tag-dir)
                      (directory-files tag-dir nil "\\.org$")))
             (tags '())
             (used-keys '()))
        (dolist (file files)
          (let* ((tag-name (file-name-sans-extension file))
                 (file-path (expand-file-name file tag-dir))
                 (desc (claude-org--extract-tag-description file-path))
                 (key (claude-org--assign-tag-key tag-name used-keys)))
            (push key used-keys)
            (push (list key tag-name (or desc (capitalize tag-name))) tags)))
        (setq tags (nreverse tags))
        (setq claude-org--discovered-tags-cache (cons now tags))
        tags))))

(defun claude-org--extract-tag-description (file-path)
  "Extract #+DESCRIPTION: from tag FILE-PATH, or nil if not found."
  (when (file-readable-p file-path)
    (with-temp-buffer
      (insert-file-contents file-path nil 0 500)  ; Read first 500 chars
      (goto-char (point-min))
      (when (re-search-forward "^#\\+DESCRIPTION:\\s-*\\(.+\\)$" nil t)
        (string-trim (match-string 1))))))

(defun claude-org--assign-tag-key (tag-name used-keys)
  "Assign a single-char key for TAG-NAME avoiding USED-KEYS.
Tries first letter, then subsequent letters, then digits."
  (let ((candidates (append (string-to-list (downcase tag-name))
                            (string-to-list "1234567890"))))
    (catch 'found
      (dolist (char candidates)
        (let ((key (char-to-string char)))
          (unless (member key used-keys)
            (throw 'found key))))
      ;; Fallback: use full tag name (shouldn't happen)
      tag-name)))

(defun claude-org--workflow-tags ()
  "Get available workflow tags (dynamic discovery).
Returns list of (key tag description)."
  (claude-org--discover-tags))

**** Finding Previous Chat Level

To insert a new AI block at the correct level, we need to find the most recent
chat section - any heading with =:claude_chat:= tag.

#+NAME: block-find-chat-level
#+BEGIN_SRC elisp
(defun claude-org--find-previous-chat-level ()
  "Find the level of the most recent :claude_chat: section before point.
Searches backwards for any heading with :claude_chat: tag.
Returns the level (integer) or nil if not found."
  (save-excursion
    (save-restriction
      (widen)
      (let ((found-level nil)
            (chat-tag-pattern (format ":%s:" claude-org-heading-tag)))
        ;; Search backwards through all headings
        (while (and (not found-level)
                    (re-search-backward "^\\(\\*+\\) " nil t))
          (let* ((level (length (match-string 1)))
                 (line (buffer-substring-no-properties
                        (point) (line-end-position))))
            ;; Check for :claude_chat: tag only
            (when (string-match-p chat-tag-pattern line)
              (setq found-level level))))
        found-level))))

**** Inserting the Block

#+NAME: block-insert-standard
#+BEGIN_SRC elisp
(defun claude-org--do-insert-block (workflow-tags)
  "Insert an AI block with optional WORKFLOW-TAGS.
WORKFLOW-TAGS is a list of tag strings like (\"research\" \"design\").
Automatically generates a CUSTOM_ID for stable navigation."
  ;; If inside an output section, skip to after it
  (claude-org--skip-to-after-output-section)
  ;; Find the level by looking for the last chat section (heading with :claude_chat: tag)
  (let* ((level (or (claude-org--find-previous-chat-level)
                    (org-current-level)
                    1))
         (stars (make-string level ?*))
         (num (claude-org--next-instruction-number))
         ;; Build tag string: workflow tags + claude-org-heading-tag
         ;; Org format is :tag1:tag2:tag3: - single colons between tags
         (all-tags (append workflow-tags (list claude-org-heading-tag)))
         (tag-str (concat ":" (mapconcat #'identity all-tags ":") ":"))
         ;; Generate CUSTOM_ID for stable navigation
         (file-base (when buffer-file-name (file-name-base buffer-file-name)))
         ;; Wrap session-id lookup to handle edge cases in batch testing
         (session-id (ignore-errors (claude-org--get-session-id)))
         (custom-id (claude-org--generate-instruction-custom-id file-base num session-id)))
    (insert stars " Instruction " (number-to-string num) " " tag-str "\n")
    ;; Add PROPERTIES drawer with CUSTOM_ID
    (when custom-id
      (insert ":PROPERTIES:\n")
      (insert ":CUSTOM_ID: " custom-id "\n")
      (insert ":END:\n"))
    (insert "\n#+begin_src ai\n\n#+end_src\n")
    (forward-line -2)))

(defun claude-org--generate-instruction-custom-id (file-base num session-id)
  "Generate a unique CUSTOM_ID for an instruction block.
FILE-BASE is the org file name without extension.
NUM is the instruction number.
SESSION-ID is the parent section's CLAUDE_SESSION_ID (can be nil).

Returns a string like \"file-instruction-N-session-id-HHMMSS\" with timestamp.
If that ID already exists in the buffer, appends -2, -3, etc. until unique."
  (let ((timestamp (format-time-string "%H%M%S")))
    (when file-base
      (let* ((base-id (if session-id
                          (format "%s-instruction-%d-%s-%s" file-base num session-id timestamp)
                        (format "%s-instruction-%d-%s" file-base num timestamp)))
             (candidate base-id)
             (counter 2))
        ;; Check if ID exists and add -N suffix until unique
        (while (claude-org--custom-id-exists-p candidate)
          (setq candidate (format "%s-%d" base-id counter))
          (setq counter (1+ counter)))
        candidate))))

** Session and Story Blocks

These create blocks with isolated conversation context. Session blocks use the
=:claude_session:= tag for section-scoped isolation. Story blocks use
=CLAUDE_SESSION_ID= property for named, persistent sessions.

| Command | Keybinding | Level Behavior |
|---------+------------+----------------|
| =claude-org-insert-session-block= | | Uses current section level |
| =claude-org-insert-story= | =C-c C-s= | Aligns with previous story, or top level if none |

Story level alignment: When inserting a new story, the function searches backwards
for an existing story section (heading with =CLAUDE_SESSION_ID= starting with "story-").
If found, the new story uses the same level. If no previous story exists, it defaults
to top level (=*=), keeping stories at a consistent hierarchy.

** Prompt Refinement

Refine the current AI block prompt using Claude's assistance.

#+NAME: block-refine-prompt
#+BEGIN_SRC elisp
(defun claude-org-refine-prompt ()
  "Refine the AI prompt in the current block.
Prompts for refinement intent, then calls Claude to improve the prompt.
Result directly replaces block content. Use \\[undo] to revert."
  (interactive)
  (unless (claude-org--in-ai-block-p)
    (user-error "Not inside an AI block"))
  (let* ((content (claude-org--get-block-content))
         intent)
    (unless content
      (user-error "Could not extract block content (missing #+end_src?)"))
    ;; Empty content is allowed - user can describe what they want to write
    (setq intent (read-string "How to refine the prompt? "))
    (when (string-empty-p intent)
      (user-error "Refinement intent cannot be empty"))
    (message "Refining prompt...")
    ;; Use lexical-let to capture buffer/marker for async callback
    ;; (literate-elisp uses dynamic binding; plain let variables go void)
    (lexical-let ((source-buffer (current-buffer))
                  (source-marker (point-marker)))
      (claude-agent-refine-prompt
       content intent
       :on-result (lambda (refined)
                    (if (buffer-live-p source-buffer)
                        (with-current-buffer source-buffer
                          (save-excursion
                            (goto-char source-marker)
                            (if (claude-org--replace-block-content refined)
                                (message "Prompt refined. Use C-/ to undo if needed.")
                              (message "Failed to replace block content"))))
                      (message "Source buffer no longer exists")))
       :on-error (lambda (err) (message "Refinement failed: %s" err))))))

#+BEGIN_SRC elisp
(defun claude-org--scan-command-dir (dir)
  "Scan DIR for .md files and return list of slash commands.
Subdirectories create namespaced commands with : separator.
Example: dir/custom/test.md becomes /custom:test"
  (when (file-directory-p dir)
    (let ((commands nil))
      (dolist (file (directory-files-recursively dir "\\.md$"))
        (let* ((relative (file-relative-name file dir))
               (parts (split-string relative "/"))
               (name (file-name-sans-extension (car (last parts))))
               (namespace (butlast parts)))
          (push (if namespace
                    (concat "/" (mapconcat #'identity namespace ":") ":" name)
                  (concat "/" name))
                commands)))
      commands)))

(defun claude-org--scan-plugin-commands ()
  "Scan plugin commands from ~/.claude/plugins/marketplaces/*/plugins/*/commands/*.md.
Returns list of slash commands with plugin namespace.
Example: /plugin-name:command"
  (let ((commands nil)
        (plugins-dir (expand-file-name "~/.claude/plugins")))
    (when (file-directory-p plugins-dir)
      ;; Scan both direct plugins and marketplace plugins
      (dolist (search-pattern (list (expand-file-name "*/commands" plugins-dir)
                                     (expand-file-name "marketplaces/*/plugins/*/commands" plugins-dir)))
        (dolist (commands-dir (file-expand-wildcards search-pattern))
          (when (file-directory-p commands-dir)
            (let* ((plugin-dir (file-name-directory (directory-file-name commands-dir)))
                   (plugin-name (file-name-nondirectory (directory-file-name plugin-dir))))
              ;; Only scan root of commands/ (flat, no recursion)
              (dolist (file (directory-files commands-dir nil "\\.md$"))
                (let ((cmd-name (file-name-sans-extension file)))
                  (push (concat "/" plugin-name ":" cmd-name) commands))))))))
    commands))

(defun claude-org--discover-slash-commands ()
  "Discover all available slash commands from user, project, and plugins.
Returns list of command strings with / prefix."

    ;; Add user commands

    ;; Add project commands if PROJECT_ROOT is set

* Response Handling

Response handling for streaming tokens.

** Response Section Boundary Detection

Since Instruction and Response sections are siblings at the same level,
=org-end-of-subtree= doesn't include Response sections. We need custom
boundary detection to find where to insert new responses.

#+BEGIN_SRC elisp
(defun claude-org--find-response-boundary ()
  "Find the boundary for searching response sections.
Returns point of next non-:ai_output: sibling at same level,
or next heading at higher level (parent boundary), or point-max.

This is needed because Instruction and Response are SIBLINGS,
not parent-child, so `org-end-of-subtree' doesn't include responses."
  (save-excursion
    (let ((current-level (org-current-level)))
      (org-end-of-subtree t)  ; Move past current heading's content
      (let ((found nil))
        (while (and (not found)
                    (re-search-forward "^\\*+ " nil t))
          (let ((heading-level (1- (- (match-end 0) (match-beginning 0)))))
            (cond
             ;; Higher level (less stars) = parent boundary
             ((< heading-level current-level)
              (setq found (match-beginning 0)))
             ;; Same level = check if :ai_output: sibling
             ((= heading-level current-level)
              (save-excursion
                (goto-char (match-beginning 0))
                (unless (looking-at (format ".*:%s:" claude-org-output-tag))
                  ;; Not an output section = boundary
                  (setq found (match-beginning 0))))))))
        (or found (point-max))))))

(defun claude-org--find-last-ai-output-sibling ()
  "Find the last :ai_output: sibling section.
Returns point at END of that section, or nil if none found."
  (save-excursion
    (let* ((current-level (org-current-level))
           (block-end (claude-org--find-block-end))
           (boundary (claude-org--find-response-boundary))
           (last-output-end nil)
           (output-pattern (format "^\\*\\{%d\\} .*:%s:"
                                   current-level claude-org-output-tag)))
      (when block-end
        (goto-char block-end)
        (while (re-search-forward output-pattern boundary t)
          (setq last-output-end
                (save-excursion (org-end-of-subtree t) (point)))))
      last-output-end)))

(defun claude-org--find-response-insert-point ()
  "Find insertion point for new response section.
Returns point after last :ai_output: sibling, or after #+end_src."
  (or (claude-org--find-last-ai-output-sibling)
      (claude-org--find-block-end)))

(defun claude-org--create-response-section-header (instr-num timestamp &optional loop-info section-level)
  "Create response section header string.
INSTR-NUM is the instruction number (can be nil for non-Instruction headings).
TIMESTAMP is from LAST_AI_EXECUTED property (YYYY-MM-DD HH:MM:SS format).
LOOP-INFO is (CURRENT . MAX) for loop iterations, or nil.
SECTION-LEVEL is the heading level for the Response section.

Returns a string like: \"** Response 1 (2025-01-13 08:00) :ai_output:\""
  (let* ((level (or section-level (claude-org--get-section-level)))
         (stars (make-string level ?*))
         ;; Trim seconds for cleaner display: "2025-01-13 08:00:15" -> "2025-01-13 08:00"
         (display-time (if (and timestamp (> (length timestamp) 16))
                           (substring timestamp 0 16)
                         (or timestamp (format-time-string "%Y-%m-%d %H:%M"))))
         (loop-suffix (if loop-info
                          (format "(%d/%d)" (car loop-info) (cdr loop-info))
                        ""))
         (instr-part (if instr-num
                         (format " %d" instr-num)
                       "")))
    (format "%s Response%s%s (%s) :%s:\n\n"
            stars instr-part loop-suffix display-time claude-org-output-tag)))

** Header Normalization

Normalize org headers in Claude's output to fit the document hierarchy.
Headers are adjusted so Claude's top-level (=*=) becomes the target level.

Uses simple regex replacement - no buffering needed since =^= matches
both start of string and start of line (after newline).

#+BEGIN_SRC elisp
(defun claude-org--normalize-headers-in-text (text target-level)
  "Normalize org headers in TEXT to start at TARGET-LEVEL.
Headers at line start are adjusted: Claude's level N becomes target-level + (N-1).
Only lines starting with asterisks followed by space are treated as headers.
Also normalizes line endings: \\r\\n (DOS) and \\r (old Mac) become \\n.
No buffering - processes each token independently using regex."
  ;; Normalize line endings: \r\n -> \n, then \r -> \n
  (let ((clean-text (replace-regexp-in-string "\r\n?" "\n" text)))
    (if (not claude-org-normalize-headers)
        clean-text
      (let ((offset (1- target-level)))
        (replace-regexp-in-string
         "^\\(\\*+\\) "
         (lambda (match)
           (let* ((stars (match-string 1 match))
                  (new-level (+ (length stars) offset)))
             (concat (make-string (max 1 new-level) ?*) " ")))
         clean-text)))))

(defun claude-org--auto-break-lines (text current-line-length)
  "Auto-break long lines in TEXT after sentence-ending punctuation.
CURRENT-LINE-LENGTH is the length of the current line before this text.
Returns (NEW-TEXT . NEW-LINE-LENGTH) cons cell.
Only active when `claude-org-auto-break-line-length' is positive."
  (if (< claude-org-auto-break-line-length 1)
      ;; Disabled - return text unchanged, update line length
      (let ((last-newline (string-match-p "\n[^\n]*\\'" text)))
        (cons text
              (if last-newline
                  (- (length text) last-newline 1)
                (+ current-line-length (length text)))))
    ;; Enabled - process text for line breaks
    (let ((result "")
          (line-len current-line-length)
          (threshold claude-org-auto-break-line-length)
          (i 0)
          (len (length text)))
      (while (< i len)
        (let ((char (aref text i)))
          ;; Always add char to result and increment line length first
          (setq result (concat result (char-to-string char)))
          (setq line-len (1+ line-len))
          (cond
           ;; Newline resets counter
           ((= char ?\n)
            (setq line-len 0))
           ;; Check for sentence-ending punctuation followed by space
           ;; Break if line length exceeds threshold
           ((and (>= line-len threshold)
                 (memq char '(?. ?! ?\?))
                 (< (1+ i) len)
                 (= (aref text (1+ i)) ?\s))
            ;; Insert newline after the punctuation
            (setq result (concat result "\n"))
            (setq line-len 0))))
        (setq i (1+ i)))
      (cons result line-len))))
#+END_SRC

** Token Handling

#+BEGIN_SRC elisp
(defun claude-org--handle-token (session-key text)
  "Handle incoming TEXT token for SESSION-KEY.
Normalizes org headers, auto-breaks long lines, and inserts text at the session's marker.
If marker is invalid (buffer killed), this function does nothing."
  (let ((marker (claude-org--session-get session-key :marker)))
    (claude-org--with-session-marker marker
      (let* ((target-level (1+ (or (claude-org--session-get session-key :section-level) 0)))
             (normalized-text (claude-org--normalize-headers-in-text text target-level))
             ;; Auto-break long lines
             (current-line-len (or (claude-org--session-get session-key :current-line-length) 0))
             (break-result (claude-org--auto-break-lines normalized-text current-line-len))
             (final-text (car break-result))
             (new-line-len (cdr break-result)))
        ;; Update line length state
        (claude-org--session-put session-key :current-line-length new-line-len)
        ;; Insert processed text
        (when (> (length final-text) 0)
          (save-excursion
            (goto-char marker)
            (insert final-text)
            (set-marker marker (point)))))
      (claude-org--schedule-fontlock))))

#+BEGIN_SRC elisp
(defun claude-org--format-todo-item (todo)
  "Format a single TODO item as org checkbox.
TODO is a plist with :content, :status, and :activeForm.
When status is in_progress, show activeForm instead of content
since activeForm is the present continuous form of the same task."
  (let* ((content (plist-get todo :content))
         (status (plist-get todo :status))
         (active-form (plist-get todo :activeForm))
         (checkbox (pcase status
                     ("completed" "[X]")
                     ("in_progress" "[-]")
                     (_ "[ ]")))
         ;; Use activeForm for in_progress, content otherwise
         (display-text (if (and (string= status "in_progress") active-form)
                           active-form
                         content)))
    (format "- %s %s" checkbox display-text)))

(defun claude-org--find-instruction-heading-for-session (session-key)
  "Find the instruction heading position for SESSION-KEY.
Uses the stored custom-id to locate the heading.
Returns marker position or nil if not found."
  (let ((custom-id (claude-org--session-get session-key :custom-id)))
    (when custom-id
      (save-excursion
        (goto-char (point-min))
        (when (re-search-forward
               (format ":CUSTOM_ID: %s" (regexp-quote custom-id)) nil t)
          (org-back-to-heading t)
          (point))))))

(defun claude-org--find-todo-region (heading-pos)
  "Find existing todo list region after HEADING-POS.
Looks for checkbox list between #+end_src and the next heading or marker.
Returns (BEG . END) of the region, or nil if no todos found."
  (save-excursion
    (goto-char heading-pos)
    ;; Find the #+end_src of the ai block
    (when (re-search-forward "^#\\+end_src" nil t)
      (forward-line 1)
      (let ((search-start (point))
            (search-end (save-excursion
                          ;; Find next heading or end of buffer
                          (if (re-search-forward "^\\*+ " nil t)
                              (line-beginning-position)
                            (point-max)))))
        ;; Look for checkbox list in this region
        (when (re-search-forward "^- \\[[ X-]\\]" search-end t)
          (goto-char (line-beginning-position))
          (let ((beg (point)))
            ;; Find end of checkbox list
            (while (and (< (point) search-end)
                        (looking-at "^- \\[[ X-]\\]"))
              (forward-line 1))
            ;; Include trailing blank line if present
            (when (and (< (point) search-end)
                       (looking-at "^$"))
              (forward-line 1))
            (cons beg (point))))))))

(defun claude-org--compute-todo-cookie (todos)
  "Compute statistics cookie string from TODOS list.
Returns string like \"[2/5]\" showing completed/total."
  (let ((total (length todos))
        (completed (cl-count-if
                    (lambda (todo)
                      (string= (plist-get todo :status) "completed"))
                    todos)))
    (format "[%d/%d]" completed total)))

(defun claude-org--update-heading-cookie (heading-pos cookie-str)
  "Update or add statistics cookie in heading at HEADING-POS.
COOKIE-STR is like \"[2/5]\". Replaces existing cookie or adds before tags."
  (save-excursion
    (goto-char heading-pos)
    (let ((line-end (line-end-position)))
      ;; Check if there's already a cookie [N/M] or [N%]
      (if (re-search-forward "\\[\\([0-9]+/[0-9]+\\|[0-9]+%\\)\\]" line-end t)
          ;; Replace existing cookie
          (replace-match cookie-str t t)
        ;; No cookie - add before tags or at end of heading text
        (goto-char heading-pos)
        ;; Skip past the stars and heading text to find insertion point
        (if (re-search-forward "[ \t]+\\(:[^ \t\n:]+:\\)+[ \t]*$" line-end t)
            ;; Has tags - insert before the space+tags
            (progn
              (goto-char (match-beginning 0))
              (insert " " cookie-str))
          ;; No tags - insert at end of line
          (end-of-line)
          (insert " " cookie-str))))))

(defun claude-org--update-todos-in-place (session-key todos)
  "Update todo list in place for SESSION-KEY with TODOS.
Finds the instruction heading via custom-id, updates the checkbox list
between #+end_src and Response section, and updates the heading cookie."
  (let ((heading-pos (claude-org--find-instruction-heading-for-session session-key)))
    (when heading-pos
      (save-excursion
        ;; Update heading cookie
        (claude-org--update-heading-cookie
         heading-pos
         (claude-org--compute-todo-cookie todos))
        ;; Format the new todo list (with trailing newline for spacing)
        (let ((new-todos-text (concat (mapconcat #'claude-org--format-todo-item todos "\n") "\n\n"))
              (existing-region (claude-org--find-todo-region heading-pos)))
          (if existing-region
              ;; Replace existing todo list
              (progn
                (delete-region (car existing-region) (cdr existing-region))
                (goto-char (car existing-region))
                (insert new-todos-text))
            ;; No existing todos - insert after #+end_src
            (goto-char heading-pos)
            (when (re-search-forward "^#\\+end_src" nil t)
              (forward-line 1)
              ;; Skip any blank lines
              (while (looking-at "^$")
                (forward-line 1))
              ;; Insert before current position (which might be Response heading)
              (insert "\n" new-todos-text))))))))

(defun claude-org--handle-tool-use (session-key tool-name tool-input)
  "Handle special TOOL-NAME with TOOL-INPUT for SESSION-KEY.
For TodoWrite: updates in-place under instruction heading, returns nil.
For other tools: returns formatted string to insert, or nil if not special."
  (pcase tool-name
    ("TodoWrite"
     (let ((todos (plist-get tool-input :todos)))
       ;; Update todos in-place under instruction heading (not at marker)
       (claude-org--update-todos-in-place session-key todos)
       ;; Return nil so nothing is inserted at streaming marker
       nil))
    (_ nil)))

(defun claude-org--handle-message (session-key msg)
  "Handle incoming MSG for SESSION-KEY.
Extracts session ID from result messages and stores it."
  ;; Store SDK UUID to org property when we get a result message
  (when (claude-agent-result-message-p msg)
    (let ((sdk-uuid (claude-agent-result-message-session-id msg))
          (marker (claude-org--session-get session-key :marker)))
      (when (and sdk-uuid marker (marker-buffer marker))
        ;; Store in session state for extraction to use
        (claude-org--session-put session-key :sdk-uuid sdk-uuid)
        (with-current-buffer (marker-buffer marker)
          (save-excursion
            (goto-char marker)
            (claude-org--set-sdk-uuid sdk-uuid))))))
  ;; Handle special tool uses in assistant messages
  (when (claude-agent-assistant-message-p msg)
    ;; Store query-id that produced this assistant message.
    ;; In handle-token-v2, we insert a newline separator only when the
    ;; current query-id matches this stored id — meaning a previous
    ;; assistant message already produced output in this same query.
    ;; Using query-id instead of a boolean avoids stale-flag issues across
    ;; queries: a leftover value from query N cannot affect query N+1
    ;; because their query-ids differ.
    (claude-org--session-put session-key :last-assistant-query-id
                             (claude-org--session-get session-key :query-id))
    (let ((marker (claude-org--session-get session-key :marker)))
      (when (and marker (marker-buffer marker))
        (dolist (block (claude-agent-assistant-message-content msg))
          (when (claude-agent-tool-use-block-p block)
            (let* ((tool-name (claude-agent-tool-use-block-name block))
                   (tool-input (claude-agent-tool-use-block-input block))
                   (formatted (claude-org--handle-tool-use session-key tool-name tool-input)))
              (when formatted
                (with-current-buffer (marker-buffer marker)
                  (save-excursion
                    (goto-char marker)
                    (insert formatted)
                    (set-marker marker (point)))))))))))
  ;; Display system messages if enabled
  (when (and claude-org-show-system-messages
             (claude-agent-system-message-p msg))
    (let ((marker (claude-org--session-get session-key :marker)))
      (when (and marker (marker-buffer marker))
        (with-current-buffer (marker-buffer marker)
          (save-excursion
            (goto-char marker)
            (insert (format "\n[System: %s]\n"
                            (claude-agent-system-message-subtype msg)))
            (set-marker marker (point))))))))

(defun claude-org--maybe-continue-loop (session-key)
  "Continue loop execution by starting the next iteration.
Called from handle-complete only when loop-current < loop-max (caller
already verified continuation is needed).  Increments the loop counter
and either schedules delayed execution or runs immediately."
  (let* ((loop-current (or (claude-org--session-get session-key :loop-current) 1))
         (loop-max (or (claude-org--session-get session-key :loop-max) 1))
         (loop-interval (or (claude-org--session-get session-key :loop-interval) 0))
         (original-prompt (claude-org--session-get session-key :original-prompt))
         (instr-num (claude-org--session-get session-key :instruction-num))
         (custom-id (claude-org--session-get session-key :custom-id))
         (next-iteration (1+ loop-current)))
    ;; Increment loop counter
    (claude-org--session-put session-key :loop-current next-iteration)
    ;; Schedule next iteration
    (if (> loop-interval 0)
        ;; Delayed execution
        (run-at-time loop-interval nil
                     #'claude-org--execute-loop-iteration
                     session-key next-iteration loop-max original-prompt
                     instr-num custom-id loop-interval)
      ;; Immediate execution
      (claude-org--execute-loop-iteration
       session-key next-iteration loop-max original-prompt
       instr-num custom-id loop-interval))))

(defun claude-org--execute-loop-iteration (session-key iteration max prompt instr-num custom-id interval)
  "Execute a single loop iteration.
SESSION-KEY identifies the session.
ITERATION is current iteration number (1-based).
MAX is total iterations.
PROMPT is the original query.
INSTR-NUM and CUSTOM-ID are for session manager display.
INTERVAL is delay between iterations (for display).

Creates a proper response section with :QUERY_ID: property at the correct
position (after the previous iteration's response section, found via query-id
lookup).  This ensures tokens are routed to the new section, not the old one."
  ;; Get buffer from session marker (needed when called via run-at-time)
  (let ((marker (claude-org--session-get session-key :marker)))
    (when (and marker (marker-buffer marker))
      (with-current-buffer (marker-buffer marker)
        ;; Set busy state
        (claude-org--session-put session-key :busy t)
        (claude-org--session-put session-key :start-time (float-time))
        ;; Start spinner
        (claude-org--start-spinner session-key)
        ;; Generate new query-id for this iteration (tokens route via query-id)
        (let* ((old-query-id (claude-org--session-get session-key :query-id))
               (new-query-id (claude-org--generate-query-id))
               ;; Find end of previous response section by old query-id
               (insert-pos (claude-org--find-response-end-by-query-id old-query-id)))
          ;; Store new query-id BEFORE creating section (callbacks read it)
          (claude-org--session-put session-key :query-id new-query-id)
          ;; Create response section at correct position (after previous response)
          ;; If insert-pos is nil (e.g. response section deleted), abort iteration
          (if (not insert-pos)
              (progn
                (message "Claude loop: cannot find previous response section, aborting iteration %d" iteration)
                (claude-org--session-put session-key :busy nil)
                (claude-org--stop-spinner session-key))
            (save-excursion
              (goto-char insert-pos)
              (insert "\n\n")
              (claude-org--create-response-section
               session-key new-query-id 'normal
               nil nil (cons iteration max)))
            ;; Build query-context with updated iteration
            (let ((query-ctx (when instr-num
                               (claude-agent-make-query-context
                                :instruction-num instr-num
                                :loop-current iteration
                                :loop-max max
                                :custom-id custom-id))))
              ;; Send request (uses continue-conversation for context)
              (claude-org--send-request prompt query-ctx session-key))))))))

(defun claude-org--free-marker (session-key)
  "Free marker for SESSION-KEY to prevent memory leak.
Markers hold references to buffers; must be explicitly freed."
  (when-let ((marker (claude-org--session-get session-key :marker)))
    (when (markerp marker)
      (set-marker marker nil))
    (claude-org--session-put session-key :marker nil)))

(defun claude-org--unregister-active-query (session-key)
  "Cancel and clean up the active query for SESSION-KEY.
This ensures the mode-line spinner and *Claude Queries* buffer reflect the
terminal state immediately, without waiting for the CLI process to exit."
  (when-let* ((backend (claude-org--session-get session-key :backend))
              (handle (claude-org--session-get session-key :query-handle)))
    (claude-agent-backend-cancel backend handle)))

(defun claude-org--handle-complete (session-key result)
  "Handle query completion for SESSION-KEY with RESULT.
Uses query-id based architecture with marker for queue duplicate detection.

IMPORTANT: Loop continuation check must happen BEFORE freeing the marker,
because execute-loop-iteration needs the marker to find the buffer.
When the loop continues, :busy and :marker are kept alive for the next
iteration (including across run-at-time delays for :interval)."
  (claude-org--stop-spinner session-key)
  ;; Add newline after response using query-id lookup (marker-free)
  (let ((query-id (claude-org--session-get session-key :query-id)))
    (when query-id
      (claude-org--insert-at-response session-key "\n")))
  ;; Update header line
  (claude-org--refresh-header-line)
  ;; Run completion hook (no marker to pass - we're marker-free)
  (run-hook-with-args 'claude-org-complete-hook session-key result 'completed)
  ;; Check loop state BEFORE any cleanup - execute-loop-iteration needs :marker
  (let* ((loop-current (or (claude-org--session-get session-key :loop-current) 1))
         (loop-max (or (claude-org--session-get session-key :loop-max) 1))
         (should-continue (< loop-current loop-max)))
    (if should-continue
        ;; Loop has more iterations: keep :busy and :marker alive,
        ;; clear only transient flags, then trigger next iteration
        (progn
          (claude-org--session-put session-key :recovering nil)
          (claude-org--session-put session-key :last-assistant-query-id nil)
          (claude-org--maybe-continue-loop session-key))
      ;; Loop complete (or single-shot) - full cleanup
      (unless (equal (claude-org--get-exec-status-for-session session-key) "cancelled")
        (claude-org--set-exec-status-for-session session-key "completed"))
      (claude-org--reset-session-state session-key)
      (claude-org--free-marker session-key)
      ;; Process pending queue
      (let ((next-block (claude-org--dequeue-block session-key)))
        (if next-block
            (claude-org--execute-queued-block session-key next-block)
          ;; Truly done - unregister from active queries so mode-line and
          ;; *Claude Queries* buffer reflect completion immediately
          (claude-org--unregister-active-query session-key))))))

(defun claude-org--extract-error-message (error)
  "Extract human-readable message from ERROR.
ERROR can be (symbol :message ...) plist, a string, or other."
  (cond
   ;; CLI error: (claude-agent-cli-error :message "..." ...) - plist starts at cdr
   ((and (listp error) (symbolp (car error)) (plist-get (cdr error) :message))
    (plist-get (cdr error) :message))
   ;; Plain plist with :message
   ((and (listp error) (plist-get error :message))
    (plist-get error :message))
   ;; String error
   ((stringp error) error)
   ;; Symbol error (e.g., 'error)
   ((symbolp error) (symbol-name error))
   ;; List with error symbol and details: (error "message" ...)
   ((and (listp error) (eq (car error) 'error) (stringp (cadr error)))
    (cadr error))
   ;; Any list - try to extract meaningful string
   ((listp error)
    (let ((str (format "%S" error)))
      (if (> (length str) 200)
          (concat (substring str 0 197) "...")
        str)))
   ;; Fallback: convert to string representation
   (t (let ((str (format "%S" error)))
        (if (> (length str) 200)
            (concat (substring str 0 197) "...")
          str)))))

(defun claude-org--handle-error (session-key error)
  "Handle error ERROR for SESSION-KEY.
Attempts session recovery if error indicates expired session or context too long.
If already recovering and another error occurs, give up and show error to user."
  (let ((error-msg (claude-org--extract-error-message error))
        (is-recovering (claude-org--session-get session-key :recovering))
        (backend (claude-org--session-get session-key :backend)))
    (cond
     ;; Already recovering and hit another error - give up to prevent infinite loop
     (is-recovering
      (message "Claude: Recovery failed with error: %s" error-msg)
      (claude-org--insert-error session-key
                                (format "Recovery failed: %s" error-msg)))
     ;; Use backend protocol for error classification (backend-agnostic)
     (t
      (pcase (if backend
                 (claude-agent-backend-classify-error backend error-msg)
               'unknown)
        ('context-limit
         (message "Claude context limit reached, starting fresh session with history...")
         (claude-org--recover-session session-key 'context-limit))
        ('session-expired
         (message "Claude session expired, starting new session...")
         (claude-org--recover-session session-key 'expired))
        (_
         (claude-org--insert-error session-key error-msg)))))))

(defun claude-org--insert-error (session-key error-msg)
  "Insert ERROR-MSG at SESSION-KEY's marker and clean up.
CRITICAL: This function MUST clear :recovering flag to prevent stuck state."
  (claude-org--reset-session-state session-key)  ; CRITICAL: Clears :recovering to prevent stuck state
  (claude-org--stop-spinner session-key)
  (let ((marker (claude-org--session-get session-key :marker)))
    (claude-org--with-session-marker marker
      (save-excursion
        (goto-char marker)
        (insert (format "\n[Error: %s]\n" error-msg)))))
  ;; Set error status on the heading
  (when-let ((custom-id (claude-org--session-get session-key :custom-id)))
    (save-excursion
      (when (claude-org--goto-block-by-custom-id custom-id)
        (claude-org--set-exec-status "error"))))
  ;; Free marker to prevent memory leak
  (claude-org--free-marker session-key)
  ;; Clear pending queue on error (don't continue with queued blocks)
  ;; Also clear scheduled status from queued blocks
  (let ((queue (claude-org--session-get session-key :pending-queue)))
    (when queue
      (dolist (block-info queue)
        (when-let ((queued-marker (plist-get block-info :marker)))
          (when (and queued-marker (marker-buffer queued-marker))
            (with-current-buffer (marker-buffer queued-marker)
              (save-excursion
                (goto-char queued-marker)
                (claude-org--set-exec-status nil))))))  ; Clear scheduled status
      (claude-org--clear-queue session-key)
      (message "Cleared %d queued block(s) due to error" (length queue))))
  ;; Unregister from active queries so mode-line/queries buffer update immediately
  (claude-org--unregister-active-query session-key)
  (claude-org--refresh-header-line)
  ;; Run completion hook with error status
  (run-hook-with-args 'claude-org-complete-hook session-key error-msg 'error))

(defun claude-org--history-file-path ()
  "Return path to history file for current buffer.
Uses format: <basename>--<short-hash>.el for readability."
  (let* ((org-path (buffer-file-name))
         (basename (file-name-sans-extension
                    (file-name-nondirectory org-path)))
         (hash (substring (md5 org-path) 0 8))
         (dir claude-org-history-directory))
    (expand-file-name (format "%s--%s.el" basename hash) dir)))

(defun claude-org--ensure-history-directory ()
  "Ensure the history directory exists."
  (unless (file-directory-p claude-org-history-directory)
    (make-directory claude-org-history-directory t)))

(defun claude-org--load-history ()
  "Load history from disk for current buffer."
  (when (and (buffer-file-name)
             (not claude-org--history-loaded))
    (let ((history-file (claude-org--history-file-path))
          (current-org-file (buffer-file-name))
          (loaded-blocks nil))
      (when (file-exists-p history-file)
        (condition-case err
            (setq loaded-blocks
                  (with-temp-buffer
                    (insert-file-contents history-file)
                    (let ((data (read (current-buffer))))
                      (when (and (plist-get data :blocks)
                                 (string= (plist-get data :org-file)
                                          current-org-file))
                        (plist-get data :blocks)))))
          (error
           (message "claude-org: Failed to load history: %s" err))))
      (when loaded-blocks
        (setq claude-org--block-history loaded-blocks)))
    (setq claude-org--history-loaded t)))

(defun claude-org--save-history ()
  "Save history to disk for current buffer (debounced)."
  (when (buffer-file-name)
    ;; Cancel existing timer
    (when claude-org--history-save-timer
      (cancel-timer claude-org--history-save-timer))
    ;; Schedule save
    (setq claude-org--history-save-timer
          (run-with-timer
           claude-org--history-save-delay nil
           (lambda (buf)
             (when (buffer-live-p buf)
               (with-current-buffer buf
                 (claude-org--save-history-now))))
           (current-buffer)))))

(defun claude-org--save-history-now ()
  "Immediately save history to disk."
  (when (and (buffer-file-name) claude-org--block-history)
    (claude-org--ensure-history-directory)
    (let ((history-file (claude-org--history-file-path))
          (data `(:version 2  ; Version 2: Added :custom-id for stable navigation
                  :org-file ,(buffer-file-name)
                  :updated ,(float-time)
                  :blocks ,(claude-org--prepare-history-for-save))))
      (with-temp-file history-file
        (insert ";; -*- mode: lisp-data -*-\n")
        (insert ";; Claude-org block history - do not edit\n")
        ;; `pp' respects `print-length' and `print-level' global settings.
        ;; If user has these set (e.g., for debugging), large history data
        ;; gets truncated with "..." which becomes symbol `\...' when read
        ;; back, corrupting the history.  Bind to nil to ensure full output.
        (let ((print-length nil)
              (print-level nil))
          (pp data (current-buffer)))))))

(defun claude-org--prepare-history-for-save ()
  "Prepare history for saving by removing transient data.
Keeps only the most recent entries, limited by `claude-org-history-max-entries'.
Only saves entries with CUSTOM_ID - titles are built dynamically."
  (let ((entries (cl-remove-if-not
                  (lambda (entry) (plist-get (cdr entry) :custom-id))
                  (mapcar
                   (lambda (entry)
                     (let ((id (car entry))
                           (plist (cdr entry)))
                       ;; Only keep timestamp, status, and custom-id
                       (cons id (list :timestamp (plist-get plist :timestamp)
                                      :status (plist-get plist :status)
                                      :custom-id (plist-get plist :custom-id)))))
                   claude-org--block-history)))
        (limit claude-org-history-max-entries))
    ;; Sort by timestamp, keep most recent
    (setq entries (sort entries
                        (lambda (a b)
                          (> (or (plist-get (cdr a) :timestamp) 0)
                             (or (plist-get (cdr b) :timestamp) 0)))))
    (seq-take entries limit)))

(defun claude-org--ensure-history-loaded ()
  "Ensure history is loaded from disk."
  (unless claude-org--history-loaded
    (claude-org--load-history)))

(defun claude-org--find-instruction-custom-id ()
  "Find the CUSTOM_ID of the instruction heading containing point.
Checks: immediate heading, previous siblings at same level, then parent headings.
Returns CUSTOM_ID string or nil if not found."
  (save-excursion
    (let ((custom-id nil))
      ;; First check the immediate containing heading
      (ignore-errors
        (org-back-to-heading t)
        (when (member "claude_chat" (org-get-tags nil t))
          (setq custom-id (org-entry-get nil "CUSTOM_ID"))))
      ;; Check previous siblings at same level (Response is sibling to Instruction)
      (when (not custom-id)
        (let ((current-level (org-current-level)))
          (while (and (not custom-id)
                      (org-get-previous-sibling))
            (when (and (= (org-current-level) current-level)
                       (member "claude_chat" (org-get-tags nil t)))
              (setq custom-id (org-entry-get nil "CUSTOM_ID"))))))
      ;; If still not found, walk up parent headings
      (while (and (not custom-id) (org-up-heading-safe))
        (when (member "claude_chat" (org-get-tags nil t))
          (setq custom-id (org-entry-get nil "CUSTOM_ID"))))
      custom-id)))

(defun claude-org-goto-custom-id (custom-id)
  "Navigate to the heading with CUSTOM_ID.
This is used as a source-location-fn for session manager navigation.
Returns t if found and positioned, nil otherwise."
  (goto-char (point-min))
  (when (re-search-forward
         (format ":CUSTOM_ID: %s" (regexp-quote custom-id)) nil t)
    (org-back-to-heading t)
    t))

(defun claude-org--record-block-execution (session-key _query _marker)
  "Record block execution start.
SESSION-KEY identifies the session.
Called from `claude-org-execute-hook' when point is still in the AI block.
Only stores CUSTOM_ID - titles are built dynamically when listing.
Blocks without CUSTOM_ID are not recorded.
If block with same CUSTOM_ID exists, updates it instead of creating duplicate."
  (claude-org--ensure-history-loaded)
  (let ((custom-id (claude-org--find-instruction-custom-id)))
    ;; Only record if we have a CUSTOM_ID
    (when custom-id
      ;; Check if entry with this CUSTOM_ID already exists
      (let ((existing (cl-find-if (lambda (e)
                                    (and (listp e) (string= (plist-get (cdr e) :custom-id) custom-id)))
                                  claude-org--block-history)))
        (if existing
            ;; Update existing entry - move to front and update timestamp/status
            (progn
              (setq claude-org--block-history (delete existing claude-org--block-history))
              (let ((updated-entry `(,(car existing)
                                     :timestamp ,(float-time)
                                     :status in-progress
                                     :custom-id ,custom-id)))
                (push updated-entry claude-org--block-history)
                (claude-org--session-put session-key :block-id (car existing))))
          ;; Create new entry
          (let* ((block-id (format "block-%s-%s"
                                   (substring custom-id (max 0 (- (length custom-id) 20)))
                                   (format-time-string "%H%M%S")))
                 (entry `(:timestamp ,(float-time)
                          :status in-progress
                          :custom-id ,custom-id)))
            (push (cons block-id entry) claude-org--block-history)
            (claude-org--session-put session-key :block-id block-id)))
        ;; Trigger debounced save
        (claude-org--save-history)))))

(defun claude-org--update-block-status (session-key _result status)
  "Update block status on completion.
SESSION-KEY identifies the session, STATUS is `completed' or `error'."
  (let ((block-id (claude-org--session-get session-key :block-id)))
    (when block-id
      (let ((entry (assoc block-id claude-org--block-history)))
        (when entry
          (plist-put (cdr entry) :status status)
          (claude-org--save-history))))))

(add-hook 'claude-org-complete-hook #'claude-org--update-block-status)

(defun claude-org--format-time-ago (timestamp)
  "Format TIMESTAMP as relative time string."
  (let* ((now (float-time))
         (diff (- now timestamp))
         (minutes (floor (/ diff 60)))
         (hours (floor (/ diff 3600)))
         (days (floor (/ diff 86400))))
    (cond
     ((< diff 60) "just now")
     ((< minutes 60) (format "%dm ago" minutes))
     ((< hours 24) (format "%dh ago" hours))
     (t (format "%dd ago" days)))))

(defun claude-org--extract-query-title-from-ai-block ()
  "Extract a title from the first AI block in current subtree.
Returns first line of query content, truncated to 60 chars."
  (save-excursion
    (let ((subtree-end (save-excursion (org-end-of-subtree t) (point))))
      (when (re-search-forward "#\\+begin_src ai" subtree-end t)
        (forward-line 1)
        (let* ((start (point))
               (end (save-excursion
                      (if (re-search-forward "#\\+end_src" subtree-end t)
                          (line-beginning-position)
                        subtree-end)))
               (content (string-trim (buffer-substring-no-properties start end)))
               ;; Get first non-empty line
               (first-line (car (seq-filter (lambda (s) (not (string-empty-p s)))
                                            (split-string content "\n")))))
          (when first-line
            (let ((title (string-trim first-line)))
              (if (> (length title) 60)
                  (concat (substring title 0 57) "...")
                title))))))))

(defun claude-org--build-block-title-from-custom-id (custom-id)
  "Build a meaningful title by navigating to CUSTOM_ID heading.
Returns full hierarchy: \"Instruction > Parent > Grandparent\" format.
Skips 'Workflow' headings as they're SDD containers.
For generic 'Instruction N' headings, uses first line of AI query instead."
  (when custom-id
    (save-excursion
      (save-restriction
        (widen)
        (goto-char (point-min))
        (condition-case nil
            (progn
              ;; Navigate to the heading with CUSTOM_ID
              (org-link-search (format "#%s" custom-id))
              ;; Get current heading
              (let* ((heading (substring-no-properties (org-get-heading t t t t)))
                     ;; Check if heading is generic "Instruction N" pattern
                     (is-generic (string-match-p "^Instruction [0-9]+$" heading))
                     ;; For generic headings, extract title from AI block query
                     (effective-heading (if is-generic
                                            (or (claude-org--extract-query-title-from-ai-block)
                                                heading)
                                          heading))
                     (headings (list effective-heading)))
                ;; Collect parent headings (skip Workflow)
                (save-excursion
                  (while (org-up-heading-safe)
                    (let ((parent (substring-no-properties (org-get-heading t t t t))))
                      (unless (string= parent "Workflow")
                        (push parent headings)))))
                ;; Build title: most specific first, then parents
                ;; headings is now (root parent ... instruction)
                ;; We want: instruction > parent > root
                (string-join (reverse headings) " > ")))
          (error nil))))))

(defun claude-org--format-block-candidate (entry)
  "Format ENTRY for display in completing-read.
ENTRY is (BLOCK-ID . PLIST).
Builds title dynamically from CUSTOM_ID to show current heading hierarchy."
  (let* ((plist (cdr entry))
         (status (plist-get plist :status))
         (custom-id (plist-get plist :custom-id))
         ;; Build title dynamically from CUSTOM_ID
         (title (or (claude-org--build-block-title-from-custom-id custom-id) "Untitled"))
         (timestamp (plist-get plist :timestamp))
         (status-icon (pcase status
                        ('completed "✓")
                        ('in-progress "⋯")
                        ('error "✗")
                        (_ "?")))
         (time-str (if timestamp
                       (claude-org--format-time-ago timestamp)
                     "unknown")))
    (format "[%s] %s (%s)"
            status-icon
            title  ;; No truncation - show full hierarchy
            time-str)))

(defun claude-org--build-candidate-info (custom-id)
  "Build display info for CUSTOM_ID in a single navigation pass.
Returns (TITLE . STORY-NAME) or nil if CUSTOM_ID not found.
TITLE is the heading hierarchy with the story root stripped when present.
STORY-NAME is the session ancestor heading text (or nil).
This avoids multiple `org-link-search' calls per candidate."
  (when custom-id
    (save-excursion
      (save-restriction
        (widen)
        (goto-char (point-min))
        (condition-case nil
            (progn
              (org-link-search (format "#%s" custom-id))
              ;; Build title from heading hierarchy
              (let* ((heading (substring-no-properties (org-get-heading t t t t)))
                     (is-generic (string-match-p "^Instruction [0-9]+$" heading))
                     (effective-heading (if is-generic
                                            (or (claude-org--extract-query-title-from-ai-block)
                                                heading)
                                          heading))
                     (headings (list effective-heading))
                     (story-name nil))
                ;; Walk up parents: collect headings AND find story
                (save-excursion
                  (while (org-up-heading-safe)
                    (let ((parent (substring-no-properties (org-get-heading t t t t))))
                      (unless (string= parent "Workflow")
                        (push parent headings)))
                    ;; Check if this heading defines the session scope
                    (when (and (not story-name)
                               (or (claude-org--has-session-tag-p)
                                   (org-entry-get nil "CLAUDE_SESSION_ID" nil)))
                      (setq story-name
                            (substring-no-properties (org-get-heading t t t t))))))
                ;; Strip story heading from title to avoid duplication
                (let ((display-headings (if story-name
                                            (cl-remove story-name headings
                                                       :test #'string= :count 1)
                                          headings)))
                  (cons (string-join (reverse display-headings) " > ")
                        story-name))))
          (error nil))))))

(defun claude-org--collect-recent-blocks ()
  "Collect recent blocks for completing-read.
Returns alist of (DISPLAY-STRING . ENTRY).
Only includes entries with CUSTOM_ID that still exist in the buffer.
Limited by `claude-org-history-max-entries'.
Each DISPLAY-STRING is prefixed with [Story Name] for grouping.
Uses single-pass navigation per candidate to avoid redundant searches."
  (claude-org--ensure-history-loaded)
  (let* ((entries-with-id (cl-remove-if-not
                           (lambda (entry)
                             (and (listp entry)
                                  (plist-get (cdr entry) :custom-id)))
                           claude-org--block-history))
         ;; Build candidate info in single pass per entry
         ;; This replaces separate exists-p + format + story-name calls
         (candidates nil)
         (count 0))
    (dolist (entry entries-with-id)
      (when (< count claude-org-history-max-entries)
        (let* ((plist (cdr entry))
               (custom-id (plist-get plist :custom-id))
               (info (claude-org--build-candidate-info custom-id)))
          ;; info is (TITLE . STORY) or nil if CUSTOM_ID not found
          (when info
            (let* ((title (car info))
                   (story (or (cdr info) "Ungrouped"))
                   (status (plist-get plist :status))
                   (timestamp (plist-get plist :timestamp))
                   (status-icon (pcase status
                                  ('completed "✓")
                                  ('in-progress "⋯")
                                  ('error "✗")
                                  (_ "?")))
                   (time-str (if timestamp
                                 (claude-org--format-time-ago timestamp)
                               "unknown"))
                   (display (format "[%s] [%s] %s (%s)"
                                    story status-icon title time-str)))
              (push (cons display entry) candidates)
              (cl-incf count))))))
    (nreverse candidates)))

(defun claude-org-execute ()
  "Execute the AI query at point.
Must be called when point is inside a #+begin_src ai block.
Sends the query to Claude and streams the response below the block.

Supports loop execution via header arguments:
  :loop N     - Execute N iterations (default 1)
  :interval N - Wait N seconds between iterations (default 0)

When `claude-org-auto-create-response-section' is non-nil, creates a Response
section with :ai_output: tag for flat pattern organization.
When `claude-org-auto-generate-title' is non-nil, generates a title for
headings matching `claude-org-auto-title-heading-pattern' using Haiku.

If the session is busy, queues the block for execution when current query completes."
  (interactive)
  (cl-block claude-org-execute
  (unless (claude-org--in-ai-block-p)
    (user-error "Not inside an ai block. Use #+begin_src ai ... #+end_src"))
  (let* ((content (claude-org--get-block-content))
         (session-key (claude-org--current-session-key))
         ;; Get header args for loop support
         (header-args (claude-org--get-block-header-args))
         (loop-max (or (plist-get header-args :loop) 1))
         (loop-interval (or (plist-get header-args :interval) 0))
         ;; Convert string values to numbers if needed
         (loop-max (if (stringp loop-max) (string-to-number loop-max) loop-max))
         (loop-interval (if (stringp loop-interval) (string-to-number loop-interval) loop-interval))
         ;; Get CUSTOM_ID for session manager navigation (before buffer changes)
         (custom-id (claude-org--find-instruction-custom-id))
         ;; Capture section level at AI block position BEFORE any buffer modifications
         ;; This ensures loop iterations use the correct level even if AI generates nested headings
         (section-level (claude-org--get-section-level))
         ;; Check for auto-title BEFORE any buffer modifications
         (should-auto-title (and claude-org-auto-generate-title
                                 (claude-org--heading-matches-auto-title-pattern-p)))
         ;; Create marker at heading position for title update
         (heading-marker (when should-auto-title
                           (save-excursion
                             (org-back-to-heading t)
                             (copy-marker (point))))))
    (unless content
      (user-error "Empty ai block"))
    ;; If session is busy, queue the block instead of erroring
    (when (claude-org--session-get session-key :busy)
      (let* ((block-info (list :custom-id custom-id
                               :content content
                               :marker (copy-marker (point))
                               :loop-max loop-max
                               :loop-interval loop-interval
                               :section-level section-level
                               :should-auto-title should-auto-title
                               :heading-marker heading-marker))
             (result (claude-org--queue-block session-key block-info)))
        (pcase result
          ('queued
           ;; Set status to scheduled
           (claude-org--set-exec-status "scheduled")
           (message "Scheduled [%d]. Will run after current query completes."
                    (claude-org--queue-count session-key)))
          ('running
           (message "This block is already running. Wait for it to complete."))
          ('in-queue
           (message "This block is already scheduled [%d in queue]."
                    (claude-org--queue-count session-key))))
        (cl-return-from claude-org-execute nil)))
    ;; Set status to executing and record timestamp
    (claude-org--set-exec-status "executing")
    (let ((timestamp (format-time-string "%Y-%m-%d %H:%M:%S")))
      (save-excursion
        (org-back-to-heading t)
        (org-entry-put nil "LAST_AI_EXECUTED" timestamp))
      ;; Find insertion point (after last :ai_output: sibling, or after #+end_src)
      (let ((insert-point (claude-org--find-response-insert-point))
            (instr-num (claude-org--find-instruction-number)))
        (unless insert-point
          (user-error "Cannot find block end"))
        ;; Generate query-id FIRST (marker-free architecture)
        (let ((query-id (claude-org--generate-query-id))
              ;; Create marker at current AI block position for queue duplicate detection
              (block-marker (copy-marker (point))))
          ;; Store session state BEFORE creating response section
          (claude-org--session-put session-key :query-id query-id)
          (claude-org--session-put session-key :marker block-marker)
          (claude-org--session-put session-key :original-prompt content)
          (claude-org--session-put session-key :section-level section-level)
          (claude-org--session-put session-key :start-time (float-time))
          (claude-org--session-put session-key :busy t)
          ;; Store loop state
          (claude-org--session-put session-key :loop-max loop-max)
          (claude-org--session-put session-key :loop-current 1)
          (claude-org--session-put session-key :loop-interval loop-interval)
          ;; Store instruction info for loop continuation
          (claude-org--session-put session-key :instruction-num instr-num)
          (claude-org--session-put session-key :custom-id custom-id)
          ;; Reset recovery count for new query
          (claude-org--session-put session-key :recovery-count 0)
          ;; Create Response section with query-id (marker-free)
          (save-excursion
            (goto-char insert-point)
            (insert "\n\n")
            (when claude-org-auto-create-response-section
              (claude-org--create-response-section session-key query-id 'normal)))
          ;; Run pre-execution hook (pass nil for marker - we're marker-free now)
          (run-hook-with-args 'claude-org-execute-hook session-key content nil)
          ;; Start spinner and send request
          (claude-org--start-spinner session-key)
          ;; Auto-generate title in parallel (using Haiku, separate session)
          (when heading-marker
            (claude-org--maybe-auto-generate-title content heading-marker))
          ;; Build query-context for session manager (with loop info)
          (let ((query-ctx (when instr-num
                             (claude-agent-make-query-context
                              :instruction-num instr-num
                              :loop-current 1
                              :loop-max loop-max
                              :custom-id custom-id))))
            ;; Send request - query-id already stored in session
            (claude-org--send-request content query-ctx session-key))
          ;; Run post-execution hook (pass nil for marker - we're marker-free now)
          (run-hook-with-args 'claude-org-execute-after-hook session-key content nil)))))))

(defun claude-org--make-guarded-callback (buf session-key query-id handler)
  "Return a callback that calls HANDLER only if BUF is live and QUERY-ID current.
Guards against stale callbacks from cancelled or superseded queries."
  (lexical-let ((buf buf)
                (session-key session-key)
                (qid query-id)
                (handler handler))
    (lambda (arg)
      (when (buffer-live-p buf)
        (with-current-buffer buf
          (when (equal qid (claude-org--session-get session-key :query-id))
            (funcall handler session-key arg)))))))

(defun claude-org--build-full-prompt (prompt system-reminder)
  "Prepend SYSTEM-REMINDER to PROMPT if non-nil and non-empty.
Returns the combined prompt string, or PROMPT unchanged when
SYSTEM-REMINDER is nil or empty."
  (if (and system-reminder (not (string-empty-p system-reminder)))
      (concat system-reminder "\n" prompt)
    prompt))

(defun claude-org--dispatch-query (session-key full-prompt callbacks
                                    &rest props)
  "Dispatch FULL-PROMPT through the backend for SESSION-KEY.
CALLBACKS is a plist of :on-token, :on-message, :on-error, :on-complete.
PROPS are keyword args passed through to `claude-agent-backend-query'.
SESSION-KEY is automatically injected into PROPS.
Stores the resulting backend and query handle in the session."
  (let* ((props (plist-put props :session-key session-key))
         (options (plist-get props :options))
         (backend (or (claude-org--session-get session-key :backend)
                      (claude-org--make-default-backend session-key options)))
         (filtered-callbacks (claude-agent-backend-filter-callbacks backend callbacks))
         (handle (apply #'claude-agent-backend-query backend full-prompt
                        filtered-callbacks props)))
    ;; Store backend and handle in session
    (claude-org--session-put session-key :backend backend)
    (claude-org--session-put session-key :query-handle handle)
    ;; Update persistent client activity if applicable
    (when (claude-agent-backend-supports-p backend :persistent-client)
      (claude-org--update-persistent-client-activity session-key))))

(defun claude-org--send-request (prompt &optional query-context session-key-override)
  "Send PROMPT to Claude via claude-agent.
QUERY-CONTEXT is a claude-agent-query-context struct for Session Manager display.
SESSION-KEY-OVERRIDE if provided, uses this session-key instead of calculating from
current buffer position. Essential for loop iterations where cursor may have moved.

When Docker mode is active (CLAUDE_CODE_PATH contains 'docker'), this function
passes :cli-path and :path-mappings to claude-agent-query for automatic path
translation between host (PROJECT_ROOT) and container (CLAUDE_CONTAINER_PATH)."
  (let* ((session-key (or session-key-override (claude-org--current-session-key)))
         (sdk-uuid (claude-org--get-sdk-uuid))
         (project-root (claude-org--get-project-root))
         (system-prompt (claude-org--build-system-prompt))
         ;; Docker configuration from org properties
         (cli-path (claude-org--get-cli-path))
         (path-mappings (claude-org--get-path-mappings))
         ;; Build IDE context reminder and query options using helpers
         (system-reminder (claude-org--build-ide-context-reminder project-root))
         (options (claude-org--build-query-options project-root system-prompt sdk-uuid))
         ;; Build full prompt with system reminder
         (full-prompt (claude-org--build-full-prompt prompt system-reminder))
         ;; Capture source context for session manager display
         (source-buf (current-buffer))
         (custom-id (when query-context (claude-agent-query-context-custom-id query-context))))
    ;; Get session heading name for permission prompts
    ;; Need to position at heading first since we might be inside a src block
    (let ((org-section-name
           (save-excursion
             (ignore-errors (org-back-to-heading t))
             (when-let ((heading-pos (claude-org--find-session-scope-heading)))
               (goto-char heading-pos)
               (substring-no-properties (org-get-heading t t t t))))))
      ;; Build callbacks with query-id validation via guarded helper
      (let* ((query-id (claude-org--session-get session-key :query-id))
             (mk (lambda (handler)
                   (claude-org--make-guarded-callback
                    source-buf session-key query-id handler)))
             (callbacks
              (list
               :on-token    (funcall mk #'claude-org--handle-token-v2)
               :on-message  (funcall mk #'claude-org--handle-message)
               :on-error    (funcall mk #'claude-org--handle-error)
               :on-complete (funcall mk #'claude-org--handle-complete))))
        ;; Dispatch through backend
        (claude-org--dispatch-query session-key full-prompt callbacks
          :options options
          :source-buffer source-buf
          :query-context query-context
          :source-location-fn (when custom-id 'claude-org-goto-custom-id)
          :source-location-args (when custom-id (list custom-id))
          :cli-path cli-path
          :path-mappings path-mappings
          :project-root project-root
          :org-section org-section-name)))))

(defun claude-org--execute-queued-block (session-key block-info)
  "Execute a queued BLOCK-INFO for SESSION-KEY.
BLOCK-INFO is a plist with :custom-id, :content, :marker, :loop-max, etc."
  (cl-block claude-org--execute-queued-block
  (let ((custom-id (plist-get block-info :custom-id))
        (content (plist-get block-info :content))
        (orig-marker (plist-get block-info :marker))
        (loop-max (plist-get block-info :loop-max))
        (loop-interval (plist-get block-info :loop-interval))
        (section-level (plist-get block-info :section-level))
        (should-auto-title (plist-get block-info :should-auto-title))
        (heading-marker (plist-get block-info :heading-marker)))
    ;; Check if marker is still valid (block not deleted)
    (unless (and orig-marker (marker-buffer orig-marker))
      (message "Skipping queued block - marker invalid (block deleted?)")
      ;; Try next in queue
      (when-let ((next (claude-org--dequeue-block session-key)))
        (claude-org--execute-queued-block session-key next))
      (cl-return-from claude-org--execute-queued-block nil))
    ;; Navigate to the original position and execute
    (with-current-buffer (marker-buffer orig-marker)
      (save-excursion
        (goto-char orig-marker)
        ;; Update status from scheduled to executing
        (claude-org--set-exec-status "executing")
        (let ((timestamp (format-time-string "%Y-%m-%d %H:%M:%S")))
          ;; Record execution timestamp
          (save-excursion
            (org-back-to-heading t)
            (org-entry-put nil "LAST_AI_EXECUTED" timestamp))
          ;; Find insertion point
          (let ((insert-point (claude-org--find-response-insert-point))
                (instr-num (claude-org--find-instruction-number)))
            (unless insert-point
              (message "Cannot find block end for queued block")
              (set-marker orig-marker nil)  ; Free marker before early return
              (cl-return-from claude-org--execute-queued-block nil))
            ;; Generate new query-id for this queued block (critical for token routing)
            (let ((query-id (claude-org--generate-query-id)))
              ;; Store query-id BEFORE creating response section
              (claude-org--session-put session-key :query-id query-id)
              ;; Set up at insertion point
              (save-excursion
                (goto-char insert-point)
                (insert "\n\n")
                ;; Create Response section with :QUERY_ID: property (marker-free architecture)
                (when claude-org-auto-create-response-section
                  (claude-org--session-put session-key :section-level section-level)
                  (claude-org--session-put session-key :instruction-num instr-num)
                  (claude-org--create-response-section session-key query-id 'normal)))
              (let ((marker (point-marker)))
                (claude-org--session-put session-key :marker marker)
                (claude-org--session-put session-key :original-prompt content)
                (claude-org--session-put session-key :section-level section-level)
                (claude-org--session-put session-key :start-time (float-time))
                (claude-org--session-put session-key :busy t)
                ;; Store loop state
                (claude-org--session-put session-key :loop-max loop-max)
                (claude-org--session-put session-key :loop-current 1)
                (claude-org--session-put session-key :loop-interval loop-interval)
                ;; Store instruction info
                (claude-org--session-put session-key :instruction-num instr-num)
                (claude-org--session-put session-key :custom-id custom-id)
                ;; Run pre-execution hook
                (run-hook-with-args 'claude-org-execute-hook session-key content marker)))
            ;; Start spinner and send request
            (claude-org--start-spinner session-key)
            ;; Auto-generate title if needed
            (when heading-marker
              (claude-org--maybe-auto-generate-title content heading-marker))
            ;; Build query-context and send
            (let ((query-ctx (when instr-num
                               (claude-agent-make-query-context
                                :instruction-num instr-num
                                :loop-current 1
                                :loop-max loop-max
                                :custom-id custom-id))))
              (claude-org--send-request content query-ctx session-key))
            ;; Run post-execution hook
            (let ((marker (claude-org--session-get session-key :marker)))
              (run-hook-with-args 'claude-org-execute-after-hook session-key content marker)))))
    ;; Free original marker
    (set-marker orig-marker nil)))))

(defun claude-org-scheduled--should-execute-p (scheduled-time last-executed-str)
  "Return t if AI block should execute based on times.
SCHEDULED-TIME is Emacs time from `org-get-scheduled-time'.
LAST-EXECUTED-STR is string from LAST_AI_EXECUTED property (or nil).

Execution happens when:
1. Scheduled time has arrived (scheduled-time <= now)
2. AND either never executed OR scheduled after last execution"
  (let ((now (current-time))
        (last-executed (when (and last-executed-str
                                  (not (string-empty-p last-executed-str)))
                         (encode-time (parse-time-string last-executed-str)))))
    (and
     ;; Scheduled time has arrived
     (not (time-less-p now scheduled-time))
     ;; Either never executed, or scheduled after last execution
     (or (null last-executed)
         (time-less-p last-executed scheduled-time)))))

(defun claude-org-scheduled--check-and-execute ()
  "Check all scheduled AI blocks and execute those that are due.
Called by the timer every 60 seconds."
  (dolist (entry claude-org--scheduled-blocks)
    (let* ((custom-id (car entry))
           (plist (cdr entry))

(defun claude-org-scheduled--maybe-execute (file custom-id scheduled-time)
  "Execute AI block if due and not already executed.
FILE is the org file path.
CUSTOM-ID identifies the heading.
SCHEDULED-TIME is when the block should execute.
Returns t if execution started, nil if skipped (busy, not due, etc)."
  (when (file-exists-p file)
    (with-current-buffer (find-file-noselect file)
      (org-with-wide-buffer
       (goto-char (point-min))
       (when (re-search-forward
              (format ":CUSTOM_ID: %s" (regexp-quote custom-id)) nil t)
         (org-back-to-heading t)
         (let ((last-exec-str (org-entry-get nil "LAST_AI_EXECUTED"))
               (heading-pos (point)))
           (when (claude-org-scheduled--should-execute-p
                  scheduled-time last-exec-str)
             ;; Find AI block within subtree
             (let ((subtree-end (save-excursion (org-end-of-subtree t) (point))))
               (when (re-search-forward "#\\+begin_src ai" subtree-end t)
                 (forward-line 1)  ; Move INTO the block, not on begin_src line
                 ;; Check if session is busy before executing
                 (let ((session-key (claude-org--current-session-key)))
                   (if (claude-org--session-get session-key :busy)
                       (message "Skipping scheduled block %s - session busy" custom-id)
                     ;; Session not busy, proceed with execution
                     (message "Executing scheduled AI block: %s" custom-id)
                     (claude-org-execute)
                     ;; After execution, advance repeater if present
                     (goto-char heading-pos)
                     (let ((new-time (claude-org-scheduled--advance-repeater)))
                       (when new-time
                         ;; Update the in-memory alist with new scheduled time
                         (claude-org-scheduled--update-entry custom-id file new-time)
                         (message "Advanced repeater for %s to next occurrence"
                                  custom-id)
                         ;; Save the buffer to persist the change
                         (save-buffer))))))))))))))

(defun claude-org-scheduled--advance-repeater ()
  "Advance the SCHEDULED timestamp if it has a repeater.
Must be called with point on the heading.
Returns the new scheduled time if advanced, nil otherwise."
  (let ((repeat (org-get-repeat)))
    (when repeat
      (save-excursion
        ;; Find the SCHEDULED line within the heading
        (let ((heading-end (save-excursion (outline-next-heading) (point))))
          (when (re-search-forward "SCHEDULED:" heading-end t)
            ;; Find the timestamp on this line
            (when (re-search-forward "<[^>]+>" (line-end-position) t)
              (goto-char (match-beginning 0))
              ;; Parse the repeater: +1d, +1w, +1m, .+1d, ++1d, etc.
              (let* ((clean-repeat (if (string-match "^[.+]+" repeat)
                                       (replace-match "" nil nil repeat)
                                     repeat))
                     (n (string-to-number (substring clean-repeat 0 -1)))
                     (unit-char (substring clean-repeat -1))
                     ;; Convert to days - org-timestamp-change works best with 'day
                     (days (pcase unit-char
                             ("d" n)
                             ("w" (* n 7))
                             ("m" (* n 30))  ; Approximate
                             ("y" (* n 365)))))  ; Approximate
                (when (and days (> days 0))
                  (org-timestamp-change days 'day)
                  ;; Return the new scheduled time
                  (org-get-scheduled-time (point)))))))))))

  (dolist (buf (buffer-list))

* Cancel Support

#+BEGIN_SRC elisp
(defun claude-org-cancel ()
  "Cancel the current session's active query, stop any loop, and clear queue."
  (interactive)
  (let* ((session-key (claude-org--current-session-key))
         (backend (claude-org--session-get session-key :backend))
         (query-handle (claude-org--session-get session-key :query-handle))
         (loop-current (claude-org--session-get session-key :loop-current))
         (loop-max (claude-org--session-get session-key :loop-max))
         (queue-count (claude-org--queue-count session-key)))
    (if (and backend (claude-org--session-get session-key :busy))
        (progn
          ;; Stop loop by setting current = max
          (when (and loop-max (> loop-max 1))
            (claude-org--session-put session-key :loop-current loop-max))
          (claude-agent-backend-cancel backend query-handle)
          ;; Mark closed and unregister so mode-line/queries buffer update immediately
          (claude-org--unregister-active-query session-key)
          (claude-org--session-put session-key :busy nil)
          (claude-org--stop-spinner session-key)
          ;; Clear pending queue
          (when (> queue-count 0)
            (claude-org--clear-queue session-key))
          ;; Insert cancellation message at end of response section
          ;; using query-id lookup (same mechanism as token insertion).
          ;; The :marker points to the AI block, NOT the response section,
          ;; so using it would insert [Cancelled] inside the src block.
          (let ((cancel-text (if (and loop-max (> loop-max 1))
                                 (format "\n[Cancelled at iteration %d/%d]\n"
                                         (or loop-current 1) loop-max)
                               "\n[Cancelled]\n")))
            (or (claude-org--insert-at-response session-key cancel-text)
                ;; Fallback: if no response section found (e.g., cancelled
                ;; before response section was created), use marker
                (let ((marker (claude-org--session-get session-key :marker)))
                  (when (and marker (marker-buffer marker))
                    (with-current-buffer (marker-buffer marker)
                      (save-excursion
                        (goto-char marker)
                        ;; Find end_src to insert after the block, not inside it
                        (when (re-search-forward "^#\\+end_src" nil t)
                          (end-of-line)
                          (insert cancel-text))))))))
          ;; Update exec status to cancelled
          (claude-org--set-exec-status-for-session session-key "cancelled")
          ;; Free marker immediately to prevent race with sentinel callback
          ;; (sentinel's handle-complete would otherwise free the NEW marker
          ;; if user quickly re-executes before sentinel runs)
          (claude-org--free-marker session-key)
          (claude-org--refresh-header-line)
          (if (> queue-count 0)
              (message "Query cancelled, cleared %d queued block(s)" queue-count)
            (message "Query cancelled")))
      (message "No active query to cancel"))))

(defun claude-org-cancel-all ()
  "Cancel all active queries in this buffer and clear all queues."
  (interactive)
  (let ((cancelled 0)
        (queued-cleared 0))
    (maphash (lambda (key state)
               (when (claude-org--session-state-p state)
                 ;; Clear queue
                 (let ((q-count (length (claude-org--session-state-pending-queue state))))
                   (when (> q-count 0)
                     (cl-incf queued-cleared q-count)
                     (setf (claude-org--session-state-pending-queue state) nil)))
                 ;; Cancel active query via backend protocol
                 (when (claude-org--session-state-busy state)
                   (when-let* ((backend (claude-org--session-state-backend state))
                               (handle (claude-org--session-state-query-handle state)))
                     (claude-agent-backend-cancel backend handle))
                   (claude-org--unregister-active-query key)
                   (setf (claude-org--session-state-busy state) nil)
                   (cl-incf cancelled))))
             claude-org--sessions)
    (claude-org--refresh-header-line)
    (if (> queued-cleared 0)
        (message "Cancelled %d queries, cleared %d queued blocks" cancelled queued-cleared)
      (message "Cancelled %d queries" cancelled))))

(defun claude-org-cancel-queue ()
  "Cancel only queued blocks, leaving the running query intact."
  (interactive)
  (let* ((session-key (claude-org--current-session-key))
         (queue-count (claude-org--queue-count session-key)))
    (if (> queue-count 0)
        (progn
          (claude-org--clear-queue session-key)
          (claude-org--refresh-header-line)
          (message "Cleared %d queued block(s), running query continues" queue-count))
      (message "No queued blocks to cancel"))))

* Org File Protection Hook

*NOTE: This hook does NOT work as intended.* It is kept for documentation purposes
and potential future use if Claude Code CLI changes its architecture.

** How Permission Functions Work

When Claude Code CLI is in =acceptEdits= mode, it sends =can_use_tool= control
requests to Emacs before executing Edit/Write tools. The
=claude-agent-permission-functions= hook processes these requests:

| Permission Mode | Edit/Write Flow | Protection? |
|-----------------+-----------------+-------------|
| bypassPermissions | CLI auto-approves | ❌ No prompts |
| acceptEdits | CLI → can_use_tool → Emacs | ✅ Permission functions run |
| default | CLI prompts user | ⚠️ CLI UI (not Emacs) |

To protect org files, add =claude-org-permission-protect-org= to
=claude-agent-permission-functions=. This only works in =acceptEdits= mode.

** Org File Protection (Permission Function)

This permission function protects .org files from modifications via:
1. Edit/Write tools directly targeting .org files
2. Bash commands that would modify .org files (sed -i, redirects, cp, mv, etc.)

Add it to =claude-agent-permission-functions= to enable protection.

*** Bash Command Detection

Detect if a bash command would modify an .org file.

#+NAME: org-protect-bash-detect
#+BEGIN_SRC elisp
(defun claude-org--bash-modifies-org-p (command)
  "Return non-nil if COMMAND would modify an .org file.
Checks for:
- In-place edit commands (sed -i, perl -i) referencing .org
- Output redirection (>, >>) to .org files
- File operations (cp, mv, install, tee) targeting .org files
- Temp file swap patterns (cmd > tmp && mv tmp file.org)"
  (when (and command (stringp command) (string-match-p "\\.org\\b" command))
    (or
     ;; In-place edit commands: sed -i, perl -i, ruby -i
     (and (string-match-p "\\b\\(sed\\|perl\\|ruby\\)\\b" command)
          (string-match-p " -[^ ]*i" command))
     ;; Output redirection to .org: > file.org, >> file.org, 2> file.org
     ;; Match > or >> followed by anything then .org (but not | or ; before .org)
     (string-match-p ">[>&]?[^|;]*\\.org" command)
     ;; File operations with .org as target at end of command
     (string-match-p "\\b\\(cp\\|mv\\|install\\)\\b.*\\.org[ \t]*$" command)
     ;; File operations with .org in quotes
     (string-match-p "\\b\\(cp\\|mv\\|install\\)\\b.*\\.org['\"]" command)
     ;; tee to .org file
     (string-match-p "\\btee\\b.*\\.org" command)
     ;; Temp file swap pattern: ... && mv ... .org
     (string-match-p "&&.*\\bmv\\b.*\\.org" command))))
#+END_SRC

*** Main Protection Function

#+NAME: org-protect-permission
#+BEGIN_SRC elisp
(defun claude-org-permission-protect-org (tool-name tool-input _context)
  "Permission function to protect .org files from modifications.

TOOL-NAME: string like \"Edit\", \"Write\", \"Bash\"
TOOL-INPUT: plist with tool-specific parameters
CONTEXT: plist with :session-id, :org-section

Blocks:
1. Edit/Write tools on .org files
2. Bash commands that would modify .org files

Returns nil to pass through, or permission result to deny.
Should be added to `claude-agent-permission-functions'."
  (let ((file-path (plist-get tool-input :file_path))
        (command (plist-get tool-input :command)))
    (cond
     ;; Layer 1: Block Edit/Write on .org files
     ((and (member tool-name '("Edit" "Write"))
           file-path
           (string-match-p "\\.org$" file-path))
      (claude-org--deny-org-modification tool-name))
     ;; Layer 2-4: Block Bash commands modifying .org files
     ((and (string= tool-name "Bash")
           command
           (claude-org--bash-modifies-org-p command))
      (claude-org--deny-org-modification "Bash")))))
#+END_SRC

** Protection Installation

Install/remove org protection in the permission hook.

#+NAME: org-protect-install
#+BEGIN_SRC elisp
(defun claude-org--install-protection ()
  "Install org file protection in permission functions.
The protection must be global because it runs in process filter context."
  (add-hook 'claude-agent-permission-functions
            #'claude-org-permission-protect-org))

(defun claude-org--remove-protection ()
  "Remove org file protection if no claude-org buffers remain."
  (unless (cl-some (lambda (buf)
                     (and (not (eq buf (current-buffer)))
                          (buffer-live-p buf)
                          (with-current-buffer buf
                            claude-org-mode)))
                   (buffer-list))
    (setq claude-agent-permission-functions
          (delq #'claude-org-permission-protect-org
                claude-agent-permission-functions))))
#+END_SRC
