#+TITLE: Architecture
#+DESCRIPTION: Meta-map for emacs-agent — cross-module concerns only

Each .org file documents itself; this file covers only what falls
between them.  The 2026-08-13 cleanup narrowed the repo to the Emacs
MCP server; the full pre-cleanup architecture (tri-protocol backends,
org workspace layer, python bridge) is preserved on the
=legacy-2026-08-13= branch and in that branch's ARCHITECTURE.org.

* Layout — =lp/<group>/= subtree

| Group | Role | Contents |
|---+---+---|
| =lp/trace/= | tracing macros (no deps, loaded first) | code-agent-trace |
| =lp/sdk/= | MCP server | emacs-mcp-server |
| =lp/backend/= | Pi-side TS extensions (tangle-only) | code-agent-pi-extensions |
| =lp/_drafts/= | design proposals queue | draft.org |

=code-agent.el= loader searches the repo root + every =lp/*/= subdir,
so caller code stays layout-agnostic.

* Module boundaries

#+begin_example
  code-agent.el
    └─ lp/trace/code-agent-trace.org    (span macros)
         └─ lp/sdk/emacs-mcp-server.org (MCP HTTP server :9999)
              ▲ HTTP
  external agents ──────────────────────┘
    Claude Code (mcp__emacs__evalElisp …)
    Pi via ~/.pi/agent/extensions/emacs-mcp.ts
      (tangled from lp/backend/code-agent-pi-extensions.org)
#+end_example

* Invariants

- The MCP server runs on Emacs's main thread: every handler must be
  fast (< 2 s) and must never signal out of a process filter.
- Only interactive tools warrant MCP calls from hooks — Emacs is
  contacted when it owns state to update, never per-tool-use
  (=minimize-emacs-mcp-calls= rule, kept from the pre-cleanup era).
- Trace macros load before any module that uses them; changing a
  macro requires reloading every consumer module.

* Extension points

- New in-Emacs agents (org-ai-agent-pi-topics first) land as new
  =lp/<group>/= modules registered in =code-agent.el=.  Follow the
  protocol style: classes + =cl-defgeneric= dispatched on the
  receiver, never string discriminators (=oop-smalltalk-protocols=
  rule).
- New MCP tools: add a handler section in =emacs-mcp-server.org= +
  a unit test in =tests/test-mcp-*.el=.
