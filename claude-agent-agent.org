* Claude Agent — Agent Family Base
:PROPERTIES:
:header-args:elisp: :tangle yes
:END:

Abstract base class for all AI-agent backends — Claude Code, OpenCode,
Gemini, Codex — plus the Protocol 2a agent-wire generics that every
concrete agent implements.

This module is the agent-family sibling of =claude-agent-multiplexer.org=
(multiplexer-family). Both sit directly under =claude-agent-backend.org=
(root lifecycle protocol). Concrete agents subclass the abstract base
here and supply a handful of =cl-defmethod= overrides: spawn-cmd,
handshake, send-prompt, handle-permission. Everything else — org
integration defaults, lifecycle plumbing — is inherited.

Phase 0 status: *skeleton only*. The generics declared here have
no-op defaults. In Phase 1 the abstract =backend-query= method is
implemented as the Template Method that orchestrates handshake →
send-prompt → stream-event, and concrete backends inherit it.

** Dependencies

#+BEGIN_SRC elisp
(require 'cl-lib)
(require 'claude-agent-backend)
#+END_SRC

** Agent Base Struct

Identity and shared state for every agent backend. Session-key +
session-id + cwd are universal; options + permission-policy are
customisation surfaces populated by the factory/constructor.

The =(:constructor nil)= marker forbids direct instantiation — this
class is abstract; callers must construct a concrete subclass
(=claude-agent-claude-code-backend=, =claude-agent-opencode-backend=,
etc., introduced in Phase 1+).

#+BEGIN_SRC elisp
(cl-defstruct (claude-agent-agent-backend
               (:include claude-agent-backend (type :agent))
               (:constructor nil)
               (:copier nil))
  "Abstract base for AI-agent backends (stream-json, ACP, etc.).
Concrete subclasses: `claude-agent-claude-code-backend',
`claude-agent-acp-agent-backend' (and its flat subclasses for
OpenCode, Gemini, Codex).  Do not instantiate directly."
  (session-key       nil
   :documentation "Session key `file::session-id'.")
  (session-id        nil
   :documentation "Session identifier as understood by the underlying CLI.")
  (cwd               nil
   :documentation "Working directory for the spawned CLI.")
  (options           nil
   :documentation "Plist of launch / prompt options.")
  (permission-policy nil
   :documentation "Permission policy struct or nil (use global defaults)."))
#+END_SRC

** Protocol 2a Generics

The published wire protocol for agents. Each concrete backend
specialises a subset; the rest inherit defaults. In Phase 0 the
generics are declared with no-op defaults — Phase 1 wires them into
the real protocol flow.

*** Handshake

Initialize the connection. ACP agents send =initialize= RPC; Claude
Code's stream-json format sends an =initialize= control-request on
stdin. Default: no-op (stream-json one-shot mode doesn't need it).

#+BEGIN_SRC elisp
(cl-defgeneric claude-agent-agent-handshake (backend)
  "Initialize BACKEND's connection to the agent.
Returns non-nil on success.  Called once per session before the first
`claude-agent-agent-send-prompt' call."
  (ignore backend)
  nil)
#+END_SRC

*** Spawn command

Build the CLI argv list. Backends differ on binary name, flags, and
profile-driven options. No default — abstract; every concrete agent
must supply this.

#+BEGIN_SRC elisp
(cl-defgeneric claude-agent-agent-spawn-cmd (backend)
  "Return the CLI command list for BACKEND as a list of strings.
The first element is the executable and the remaining elements are
command-line flags.  There is no default method: every concrete
agent must override this generic.")
#+END_SRC

*** Send prompt

Submit a user prompt to the running agent. Callbacks is a plist with
=:on-token=, =:on-message=, =:on-error=, =:on-complete=. Returns an
opaque handle that =claude-agent-backend-cancel= can interrupt. In
Phase 1 this is the primary entry the Template Method =backend-query=
delegates to.

#+BEGIN_SRC elisp
(cl-defgeneric claude-agent-agent-send-prompt (backend prompt callbacks)
  "Send PROMPT to BACKEND, invoking CALLBACKS during execution.
Returns an opaque handle for cancellation."
  (ignore backend prompt callbacks)
  (error "claude-agent-agent-send-prompt: no method on %S" (type-of backend)))
#+END_SRC

*** Load session

Resume a prior session by id. Agents that support resume override
this; others fall through to the default (no-op + nil return) and the
frontend treats the session as fresh.

#+BEGIN_SRC elisp
(cl-defgeneric claude-agent-agent-load-session (backend session-id)
  "Resume BACKEND with SESSION-ID.  Returns non-nil if the session
was accepted by the agent; nil if the agent rejected it or doesn't
support resume."
  (ignore backend session-id)
  nil)
#+END_SRC

*** Handle permission

Handle a tool-use permission request from the agent. For ACP this is
the =session/request_permission= server-to-client request; for Claude
Code stream-json it's a =can_use_tool= control-request. Default
routes to the shared =claude-agent-permission-functions= chain.

#+BEGIN_SRC elisp
(cl-defgeneric claude-agent-agent-handle-permission (backend request)
  "Handle a permission REQUEST from BACKEND's agent.
Consults `claude-agent-permission-functions'.  Returns a decision
plist with :behavior (\"allow\" / \"deny\") and optional :reason."
  (ignore backend request)
  nil)
#+END_SRC

*** Stream event

Internal hook fired once per decoded JSON/JSON-RPC event from the
agent. The Template Method dispatches events here so concrete
backends can extract per-wire-format details (ACP =session/response=
vs. Claude Code =assistant= / =result= envelopes).

#+BEGIN_SRC elisp
(cl-defgeneric claude-agent-agent-stream-event (backend event)
  "Process one decoded EVENT from BACKEND's event stream.
EVENT is the parsed JSON/JSON-RPC object.  Default is no-op — used
as a hook point for subclasses."
  (ignore backend event)
  nil)
#+END_SRC

*** Interrupt

Send an interrupt signal (SIGINT for subprocess, ACP
=session/cancelNotification=, etc.) while a query is in-flight.
Default dispatches to root-level =backend-cancel= with the current
handle; concrete backends override if they have a more graceful
signal.

#+BEGIN_SRC elisp
(cl-defgeneric claude-agent-agent-interrupt (backend)
  "Interrupt BACKEND's in-flight query.  Default: no-op placeholder;
concrete subclasses override with SIGINT / cancel RPC / etc."
  (ignore backend)
  nil)
#+END_SRC

*** Permission mode translation

Translate the org-level =CLAUDE_PERMISSION_MODE= preset (=readonly=,
=accept-edits=, =plan=, =bypass=) into a CLI flag list. Only Claude
Code has a first-class mode flag today; others no-op.

#+BEGIN_SRC elisp
(cl-defgeneric claude-agent-agent-permission-mode (backend mode)
  "Translate MODE keyword/string to CLI flags for BACKEND.
MODE is one of: readonly, accept-edits, plan, bypass, or nil.
Returns a list of argv flags (may be empty)."
  (ignore backend mode)
  nil)
#+END_SRC

*** Allowed-tools translation

Translate =claude-org-allowed-tools= to a CLI flag list. Claude Code
and OpenCode accept =--allowedTools=; Gemini/Codex do not.

#+BEGIN_SRC elisp
(cl-defgeneric claude-agent-agent-allowed-tools (backend tools)
  "Translate TOOLS list (of strings) to CLI flags for BACKEND.
Returns a list of argv flags (may be empty)."
  (ignore backend tools)
  nil)
#+END_SRC

*** Session property name

Each agent writes its resumable session-id to a distinct org property
(=CLAUDE_CLI_SESSION= for Claude Code, =ACP_SESSION_ID= for ACP
agents, =OPENCODE_SESSION_ID= for OpenCode legacy). Concrete
backends declare their name here so the frontend persists to the
right property without hard-coding agent names.

#+BEGIN_SRC elisp
(cl-defgeneric claude-agent-agent-session-property-name (backend)
  "Return the org property name where BACKEND persists its session id.
Used by the frontend for resume.  Concrete agents override."
  (ignore backend)
  nil)
#+END_SRC
