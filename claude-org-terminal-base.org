* Claude Org Terminal Base
:PROPERTIES:
:header-args:elisp: :tangle yes
:END:

Shared utilities for terminal backends (iTerm2, cmux). Provides status file I/O,
session heading navigation, query registration, and shared hash tables.

Both iTerm2 and cmux backends need identical logic for: finding the SDD session
heading in the org tree, reading/writing status files in =/tmp/claude-agent-status=,
registering queries in =claude-agent--active-queries=, and generating tab titles.
This module extracts those functions with a =claude-org-terminal--= prefix.

** Navigation Helpers

Find the SDD session heading and read properties from the session scope.
These are identical across iTerm2 and cmux backends.

#+BEGIN_SRC elisp
(defun claude-org-terminal--goto-session-heading ()
  "Move point to the nearest ancestor heading with CLAUDE_SESSION_ID.
Starts at current heading, walks up. Returns the session ID string, or nil."
  (widen)
  (condition-case nil (org-back-to-heading t) (error nil))
  (or (org-entry-get nil "CLAUDE_SESSION_ID")
      (let ((found nil))
        (while (and (not found) (org-up-heading-safe))
          (setq found (org-entry-get nil "CLAUDE_SESSION_ID")))
        found)))

(defun claude-org-terminal--find-session-property (prop)
  "Find PROP in the SDD session scope.
Searches up from point for org property PROP using inheritance.
Returns the value string, or nil if not found."
  (save-excursion
    (save-restriction
      (widen)
      (org-entry-get nil prop t))))
#+END_SRC

** Tab Title

Generate a tab/workspace title from the SDD session heading — used by both
iTerm2 tab naming and cmux workspace naming.

#+BEGIN_SRC elisp
(defun claude-org-terminal--tab-title ()
  "Generate terminal tab/workspace title for current SDD session.
Format: HEADING [SDD-SESSION-ID] — unique across org files."
  (save-excursion
    (save-restriction
      (let ((sdd-id (claude-org-terminal--goto-session-heading)))
        (format "%s [%s]"
                (truncate-string-to-width
                 (or (org-get-heading t t t t) "untitled") 40)
                (or sdd-id "no-session"))))))
#+END_SRC

** Status File I/O

Read and write status files in =claude-org-terminal-status-dir=. The Python
SDD bridge hooks write status (ready/busy), and Emacs reads them for fast
polling without API calls.

#+BEGIN_SRC elisp
(defun claude-org-terminal--save-request-id (sdd-session-id request-id)
  "Save REQUEST-ID to status file for SDD-SESSION-ID."
  (let ((dir claude-org-terminal-status-dir))
    (make-directory dir t)
    (with-temp-file (expand-file-name
                     (concat sdd-session-id ".request-id") dir)
      (insert request-id))))

(defun claude-org-terminal--read-request-id (sdd-session-id)
  "Read the request-id for SDD-SESSION-ID, or nil if not set."
  (let ((path (expand-file-name
               (concat sdd-session-id ".request-id")
               claude-org-terminal-status-dir)))
    (when (file-exists-p path)
      (let ((val (string-trim (with-temp-buffer
                                (insert-file-contents path)
                                (buffer-string)))))
        (unless (string-empty-p val) val)))))

(defun claude-org-terminal--read-hook-status (sdd-session-id)
  "Read Claude Code status from hook-written file. Fast, no API call."
  (let ((file (expand-file-name (or sdd-session-id "unknown")
                                claude-org-terminal-status-dir)))
    (if (file-exists-p file)
        (string-trim (with-temp-buffer
                       (insert-file-contents file)
                       (buffer-string)))
      "unknown")))

(defun claude-org-terminal--write-from-emacs-flag (sdd-session-id)
  "Write flag file indicating the next prompt was sent from Emacs.
sdd-bridge.sh checks this to skip duplicate instruction insertion."
  (let ((dir claude-org-terminal-status-dir))
    (make-directory dir t)
    (with-temp-file (expand-file-name
                     (concat sdd-session-id ".from-emacs") dir)
      (insert "1"))
    (let ((custom-id (org-entry-get nil "CUSTOM_ID")))
      (when custom-id
        (with-temp-file (expand-file-name
                         (concat sdd-session-id ".custom-id") dir)
          (insert custom-id))))))
#+END_SRC

** Query Registration

Register an AI block execution as an active query in =claude-agent--active-queries=.
Both backends create identical process-state structs and save the request-id
to a status file for the Python response hook.

#+BEGIN_SRC elisp
(defun claude-org-terminal--register-query (sdd-session-id _terminal-id)
  "Register the current AI block as an active query.
SDD-SESSION-ID is the SDD session, _TERMINAL-ID is the backend-specific ID (ignored).
Creates a process-state, registers in `claude-agent--active-queries',
and saves the request-id to a status file for the Python hook."
  (let* ((custom-id (org-entry-get nil "CUSTOM_ID"))
         (heading (org-get-heading t t t t))
         (instr-num (when (and heading
                               (string-match "\\bInstruction \\([0-9]+\\)" heading))
                      (string-to-number (match-string 1 heading))))
         (req-id (claude-agent--generate-request-id))
         (ctx (claude-agent-make-query-context
               :instruction-num instr-num
               :custom-id custom-id))
         (state (claude-agent--make-process-state
                 :request-id req-id
                 :start-time (float-time)
                 :source-buffer (current-buffer)
                 :query-context ctx
                 :source-location-fn (when custom-id #'claude-org-goto-custom-id)
                 :source-location-args (when custom-id (list custom-id)))))
    (claude-agent--register-query req-id state)
    (claude-org-terminal--save-request-id sdd-session-id req-id)))
#+END_SRC
