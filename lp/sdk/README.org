#+TITLE: lp/sdk — Core SDK + Backend Protocol + IDE Context

The /sdk/ group is the bottom of the dependency graph: every other
group loads through it.  No module here may =require= a module from
=lp/org/=, =lp/chat/=, =lp/ide/=, =lp/backend/= concrete subclasses,
or =lp/trace/=.  Everything else may =require= /sdk/.

* Modules

| File | Role |
|------+------|
| [[file:code-agent-backend.org][code-agent-backend.org]] | Tri-protocol backend abstract base (lifecycle / agent-wire / multiplexer-wire generics).  Every concrete backend in =lp/backend/= subclasses one of the bases declared here. |
| [[file:code-agent-python.org][code-agent-python.org]] | The literate-programming source of =python/code_agent/= — Python helpers tangled here, including the workspace-bridge daemon, OTel exporter, workspace-launcher, MCP client wrappers. |
| [[file:code-agent-ide.org][code-agent-ide.org]] | IDE-context collector: builds the =<system-reminder>= envelope (buffer / region / visible buffers) prepended to every prompt. |
| [[file:emacs-mcp-server.org][emacs-mcp-server.org]] | The MCP server Emacs exposes to Claude / Pi over localhost:9999.  Tools: read buffer, eval elisp, query org properties. |
| [[file:PROTOCOL-MAP.org][PROTOCOL-MAP.org]] | One-page reference: every =cl-defgeneric= × every backend.  Generated; refresh with =make audit-quarterly=. |

* Read order

1. [[file:code-agent-backend.org][code-agent-backend.org]] first — the tri-protocol model is the
   vocabulary every other doc speaks.
2. [[file:code-agent-python.org][code-agent-python.org]] second — knowing what's in the Python
   helpers prevents reaching for Elisp equivalents that don't exist.
3. [[file:code-agent-ide.org][code-agent-ide.org]] as needed — self-contained.
4. [[file:emacs-mcp-server.org][emacs-mcp-server.org]] when investigating MCP traffic.

* Boundaries to other groups

- /sdk/ → /backend/: concrete subclasses (cmux, tmux, ACP profiles)
  live in /backend/.  /sdk/ declares the contract; /backend/ honours it.
- /sdk/ → /org/: [[file:../org/code-agent-org.org][code-agent-org.org]] consumes the backend contract
  declared here and never reaches into /sdk/ internals.
- /sdk/ → /trace/: trace macros are imported by /sdk/ modules but
  must be available before /sdk/ loads (load order in =code-agent.el=).
