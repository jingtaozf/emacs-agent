#+TITLE: lp/ide — VS Code / JetBrains IDE Server Bridge

One module: a tiny WebSocket server Emacs runs so VS Code / JetBrains
extensions that speak the Claude IDE protocol can attach to the same
Emacs session.

* Modules

| File | Role |
|------+------|
| [[file:claude-ide.org][claude-ide.org]] | WebSocket server, MCP-style protocol handlers, selection tracking, diff visibility, lockfile coordination.  Multi-window (one server per Emacs frame) supported. |

* Read order

1. =claude-ide.org= top-down — the file is self-contained.  Start
   at =* Overview= → =* Session Management= → =* WebSocket Communication=.

* Boundaries

- /ide/ → /sdk/: minimal — uses no SDK generics today, just plays
  the role of an "external client" that talks to Emacs.  Future
  refactors may unify the IDE surface with the org/chat surfaces
  through =lp/sdk/= protocols.
- /ide/ ⟂ everything else: zero dependencies on /org/, /chat/,
  /backend/, /trace/.  The IDE surface is genuinely orthogonal.
