=.org= source in this repo.  Modules group by *role* — see each
group's README for the role-level overview and the per-module table.

* Read order for first-time readers

1. =ARCHITECTURE.org= (top of repo) — Module Boundary Diagram +
   invariants + extension points.
2. =lp/INDEX.org= (this file) — pick the group whose README to read.
3. The group's =README.org= — picks the module within the group.
4. The module's =* Overview= section — motivation + invariant.

* Load order (enforced by =code-agent.el=)

The high-level group order is:

1. =lp/trace/= — macros must exist before any consumer compiles.
2. =lp/sdk/= — protocol generics + backend abstract base.
3. =lp/backend/= — concrete backends register =cl-defmethod=
   against /sdk/ generics.
4. =lp/org/= — top-level integration; loads sub-modules in
   internal-order.
5. =lp/chat/= — independent of /org/; loads at any point after /sdk/.
6. =lp/ide/= — independent of everything except minimal /sdk/ surface.
