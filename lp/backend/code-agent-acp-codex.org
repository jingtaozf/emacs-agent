* Overview
:PROPERTIES:
:CUSTOM_ID: acp-codex-overview
:END:

OpenAI's Codex CLI does NOT speak ACP natively — it needs Zed
Industries' =codex-acp= shim binary installed separately.  This
profile module hides the shim from callers: they construct a Codex
backend the same way they construct any other ACP backend, and the
shim spawn-command + Codex-specific auth methods (=openai-api-key=,
=codex-api-key=, interactive =chatgpt= login) are wired in here.

Invariant: =code-agent-acp-codex-create= always launches the shim
(not the bare =codex= CLI) and the authenticate RPC during the ACP
handshake matches =code-agent-acp-codex-auth-method=.  When the shim
is missing, errors surface at spawn time, not mid-handshake.

* Codex ACP Profile

Per-agent configuration for OpenAI's Codex CLI.  Codex does NOT speak
ACP natively; it needs the =codex-acp= shim binary from
https://github.com/zed-industries/codex-acp installed separately
(e.g. =npm install -g @zed-industries/codex-acp= or equivalent).

Three auth methods:

| Method          | How                                              |
|-----------------+--------------------------------------------------|
| openai-api-key  | Set OPENAI_API_KEY, sent via authenticate RPC    |
| codex-api-key   | Set CODEX_API_KEY, sent via authenticate RPC     |
| chatgpt         | Interactive ChatGPT login                        |

References:
- https://github.com/zed-industries/codex-acp
- reference/agent-shell/agent-shell-openai.el

** Dependencies

(require 'code-agent-acp)
#+END_SRC

** Customization

User-facing knobs.  Each =defcustom= is documented inline; the group name keeps Customize navigable for end users.

#+BEGIN_SRC elisp
(defgroup code-agent-acp-codex nil
  "Codex ACP profile."
  :group 'code-agent-acp
  :prefix "code-agent-acp-codex-")

(defcustom code-agent-acp-codex-command '("codex-acp")
  "Command to launch the codex-acp shim.
The shim is separate from the =codex= CLI: install from
https://github.com/zed-industries/codex-acp."
  :type '(repeat string)
  :group 'code-agent-acp-codex)

(defcustom code-agent-acp-codex-auth-method 'openai-api-key
  "Which authenticate method to advertise during the ACP handshake.
- `openai-api-key': sends OPENAI_API_KEY (must be in environment)
- `codex-api-key': sends CODEX_API_KEY (must be in environment)
- `chatgpt': interactive ChatGPT login flow"
  :type '(choice (const openai-api-key)
                 (const codex-api-key)
                 (const chatgpt))
  :group 'code-agent-acp-codex)

(defcustom code-agent-acp-codex-environment nil
  "Extra environment variables for the codex-acp subprocess.
List of \"NAME=VALUE\" strings.  Typical entries:
  \"OPENAI_API_KEY=...\" for openai-api-key auth,
  \"CODEX_API_KEY=...\" for codex-api-key auth."
  :type '(repeat string)
  :group 'code-agent-acp-codex)
#+END_SRC

** Class

The Codex ACP flow runs through the =codex-acp= shim binary rather
than the vendor's native JSON-RPC server; a dedicated subclass keeps
the distinction visible at dispatch time if we ever need to override
shim-specific behaviour.

#+BEGIN_SRC elisp
(cl-defstruct (code-agent-codex-backend
               (:include code-agent-acp-backend (type :codex))
               (:constructor code-agent-codex-backend--create)
               (:copier nil))
  "ACP backend specialised for OpenAI Codex (via codex-acp shim).")
#+END_SRC

** Constructor

Single factory function — callers MUST go through this, not =make-instance= equivalents.

#+BEGIN_SRC elisp
(defun code-agent-acp-codex-create (&rest args)
  "Create an ACP backend configured for OpenAI Codex (via codex-acp shim).
ARGS are forwarded to `code-agent-codex-backend--create' after the
codex-specific defaults.  Typical usage:

  (code-agent-acp-codex-create :cwd \"/path\" :session-key \"sdd-...\")

Requires the `codex-acp' binary on PATH; install separately."
  (apply #'code-agent-acp--make-profile-backend
         #'code-agent-codex-backend--create
         "codex"
         code-agent-acp-codex-command
         code-agent-acp-codex-environment
         'code-agent-acp-codex-auth-method
         args))
#+END_SRC
