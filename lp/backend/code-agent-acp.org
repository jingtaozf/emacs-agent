#+TITLE: Claude Agent ACP Backend (Generic)
#+PROPERTY: literate-load yes

* Overview
:PROPERTIES:
:CUSTOM_ID: acp-overview
:END:

ACP is to AI agents what LSP is to language servers — one JSON-RPC
protocol that every conforming agent speaks the same way.  Without
this generic backend, each agent (OpenCode, Gemini, Codex, future
arrivals) would need a per-agent backend module hand-coded against
its own RPC vocabulary.  This module provides the single ACP
implementation that all per-agent profile modules (=code-agent-acp-opencode.org=
et al.) wrap with their own spawn-command + auth-method tuple.

Invariant: every ACP backend instance owns one persistent subprocess,
one =session/new= -derived =sessionId=, and runs the full handshake
(initialize → optional authenticate → session/new) exactly once at
construction time.  =session/prompt= calls reuse the same process
for all turns; cancellation flows through =session/cancel= notification,
not by killing the subprocess.  Permission requests
(=session/request_permission=) flow back to the user through the
interactive permission system, never silently auto-approved unless a
user-set defcustom flips that default.

* Claude Agent ACP Backend

Generic Agent Client Protocol (ACP) backend.  Supports any agent that
speaks ACP over stdio: OpenCode, Gemini CLI, Codex (via the =codex-acp=
shim), and Anthropic's =code-agent-acp=.  Per-agent configuration
(spawn command, auth method, env vars) is supplied at construction time.

Uses =code-agent-jsonrpc= for wire-level transport.  No external
=acp.el= dependency.

Spec: https://agentclientprotocol.com/protocol/schema
Reference: =reference/agent-shell/agent-shell.el= (xenodium)

** Protocol Overview

ACP is to AI agents what LSP is to language servers: a JSON-RPC 2.0
protocol over stdio, one persistent subprocess, bidirectional, with a
small fixed message vocabulary. The flow a single =C-c C-c= takes
through this module:

#+begin_example
Emacs (client)                        acp subprocess (server)
  |                                          |
  |-- spawn "<agent> acp" subprocess ------->|
  |-- subscribe (notifications, requests) -->|
  |-- initialize {protocolVersion: 1} ------>|
  |<-- initialize response ------------------|  (capabilities, authMethods)
  |-- authenticate {methodId: "..."} ------->|  (skipped when needs-authenticate is nil)
  |<-- authenticate response ----------------|  (success)
  |-- session/new {cwd: "/path"} ----------->|
  |<-- session/new response -----------------|  (sessionId)
  |                                          |
  |-- session/prompt {sessionId, prompt} --->|
  |<-- session/update (agent_message_chunk) -|  (streaming text)
  |<-- session/update (tool_call) -----------|  (tool invocation)
  |<-- session/request_permission -----------|  (server → client request)
  |-- permission response ------------------>|  (user decision)
  |<-- session/update (tool_call_update) ----|  (tool result)
  |<-- session/update (agent_message_chunk) -|  (more text)
  |<-- prompt response (stopReason) ---------|  (turn complete)
  |                                          |
  |-- session/cancel notification ---------->|  (interrupt)
  |                                          |
  |-- session/prompt (next turn) ----------->|  (reuse same process)
#+end_example

The bidirectional design is the property that makes ACP worth wiring
to. =session/request_permission= flows /from/ the agent /to/ Emacs so
the user is asked through the editor's normal permission UI; the agent
side waits for the response before continuing. That single capability
is what eliminates the entire screen-scraping / TUI-watching layer that
multiplexer-based backends need.

ACP =session/update= events are mapped into the same callback shape
as the Claude Code JSON-stream backend, so any frontend that
subscribes to =:on-token= / =:on-message= / =:on-thought= /
=:on-complete= / =:on-permission= / =:on-error= works against either
family without changes:

| ACP =session/update= | Our callback | Notes |
|----------------------+--------------+-------|
| =agent_message_chunk= | =:on-token= | Text chunks for streaming |
| =tool_call= | =:on-message= | Tool invocation (name, input) |
| =tool_call_update= | =:on-message= | Tool result (output, status) |
| =agent_thought_chunk= | =:on-thought= | Extended thinking content |
| =turn_complete= | =:on-complete= | Final stop, usage stats |
| =session/request_permission= | =:on-permission= | Permission dialog request |
| =error= | =:on-error= | API or agent errors |

The contrast with Claude Code's NDJSON stream backend — they are not
interchangeable on every axis:

| Dimension | Claude Code NDJSON stream | ACP (this module) |
|-----------+---------------------------+-------------------|
| Transport | NDJSON over stdout | JSON-RPC 2.0 over stdio (request/response + notifications) |
| Direction | one-way (we read) | bidirectional (server can call client) |
| Process lifetime | one process per query | one persistent subprocess per session |
| Session start | CLI flag =--session-key= or fresh | =session/new= RPC returns the id |
| Streaming granularity | token-by-token deltas | chunk-level =agent_message_chunk= |
| Permissions | CLI prompt / shell hooks | =session/request_permission= RPC to client |
| Cancellation | kill process / SIGINT | =session/cancel= notification |
| Multi-turn | new process per turn | same process, new =session/prompt= |

(defgroup code-agent-acp nil
  "Generic ACP (Agent Client Protocol) backend."
  :group 'code-agent
  :prefix "code-agent-acp-")

(defcustom code-agent-acp-auto-approve nil
  "If non-nil, auto-approve all ACP `session/request_permission' requests.
When nil (default, safer), prompt the user via `completing-read' for each
tool call, letting them pick one of the options the agent offered.

Set to t only in trusted/sandboxed environments where every tool call is
pre-vetted.  Leave nil in normal development; the prompt is fast and
lets you see exactly which operation the agent wants to run."
  :type 'boolean
  :group 'code-agent-acp)

(defcustom code-agent-acp-protocol-version 1
  "ACP protocol version advertised during `initialize'.
The ACP spec uses an integer (currently 1); bump only if the upstream
spec updates and all agents agree on the new value."
  :type 'integer
  :group 'code-agent-acp)

(defcustom code-agent-acp-fs-write-root nil
  "If non-nil, reject `fs/write_text_file' paths outside this directory.
A lightweight safety net — lets an agent edit files in your project but
prevents it from scribbling elsewhere.  Nil means no check (agent can
write anywhere).  The check is symlink-aware: both the root and the
target are resolved with `file-truename' before the prefix comparison,
so a symlink inside the root can't escape the sandbox."
  :type '(choice (const :tag "No restriction" nil) directory)
  :group 'code-agent-acp)

(defcustom code-agent-acp-fs-read-roots nil
  "If non-nil, restrict `fs/read_text_file' to paths under these roots.
A list of directory paths (each resolved via `file-truename' before the
prefix check).  Nil means no check (agent can read any file readable by
Emacs).  Setting this to your project root is recommended if you worry
about prompt-injection attacks exfiltrating ~/.ssh, ~/.aws/credentials,
or ~/.claude/.credentials.json."
  :type '(choice (const :tag "No restriction" nil)
                 (repeat directory))
  :group 'code-agent-acp)

(defcustom code-agent-acp-permission-title-max 200
  "Maximum length of an agent-supplied title in the permission prompt.
Titles are also stripped of control characters before display to avoid
terminal-escape or homoglyph spoofing."
  :type 'integer
  :group 'code-agent-acp)

** Backend Struct

Per-agent knobs live on the struct, not in global defvars — each
profile module constructs an instance with its own =:spawn-args=,
=:environment=, =:needs-authenticate=, and =:auth-request-maker=.

#+BEGIN_SRC elisp
(cl-defstruct (code-agent-acp-backend
               (:include code-agent-backend (type :acp))
               (:constructor code-agent-acp-backend--create)
               (:copier nil))
  "Generic ACP backend — one subprocess, one session, one agent."
  ;; Agent identity + launch config
  (agent-name nil :documentation "Short id, e.g. \"opencode\", \"gemini\"")
  (spawn-args nil :documentation "List: command + args, e.g. (\"opencode\" \"acp\")")
  (environment nil :documentation "List of \"NAME=VALUE\" env vars for the subprocess")
  (needs-authenticate nil :documentation "t if the agent requires an authenticate RPC")
  (auth-request-maker nil :documentation "Function () -> alist of authenticate params, or nil")
  ;; Transport + session
  (client nil :documentation "JSON-RPC client plist from code-agent-jsonrpc")
  (session-key nil :documentation "Emacs session key (for shared verbose buffer)")
  (session-id nil :documentation "sessionId returned by session/new")
  (initial-session-id nil
                      :documentation "If non-nil, try `session/load' with this id before `session/new'")
  (save-session-id-fn nil
                      :documentation "Function (session-id) -> void, called whenever sessionId changes (for persistence)")
  (cwd nil :documentation "Working directory for the agent's session")
  (active-query nil :documentation "Non-nil while a prompt is in-flight")
  (callbacks nil :documentation "Current query callbacks plist")
  (initialized nil :documentation "Non-nil after handshake completes")
  (prompt-start-time nil :documentation "float-time when current prompt was sent")
  ;; Usage tracking (accumulated from usage_update notifications)
  (cost-amount nil)
  (cost-currency nil)
  (input-tokens 0)
  (output-tokens 0)
  (context-used 0)
  (context-size 0))

** Live-Backend Registry (cleanup on Emacs exit)

Track every backend whose subprocess is alive so we can kill them when
Emacs exits — prevents orphan =opencode acp= / =gemini --experimental-acp=
processes.

#+BEGIN_SRC elisp
(defvar code-agent-acp--live-backends nil
  "List of live ACP backends with running subprocesses.
Populated when `code-agent-acp--start-process' runs; drained by
cleanup or by `kill-emacs-hook'.")

(defun code-agent-acp--register-backend (backend)
  "Add BACKEND to the live-backend registry."
  (unless (memq backend code-agent-acp--live-backends)
    (push backend code-agent-acp--live-backends)))

(defun code-agent-acp--unregister-backend (backend)
  "Remove BACKEND from the live-backend registry."
  (setq code-agent-acp--live-backends
        (delq backend code-agent-acp--live-backends)))

(defun code-agent-acp--cleanup-all ()
  "Kill every live ACP backend — registered on `kill-emacs-hook'."
  (dolist (backend (copy-sequence code-agent-acp--live-backends))
    (ignore-errors (code-agent-backend-cleanup backend))))

(add-hook 'kill-emacs-hook #'code-agent-acp--cleanup-all)
#+END_SRC

(defun code-agent-acp--verbose-log (backend text)
  "Write TEXT to the shared verbose buffer for BACKEND's session.
`code-agent--verbose-insert' creates the buffer on demand, so no

  (when-let* ((sk (code-agent-acp-backend-session-key backend)))

** Process Startup

Subprocess lifecycle entry — spawns the daemon and wires its stdout/stderr filters.

#+BEGIN_SRC elisp
(defun code-agent-acp--start-process (backend)
  "Start the agent subprocess for BACKEND.
Reads spawn-args, environment, cwd from the struct.  Returns the
JSON-RPC client plist.  The caller is responsible for wiring the client
into the backend and calling `code-agent-acp--register-backend'."
  (let* ((spawn-args (code-agent-acp-backend-spawn-args backend))
         (agent (or (code-agent-acp-backend-agent-name backend) "acp"))
         (cwd (code-agent-acp-backend-cwd backend))
         (env (code-agent-acp-backend-environment backend))
         (default-directory (or cwd default-directory))
         (stderr-buf (generate-new-buffer (format " *acp-stderr-%s*" agent)))
         (process-environment (append env process-environment))
         (proc (make-process
                :name (format "acp-%s" agent)
                :command spawn-args
                :connection-type 'pipe
                :coding 'utf-8-unix
                :noquery t
                :stderr stderr-buf))
         (client (code-agent-jsonrpc-make-client proc)))
    (setf (code-agent-jsonrpc-client-stderr-buffer client) stderr-buf)
    (message "code-agent-acp: started %s pid=%d"
             agent (process-id proc))
    client))
#+END_SRC

** Handshake

Protocol handshake — exchanged once at session start to negotiate capabilities + auth.

#+BEGIN_SRC elisp
(defun code-agent-acp--connect (backend on-ready on-error)
  "Connect BACKEND: start process, handshake, optional authenticate, session/new.
Calls ON-READY on success, ON-ERROR with an error string on failure."
  (let ((session-key (code-agent-acp-backend-session-key backend))
        (spawn (code-agent-acp-backend-spawn-args backend)))
    (when session-key
      (code-agent--get-session-verbose-buffer session-key)
      (code-agent--verbose-insert
       session-key
       (format "%s ACP connecting: %s\n%s %s\n"
               (propertize "▸" 'face 'font-lock-keyword-face)
               (string-join spawn " ")
               (propertize "  cwd:" 'face 'font-lock-comment-face)
               (or (code-agent-acp-backend-cwd backend)
                   default-directory)))))
  ;; First-time connect only: start process, wire client, register for
  ;; cleanup, and subscribe ACP notification/request handlers.  Guarding
  ;; inside the `unless' prevents handler duplication on reconnect — each
  ;; `code-agent-jsonrpc-add-*-handler' pushes onto a list with no dedup.
  (unless (code-agent-acp-backend-client backend)
    (setf (code-agent-acp-backend-client backend)
          (code-agent-acp--start-process backend))
    (code-agent-acp--register-backend backend)
    (code-agent-acp--subscribe backend))
  (lexical-let ((backend backend)
                (on-ready on-ready)
                (on-error on-error))
    (code-agent-acp--initialize backend
     (lambda ()
       (code-agent-acp--verbose-log backend "initialize OK")
       (if (code-agent-acp-backend-needs-authenticate backend)
           (code-agent-acp--authenticate backend
            (lambda ()
              (code-agent-acp--verbose-log backend "authenticate OK")
              (code-agent-acp--resume-or-new backend on-ready on-error))
            on-error)
         (code-agent-acp--resume-or-new backend on-ready on-error)))
     on-error)))

(defun code-agent-acp--resume-or-new (backend on-ready on-error)
  "Try `session/load' (if `initial-session-id' set) else `session/new'.
A load failure transparently falls back to creating a fresh session so a
stale session id in the org property doesn't block the user."
  (let ((initial (code-agent-acp-backend-initial-session-id backend)))
    (lexical-let ((backend backend)
                  (on-ready on-ready)
                  (on-error on-error))
      (if initial
          (code-agent-acp--load-session
           backend initial
           (lambda ()
             (setf (code-agent-acp-backend-initialized backend) t)
             (code-agent-acp--verbose-log
              backend
              (format "session/load OK  session=%s"
                      (code-agent-acp-backend-session-id backend)))
             (funcall on-ready))
           (lambda (err)
             (code-agent-acp--verbose-log
              backend
              (format "session/load failed (%s); falling back to session/new" err))
             (code-agent-acp--new-session-and-save backend on-ready on-error)))
        (code-agent-acp--new-session-and-save backend on-ready on-error)))))

(defun code-agent-acp--new-session-and-save (backend on-ready on-error)
  "Call `session/new' then invoke the save-session-id-fn if set.
Errors from the save callback are logged (not swallowed) so a failed
persistence write is diagnosable via *Messages*."
  (lexical-let ((backend backend)
                (on-ready on-ready)
                (on-error on-error))
    (code-agent-acp--new-session
     backend
     (lambda ()
       (setf (code-agent-acp-backend-initialized backend) t)
       (let ((sid (code-agent-acp-backend-session-id backend))
             (save-fn (code-agent-acp-backend-save-session-id-fn backend)))
         (code-agent-acp--verbose-log
          backend (format "session/new OK  session=%s" sid))
         (when (functionp save-fn)
           (condition-case err
               (funcall save-fn sid)
             (error
              (message "code-agent-acp: save-session-id-fn failed: %s"
                       (error-message-string err))))))
       (funcall on-ready))
     on-error)))

(defun code-agent-acp--initialize (backend on-success on-error)
  "Send ACP =initialize= RPC for BACKEND.
Advertises =fs.readTextFile= + =fs.writeTextFile= capabilities so agents
that prefer to delegate file I/O to the client (e.g. code-agent-acp,
codex-acp) can do so instead of shelling out.  Warns but does not error
if the agent responds with a mismatched protocolVersion."
  (lexical-let ((on-success on-success)
                (on-error on-error))
    (code-agent-jsonrpc-send-request
     (code-agent-acp-backend-client backend)
     "initialize"
     `((protocolVersion . ,code-agent-acp-protocol-version)
       (clientCapabilities
        . ((fs . ((readTextFile . t)
                  (writeTextFile . t))))))
     (lambda (result)
       (let ((agent-version (and (listp result)
                                 (map-elt result 'protocolVersion))))
         (when (and agent-version
                    (not (equal agent-version
                                code-agent-acp-protocol-version)))
           (display-warning
            'code-agent-acp
            (format "ACP protocolVersion mismatch: client=%s agent=%s — proceeding"
                    code-agent-acp-protocol-version agent-version)
            :warning)))
       (funcall on-success))
     (lambda (err)
       (funcall on-error
                (format "ACP initialize failed: %s"
                        (map-elt err 'message)))))))

(defun code-agent-acp--authenticate (backend on-success on-error)
  "Send ACP =authenticate= RPC using BACKEND's `auth-request-maker'.
Called only when `needs-authenticate' is t."
  (let ((maker (code-agent-acp-backend-auth-request-maker backend)))
    (if (not (functionp maker))
        (funcall on-error
                 "ACP authenticate required but auth-request-maker is missing")
      (lexical-let ((on-success on-success)
                    (on-error on-error))
        (code-agent-jsonrpc-send-request
         (code-agent-acp-backend-client backend)
         "authenticate"
         (funcall maker)
         (lambda (_result) (funcall on-success))
         (lambda (err)
           (funcall on-error
                    (format "ACP authenticate failed: %s"
                            (map-elt err 'message)))))))))

(defun code-agent-acp--new-session (backend on-success on-error)
  "Create a new ACP session for BACKEND."
  (lexical-let ((backend backend)
                (on-success on-success)
                (on-error on-error))
    (code-agent-jsonrpc-send-request
     (code-agent-acp-backend-client backend)
     "session/new"
     `((cwd . ,(expand-file-name
                (or (code-agent-acp-backend-cwd backend)
                    default-directory)))
       (mcpServers . []))
     (lambda (result)
       (let ((session-id (map-elt result 'sessionId)))
         (if session-id
             (progn
               (setf (code-agent-acp-backend-session-id backend) session-id)
               (funcall on-success))
           (funcall on-error "ACP session/new: no sessionId in response"))))
     (lambda (err)
       (funcall on-error
                (format "ACP session/new failed: %s"
                        (map-elt err 'message)))))))

(defun code-agent-acp--load-session (backend session-id on-success on-error)
  "Attempt to resume the ACP session SESSION-ID for BACKEND via `session/load'.
If the agent doesn't support `session/load' (returns -32601) or the
session is stale, ON-ERROR is invoked; the caller is expected to then
fall back to `session/new'."
  (lexical-let ((backend backend)
                (session-id session-id)
                (on-success on-success)
                (on-error on-error))
    (code-agent-jsonrpc-send-request
     (code-agent-acp-backend-client backend)
     "session/load"
     `((sessionId . ,session-id)
       (cwd . ,(expand-file-name
                (or (code-agent-acp-backend-cwd backend)
                    default-directory))))
     (lambda (_result)
       (setf (code-agent-acp-backend-session-id backend) session-id)
       (funcall on-success))
     (lambda (err)
       (funcall on-error (or (map-elt err 'message) "unknown"))))))
#+END_SRC

** Notification and Request Subscriptions

Wiring for server-initiated messages — every notification / request the protocol can deliver routes through here.

#+BEGIN_SRC elisp
(defun code-agent-acp--subscribe (backend)
  "Wire ACP-level notification and request handlers onto BACKEND's client."
  (let ((client (code-agent-acp-backend-client backend)))
    (lexical-let ((backend backend))
      (code-agent-jsonrpc-add-notification-handler
       client
       (lambda (notification)
         (code-agent-acp--handle-notification backend notification)))
      (code-agent-jsonrpc-add-request-handler
       client
       (lambda (request)
         (code-agent-acp--handle-request backend request))))))
#+END_SRC

** Notification Handler

Dispatcher for server-initiated notifications (one-way messages, no response expected).

#+BEGIN_SRC elisp
(defun code-agent-acp--handle-notification (backend notification)
  "Dispatch ACP NOTIFICATION to BACKEND callbacks."
  (let* ((params (map-elt notification 'params))
         (update (map-elt params 'update))
         (event-type (map-elt update 'sessionUpdate))
         (callbacks (code-agent-acp-backend-callbacks backend))
         (sk (code-agent-acp-backend-session-key backend)))
    (cond
     ((equal event-type "agent_message_chunk")
      (let* ((content (map-elt update 'content))
             (text (map-elt content 'text)))
        (when text
          (when sk
            (code-agent--verbose-insert sk text))
          (when (plist-get callbacks :on-token)
            (funcall (plist-get callbacks :on-token) text)))))

     ((equal event-type "tool_call")
      (let ((title (map-elt update 'title))
            (status (map-elt update 'status)))
        (when sk
          (code-agent--verbose-insert
           sk (format "\n%s %s  (%s)\n"
                      (propertize "▶ Tool:" 'face 'font-lock-keyword-face)
                      (propertize (or title "unknown")
                                  'face 'font-lock-function-name-face)
                      (or status ""))))
        (when (plist-get callbacks :on-token)
          (funcall (plist-get callbacks :on-token)
                   (format "\n[Tool: %s (%s)]\n"
                           (or title "unknown") (or status ""))))))

     ((equal event-type "tool_call_update")
      (let ((status (map-elt update 'status))
            (title (map-elt update 'title))
            (content-items (map-elt update 'content)))
        (when (member status '("completed" "failed"))
          (let ((output (code-agent-acp--extract-content-text content-items)))
            (when sk
              (code-agent--verbose-insert
               sk (format "%s %s  %s\n%s\n"
                          (propertize "◀ Result:" 'face 'font-lock-keyword-face)
                          (if (equal status "failed")
                              (propertize "FAILED" 'face 'error)
                            (propertize "OK" 'face 'success))
                          (or title "")
                          (or (and output (> (length output) 0)
                                   (truncate-string-to-width
                                    output 2000 nil nil "..."))
                              ""))))
            (when (and output (> (length output) 0)
                       (plist-get callbacks :on-token))
              (funcall (plist-get callbacks :on-token)
                       (format "\n[%s: %s]\n%s\n"
                               (if (equal status "failed")
                                   "Tool failed" "Tool result")
                               (or title "")
                               (truncate-string-to-width
                                output 500 nil nil "..."))))))))

     ((equal event-type "agent_thought_chunk")
      (let* ((content (map-elt update 'content))
             (text (map-elt content 'text)))
        (when (and sk text)
          (code-agent--verbose-insert
           sk (propertize text 'face 'font-lock-doc-face)))))

     ((equal event-type "usage_update")
      (let ((usage (map-elt update 'usage))
            (cost (map-elt update 'cost))
            (used (map-elt update 'used))
            (size (map-elt update 'size)))
        (when usage
          (when-let* ((inp (map-elt usage 'inputTokens)))
            (setf (code-agent-acp-backend-input-tokens backend) inp))
          (when-let* ((out (map-elt usage 'outputTokens)))
            (setf (code-agent-acp-backend-output-tokens backend) out)))
        (when cost
          (when-let* ((amt (map-elt cost 'amount)))
            (setf (code-agent-acp-backend-cost-amount backend) amt))
          (when-let* ((cur (map-elt cost 'currency)))
            (setf (code-agent-acp-backend-cost-currency backend) cur)))
        (when used
          (setf (code-agent-acp-backend-context-used backend) used))
        (when size
          (setf (code-agent-acp-backend-context-size backend) size))
        (when sk
          (code-agent-acp--verbose-log
           backend
           (format "usage: in=%s out=%s%s"
                   (or (and usage (map-elt usage 'inputTokens)) "?")
                   (or (and usage (map-elt usage 'outputTokens)) "?")
                   (if cost
                       (format " cost=%s %s"
                               (or (map-elt cost 'amount) "?")
                               (or (map-elt cost 'currency) ""))
                     ""))))))

     ((equal event-type "available_commands_update") nil))))

(defun code-agent-acp--extract-content-text (content-items)
  "Extract text from ACP CONTENT-ITEMS (vector of content objects)."
  (when content-items
    (let ((texts nil))
      (seq-doseq (item content-items)
        (when-let* ((text (map-elt item 'text)))
          (push text texts)))
      (when texts
        (string-join (nreverse texts) "\n")))))

** Permission Request Handler

Default (=code-agent-acp-auto-approve= nil) prompts the user via
=completing-read=; C-g translates into a =cancelled= outcome.
Setting the customization to t restores auto-approve-first-option
for trusted environments.

#+BEGIN_SRC elisp
(defun code-agent-acp--handle-request (backend request)
  "Dispatch ACP server-to-client REQUEST for BACKEND."
  (let ((method (map-elt request 'method)))
    (cond
     ((equal method "session/request_permission")
      (code-agent-acp--handle-permission backend request))
     ((equal method "fs/read_text_file")
      (code-agent-acp--handle-fs-read backend request))
     ((equal method "fs/write_text_file")
      (code-agent-acp--handle-fs-write backend request))
     (t
      (message "code-agent-acp: unknown request: %s" method)
      ;; Respond with a -32601 method-not-found so the agent isn't hung.
      (when-let* ((id (map-elt request 'id)))
        (code-agent-jsonrpc-send-response
         (code-agent-acp-backend-client backend)
         id nil
         `((code . -32601)
           (message . ,(format "Unknown method: %s" method)))))))))

(defun code-agent-acp--resolved-dir (path)
  "Return PATH expanded + truename'd + with a trailing slash.
Trailing slash matters: without it, `string-prefix-p' of \"/home/user/p\"
would accept \"/home/user/project-evil/...\"."
  (file-name-as-directory (file-truename (expand-file-name path))))

(defun code-agent-acp--resolved-target (path)
  "Resolve PATH the way the OS would, before any sandbox check.
If PATH does not exist yet (typical for an fs/write_text_file), resolve
its parent directory (which MUST exist) and re-append the basename;
otherwise we would miss symlinks pointing outside the sandbox."
  (let ((expanded (expand-file-name path)))
    (if (file-exists-p expanded)
        (file-truename expanded)
      (expand-file-name (file-name-nondirectory expanded)
                        (file-truename
                         (file-name-directory expanded))))))

(defun code-agent-acp--path-inside-p (path root)
  "Return non-nil if PATH resolves inside ROOT (both symlink-resolved)."
  (let ((resolved-root (code-agent-acp--resolved-dir root))
        (resolved-path (code-agent-acp--resolved-target path)))
    (string-prefix-p resolved-root resolved-path)))

(defun code-agent-acp--read-allowed-p (path)
  "Return non-nil if PATH may be read.
Honours `code-agent-acp-fs-read-roots' when set; otherwise permits any
file Emacs can read."
  (and path
       (file-readable-p path)
       (or (null code-agent-acp-fs-read-roots)
           (cl-some (lambda (root)
                      (code-agent-acp--path-inside-p path root))
                    code-agent-acp-fs-read-roots))))

(defun code-agent-acp--handle-fs-read (backend request)
  "Handle `fs/read_text_file' REQUEST by reading the file and returning content.
Enforces `code-agent-acp-fs-read-roots' (when set) symlink-aware.
Errors are surfaced to the agent as JSON-RPC error responses so it can
decide how to recover."
  (let* ((id (map-elt request 'id))
         (params (map-elt request 'params))
         (path (map-elt params 'path))
         (client (code-agent-acp-backend-client backend)))
    (condition-case err
        (cond
         ((null path)
          (code-agent-jsonrpc-send-response
           client id nil `((code . -32602) (message . "Missing path"))))
         ((not (code-agent-acp--read-allowed-p path))
          (code-agent-jsonrpc-send-response
           client id nil
           `((code . -32603)
             (message . ,(format "Read denied by fs-read-roots policy: %s"
                                 path)))))
         (t
          (let ((content (with-temp-buffer
                           (insert-file-contents path)
                           (buffer-string))))
            (code-agent-jsonrpc-send-response
             client id `((content . ,content)))
            (code-agent-acp--verbose-log
             backend (format "fs/read_text_file: %s (%d bytes)"
                             path (length content))))))
      (error
       (code-agent-jsonrpc-send-response
        client id nil
        `((code . -32603) (message . ,(error-message-string err))))))))

(defun code-agent-acp--handle-fs-write (backend request)
  "Handle `fs/write_text_file' REQUEST.
Writes the supplied content to =path= and acknowledges.  Refuses to
write outside `code-agent-acp-fs-write-root' if that variable is set
(symlink-aware — see `code-agent-acp--path-inside-p')."
  (let* ((id (map-elt request 'id))
         (params (map-elt request 'params))
         (path (map-elt params 'path))
         (content (map-elt params 'content))
         (client (code-agent-acp-backend-client backend)))
    (condition-case err
        (cond
         ((null path)
          (code-agent-jsonrpc-send-response
           client id nil `((code . -32602) (message . "Missing path"))))
         ((and code-agent-acp-fs-write-root
               (not (code-agent-acp--path-inside-p
                     path code-agent-acp-fs-write-root)))
          (code-agent-jsonrpc-send-response
           client id nil
           `((code . -32603)
             (message . ,(format "Refusing write outside %s: %s"
                                 code-agent-acp-fs-write-root path)))))
         (t
          (with-temp-file path
            (insert (or content "")))
          (code-agent-jsonrpc-send-response client id '())
          (code-agent-acp--verbose-log
           backend (format "fs/write_text_file: %s (%d bytes)"
                           path (length (or content ""))))))
      (error
       (code-agent-jsonrpc-send-response
        client id nil
        `((code . -32603) (message . ,(error-message-string err))))))))

(defun code-agent-acp--handle-permission (backend request)
  "Handle a =session/request_permission= REQUEST for BACKEND.
Default prompts the user; if `code-agent-acp-auto-approve' is non-nil,
auto-approves with the first option."
  (let* ((request-id (map-elt request 'id))
         (params (map-elt request 'params))
         (tool-call (map-elt params 'toolCall))
         (title (or (and tool-call (map-elt tool-call 'title)) "tool call"))
         (options (map-elt params 'options))
         (option-id
          (if code-agent-acp-auto-approve
              (code-agent-acp--first-option-id options)
            (code-agent-acp--prompt-user-for-option title options)))
         (callbacks (code-agent-acp-backend-callbacks backend))
         (client (code-agent-acp-backend-client backend)))
    (if (and request-id option-id)
        (progn
          (code-agent-jsonrpc-send-response
           client request-id
           `((outcome . ((outcome . "selected") (optionId . ,option-id)))))
          (code-agent-acp--verbose-log
           backend (format "permission %s: %s"
                           (if code-agent-acp-auto-approve
                               "auto-approved"
                             "user-selected")
                           title))
          (when (plist-get callbacks :on-token)
            (funcall (plist-get callbacks :on-token)
                     (format "\n[Permission: %s → %s]\n" title option-id))))
      ;; User cancelled or no options — tell the agent.
      (when request-id
        (code-agent-jsonrpc-send-response
         client request-id
         `((outcome . ((outcome . "cancelled")))))
        (code-agent-acp--verbose-log
         backend (format "permission cancelled: %s" title))))))

(defun code-agent-acp--first-option-id (options)
  "Return the id of the first option in OPTIONS, or nil if none."
  (when (and options (> (length options) 0))
    (map-elt (aref options 0) 'id)))

(defun code-agent-acp--sanitize-agent-string (s)
  "Strip control characters from agent-supplied string S and truncate.
Prevents terminal-escape / whitespace-padding spoofing at the permission
prompt.  Truncates to `code-agent-acp-permission-title-max' chars."
  (let ((clean (replace-regexp-in-string "[[:cntrl:]]" "" (or s ""))))
    (if (> (length clean) code-agent-acp-permission-title-max)
        (concat (substring clean 0 code-agent-acp-permission-title-max) "…")
      clean)))

(defun code-agent-acp--prompt-user-for-option (title options)
  "Prompt user via `completing-read' to pick one of OPTIONS for TITLE.
Returns the option id, or nil if the user hit C-g.  TITLE is sanitised
(control chars stripped, length capped) before display."
  (when (and options (> (length options) 0))
    (let* ((choices
            (mapcar (lambda (opt)
                      (let ((id (map-elt opt 'id))
                            (label (or (map-elt opt 'name)
                                       (map-elt opt 'label)
                                       (map-elt opt 'id))))
                        (cons (code-agent-acp--sanitize-agent-string label)
                              id)))
                    (append options nil)))
           (safe-title (code-agent-acp--sanitize-agent-string title))
           (prompt (format "ACP %s: " safe-title))
           (label (condition-case nil
                      (completing-read prompt (mapcar #'car choices) nil t)
                    (quit nil))))
      (when label
        (cdr (assoc label choices))))))

** Backend Protocol Methods

*** Query

Public query entry — translates user prompt + callbacks into a backend-specific RPC.

#+BEGIN_SRC elisp
(cl-defmethod code-agent-backend-query
    ((backend code-agent-acp-backend) prompt callbacks &rest _args)
  "Send PROMPT via ACP BACKEND, invoking CALLBACKS.  Returns BACKEND as handle.
Rejects the call immediately if another query is in-flight — previous
versions silently overwrote the earlier query's callbacks, losing the
first prompt's `:on-complete' and `:on-error'."
  (if (code-agent-acp-backend-active-query backend)
      (progn
        (when (plist-get callbacks :on-error)
          (funcall (plist-get callbacks :on-error)
                   "ACP backend busy: prior query still in-flight"))
        (when (plist-get callbacks :on-complete)
          (funcall (plist-get callbacks :on-complete) nil))
        backend)
    (setf (code-agent-acp-backend-callbacks backend) callbacks)
    (setf (code-agent-acp-backend-active-query backend) t)
    (lexical-let ((backend backend)
                  (prompt prompt)
                  (callbacks callbacks))
      (if (code-agent-acp-backend-initialized backend)
          (code-agent-acp--send-prompt backend prompt callbacks)
        (code-agent-acp--connect backend
         (lambda ()
           (code-agent-acp--send-prompt backend prompt callbacks))
         (lambda (err)
           (setf (code-agent-acp-backend-active-query backend) nil)
           (when (plist-get callbacks :on-error)
             (funcall (plist-get callbacks :on-error) err))
           (when (plist-get callbacks :on-complete)
             (funcall (plist-get callbacks :on-complete) nil))))))
    backend))

(defun code-agent-acp--send-prompt (backend prompt callbacks)
  "Send PROMPT on the existing ACP session for BACKEND."
  (setf (code-agent-acp-backend-prompt-start-time backend) (float-time))
  (when-let* ((sk (code-agent-acp-backend-session-key backend)))
    (code-agent--get-session-verbose-buffer sk)
    (code-agent--verbose-insert-query-header
     sk prompt
     (string-join (code-agent-acp-backend-spawn-args backend) " ")
     nil
     (or (code-agent-acp-backend-cwd backend) default-directory)
     nil))
  (lexical-let ((backend backend)
                (callbacks callbacks))
    (let ((content-blocks (vector `((type . "text") (text . ,prompt)))))
      (code-agent-jsonrpc-send-request
       (code-agent-acp-backend-client backend)
       "session/prompt"
       `((sessionId . ,(code-agent-acp-backend-session-id backend))
         (prompt . ,content-blocks))
       (lambda (result)
         (when-let* ((usage (map-elt result 'usage)))
           (when-let* ((inp (map-elt usage 'inputTokens)))
             (setf (code-agent-acp-backend-input-tokens backend) inp))
           (when-let* ((out (map-elt usage 'outputTokens)))
             (setf (code-agent-acp-backend-output-tokens backend) out)))
         (code-agent-acp--verbose-completion backend)
         (setf (code-agent-acp-backend-active-query backend) nil)
         (setf (code-agent-acp-backend-callbacks backend) nil)
         (when (plist-get callbacks :on-complete)
           (funcall (plist-get callbacks :on-complete) nil)))
       (lambda (err)
         (code-agent-acp--verbose-log
          backend (format "prompt error: %s" (map-elt err 'message)))
         (setf (code-agent-acp-backend-active-query backend) nil)
         (setf (code-agent-acp-backend-callbacks backend) nil)
         (when (plist-get callbacks :on-error)
           (funcall (plist-get callbacks :on-error)
                    (format "ACP prompt failed: %s"
                            (map-elt err 'message))))
         (when (plist-get callbacks :on-complete)
           (funcall (plist-get callbacks :on-complete) nil)))))))

(defun code-agent-acp--format-tokens-compact (n)
  "Format token count N compactly with k/m suffixes."
  (cond
   ((>= n 1000000) (format "%.0fm" (/ n 1000000.0)))
   ((>= n 1000) (format "%.1fk" (/ n 1000.0)))
   (t (format "%d" n))))

(defun code-agent-acp--verbose-completion (backend)
  "Write prompt-complete line to verbose buffer for BACKEND."
  (when-let* ((sk (code-agent-acp-backend-session-key backend))
              (start (code-agent-acp-backend-prompt-start-time backend)))
    (let* ((elapsed (- (float-time) start))
           (cost (code-agent-acp-backend-cost-amount backend))
           (currency (code-agent-acp-backend-cost-currency backend))
           (in-tok (code-agent-acp-backend-input-tokens backend))
           (out-tok (code-agent-acp-backend-output-tokens backend))
           (parts (list (format "%.1fs" elapsed))))
      (when (and cost (numberp cost) (> cost 0))
        (push (if (and currency (equal currency "USD"))
                  (format "$%.4f" cost)
                (format "%s %s" cost (or currency "")))
              parts))
      (when (and (numberp in-tok) (> in-tok 0))
        (push (format "%s in %s out"
                      (code-agent-acp--format-tokens-compact in-tok)
                      (code-agent-acp--format-tokens-compact (or out-tok 0)))
              parts))
      (code-agent--verbose-insert
       sk (format "\n%s\n"
                  (propertize
                   (format "════ Complete: %s ════"
                           (string-join (nreverse parts) " | "))
                   'face 'font-lock-comment-face)))
      (setf (code-agent-acp-backend-prompt-start-time backend) nil))))

(cl-defmethod code-agent-backend-classify-error
    ((_backend code-agent-acp-backend) error)
  "Classify ERROR from ACP backend."
  (let ((msg (cond
              ((stringp error) error)
              ((and (listp error) (map-elt error 'message))
               (map-elt error 'message))
              (t nil))))
    (cond
     ((null msg) 'unknown)
     ((string-match-p "auth" msg) 'auth)
     ((string-match-p "session.*expired\\|invalid.*session" msg)

     ((string-match-p "connect\\|timeout\\|ECONNREFUSED" msg) 'network)
     (t 'unknown))))

** Profile Factory Helper

Shared by every per-vendor ACP profile (=opencode=, =gemini=,
=codex=).  The =auth-method-symbol= is dereferenced *at request
time* so a user who toggles e.g. =code-agent-acp-codex-auth-method=
between two calls sees the change immediately.

#+BEGIN_SRC elisp
(defun code-agent-acp--make-profile-backend
    (constructor agent-name command environment auth-method-symbol &rest args)
  "Create an ACP profile backend instance with the shared default plumbing.
CONSTRUCTOR is the subclass's `--create' function.
AGENT-NAME is the agent identifier string (e.g. \"codex\", \"gemini\").
COMMAND is the spawn command list (read from a `defcustom').
ENVIRONMENT is the extra env vars list (read from a `defcustom').
AUTH-METHOD-SYMBOL is the symbol holding the current auth method;
its `symbol-value' is reread at each authenticate request.
ARGS are extra :key VAL pairs forwarded to CONSTRUCTOR (typically
:cwd, :session-key).

`lexical-let' is required because literate-elisp evaluates this
file with dynamic binding — without it, the auth-request lambda
would not capture `auth-method-symbol' and would error
`void-variable' when invoked from the ACP handshake."
  (lexical-let ((auth-method-symbol auth-method-symbol))
    (apply constructor
           :agent-name agent-name
           :spawn-args command
           :environment environment
           :needs-authenticate t
           :auth-request-maker (lambda ()
                                 `((methodId . ,(symbol-name
                                                 (symbol-value auth-method-symbol)))))
           args)))
