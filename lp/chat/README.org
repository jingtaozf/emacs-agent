#+TITLE: lp/chat — Package Shell (Activity / Usage Mode-Lines)

The package entry-point module: activity mode-line showing in-flight
query count, the rate-limit indicator, defcustoms, autoloads, and
release tags.  Every other module loads through here.

(The interactive comint chat buffer, prompt-refinement helper, and
one-shot translation helper that used to live alongside this file —
=code-agent-chat.org=, =code-agent-refine.org=,
=code-agent-translate.org= — were removed: the pivot direction is
agents living in cmux/tmux terminals, not an embedded-chat frontend.
=code-agent-title.org= — auto-title generation — had no surviving
caller either and was removed as well, after an initial keep-and-flag
period.)

| File | Role |
|------+------|
| [[file:code-agent.org][code-agent.org]] | Package entry-point — activity mode-line, rate-limit mode-line, defcustoms, autoloads, release tags. |

* Boundaries

- /chat/ → /sdk/: consumes the backend protocol; receives token
  callbacks from any backend without backend-specific branching.
- /chat/ ⟂ /org/: this module group and org surface (=lp/org/=) are
  independent — neither module group =require=s the other's
  internals.  Both consume /sdk/.
