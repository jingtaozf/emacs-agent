#+TITLE: lp/chat — Chat Surface (Activity / Usage / Auxiliary Modes)

Modules that own the *non-org* user-facing surfaces: the activity
mode-line showing in-flight query count, the rate-limit indicator, the
interactive chat-mode, the prompt-refinement helper, the title-gen and
translation modes.

* Modules

| File | Role |
|------+------|
| [[file:code-agent.org][code-agent.org]] | Package entry-point — activity mode-line, rate-limit mode-line, defcustoms, autoloads, release tags.  Every other module loads through here. |
| [[file:code-agent-chat.org][code-agent-chat.org]] | =*Claude Chat*= comint-based interactive chat buffer. |
| [[file:code-agent-refine.org][code-agent-refine.org]] | Prompt-refinement helper — sends a prompt to Claude to improve it before execution. |
| [[file:code-agent-title.org][code-agent-title.org]] | Auto-generates titles for response sections (mirrors the org-side title-gen but for the chat surface). |
| [[file:code-agent-translate.org][code-agent-translate.org]] | One-shot translation helper using Claude. |

* Read order

1. [[file:code-agent.org][code-agent.org]] — the package shell.  Everything else depends on
   the activity-count + usage-level state declared here.
2. [[file:code-agent-chat.org][code-agent-chat.org]] when investigating chat-buffer behaviour.
3. The auxiliary modes (=refine=, =title=, =translate=) are
   self-contained; consult only when changing that feature.

* Boundaries

- /chat/ → /sdk/: consumes the backend protocol; receives token
  callbacks from any backend without backend-specific branching.
- /chat/ ⟂ /org/: chat surface (this group) and org surface
  (=lp/org/=) are independent — neither module group =require=s the
  other's internals.  Both consume /sdk/.
