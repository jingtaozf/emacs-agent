* Overview
:PROPERTIES:
:CUSTOM_ID: org-workspace-bridge-overview
:END:

When the user types a prompt directly into the Claude Code terminal
(not via =C-c C-c= on an =#+begin_src ai= block), Emacs is bypassed
entirely — there is no marker, no session state, no in-flight query
to track.  Without this module, the prompt and its eventual response
would never appear in the org buffer; the user would have two
disconnected views of the conversation.

Invariant: every function here is called non-interactively from
=python/code_agent/workspace_bridge.py= through MCP =evalElisp=.  Each
mutation is idempotent (re-running a handler with the same payload
must not double-insert a heading or marker).  The routing-key
contract — =:CUSTOM_ID:= preferred, falling back to
=CLAUDE_SESSION_ID=, falling back to agent =--name= slug — is the
*only* path from a terminal hook payload to the right org section.

* Claude Org Workspace Bridge
:PROPERTIES:
:LITERATE_ORG_BLOCK_KIND: atomic
:header-args:elisp: :tangle yes
:END:

Functions for bridging between Claude Code CLI (running in a terminal) and
org-mode workspace sections. Called non-interactively via MCP ~evalElisp~ from
hook scripts.

** Architecture

When the user types a prompt directly into the Claude Code terminal
(no =C-c C-c= involved), Claude's =UserPromptSubmit= and =Stop= hooks
fire, =workspace_bridge.py= relays them over MCP, and the functions in
this file mutate the org buffer to reflect the conversation. Five hops:

#+begin_example
Terminal user types prompt
  ↓
Claude CLI fires UserPromptSubmit hook (per hooks.json matcher)
  ↓
python/code_agent/workspace_bridge.py handle_prompt()
  ↓
MCP evalElisp → code-agent-org-workspace-bridge-insert-prompt
  ↓
Org buffer gains: ,*** Instruction N + ,#+begin_src ai prompt ,#+end_src
                  + new ,*** Response N :ai_output: skeleton
                  + active-queries entry (mode-line / Query Manager)

Claude responds, CLI fires Stop hook
  ↓
workspace_bridge.py handle_response()
  ↓
MCP evalElisp → code-agent-org-workspace-bridge-insert-response
                + run-hook-with-args 'code-agent-org-complete-hook
                + --query-completed (unregister, advance loop)
#+end_example

** Module Rename — From "SDD Bridge"

This module was originally called the "SDD bridge" in the design doc
(2026-03-06) and shipped under that name. It was renamed to
*workspace bridge* in 2026-04 once it became clear the same hook
plumbing serves any terminal-typed prompt — not just SDD stories.
Only the names changed; the wire format (hook JSON over stdin →
=workspace_bridge.py= → MCP =evalElisp=) is unchanged. The Python
file is =python/code_agent/workspace_bridge.py=; older history
referring to =sdd_bridge.py= or "SDD hook" describes the same code.

** Lifecycle Parity Across Entry Points

Two entry points reach this file's =insert-prompt= / =insert-response=:
=C-c C-c= on an =ai= block, *and* prompts typed directly in the
terminal. Both must result in the same Emacs-side state — same
=active-queries= entry, same exec-status property, same complete-hook
firing — otherwise downstream features (mode-line spinner, Query
Manager, "Jump to AI block" via =goto-story=, telemetry persistence)
silently break for the terminal-typed path.

The shipped strategy: =workspace-bridge-insert-prompt= fires
=code-agent-org-execute-hook= itself, after the org structure is in
place. This reuses the existing hook chain — the same chain that
=code-agent-org-execute= fires for =C-c C-c= — so every hook function
treats both paths identically.

The dedup mechanism that lets both paths coexist without
double-insertion is the =.from-emacs= flag (see
=code-agent-org-terminal-base.org= → "Status File I/O"): =C-c C-c=
writes the flag *before* sending the prompt; the bridge's
=insert-prompt= sees the flag set and skips insertion (the org
structure was already created on the Emacs side); =PostToolUse=
clears the flag.

Telemetry (token counts, duration, cost) is the one feature where
parity is intentionally partial — the =Stop= hook JSON carries
=duration_ms= and =usage= fields, but they don't currently flow into
the Emacs side. Adding them is a small additive change to
=workspace_bridge.handle_response= plus a Protocol 3 method on the
backend; left as a follow-up because no current consumer needs it.

** Buffer and Navigation

Movement primitives for buffer and — wraps =org-goto-*= so callers express intent, not point arithmetic.

#+BEGIN_SRC elisp
(defun code-agent-org-workspace-bridge--ensure-buffer (org-file)
  "Ensure ORG-FILE is loaded in Emacs and return its buffer.
Opens the file via `find-file-noselect' if not already visiting."
  (or (find-buffer-visiting org-file)
      (find-file-noselect org-file)))

(defun code-agent-org-workspace-bridge-list-sessions (org-file)
  "List all workspace sessions in ORG-FILE.
Returns a newline-separated string of \"SESSION_ID\\tHEADING\\tPARENT\" lines,
one per workspace section found. PARENT is the outline path above the workspace heading."
  (with-current-buffer (code-agent-org-workspace-bridge--ensure-buffer org-file)
    (save-excursion
      (save-restriction
        (widen)
        (goto-char (point-min))
        (let (results)
          (while (re-search-forward
                  "^[ \t]*:CLAUDE_SESSION_ID:[ \t]+\\(.+?\\)[ \t]*$" nil t)
            (let ((sid (match-string-no-properties 1)))
              (save-excursion
                (org-back-to-heading t)
                (let* ((heading (substring-no-properties (org-get-heading t t t t)))
                       (parent (mapconcat
                                (lambda (s) (substring-no-properties s))
                                (org-get-outline-path)
                                " / ")))
                  (push (format "%s\t%s\t%s" sid heading parent) results)))))
          (mapconcat #'identity (nreverse results) "\n"))))))

(defun code-agent-org-workspace-bridge--goto-session (workspace-key)
  "Move point to the workspace section matching WORKSPACE-KEY in current buffer.

WORKSPACE-KEY is matched against two properties, in this order:

1. =:CUSTOM_ID:= — the stable, globally-unique heading anchor.  This
   is the preferred routing key set by ``workspace_launcher.py`` as
   the ``WORKSPACE_CUSTOM_ID`` env var.  Survives heading rename and
   cmux workspace rename, which closes the cross-workspace routing
   bug seen on 2026-05-21.

2. =:CLAUDE_SESSION_ID:= — legacy routing key.  Retained so existing
   tests and any code path still using ``WORKSPACE_SESSION_ID`` keep
   working unchanged.

Signals error if neither match is found."
  (goto-char (point-min))
  (let ((found nil)
        (pattern-cid
         (format "^[ \t]*:CUSTOM_ID:[ \t]+%s[ \t]*$"
                 (regexp-quote workspace-key)))
        (pattern-sid
         (format "^[ \t]*:CLAUDE_SESSION_ID:[ \t]+%s[ \t]*$"
                 (regexp-quote workspace-key))))
    ;; Try CUSTOM_ID first (preferred).
    (save-excursion
      (while (and (not found) (re-search-forward pattern-cid nil t))
        (save-excursion
          (org-back-to-heading t)
          ;; Only accept matches on workspace-level headings — a
          ;; ``:CUSTOM_ID:`` on an instruction or response inside the
          ;; workflow would otherwise sometimes win and misroute.  A
          ;; workspace heading is the ancestor that owns
          ;; ``:CLAUDE_SESSION_ID:``.
          (when (org-entry-get nil "CLAUDE_SESSION_ID")
            (setq found (point))))))
    ;; Fall back to CLAUDE_SESSION_ID.
    (unless found
      (save-excursion
        (while (and (not found) (re-search-forward pattern-sid nil t))
          (setq found (match-beginning 0)))))
    (unless found
      (error "Workspace %s not found in buffer (matched neither :CUSTOM_ID: nor :CLAUDE_SESSION_ID:)"
             workspace-key))
    (goto-char found)
    (org-back-to-heading t)))

(defun code-agent-org-workspace-bridge--find-workflow (session-id)
  "Find the Workflow subsection under the active story for SESSION-ID.
Uses ACTIVE_STORY to narrow to the correct story, falls back to any Workflow.
Returns the position of the Workflow heading, or signals error."
  (code-agent-org-workspace-bridge--goto-session session-id)
  (let* ((workspace-end (save-excursion (org-end-of-subtree t t) (point)))
         (active-story (org-entry-get nil "ACTIVE_STORY"))
         (search-start (point))
         (search-end workspace-end)
         (found nil))
    ;; If ACTIVE_STORY is set, narrow search to that story's subtree
    (when active-story
      (save-excursion
        (let ((ws-level (org-current-level)))
          (when (re-search-forward
                 (format "^\\*\\{%d\\} +%s" (1+ ws-level) (regexp-quote active-story))
                 workspace-end t)
            (goto-char (line-beginning-position))
            (setq search-start (point))
            (setq search-end (save-excursion (org-end-of-subtree t t) (point)))))))
    ;; Find Workflow heading (with or without :sdd: tag)
    (save-excursion
      (goto-char search-start)
      (while (and (not found)
                  (re-search-forward "^\\*+ +Workflow\\b" search-end t))
        (setq found (line-beginning-position))))
    (unless found
      (error "Workflow section not found under session %s" session-id))
    (goto-char found)))
#+END_SRC

** Prompt Insertion

Inserts prompt into the org buffer at the matching marker — preserves point + window-start.

#+BEGIN_SRC elisp
(defun code-agent-org-workspace-bridge--count-instructions (instr-level workflow-end)
  "Count headings of depth INSTR-LEVEL tagged with `code-agent-org-heading-tag'.
Counts by tag, not text — auto-title may rename ``Instruction N''
to ``Fix parser bug'', so a regex over the visible heading text
would miss renamed entries.  Scans up to WORKFLOW-END."
  (let ((count 0))
    (save-excursion
      (while (re-search-forward
              (format "^\\*\\{%d\\} +.+:%s:"
                      instr-level code-agent-org-heading-tag)
              workflow-end t)
        (setq count (1+ count))))
    count))

(defun code-agent-org-workspace-bridge--write-instruction-block
    (workflow-end instr-level instr-num custom-id prompt)
  "Insert ``Instruction N :tag:'' heading + properties + ai block at WORKFLOW-END.
Returns a marker on the heading line so the caller can re-position
for register-query / auto-title hooks."
  (goto-char workflow-end)
  (unless (bolp) (insert "\n"))
  (unless (save-excursion (forward-line -1) (looking-at "^[ \t]*$"))
    (insert "\n"))
  (let ((stars (make-string instr-level ?*)))
    (insert (format "%s Instruction %d :%s:\n"
                    stars instr-num code-agent-org-heading-tag)))
  (let ((heading-marker (copy-marker (line-beginning-position 0))))
    (insert ":PROPERTIES:\n"
            (format ":CUSTOM_ID: %s\n" custom-id)
            ":END:\n\n"
            "#+begin_src ai\n"
            prompt "\n"
            "#+end_src\n")
    heading-marker))

(defun code-agent-org-workspace-bridge--wire-new-instruction
    (session-id prompt heading-marker)
  "Hook a freshly-inserted terminal-bridge prompt into the rest of the system.

Point starts at HEADING-MARKER inside the org buffer; the function
registers an active query, fires the standard execute-hook,
flips :busy, maps workspace-id → session-key, marks the heading's
AI_EXEC_STATUS, and kicks off auto-title (if enabled)."
  (goto-char heading-marker)
  (code-agent-org-terminal--register-query session-id nil)
  (when-let* ((session-key (code-agent-org--current-session-key)))
    (run-hook-with-args 'code-agent-org-execute-hook session-key prompt nil)
    (code-agent-org--session-put session-key :busy t)
    (puthash session-id session-key
             code-agent-org-terminal--workspace-to-session-key))
  (code-agent-org--set-exec-status "executing")
  (when code-agent-org-auto-generate-title
    (code-agent-org--maybe-auto-generate-title prompt heading-marker)))

(defun code-agent-org-workspace-bridge-insert-prompt (org-file session-id prompt)
  "Insert PROMPT as a new AI block in the workspace Workflow for SESSION-ID in ORG-FILE.
Creates a new Instruction N subsection under the Workflow heading.
Returns the CUSTOM_ID string for correlating with the Stop hook."
  (code-agent-with-span "workspace-insert-prompt"
      (list :session-id session-id) nil
    (with-current-buffer (code-agent-org-workspace-bridge--ensure-buffer org-file)
      (let (custom-id)
        (save-excursion
          (save-restriction
            (widen)
            (code-agent-org-workspace-bridge--find-workflow session-id)
            (let* ((workflow-level (org-current-level))
                   (instr-level    (1+ workflow-level))
                   (workflow-end
                    (code-agent-org-workspace-bridge--find-next-sibling-heading
                     workflow-level (point-max)))
                   (instr-num
                    (1+ (code-agent-org-workspace-bridge--count-instructions
                         instr-level workflow-end)))
                   (file-base
                    (file-name-sans-extension (file-name-nondirectory org-file)))
                   (heading-marker nil))
              (setq custom-id (code-agent-org--generate-instruction-custom-id
                               file-base instr-num session-id))
              (setq heading-marker
                    (code-agent-org-workspace-bridge--write-instruction-block
                     workflow-end instr-level instr-num custom-id prompt))
              (code-agent-org-workspace-bridge--wire-new-instruction
               session-id prompt heading-marker))))
        (save-buffer)
        custom-id))))
#+END_SRC

** Response Insertion

#+BEGIN_SRC elisp
(defun code-agent-org-workspace-bridge--shift-org-headings (text parent-level)
  "Shift org heading levels in TEXT to be subsections of PARENT-LEVEL.
Lines starting with *+ get PARENT-LEVEL additional stars prepended,
making them children of the parent heading."
  (let ((prefix (make-string parent-level ?*)))
    (replace-regexp-in-string
     "^\\(\\*+ \\)"
     (concat prefix "\\1")
     text)))

(defun code-agent-org-workspace-bridge--find-next-sibling-heading (level limit)
  "Find the next heading at LEVEL or shallower before LIMIT.
Searches by regex to avoid `org-end-of-subtree' confusion from
embedded org headings in response content.
Returns the position, or LIMIT if none found."
  (save-excursion
    ;; Skip current heading line
    (forward-line 1)
    (let ((pattern (format "^\\*\\{1,%d\\} " level)))
      (if (re-search-forward pattern limit t)
          (line-beginning-position)
        limit))))

(defun code-agent-org-workspace-bridge--find-heading-by-custom-id (custom-id limit)
  "Find heading with CUSTOM_ID before LIMIT.  Returns position or nil."
  (save-excursion
    (let ((pattern (format ":CUSTOM_ID: %s" (regexp-quote custom-id))))
      (when (re-search-forward pattern limit t)
        (org-back-to-heading t)
        (point)))))

(defun code-agent-org-workspace-bridge--find-next-instruction-heading (instr-level tag workflow-end)
  "Find the next instruction heading (with TAG) at INSTR-LEVEL before WORKFLOW-END.
Skips response headings (:ai_output:). Returns position, or WORKFLOW-END."
  (save-excursion
    (forward-line 1)
    (let ((pattern (format "^\\*\\{%d\\} +.+:%s:" instr-level tag)))
      (if (re-search-forward pattern workflow-end t)
          (line-beginning-position)
        workflow-end))))

(defun code-agent-org-workspace-bridge--find-existing-response (instr-pos instr-level next-instr-pos)
  "Find existing Response heading for instruction at INSTR-POS.
Searches between INSTR-POS and NEXT-INSTR-POS for a heading at INSTR-LEVEL
with :ai_output: tag.  Returns (BEG . END) of the response subtree, or nil."
  (save-excursion
    (goto-char instr-pos)
    (forward-line 1)
    (let ((pattern (format "^\\*\\{%d\\} +.+:ai_output:" instr-level)))
      (when (re-search-forward pattern next-instr-pos t)
        (let ((beg (line-beginning-position)))
          ;; Find end of response subtree (next same-level heading or next-instr-pos)
          (let ((end (code-agent-org-workspace-bridge--find-next-sibling-heading
                      instr-level next-instr-pos)))
            (cons beg end)))))))

(defun code-agent-org-workspace-bridge-insert-response (org-file session-id response instr-custom-id)
  "Insert RESPONSE after the Instruction with INSTR-CUSTOM-ID in ORG-FILE.
If a Response section already exists for this instruction, appends to it.
Otherwise creates a new Response section.
Org headings in response content are shifted to become subsections."
  (code-agent-with-span "workspace-insert-response"
      (list :session-id session-id :custom-id instr-custom-id
            :response-length (length response)) nil
  (with-current-buffer (code-agent-org-workspace-bridge--ensure-buffer org-file)
    (save-excursion
      (save-restriction
        (widen)
        (code-agent-org-workspace-bridge--find-workflow session-id)
        (let* ((workflow-level (org-current-level))
               (instr-level (1+ workflow-level))
               (stars (make-string instr-level ?*))
               (workflow-end (code-agent-org-workspace-bridge--find-next-sibling-heading
                              workflow-level (point-max)))
               (instr-pos (code-agent-org-workspace-bridge--find-heading-by-custom-id
                           instr-custom-id workflow-end))
               (response-num 0))
          (unless instr-pos
            (error "Instruction %s not found under Workflow for session %s"
                   instr-custom-id session-id))
          ;; Count which instruction this is among siblings (1-indexed)
          (save-excursion
            (while (and (re-search-forward
                         (format "^\\*\\{%d\\} +.+:%s:" instr-level code-agent-org-heading-tag)
                         workflow-end t)
                        (<= (line-beginning-position) instr-pos))
              (setq response-num (1+ response-num))))
          ;; Find the next instruction heading (skip responses)
          (goto-char instr-pos)
          (let* ((next-instr-pos (code-agent-org-workspace-bridge--find-next-instruction-heading
                                  instr-level code-agent-org-heading-tag workflow-end))
                 (existing (code-agent-org-workspace-bridge--find-existing-response
                            instr-pos instr-level next-instr-pos)))
            (if existing
                ;; Append to existing response section (before its end)
                (let ((response-end (cdr existing)))
                  (goto-char response-end)
                  ;; Back up to insert before the next heading, after existing content
                  (unless (bolp) (insert "\n"))
                  (insert "\n" (code-agent-org-workspace-bridge--shift-org-headings response instr-level) "\n"))
              ;; Create new response section — insert just before the next instruction
              (let ((timestamp (format-time-string "%Y-%m-%d %H:%M")))
                (goto-char next-instr-pos)
                (unless (bolp) (insert "\n"))
                (unless (save-excursion (forward-line -1) (looking-at "^[ \t]*$"))
                  (insert "\n"))
                (insert (format "%s Response %d (%s) :ai_output:\n"
                                stars response-num timestamp))
                (insert ":PROPERTIES:\n:QUERY_TYPE: terminal\n:END:\n\n")
                (insert (code-agent-org-workspace-bridge--shift-org-headings response instr-level) "\n")))
            ;; Flip the instruction's status so the header-line shows
            ;; "completed" rather than staying stuck at "executing".
            ;; Previously no code path did this on terminal-typed prompts,
            ;; which is why 4 PCR-dev1 blocks remained "executing" even
            ;; after their responses arrived.
            (save-excursion
              (goto-char instr-pos)
              (org-entry-put nil code-agent-org-exec-status-property "completed"))))))
    (save-buffer)
    ;; Multiplexer-family completion bookkeeping.  Agent-family backends
    ;; do this in `code-agent-org--handle-complete'; the multiplexer path
    ;; relies on the bridge for response delivery and so must drive the
    ;; same lifecycle here:
    ;;   - persist telemetry (D1)
    ;;   - continue the loop if `:loop-current < :loop-max' (A5)
    ;;   - otherwise clear `:busy' and dequeue any pending block (A6)
    ;; Without this, cmux session-state stays :busy forever, queued
    ;; blocks never run, and loop iterations stop after the first.
    (let* ((session-key (code-agent-org-workspace-bridge--session-key
                         org-file session-id)))
      (when session-key
        (condition-case nil
            (code-agent-org-workspace-bridge--complete-multiplexer-cycle
             session-key)
          (error nil))))
    (format "Inserted Response (%d chars)" (length response)))))

(defun code-agent-org-workspace-bridge--session-key (org-file session-id)
  "Build the canonical session-key string used by the multiplexer
session table.  Mirrors `code-agent-org--current-session-key' but
takes its inputs as arguments so the bridge MCP target can look up
the same key without an active buffer point."
  (when (and org-file session-id)
    (format "%s::%s" (expand-file-name org-file) session-id)))

(defun code-agent-org-workspace-bridge--complete-multiplexer-cycle (session-key)
  "Run agent-family-equivalent completion bookkeeping for a
multiplexer session.  Called from `insert-response' after a Stop
hook delivers the agent's reply.  Persists telemetry, then either
schedules the next loop iteration or clears busy + dequeues any
pending block."
  (when (and session-key (gethash session-key code-agent-org--sessions))
    ;; Persist telemetry on the response heading (D1 fix).  Best-effort —
    ;; protect surrounding logic from failures inside individual writers.
    (condition-case nil
        (progn
          (when (fboundp 'code-agent-org--persist-duration)
            (code-agent-org--persist-duration session-key))
          (when (fboundp 'code-agent-org--persist-tool-count)
            (code-agent-org--persist-tool-count session-key)))
      (error nil))
    (let* ((loop-current (or (code-agent-org--session-get session-key :loop-current) 1))
           (loop-max (or (code-agent-org--session-get session-key :loop-max) 1))
           (should-continue (< loop-current loop-max)))
      (cond
       (should-continue
        ;; Loop has more iterations: re-fire the prompt to cmux.  Keep
        ;; :busy + :marker alive (next iteration needs them).
        (code-agent-org-workspace-bridge--continue-multiplexer-loop session-key))
       (t
        ;; Loop done (or single-shot) — drive through the centralized
        ;; cleanup path so :busy clears, markers free, queued blocks pick
        ;; up next, and the header line refreshes.
        (let ((next-block (when (fboundp 'code-agent-org--dequeue-block)
                            (condition-case nil
                                (code-agent-org--dequeue-block session-key)
                              (error nil)))))
          (condition-case nil
              (code-agent-org--cleanup-session session-key "completed" nil)
            (error nil))
          (when next-block
            (code-agent-org-workspace-bridge--execute-queued-multiplexer-block
             session-key next-block))))))))

(defun code-agent-org-workspace-bridge--continue-multiplexer-loop (session-key)
  "Schedule the next loop iteration for a multiplexer session by
re-firing the original prompt.  Mirrors the agent-family
`code-agent-org--maybe-continue-loop' but goes through the
multiplexer execute-block dispatch rather than the streaming send."
  (let* ((loop-current (or (code-agent-org--session-get session-key :loop-current) 1))
         (loop-max (or (code-agent-org--session-get session-key :loop-max) 1))
         (loop-interval (or (code-agent-org--session-get session-key :loop-interval) 0))
         (original-prompt (code-agent-org--session-get session-key :original-prompt))
         (custom-id (code-agent-org--session-get session-key :custom-id))
         (section-level (code-agent-org--session-get session-key :section-level))
         (backend (code-agent-org--session-get session-key :backend))
         (next-iteration (1+ loop-current)))
    (code-agent-org--session-put session-key :loop-current next-iteration)
    (when (and backend original-prompt)
      (let ((dispatch
             (lambda ()
               (condition-case nil
                   (code-agent-org-backend-execute-block
                    backend
                    (list :prompt original-prompt
                          :session-key session-key
                          :custom-id custom-id
                          :loop-max loop-max
                          :loop-interval loop-interval
                          :section-level section-level))
                 (error nil)))))
        (if (> loop-interval 0)
            (run-at-time loop-interval nil dispatch)
          (funcall dispatch))))))

(defun code-agent-org-workspace-bridge--execute-queued-multiplexer-block
    (session-key block-info)
  "Run a queued ai block on a multiplexer session.  Walks to the
block's saved marker, then dispatches through the backend's
`execute-block' method.  The marker is freed after dispatch."
  (let ((marker (plist-get block-info :marker))
        (backend (code-agent-org--session-get session-key :backend))
        (content (plist-get block-info :content)))
    (when (and backend content)
      (when (and marker (marker-buffer marker))
        (with-current-buffer (marker-buffer marker)
          (save-excursion
            (goto-char marker)
            (code-agent-org-backend-execute-block
             backend
             (list :prompt content
                   :session-key session-key
                   :custom-id (plist-get block-info :custom-id)
                   :loop-max (plist-get block-info :loop-max)
                   :loop-interval (plist-get block-info :loop-interval)
                   :section-level (plist-get block-info :section-level))))))
      (when (and marker (markerp marker))
        (set-marker marker nil)))))

(defun code-agent-org-workspace-bridge-latest-instruction-custom-id
    (org-file session-id)
  "Return the CUSTOM_ID of the most recent :claude_chat: instruction
under SESSION-ID's Workflow in ORG-FILE, or nil if none exists.

Used by the Python bridge when a Stop hook fires without a queued
custom-id — typically for `/loop' autonomous iterations whose
sentinel prompt (`<<autonomous-loop-dynamic>>') was filtered from
queue-append in `_handle_prompt'.  The sentinel response is a
continuation of the user's last real instruction, so we route it
there via `code-agent-org-workspace-bridge-insert-response' (which
appends to any existing Response section).

Walks the session's workflow subtree and returns the last (deepest
by position) heading that matches `code-agent-org-heading-tag'."
  (code-agent-with-span "workspace-latest-instruction-custom-id"
      (list :session-id session-id) nil
    (with-current-buffer (code-agent-org-workspace-bridge--ensure-buffer org-file)
      (save-excursion
        (save-restriction
          (widen)
          (code-agent-org-workspace-bridge--find-workflow session-id)
          (let* ((workflow-level (org-current-level))
                 (workflow-end (code-agent-org-workspace-bridge--find-next-sibling-heading
                                workflow-level (point-max)))
                 (instr-level (1+ workflow-level))
                 (latest-cid nil))
            (save-excursion
              (while (re-search-forward
                      (format "^\\*\\{%d\\} +.+:%s:" instr-level
                              code-agent-org-heading-tag)
                      workflow-end t)
                (save-excursion
                  (org-back-to-heading t)
                  (let ((cid (org-entry-get nil "CUSTOM_ID")))
                    (when cid (setq latest-cid cid))))))
            latest-cid))))))

(defun code-agent-org-workspace-bridge-mark-cancelled
    (org-file session-id instr-custom-id)
  "Flip INSTR-CUSTOM-ID's AI_EXEC_STATUS to \"cancelled\" in ORG-FILE.
Called by the workspace bridge when a queued prompt was superseded
(user typed a new prompt before Claude Code generated a reply to the
old one).  Leaves the AI block content untouched so the user can
re-execute manually."
  (code-agent-with-span "workspace-mark-cancelled"
      (list :session-id session-id :custom-id instr-custom-id) nil
  (with-current-buffer (code-agent-org-workspace-bridge--ensure-buffer org-file)
    (save-excursion
      (save-restriction
        (widen)

               (workflow-end (code-agent-org-workspace-bridge--find-next-sibling-heading

          (when instr-pos
            (goto-char instr-pos)
            (org-entry-put nil code-agent-org-exec-status-property "cancelled")
            (save-buffer)
            (format "Marked %s cancelled" instr-custom-id))))))))

#+BEGIN_SRC elisp
(defun code-agent-org-workspace-bridge--find-src-end-and-todo-region (instr-end)
  "Return ``(SRC-END TODO-START TODO-END)'' for the instruction at point.

SRC-END is the buffer position one line after ``#+end_src'' (nil
if no src block exists inside the instruction).  TODO-START /
TODO-END bracket any pre-existing checkbox region — consecutive
lines starting with ``- [`` — and are nil when no such region
exists yet.  Caller positions point at the instruction heading
before calling.

Walks at most to INSTR-END."
  (let (src-end todo-start todo-end)
    (save-excursion
      (when (re-search-forward "^#\\+end_src" instr-end t)
        (forward-line 1)
        (setq src-end (point))))
    (when src-end
      (save-excursion
        (goto-char src-end)
        (while (and (< (point) instr-end) (looking-at "^[ \t]*$"))
          (forward-line 1))
        (when (looking-at "^- \\[")
          (setq todo-start (point))
          (while (and (< (point) instr-end) (looking-at "^- \\["))
            (forward-line 1))
          (setq todo-end (point)))))
    (list src-end todo-start todo-end)))

(defun code-agent-org-workspace-bridge--render-todos (todos)
  "Render TODOS (plist list) into the markdown checkbox text."
  (mapconcat
   (lambda (todo)
     (format "- [%s] %s"
             (if (string= (plist-get todo :status) "completed") "X" " ")
             (plist-get todo :content)))
   todos "\n"))

(defun code-agent-org-workspace-bridge--write-todo-cookie (instr-pos todos)
  "Set/update the ``[N/M]'' progress cookie on the heading at INSTR-POS."
  (goto-char instr-pos)
  (let* ((done (cl-count-if
                (lambda (todo) (string= (plist-get todo :status) "completed"))
                todos))
         (total (length todos))
         (cookie (format " [%d/%d]" done total)))
    (when (re-search-forward " \\[[0-9]+/[0-9]+\\]" (line-end-position) t)
      (replace-match ""))
    (goto-char instr-pos)
    (when (re-search-forward "\\( +:\\)" (line-end-position) t)
      (goto-char (match-beginning 1))
      (insert cookie))))

(defun code-agent-org-workspace-bridge-update-todos (org-file session-id todos instr-custom-id)
  "Update checkbox list under the Instruction with INSTR-CUSTOM-ID.
TODOS is a list of plists with :content, :status, and :priority keys.
Replaces or creates the checkbox list between the src block and child headings."
  (with-current-buffer (code-agent-org-workspace-bridge--ensure-buffer org-file)
    (save-excursion
      (save-restriction
        (widen)
        (code-agent-org-workspace-bridge--find-workflow session-id)
        (let* ((workflow-level (org-current-level))
               (instr-level    (1+ workflow-level))
               (workflow-end
                (code-agent-org-workspace-bridge--find-next-sibling-heading
                 workflow-level (point-max)))
               (instr-pos
                (code-agent-org-workspace-bridge--find-heading-by-custom-id
                 instr-custom-id workflow-end)))
          (unless instr-pos
            (error "Instruction %s not found under Workflow for session %s"
                   instr-custom-id session-id))
          (goto-char instr-pos)
          (let* ((instr-end
                  (code-agent-org-workspace-bridge--find-next-sibling-heading
                   instr-level workflow-end))
                 (region
                  (code-agent-org-workspace-bridge--find-src-end-and-todo-region
                   instr-end))
                 (src-end    (nth 0 region))
                 (todo-start (nth 1 region))
                 (todo-end   (nth 2 region))
                 (checkbox-text
                  (code-agent-org-workspace-bridge--render-todos todos)))
            (when src-end
              (if todo-start
                  (progn
                    (delete-region todo-start todo-end)
                    (goto-char todo-start)
                    (insert checkbox-text "\n"))
                (goto-char src-end)
                (unless (looking-at "^[ \t]*$")
                  (insert "\n"))
                (insert checkbox-text "\n"))
              (code-agent-org-workspace-bridge--write-todo-cookie instr-pos todos))))
        (save-buffer)
        (format "Updated %d todos" (length todos))))))
