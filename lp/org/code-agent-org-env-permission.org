#+TITLE: Code Agent Org — Env Loading + Permission Mode
#+PROPERTY: literate-load yes

* Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:

Two related concerns share this module because they answer the same
shape of question: *"how does an org buffer's configuration become a
runtime value for a spawned Claude subprocess?"*

** Environment Variable Loading
:PROPERTIES:
:CUSTOM_ID: env-loading-overview
:END:

Org buffers carry a single =ENV_FILE= property pointing at a
dotenv-style file. Its =KEY=VALUE= lines become process-environment
entries on the spawned subprocess. =${VAR}= references inside the
file resolve against the file's own keys plus the current Emacs
=process-environment=. Bash-style =${VAR:-default}= falls back when
the variable isn't set.

The single-source-of-truth choice is deliberate: an earlier shape
read per-name org properties (=:ANTHROPIC_MODEL: claude-3-5-sonnet=)
on every heading and merged them into the environment. That shape
made the inheritance rules ambiguous (heading drawer + file-level
keyword + defcustom + process-env) and required code changes to
support each new env var. The =ENV_FILE= shape is one indirection,
one file, no allowlist.

** Permission Mode
:PROPERTIES:
:CUSTOM_ID: permission-mode-overview
:END:

The org property =CLAUDE_PERMISSION_MODE= selects the Claude CLI's
tool-permission level (=readonly= / =accept-edits= / =plan= /
=bypass=). The property-resolution layer applies org's inheritance
(section drawer beats file-level =#+PROPERTY:=) and falls back to
the global =code-agent-permission-preset= defcustom. The shape is
read-mostly: =--switch-permission-mode= writes the property; every
other path reads it.

MCP server auto-start is wired in here because the resulting CLI
invocation embeds the MCP HTTP endpoint as part of the
=--permission-mode= contract — if the server runs, Emacs tools are
reachable from the agent; if it doesn't, they aren't.

* ENV File Loading

#+BEGIN_SRC elisp
(cl-defun code-agent-org--parse-env (source &key from-string)
  "Parse .env content and return alist of (VAR . VALUE).
SOURCE is either a file path or a string of env content.
When FROM-STRING is non-nil, SOURCE is treated as a string.
When FROM-STRING is nil, SOURCE is treated as a file path.

Supports standard .env syntax:
  KEY=value
  KEY=\"value with spaces\"
  KEY='single quoted'
  # Comments (ignored)
  export KEY=value (export prefix ignored)
  Values containing = (only first = is split point)

Returns nil for nonexistent files. Safe parser — no Elisp execution."
  (let ((env-alist '()))
    (if from-string
        ;; Parse from string content
        (with-temp-buffer
          (insert source)
          (goto-char (point-min))
          (setq env-alist (code-agent-org--parse-env-lines)))
      ;; Parse from file path
      (let ((expanded-path (expand-file-name source)))
        (when (file-exists-p expanded-path)
          (with-temp-buffer
            (insert-file-contents expanded-path)
            (goto-char (point-min))
            (setq env-alist (code-agent-org--parse-env-lines))))))
    env-alist))

(defun code-agent-org--parse-env-lines ()
  "Parse env lines from current buffer position to end.
Returns alist of (KEY . VALUE). Internal helper for `code-agent-org--parse-env'."
  (let ((env-alist '()))
    (while (not (eobp))
      (let ((line (string-trim (buffer-substring-no-properties
                                (line-beginning-position)
                                (line-end-position)))))
        ;; Skip empty lines and comments
        (unless (or (string-empty-p line)
                    (string-prefix-p "#" line))
          ;; Remove optional "export " prefix
          (when (string-match "^\\s-*export[ \t]+" line)
            (setq line (substring line (match-end 0))))
          ;; Parse KEY=VALUE (value may contain =)
          (when (string-match "^\\([A-Za-z_][A-Za-z0-9_]*\\)=\\(.*\\)$" line)
            (let* ((key (match-string 1 line))
                   (value (match-string 2 line))
                   ;; Remove surrounding quotes if present
                   (unquoted-value (if (and (>= (length value) 2)
                                            (or (and (string-prefix-p "\"" value)
                                                     (string-suffix-p "\"" value))
                                                (and (string-prefix-p "'" value)
                                                     (string-suffix-p "'" value))))
                                       (substring value 1 -1)
                                     value)))
              (push (cons key unquoted-value) env-alist)))))
      (forward-line 1))
    (nreverse env-alist)))

(defun code-agent-org--get-env-file-path ()
  "Get ENV_FILE path from org properties.
Returns nil if not set. Supports tilde expansion."
  (when-let* ((env-file (code-agent-org--get-org-property "ENV_FILE" t))) ; no-expand=t
    (expand-file-name env-file)))

(defun code-agent-org--load-env-file ()
  "Load environment variables from ENV_FILE property.
Returns alist of (VAR . VALUE), or nil if no ENV_FILE is set."
  (when-let* ((env-file-path (code-agent-org--get-env-file-path)))
    (if (file-exists-p env-file-path)
        (code-agent-org--parse-env env-file-path)
      (message "Warning: ENV_FILE not found: %s" env-file-path)
      nil)))

* Variable Substitution

#+BEGIN_SRC elisp
(defun code-agent-org--expand-env-vars (value env-alist)
  "Expand ${VAR} references in VALUE using ENV-ALIST.
ENV-ALIST is an alist of (VAR-NAME . VAR-VALUE).
Also expands environment variables from process-environment.

Examples:
  \"${HOME}/projects\"     -> \"/Users/user/projects\"
  \"token=${API_TOKEN}\"   -> \"token=sk-abc123\"
  \"${VAR:-default}\"      -> Uses default if VAR not set (bash syntax)"
  (when value
    (let ((result value))
      ;; Replace ${VAR} with values from env-alist or process-environment
      (while (string-match "\\${\\([A-Za-z_][A-Za-z0-9_]*\\)\\(:-\\([^}]*\\)\\)?}" result)
        (let* ((var-name (match-string 1 result))
               (default-value (match-string 3 result))
               ;; Look up in env-alist first, then process-environment
               (var-value (or (cdr (assoc var-name env-alist))
                              (getenv var-name)
                              default-value
                              "")))
          (setq result (replace-match var-value t t result))))
      result)))
#+END_SRC

* Permission Mode Property Resolution

Property lookup with inheritance — section drawer wins over
file-level =#+PROPERTY:= which wins over the defcustom fallback.

#+BEGIN_SRC elisp
(defun code-agent-org--get-permission-mode-property ()
  "Get CLAUDE_PERMISSION_MODE from org properties.
Checks section property drawer first, then file-level #+PROPERTY.
Returns nil if not set.  Returns nil safely if not in org-mode context."
  (ignore-errors
    (or
     ;; Section-level property (with inheritance)
     (org-entry-get nil code-agent-org-permission-property t)
     ;; File-level property via keyword
     (code-agent-org--get-file-level-property code-agent-org-permission-property))))

(defun code-agent-org--get-permission-mode ()
  "Get effective permission mode for current session.
Priority: org property > global preset > 'readonly'.
Returns CLI permission-mode value."
  (let* ((preset (or (code-agent-org--get-permission-mode-property)
                     code-agent-permission-preset
                     "readonly"))
         (mode-info (cdr (assoc preset code-agent-org--permission-mode-map))))
    (if mode-info
        (plist-get mode-info :cli)
      "default")))

(defun code-agent-org--get-permission-mode-display ()
  "Get current permission mode name for display."
  (or (code-agent-org--get-permission-mode-property)
      code-agent-permission-preset
      "readonly"))

(defun code-agent-org--permission-mode-short ()
  "Get short permission mode string for header-line display."
  (let* ((preset (code-agent-org--get-permission-mode-display))
         (mode-info (cdr (assoc preset code-agent-org--permission-mode-map))))
    (if mode-info
        (plist-get mode-info :short)
      "??")))

(defun code-agent-org--get-setting-sources ()
  "Get setting sources for Claude CLI.
Checks CLAUDE_SETTING_SOURCES org property first, then uses default.
Returns list of strings like (\"user\" \"project\").
Returns default safely if not in org-mode context."
  (let ((prop-value
         (ignore-errors
           (or
            ;; Section-level property (with inheritance)
            (org-entry-get nil code-agent-org-setting-sources-property t)
            ;; File-level property via keyword
            (code-agent-org--get-file-level-property code-agent-org-setting-sources-property)))))
    (if prop-value
        ;; Parse comma-separated string from property
        (mapcar #'string-trim (split-string prop-value ","))
      ;; Use default
      code-agent-org-setting-sources)))

(defun code-agent-org--get-org-property (property &optional no-expand)
  "Get PROPERTY value from org properties with variable expansion.
Checks section property drawer first (with inheritance), then file-level #+PROPERTY.
Returns nil if not set.  Returns nil safely if not in org-mode context.

By default, expands ${VAR} references using ENV_FILE variables and process environment.
Set NO-EXPAND to t to disable variable expansion."
  (let ((raw-value
         (ignore-errors
           (or
            ;; Section-level property (with inheritance)
            (org-entry-get nil property t)
            ;; File-level property via keyword
            (code-agent-org--get-file-level-property property)))))
    ;; Apply variable expansion unless disabled
    (if (or no-expand (not raw-value))
        raw-value
      (let ((env-alist (code-agent-org--load-env-file)))
        (code-agent-org--expand-env-vars raw-value env-alist)))))

(defun code-agent-org--get-env-vars ()
  "Return env-var alist to inject into the spawned Claude process.

The single source of truth is the `ENV_FILE' org property — see
`code-agent-org--load-env-file'.  Hard-coded per-name org properties
(e.g. `:ANTHROPIC_MODEL:' on a section) are no longer read here; put
every VAR=VALUE in the .env file pointed at by ENV_FILE.

Section-level overrides remain available by setting `ENV_FILE' on a
heading's property drawer — org-entry-get inheritance picks the closest
enclosing value, so different sections can point at different .env
files.

Returns nil when no ENV_FILE is configured or the file is unreadable."
  (code-agent-org--load-env-file))

* Permission Mode Setter

#+BEGIN_SRC elisp
(defun code-agent-org--set-permission-mode (mode)
  "Set permission MODE in org property.
Sets at the appropriate scope based on where CLAUDE_SESSION_ID is defined:
- If session ID is in a heading (current or parent), sets in that heading's property drawer
- Otherwise sets at file level."
  (let ((session-heading (code-agent-org--find-session-scope-heading)))
    (if session-heading
        ;; Section-level: set property in the heading that defines the session
        (save-excursion
          (goto-char session-heading)
          (org-set-property code-agent-org-permission-property mode))
      ;; File-level: use #+PROPERTY keyword
      (save-excursion
        (goto-char (point-min))
        (if (re-search-forward
             (format "^#\\+PROPERTY:[ \t]+%s[ \t]+.+$" code-agent-org-permission-property)
             nil t)
            ;; Update existing
            (replace-match (format "#+PROPERTY: %s %s"
                                   code-agent-org-permission-property mode))
          ;; Insert new after other properties
          (if (re-search-forward "^#\\+PROPERTY:" nil t)
              (progn
                (end-of-line)
                (insert (format "\n#+PROPERTY: %s %s"
                                code-agent-org-permission-property mode)))
            ;; No properties, insert at beginning
            (insert (format "#+PROPERTY: %s %s\n" code-agent-org-permission-property mode))))))
    ;; Clear org's keyword property cache so org-entry-get reads fresh values
    ;; Without this, org-entry-get with inheritance returns stale cached values
    (setq-local org-keyword-properties nil)))

(defun code-agent-org-switch-permission-mode ()
  "Show current permission mode and switch to another.
Sets the CLAUDE_PERMISSION_MODE property at the appropriate scope."
  (interactive)
  (let* ((current (code-agent-org--get-permission-mode-display))
         (presets '(("readonly - Require approval for all tools" . "readonly")
                    ("accept-edits - Accept file edits without prompts" . "accept-edits")
                    ("plan - Suggests changes, requires approval for edits" . "plan")
                    ("bypass - All tools auto-approved" . "bypass")))
         (choices (mapcar (lambda (p)
                            (if (string= (cdr p) current)
                                (cons (concat (car p) " [current]") (cdr p))
                              p))
                          presets))
         (selection (completing-read
                     (format "Permission mode [%s]: " current)
                     (mapcar #'car choices)
                     nil t))
         (mode (cdr (assoc (replace-regexp-in-string " \\[current\\]$" "" selection)
                           choices))))
    (when mode
      (code-agent-org--set-permission-mode mode)
      (code-agent-org--refresh-header-line)
      (message "Permission mode set to: %s" mode))))
#+END_SRC

* MCP Server Integration

Automatically start MCP server and pass configuration to Claude CLI.

#+BEGIN_SRC elisp
(defun code-agent-org--ensure-mcp-server ()
  "Ensure MCP server is running if auto-start is enabled.
Starts the MCP server on `emacs-mcp-server-default-port' if not already running.
Raises an error if `emacs-mcp-server' module is not loaded."
  (when code-agent-org-auto-start-mcp-server
    (unless (fboundp 'emacs-mcp-server-running-p)
      (error "emacs-mcp-server module not loaded. Please load emacs-mcp-server.org first:
  (literate-elisp-load \"/path/to/emacs-mcp-server.org\")
Or set `code-agent-org-auto-start-mcp-server' to nil to disable auto-start"))
    (unless (emacs-mcp-server-running-p)
      (emacs-mcp-server-start))))

(defun code-agent-org--get-mcp-config ()
  "Get MCP config JSON string if server is running.
Returns nil if MCP server is not available or not running.
When Docker mode is active, uses host.docker.internal instead of localhost."
  (when (and (fboundp 'emacs-mcp-server-running-p)
             (emacs-mcp-server-running-p))
    (let* ((port (emacs-mcp-server-port))
           ;; Use host.docker.internal for Docker mode, localhost otherwise
           (host (if (code-agent-org--docker-mode-p)
                     "host.docker.internal"
                   "localhost")))
      (json-encode
       `((mcpServers . ((emacs . ((type . "http")
                                  (url . ,(format "http://%s:%d/mcp" host port)))))))))))
#+END_SRC
