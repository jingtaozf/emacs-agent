* Overview
:PROPERTIES:
:CUSTOM_ID: org-cmux-overview
:END:

cmux backend for code-agent-org.  Sends prompts to a Claude CLI
(=claude= / =copilot= / =opencode=) running inside a cmux workspace
via the cmux Unix socket; responses arrive through workspace-bridge
hook events.  Part of code-agent-org, loaded after code-agent-org.org.

This file is the operational body of the cmux multiplexer backend.
The matching [[file:../backend/code-agent-cmux-backend.org][code-agent-cmux-backend.org]] holds the Protocol 2b
class + dispatch shell; everything cmux-specific that doesn't fit
into the abstract =code-agent-multiplexer-backend= base lives here.

Invariant: every cmux-specific behaviour goes through =cl-defmethod=
on =code-agent-cmux-backend= (in [[file:../backend/code-agent-cmux-backend.org][code-agent-cmux-backend.org]]) or
through one of the private =code-agent-org-cmux--*= helpers here.
The frontend ([[file:code-agent-org.org][code-agent-org.org]]) NEVER reaches into this file
directly — it dispatches via the multiplexer-backend generics.

* Agent Profiles

Each supported code agent is described by a profile struct.  The profile
drives =build-launch-command=, ready/busy detection, cancel keys, and feature
guards (IDE integration, session resume).  Adding a new agent requires only
pushing a new profile onto =code-agent-org-cmux--agent-profiles= — no other elisp
changes are needed.

** Why a Profile Layer Was Needed

Before profiles, the cmux backend hard-coded *five* coupling points with
Claude Code specifically; supporting GitHub Copilot (and later OpenCode,
Gemini, Codex) without a unifying abstraction would have meant five
parallel branches threaded through unrelated code:

| Coupling point | Claude Code shape | First non-Claude agent (Copilot) |
|----------------+-------------------+-----------------------------------|
| Launch command | =claude-workspace= → =claude= CLI | =copilot-workspace= → =copilot= CLI |
| CLI flags | =--mcp-config=, =--system-prompt=, =--ide=, =--resume=, =--chrome= | =--allow-all-tools=, =--model= |
| Session resume | =--resume <id>= from =CLAUDE_CLI_SESSION= property | not supported (ephemeral sessions) |
| Hook events | =SessionStart=, =UserPromptSubmit=, =PreToolUse=, =PostToolUse=, =Stop= | =sessionStart=, =userPromptSubmitted=, =preToolUse=, =postToolUse=, =sessionEnd= |
| Ready detection | ="type a message"= / ="-- INSERT --"= | ="> "= / ="copilot>"= |

The rest of the cmux integration (workspace creation, send/capture, mode
line, verbose buffer, status file plumbing, loop / story-changed hook,
sidebar feedback) is genuinely agent-agnostic and never had to change.
Five thin agent-specific layers became five fields on the profile struct
plus a single dispatcher.

** Capability Flags — Why Each Slot Exists

The boolean capability slots aren't decoration — each one gates a code
path that would crash, write the wrong property, or expose a
non-functional UI on an agent that doesn't support the feature:

- =supports-resume= — if =nil=, we don't read or write =CLAUDE_CLI_SESSION=
  after =SessionStart=; the session is ephemeral by design (Copilot
  case). Skipping the write avoids leaving stale session IDs in org
  properties that would confuse the next launch.
- =supports-ide= — if =nil=, =--ensure-ide-server= is skipped at launch
  and the mode-line IDE indicator is hidden. Wiring it for an agent
  without WebSocket support would spin up a server nothing connects to.
- =supports-system-prompt= — gates the inline =--system-prompt= flag.
  File-based agents (Copilot's =.github/AGENTS.md=) use a different
  injection path inside their Python launcher; the elisp side just
  needs to know which path to take.
- =vi-mode= — agents like Claude Code use a Vim-style modal TUI and
  expect =i= to enter insert mode before text input; =send-text= sends
  this prefix only when the slot is =t=.

** Gap Handling — How Copilot Slotted In

Copilot exposed every limitation the profile system was designed to
absorb. The six gaps and the way each was handled illustrate the seam:

| Gap | Where it bites | Mitigation |
|-----+----------------+------------|
| No =--resume= | session continuity across Emacs restarts | =supports-resume nil=; skip =CLAUDE_CLI_SESSION= reads/writes; workspace persists but conversation history does not |
| MCP via =.github/mcp.json= (file, not flag) | bridge registration | Python launcher merges Emacs MCP entry into the file, registers =atexit= to restore original; documented race with subprocess-outliving-launcher accepted |
| System prompt via =.github/AGENTS.md= | session-scoped instructions | Same pattern: prepend session block, restore on exit |
| Different ready / busy screen patterns | =wait-for-ready-poll= regex | =ready-patterns= / =busy-patterns= slots; no structural change to the polling loop |
| No =stream-json= structured output | per-token streaming | Response arrives once via =sessionEnd= hook → =workspace_bridge= → MCP → org insert. Live terminal echo remains available via the verbose-output mirror. |
| No IDE WebSocket | mode-line IDE indicators | =supports-ide nil= guards both the launcher's =--ensure-ide-server= call and the mode-line display |

The pattern: agents that lack a feature pay zero indirection cost on
the elisp side (the guard is a single =when=), and the rest of the
cmux infrastructure works unchanged.

** Extension Protocol — Adding a Third Agent

To register a new agent (e.g. Cursor, Gemini CLI, Codex) without
touching this module:

1. Write =python/code_agent/<agent>_workspace.py= as a stateless
   launcher mirroring the Claude/Copilot ones — it receives org-file
   and session-id as CLI args, injects MCP config in whichever style
   the agent wants, and execs into the agent's binary.
2. Add =hooks/<agent>_hooks.json= with the agent's hook event names
   pointing at =workspace-bridge <event>=.
3. Add aliases in =workspace_bridge.py='s =EVENT_HANDLERS= dict so the
   new event names route to the existing handlers (they are
   protocol-agnostic).
4. Push a new =code-agent-org-cmux--agent-profile= struct onto
   =code-agent-org-cmux--agent-profiles= with the agent's launch-fn,
   patterns, cancel keys, and capability flags. *No other elisp change
   is required.*
5. Add the launcher's entry point to =python/pyproject.toml=.

The =launch-fn= field is the only piece that has any agent-specific
elisp; everything else is data.

** Relationship to the Tri-Protocol Refactor

The profile system shipped before the tri-protocol refactor (2026-04-24)
and is now structurally subsumed by it: agent identity has moved into
the agent-family classes (=code-agent-acp-*=, the Protocol-1 lifecycle
layer), and the cmux backend sees agents through the agent-profile
slot rather than dispatching on agent type directly. The profile struct
here remains the operational data — patterns, cancel keys, capability
flags — that the agent-family layer hands down to the multiplexer for
its concrete behaviour. See [[file:../sdk/code-agent-backend.org][code-agent-backend.org]] → "Tri-Protocol
Architecture" for the upper layers.

OpenCode is the clearest example of the dual-path shape this enables.
The =opencode= cmux profile here runs OpenCode's TUI inside a cmux pane
and uses screen-scraping + filesystem injection (=opencode.jsonc= +
=AGENTS.md=, restored on exit) — fine for interactive use, but a
crash-window leaves the project repo in a partially modified state.
[[file:../backend/code-agent-acp-opencode.org][code-agent-acp-opencode.org]] is the same agent reached via a
different wire (=opencode acp= over stdio, ACP/JSON-RPC) — no terminal,
no file injection, structured token stream, multi-turn session via
=session/load=. Both paths are shipped; the ACP path is preferred for
non-interactive use and for tests, the cmux path for visual workflows
with the live terminal in view.

(cl-defstruct code-agent-org-cmux--agent-profile
  "Describes how to launch and integrate with a code agent in cmux."
  (name nil)                    ; Symbol: 'claude or 'copilot
  (launch-fn nil)               ; (org-file session-id project-root) → shell-cmd string
  (ready-patterns nil)          ; List of regexp strings: TUI is ready for input
  (busy-patterns nil)           ; List of regexp strings: TUI is processing

  (supports-ide nil)            ; t if IDE WebSocket integration available
  (supports-system-prompt nil)  ; t if system prompt flag injection is supported
  (vi-mode nil))                ; t if TUI uses vi-style INSERT mode (send "i" before text)

To register a third-party agent, push a `code-agent-org-cmux--agent-profile'

(defun code-agent-org-cmux--get-agent-profile (&optional agent-type-override)
  "Return the agent profile to use, or nil to use legacy launch-command path.
Resolution order:
  1. AGENT_TYPE-OVERRIDE argument (for testing)
  2. AGENT_TYPE org property on the session heading
  3. `code-agent-org-cmux-agent-type' customization variable
  4. nil → use legacy `code-agent-org-cmux-launch-command' (Claude Code default)"

                           (intern (downcase prop))))
                       code-agent-org-cmux-agent-type)))
    (when type-sym
      (cl-find type-sym code-agent-org-cmux--agent-profiles
               :key #'code-agent-org-cmux--agent-profile-name))))

(defun code-agent-org-cmux--resolve-color (color-str)
  "Resolve COLOR-STR to a hex color.
Accepts hex (#RRGGBB) or a named preset (green, blue, etc.).
Returns nil if COLOR-STR is nil or unrecognized."
  (when color-str
    (let ((lower (downcase (string-trim color-str))))
      (cond
       ((string-prefix-p "#" lower) color-str)
       (t (cdr (assoc lower code-agent-org-cmux--color-presets)))))))

(defun code-agent-org-cmux--resolve-icon (icon-str)
  "Resolve ICON-STR to an SF Symbol name.
Accepts an SF Symbol name directly (e.g. \"bolt.fill\") or a preset.
Returns nil if ICON-STR is nil."
  (when icon-str
    (let ((lower (downcase (string-trim icon-str))))
      (or (cdr (assoc lower code-agent-org-cmux--icon-presets))
          lower))))

            (code-agent-org-cmux--call
             "workspace-action" "set-color"
             "--color" (or color-raw color)

* CLI Gateway

Every cmux interaction goes through =code-agent-org-cmux--call=, a thin
wrapper around the cmux Unix-domain socket. The wire exists in two
flavours and the daemon auto-detects which one the client speaks:

- *V1* (text): one line in, one line out — =<command> [args]\n= →
  =OK ...\n= or =ERROR: ...\n=.
- *V2* (JSON-RPC): lines beginning with ={= are treated as JSON-RPC
  envelopes, e.g. ={"id":"uuid","method":"surface.send_text","params":{…}}=.

The socket lives at =~/Library/Application Support/cmux/cmux.sock=
(production) or under =/tmp/cmux-debug-*.sock= for the dev builds
described in =.claude/rules/cmux-dev-build.md=. The daemon's default
security mode is =cmuxOnly=: processes that are not descendants of the
cmux app are refused (PID ancestry check via =sysctl KERN_PROC_PID=).
The other modes (=automation=, =password=, =allowAll=) are dev escape
hatches; production should never need them.

Addressing follows three orthogonal axes — =--workspace=, =--pane=, and
=--surface= — and each accepts the same three forms:

| Form | Example | Use when |
|------+---------+----------|
| UUID | =A4B…F12= | You stored the workspace id in an org property |
| Ref | =workspace:1= | You want the *current* leftmost workspace |
| Index | =2= | One-shot scripting; do not persist (indexes shift) |

Two convenience env vars are pre-set inside any cmux pane:
=CMUX_WORKSPACE_ID= and =CMUX_SURFACE_ID=. Calls made *from inside* a
pane can omit the flags and the daemon fills them in from those.

Sixteen distinct subcommands are exercised by the cmux pipeline below.
The table groups them by role so the call sites in this file remain
discoverable:

| Subcommand | Role |
|------------+------|
| =capture-pane= | Status detection, ready polling, INSERT-mode check |
| =send= | Send prompt text (< 100 KB) |
| =send-key= | Submit Enter, send Escape (cancel) |
| =set-buffer= / =paste-buffer= | Large-text path (≥ 100 KB) |
| =select-workspace= | Focus a workspace for paste, permission focus |
| =new-workspace= | Create workspace launching Claude Code |
| =new-window= | Fallback when TabManager is unavailable |
| =list-pane-surfaces= | Resolve workspace → surface ref |
| =rename-workspace= | Set the tab title to the story name |
| =set-status= / =clear-status= | Sidebar agent status |
| =set-progress= | Sidebar progress bar |
| =notify= | Send a notification |
| =set-app-focus= | Activate the cmux app (e.g. for permission alerts) |

The =claude-hook= session store is the persistent piece that ties our
hook handlers to cmux's: =~/.cmuxterm/claude-hook-sessions.json=,
written under =flock(LOCK_EX)=, carries =sessionId=, =workspaceId=,
=surfaceId=, =cwd=, =pid=, =lastSubtitle=, =lastBody=, =startedAt=,
and =updatedAt=. Entries are pruned after seven days, and the daemon
falls back to looking up by =surfaceId= or =workspaceId= when a
=sessionId= is unknown.

#+BEGIN_SRC elisp
(defun code-agent-org-cmux--split-stdin-arg (args)
  "Split ARGS into (STDIN-TEXT . POSITIONAL).
If ARGS contains a ``:stdin VALUE'' pair, VALUE is the stdin text
and the rest are positional CLI args.  Otherwise stdin is nil."
  (let ((stdin-text nil) (cli-args nil))
    (while args
      (if (eq (car args) :stdin)
          (progn
            (setq stdin-text (cadr args))
            (setq args (cddr args)))
        (push (car args) cli-args)
        (setq args (cdr args))))
    (cons stdin-text (nreverse cli-args))))

(defun code-agent-org-cmux--resolve-socket-and-cli ()
  "Return ``(SOCKET-PATH . CLI-PATH)'' using session-property overrides.

CMUX_SOCKET_PATH and CMUX_CLI_PATH org properties win over the
defcustoms; both may be nil if no override and the defcustom is
also nil."
  (cons (or code-agent-org-cmux-socket-path
            (ignore-errors
              (code-agent-org-terminal-find-session-property "CMUX_SOCKET_PATH")))
        (or (ignore-errors
              (code-agent-org-terminal-find-session-property "CMUX_CLI_PATH"))
            code-agent-org-cmux-cli-path)))

(defun code-agent-org-cmux--exec (cli flat-args stdin-text)
  "Invoke CLI with FLAT-ARGS, optionally piping STDIN-TEXT.
Return the trimmed stdout string on exit-code 0; signal `error'
with the trimmed stderr on non-zero exit.  Cleans up temp files."
  (let* ((stderr-file (make-temp-file "cmux-stderr-"))
         (buf (generate-new-buffer " *cmux-cli*"))
         (stdin-file (when stdin-text
                       (let ((f (make-temp-file "cmux-stdin-")))
                         (with-temp-file f (insert stdin-text))
                         f)))
         (exit-code (apply #'call-process
                           cli stdin-file
                           (list buf stderr-file) nil
                           flat-args)))
    (unwind-protect
        (with-current-buffer buf
          (if (= exit-code 0)
              (string-trim (buffer-string))
            (let ((stderr (string-trim
                           (with-temp-buffer
                             (insert-file-contents stderr-file)
                             (buffer-string)))))
              (error "cmux failed (exit %d): %s" exit-code stderr))))
      (kill-buffer buf)
      (when stdin-file (delete-file stdin-file t))
      (delete-file stderr-file t))))

(defun code-agent-org-cmux--call (subcommand &rest args)
  "Call cmux CLI with SUBCOMMAND and ARGS. Return stdout string.
If ARGS contains :stdin KEY, that value is piped as stdin.

Three phases under one ``cmux-call'' span:
1. Split ``:stdin VAL'' out of ARGS.
2. Resolve socket + CLI path (per-story properties override
   defcustoms).
3. Assemble flat argv and exec — when a custom socket is in use
   we clear ``CMUX_WORKSPACE_ID'' from the environment so the CLI
   doesn't resolve workspaces from the production instance."
  (code-agent-with-span "cmux-call"
      (list :span-kind "CLIENT" :subcommand subcommand) nil
    (let* ((split (code-agent-org-cmux--split-stdin-arg args))
           (stdin-text (car split))
           (cli-args   (cdr split))
           (paths      (code-agent-org-cmux--resolve-socket-and-cli))
           (socket     (car paths))
           (cli        (cdr paths))
           (socket-args (when socket (list "--socket" socket)))
           (flat-args
            (append socket-args (cons subcommand (flatten-tree cli-args))))
           (process-environment
            (if socket
                (cl-remove-if
                 (lambda (e) (string-match-p "^CMUX_WORKSPACE_ID=" e))
                 process-environment)
              process-environment)))
      (condition-case err
          (code-agent-org-cmux--exec cli flat-args stdin-text)
        (error (error "cmux %s failed: %s" subcommand
                      (error-message-string err)))))))
#+END_SRC

** Pre-flight: workspace-bridge hook verification
:PROPERTIES:
:CUSTOM_ID: cmux-preflight-hooks
:END:

When the user fires =C-c C-c= (or =code-agent-menu I=) on an AI block,
Emacs sends the prompt text into the cmux pane and assumes the
running claude there has our workspace-bridge ~UserPromptSubmit~ and
~Stop~ hooks loaded.  Without those hooks, the prompt vanishes —
claude responds in the terminal, but nothing reaches the org buffer.

The hooks come from a launcher-supplied flag:

#+begin_example
claude --settings <project>/workspace-hooks.json ... --resume <slug>
#+end_example

=code-agent-org-cmux-restart= (and the initial =--ensure-session=
launch) build that flag via =--build-claude-legacy-launch-command=,
so any claude *we* spawn has the hooks.  The hole is *cmux's own
session-restore*: when cmux's app restarts (or the user reopens a
saved workspace), it replays the bare =claude --resume <slug>= and
strips our launcher's extras.  The restored claude is "alive" — its
TUI works, the user can chat with it — but every hook fires silently
because Claude Code never loaded our settings.

** Triggering incident, 2026-05-26 (twice in one week)

The user pressed =code-agent-menu I= twice on different days and
typed prompts into =claude-agent-dev.org=; both times nothing
appeared in the org buffer.  Both times the root cause was the
same: the dev1 pane held a cmux-restored claude with stripped
launcher extras.  Operational workaround (=R= → manual restart)
worked but didn't prevent the next recurrence.

** Why a pre-flight check rather than a restart hook

Alternatives considered:

- *Detect at restart time.*  =code-agent-org-cmux-restart= already
  recovers from a corrupt session — but only fires when the user
  manually invokes it.  We need automatic recovery.
- *Detect at the workspace-bridge side.*  When the bridge sees a
  prompt without a registered query, it could detect the
  "hook-not-wired" pattern.  But the bridge doesn't even *run* in
  the broken case — that's the whole problem.
- *Reactive: wait, then check.*  After =--send-text=, poll for an
  expected org-buffer side effect.  If absent → assume hooks dead,
  restart.  Adds latency on every send, racy.
- *Proactive (chosen): check before send.*  ~ps -t <tty> -o command=~
  on the surface's tty reveals the claude argv.  Cheap (~10ms), no
  false positives (the argv either has =workspace-hooks.json= or it
  doesn't), no race.

** Design choices

| Decision | Rationale |
|---+---|
| Inspect via =ps -t <tty>= rather than cmux RPC | cmux has no command to fetch a pane's process argv; =ps -t= over a known tty is portable and synchronous. |
| Hook check string = ~workspace-hooks.json~ | Stable marker the launcher always appends; no false positives on bare =claude= or shell prompts. |
| Auto-restart on miss | The user already pressed =I=; making them press =R= first is a worse UX than just doing the restart. |
| Defcustom opt-out | Some users may prefer the warning-only behaviour (default before this fix); honour their choice. |
| Pre-flight at =--execute-ai-block= (not =--send-text=) | =--send-text= is also called from restart-internal flows (sending =/exit=, sending the relaunch command).  Putting the check at the outer block-execute level scopes it to the user-initiated path. |

** Hook Verification Helpers

Three small helpers implement the pre-flight check.  =--surface-tty=
resolves the cmux surface to its underlying tty, =--claude-has-bridge-hooks-p=
inspects the live ~claude~ argv on that tty for the launcher's stable
=workspace-hooks.json= marker, and =--ensure-hooks-wired= is the
choreography step that triggers a restart + ready-wait when the marker
is missing.

| Function | Role |
|---+---|
| =--surface-tty= | Look up the surface's tty via =cmux tree --json= |
| =--claude-has-bridge-hooks-p= | =ps= the tty, search for =workspace-hooks.json= |
| =--ensure-hooks-wired= | Pre-flight: call =restart= + =wait-for-ready= when missing |

#+BEGIN_SRC elisp
(defcustom code-agent-org-cmux-auto-relaunch-on-missing-hooks t
  "When non-nil, auto-relaunch the cmux pane's claude process if it lacks
the workspace-bridge hook settings.

The 2026-05-26 incident: cmux's session-restore replays the bare
``claude --resume <slug>`` command without the ``--settings
workspace-hooks.json`` / ``--plugin-dir`` extras our launcher adds at
launch time.  The restored claude runs fine but has *no* bridge hooks
loaded — every UserPromptSubmit / Stop hook silently no-ops, so
prompts and responses never reach the org buffer.

The check inspects the surface's tty via cmux + ``ps`` and looks for
``workspace-hooks.json`` in the claude argv.  Missing → call
``code-agent-org-cmux-restart`` and wait before sending the prompt.
Set this to nil to disable the auto-fix and just rely on the existing
restart flow."
  :type 'boolean
  :group 'code-agent-org)

(defun code-agent-org-cmux--surface-tty (surface-id)
  "Look up SURFACE-ID's tty (e.g. ``ttys008``) via ``cmux tree --json``.
Returns nil if cmux is unreachable, the surface isn't a terminal, or
the JSON shape changed."
  (condition-case nil
      (let* ((json-output (code-agent-org-cmux--call "tree" "--json"))
             (data (with-temp-buffer
                     (insert json-output)
                     (goto-char (point-min))
                     (json-parse-buffer :object-type 'plist :null-object nil
                                        :false-object nil)))
             (windows (plist-get data :windows))
             (found nil))
        (cl-loop for win across (or windows []) until found do
                 (cl-loop for ws across (or (plist-get win :workspaces) []) until found do
                          (cl-loop for pane across (or (plist-get ws :panes) []) until found do
                                   (cl-loop for surface across (or (plist-get pane :surfaces) [])
                                            until found do
                                            (when (string= (plist-get surface :ref) surface-id)
                                              (setq found (plist-get surface :tty)))))))
        found)
    (error nil)))

(defun code-agent-org-cmux--claude-has-bridge-hooks-p (surface-id)
  "Return non-nil when SURFACE-ID's running claude has our workspace-bridge hooks loaded.

Heuristic: the launcher appends ``--settings <path>/workspace-hooks.json``
to the spawned ``claude`` argv.  cmux's session-restore drops these
extras when replaying a saved session, leaving the restored claude
running without our bridge.  We inspect the claude process via
``ps -t <tty> -o command=`` and search for the marker.

Returns nil (treat as a missing-hooks signal) on any introspection
failure — tty lookup fails, ps doesn't run, no claude on that tty.
The caller then triggers a restart, which is the safe fallback in
every case."
  (when-let* ((tty (code-agent-org-cmux--surface-tty surface-id)))
    (let ((cmd (with-temp-buffer
                 (call-process "ps" nil t nil "-t" tty "-o" "command=")
                 (buffer-string))))
      (and (stringp cmd)
           (string-match-p "/claude\\b" cmd)
           (string-match-p "workspace-hooks\\.json" cmd)))))

(defun code-agent-org-cmux--ensure-hooks-wired (surface-id)
  "Pre-flight check before sending a prompt to SURFACE-ID.

If the running claude has our workspace-bridge hooks loaded, return t.
Otherwise — when ``code-agent-org-cmux-auto-relaunch-on-missing-hooks``
is non-nil — call ``code-agent-org-cmux-restart'' to relaunch via the
launcher (which adds the missing ``--settings workspace-hooks.json``
and WORKSPACE_* env vars), then wait until the new claude is ready.

This closes the 2026-05-26 ``recurring`` failure mode where cmux's
session-restore lost the launcher's extras and every UserPromptSubmit
/ Stop hook silently no-op'd, leaving the org buffer untouched."
  (cond
   ((code-agent-org-cmux--claude-has-bridge-hooks-p surface-id) t)
   ((not code-agent-org-cmux-auto-relaunch-on-missing-hooks)
    (message
     "code-agent-org-cmux: surface %s's claude lacks workspace-bridge hooks; \
prompts will not appear in the org buffer.  Press R in code-agent-org-menu \
to relaunch, or set `code-agent-org-cmux-auto-relaunch-on-missing-hooks' \
to t for auto-fix."
     surface-id)
    t)
   (t
    (message "code-agent-org-cmux: claude on %s is missing workspace-bridge \
hooks (cmux session-restore drops them); auto-relaunching via launcher..."
             surface-id)
    (code-agent-org-cmux-restart)
    ;; restart is async toward the end — wait until the freshly-launched
    ;; claude reports ready before the caller proceeds to send a prompt.
    (code-agent-org-cmux--wait-for-ready surface-id)
    t)))

(defun code-agent-org-cmux--wait-for-ready (surface-id)
  "Wait for Claude Code TUI to be ready in SURFACE-ID.
Uses cmux wait-for signal from SessionStart hook (50ms polling).
Falls back to capture-pane polling if signal times out."
  (code-agent-with-span "cmux-wait-for-ready"
      (list :surface-id surface-id :timeout code-agent-org-cmux-ready-timeout) nil
  (let ((workspace-session-id
         (condition-case nil
             (code-agent-org-terminal-find-session-property "CLAUDE_SESSION_ID")
           (error nil)))
        (timeout (number-to-string code-agent-org-cmux-ready-timeout)))
    (if workspace-session-id
        ;; Event-driven: wait for signal from SessionStart hook
        (condition-case nil
            (progn
              (code-agent-org-cmux--call "wait-for"
                (format "claude-ready-%s" workspace-session-id)
                "--timeout" timeout)
              t)
          (error
           ;; Fallback: poll capture-pane with shorter timeout
           (code-agent-org-cmux--wait-for-ready-poll surface-id 10)))
      ;; No session ID — poll only
      (code-agent-org-cmux--wait-for-ready-poll
       surface-id code-agent-org-cmux-ready-timeout)))))

(defun code-agent-org-cmux--wait-for-ready-poll (surface-id timeout)
  "Fallback: poll capture-pane for agent ready state every 0.5s up to TIMEOUT seconds.
Uses ready-patterns from the active agent profile, falling back to Claude Code patterns."
  (let* ((profile (code-agent-org-cmux--get-agent-profile))
         (patterns (if profile
                       (code-agent-org-cmux--agent-profile-ready-patterns profile)
                     '("type a message" "-- INSERT --" "-- insert --")))
         (pattern-re (mapconcat #'regexp-quote patterns "\\|"))
         (deadline (+ (float-time) timeout))
         (ready nil))
    (while (and (not ready) (< (float-time) deadline))
      (condition-case nil
          (let ((screen (code-agent-org-cmux--call "capture-pane"
                          "--surface" surface-id)))
            (when (string-match-p pattern-re screen)
              (setq ready t)))
        (error nil))
      (unless ready (sleep-for 0.5)))
    (unless ready
      (error "Timeout: agent not ready in cmux after %ds" timeout))
    t))
#+END_SRC

** Future: Event-Driven Ready Detection via =cmux wait-for=

The poll loop above samples =capture-pane= every 1 s for up to 30 s.
cmux ships a built-in event-driven primitive, =wait-for=, that would
trade the 1 s sampling latency for a 50 ms sentinel poll *and* a clear
"Claude Code is up" signal from the SessionStart hook on the Python
side.

The protocol is two halves: one process creates the signal file with
=cmux wait-for -S <name>=, another waits for it with =cmux wait-for
<name> --timeout 30=. Files live under =/tmp/cmux-wait-for-<name>.sig=
and are deleted on a successful wait.

The Python side would register a SessionStart hook in =hooks.json= that
runs =cmux wait-for -S claude-ready-<session-id>= once Claude Code is
inside its TUI. The Emacs side would replace the existing poll with a
=wait-for= call, keeping the current =capture-pane= loop as a fallback
for the case where the signal is missed (e.g. SessionStart fires before
Emacs blocks on the wait).

Expected gains:

| Aspect | Current poll | =wait-for= |
|--------+--------------+-----------|
| Worst-case latency | 1 s sampling | ~50 ms |
| CPU per ready-check | =capture-pane= every 1 s × 30 | one =wait-for=, 50 ms sleeps |
| Signal type | regex against terminal text | explicit hook signal |
| Failure mode | timeout only | fallback to short polling |

* Send Text Helper

Small helpers feeding the send text below — extracted so the main path stays readable.

#+BEGIN_SRC elisp
(defun code-agent-org-cmux--ensure-insert-mode (surface-id)
  "Ensure Claude Code TUI is in INSERT mode in SURFACE-ID.
If not already in INSERT mode, sends `i` to enter it and waits briefly."
  (let ((screen (condition-case nil
                    (code-agent-org-cmux--call "capture-pane" "--surface" surface-id)
                  (error ""))))
    (unless (string-match-p "-- INSERT --\\|-- insert --" screen)
      ;; Send 'i' to enter INSERT mode (like vim)
      (code-agent-org-cmux--call "send" "--surface" surface-id "i")
      (sleep-for 0.3))))

(defun code-agent-org-cmux--send-text (surface-id text)
  "Send TEXT to cmux SURFACE-ID.
Strips Emacs text properties to prevent #(...) leaking into terminal.
For agents with vi-mode TUI (Claude Code), ensures INSERT mode first.
For non-vi-mode agents (OpenCode, Copilot), multi-line text is sent line
by line with shift-enter between lines, so newlines appear as literal
characters in the TUI input box rather than submitting each line separately."
  (code-agent-with-span "cmux-send-text"
      (list :surface-id surface-id
            :text-length (length text)
            :input (truncate-string-to-width (or text "") 2000)) nil
  (let* ((clean-text (substring-no-properties text))
         (profile (code-agent-org-cmux--get-agent-profile))
         (vi-p (or (null profile)  ; legacy path = Claude Code
                   (code-agent-org-cmux--agent-profile-vi-mode profile)))
         ;; Non-vi-mode agents need shift-enter for multi-line text because
         ;; `cmux send` interprets \n as Enter, splitting the prompt.
         (use-paste-p (or (>= (length clean-text) 100000)
                          (and (not vi-p)
                               (string-match-p "\n" clean-text)))))
    ;; Only send "i" for vi-mode TUIs (Claude Code); others accept text directly
    (when vi-p
      (code-agent-org-cmux--ensure-insert-mode surface-id))
    (if use-paste-p
        ;; Multi-line path: send lines with shift-enter between them.
        ;; shift-enter inserts a literal newline in TUI input boxes.
        ;; Replaces broken paste-buffer approach (cmux "Surface is not a terminal").
        (let ((lines (split-string clean-text "\n")))
          (code-agent-org-cmux--call "send" "--surface" surface-id (car lines))
          (dolist (line (cdr lines))
            (code-agent-org-cmux--call "send-key" "--surface" surface-id "shift-enter")
            (when (> (length line) 0)
              (code-agent-org-cmux--call "send" "--surface" surface-id line))))
      ;; Direct send — safe for single-line text or vi-mode agents
      (code-agent-org-cmux--call "send" "--surface" surface-id clean-text))
    ;; Send Enter to submit the prompt
    (code-agent-org-cmux--call "send-key" "--surface" surface-id "enter")
    ;; Retry-on-failure: only for vi-mode TUIs where Enter can be lost
    ;; if Claude Code is still in INSERT mode after 3s
    (when vi-p
      (run-at-time 3 nil
        (lexical-let ((sid surface-id))
          (lambda ()
            (condition-case nil
                (let ((screen (code-agent-org-cmux--call "capture-pane"
                                "--surface" sid)))
                  (when (and (string-match-p "-- INSERT --" screen)
                             (not (string-match-p
                                   "Thinking\\|Tool:\\|Reading\\|Searching\\|Running\\|Generating"
                                   screen)))
                    (code-agent-org-cmux--call "send-key" "--surface" sid "enter")))
              (error nil)))))))))

* Launch Command

Assembles the =claude= argv with =--settings workspace-hooks.json=, =--plugin-dir=, =--name=, env overlays.  The single place launch invariants live.

#+BEGIN_SRC elisp
(defun code-agent-org-cmux--build-env-prefix ()
  "Return a shell prefix that sources ENV_FILE for the cmux launch command,
or \"\" if no ENV_FILE is configured / readable.

Why this exists.  The agent-family (json-stream) backend reads ENV_FILE
via `code-agent-org--get-env-vars' and hands the parsed alist to the
spawned Claude subprocess as the OS env block.  The cmux backend never
spawns Claude directly — it asks cmux to spawn one inside a new terminal
pane, and cmux's child shell inherits only cmux's own process environment.
Without help, the ENV_FILE that worked under json-stream silently has no
effect under cmux.

The prefix we produce is plain POSIX shell so the command cmux runs
(via `new-workspace --command') sources the env file before exec'ing the
real launcher:

  set -a; . /path/to/env-file; set +a; <launcher>

`set -a' auto-exports every subsequent assignment, so every VAR=VALUE in
ENV_FILE flows into the eventual Claude process.

Per-name org properties (e.g. `:ANTHROPIC_MODEL:' on a section) are no
longer read here — put values in the .env file instead.  Section-level
overrides are still possible via `:ENV_FILE:' inheritance on a heading."
  (let* ((env-file-raw (ignore-errors
                         (code-agent-org-get-org-property "ENV_FILE" t)))
         (env-file (and env-file-raw (expand-file-name env-file-raw)))
         ;; cmux propagates its own ``VIRTUAL_ENV`` to every spawned
         ;; pane.  When the agent's project dir is renamed (the
         ;; 2026-05-26 ``claude-agent`` → ``emacs-agent`` rename),
         ;; the inherited ``VIRTUAL_ENV`` keeps pointing at the old
         ;; venv path.  ``uv run --project X`` already ignores a
         ;; mismatched ``VIRTUAL_ENV`` and uses the project's own
         ;; venv, but it emits a noisy stderr warning every time.
         ;; Unset the var at the top of the launch chain so uv runs
         ;; quietly.  Harmless for the no-rename case because the
         ;; spawned shell does not need ``VIRTUAL_ENV`` itself —
         ;; ``uv run`` activates the project venv on its own.
         (unset-prefix "unset VIRTUAL_ENV; "))
    (if (and env-file (file-readable-p env-file))
        (format "%sset -a; . %s; set +a; "
                unset-prefix (shell-quote-argument env-file))
      unset-prefix)))

(defun code-agent-org-cmux--env-cli-fallback-args (user-extra-args)
  "Surface ENV_FILE values for `ANTHROPIC_MODEL' / `CLAUDE_CODE_EFFORT_LEVEL'
as Claude CLI flags (`--model' / `--effort'), skipping any flag that
USER-EXTRA-ARGS already specifies.

Why this exists.  ENV_FILE sourcing (see
`code-agent-org-cmux--build-env-prefix') makes the Claude SDK *see*
these env vars at startup, but `~/.claude/settings.json' `model' and
`effort' fields override the env-derived values during Claude Code's
own precedence resolution.  This was verified empirically with the
xiaomi mimo endpoint: ENV vars reach the claude process (confirmed via
`ps -E' on a live launch), but the displayed model still resolved to
whatever user settings pinned, because settings.json beats env in
Claude Code's precedence chain.  The reliable override channel is the
CLI flag, which beats settings.json unconditionally.

So when the .env file pins ANTHROPIC_MODEL or CLAUDE_CODE_EFFORT_LEVEL,
we surface each as `--model VALUE' / `--effort VALUE' on
claude-workspace's pass-through extras.  The launcher appends extras
after `--', and they flow into the spawned `claude' process as final
argv.

We bail out per-key if USER-EXTRA-ARGS already contains the flag (either
`--flag VALUE' or `--flag=VALUE') — author intent takes priority and we
avoid the awkward `--flag A --flag B' duplicate that some CLI parsers
handle inconsistently.  See `code-agent-org--env-cli-flag-map' for the
authoritative ENV → CLI mapping; add an entry there if a third case
appears."
  (let ((env-alist (ignore-errors (code-agent-org--load-env-file)))
        (out nil))
    (pcase-dolist (`(,env-key . ,flag) code-agent-org--env-cli-flag-map)
      (let ((val (cdr (assoc env-key env-alist))))
        (when (and val
                   (not (string-empty-p val))
                   (not (or (cl-find flag user-extra-args :test #'string=)
                            (cl-some (lambda (a)
                                       (string-prefix-p (concat flag "=") a))
                                     user-extra-args))))
          (setq out (append out (list flag val))))))
    out))

(defun code-agent-org-cmux--build-launch-command (org-file workspace-session-id project-root)
  "Build the shell command to launch the configured code agent in cmux.
ORG-FILE is the org notebook path, WORKSPACE-SESSION-ID the session,
PROJECT-ROOT the working directory.

Dispatches to the active agent profile's launch-fn.  Falls back to the
legacy `code-agent-org-cmux-launch-command' path when no agent profile is set.
The dispatched builder produces the bare launcher command; we prepend a
shell env prefix (see `code-agent-org-cmux--build-env-prefix') so that
the ENV_FILE values also reach the cmux-spawned Claude process — the
json-stream-equivalent of `:env' subprocess injection."
  (let* ((profile (code-agent-org-cmux--get-agent-profile))
         (base-cmd
          (if profile
              (funcall (code-agent-org-cmux--agent-profile-launch-fn profile)
                       org-file workspace-session-id project-root)
            ;; Legacy fallback: original Claude Code logic via launch-command cond
            (code-agent-org-cmux--build-claude-legacy-launch-command
             org-file workspace-session-id project-root)))
         (env-prefix (code-agent-org-cmux--build-env-prefix)))
    (concat env-prefix base-cmd)))

(defun code-agent-org-cmux--build-claude-legacy-launch-command
    (org-file workspace-session-id project-root)
  "Build Claude Code launch command using the legacy launch-command variable.
ORG-FILE is the org notebook path, WORKSPACE-SESSION-ID the session,
PROJECT-ROOT the working directory."
  (ignore project-root)
  (let* ((prop-args (code-agent-org-terminal-find-session-property "CLAUDE_EXTRA_ARGS"))
         (user-extra-args (append code-agent-org-cmux-extra-args
                                  (when prop-args (split-string prop-args))))
         ;; Surface ENV_FILE-derived ANTHROPIC_MODEL / CLAUDE_CODE_EFFORT_LEVEL
         ;; as CLI flags — env-only injection loses to ~/.claude/settings.json,
         ;; CLI flags beat settings.json.  See `--env-cli-fallback-args'.
         (cli-flag-args (code-agent-org-cmux--env-cli-fallback-args
                         user-extra-args))
         (all-extra (append user-extra-args cli-flag-args))
         (extra (mapconcat #'shell-quote-argument all-extra " ")))
    (cond
     ;; claude-workspace: passes org-file and session-id
     ((eq code-agent-org-cmux-launch-command 'claude-workspace)
      ;; Emacs is the state owner for --resume (reads CLAUDE_CLI_SESSION).
      ;; Do NOT use find-session-property (inheritance=t) here — a stale
      ;; file-level #+PROPERTY: CLAUDE_CLI_SESSION contaminates all stories.
      ;; Read directly from the session heading (no inheritance).
      (let* ((workspace-script code-agent-org-cmux-workspace-script)
             (cli-session
              (ignore-errors
                (save-excursion
                  (code-agent-org-terminal-goto-session-heading)
                  (org-entry-get nil "CLAUDE_CLI_SESSION" nil))))
             (parts (list workspace-script
                          (shell-quote-argument (or org-file ""))
                          (shell-quote-argument (or workspace-session-id "")))))
        (when cli-session
          (setq parts (append parts
                              (list "--"
                                    "--resume"
                                    (shell-quote-argument cli-session)))))
        (when (and extra (not (string-empty-p extra)))
          (unless cli-session
            (setq parts (append parts (list "--"))))
          (setq parts (append parts (list extra))))
        (mapconcat #'identity parts " ")))
     ;; bare claude
     ((eq code-agent-org-cmux-launch-command 'claude)

(defun code-agent-org-cmux--parse-surface-ref (output)
  "Extract a surface ref (e.g. \"surface:1\") from cmux OUTPUT.
Handles three formats:
  - JSON with .focused.surface_ref key (from identify)
  - \"OK workspace:N\" (from new-workspace)
  - Plain \"surface:N\" string
Returns the surface ref string, or OUTPUT unchanged as fallback."
  (cond
   ;; JSON: extract focused.surface_ref
   ((string-prefix-p "{" (string-trim output))
    (condition-case nil
        (let* ((json (json-read-from-string output))
               (focused (cdr (assq 'focused json)))
               (ref (cdr (assq 'surface_ref focused))))
          (or ref output))
      (error output)))
   ;; "OK workspace:N" → extract workspace ref
   ((string-match "OK \\(workspace:[^ \t\n]+\\)" output)
    (match-string 1 output))
   ;; "* surface:N ..." from list-pane-surfaces
   ((string-match "\\(surface:[^ \t\n]+\\)" output)
    (match-string 1 output))
   ;; Already a clean ref
   (t output)))

(defun code-agent-org-cmux--find-workspace-by-name (name)
  "Return the current workspace ref (e.g. \"workspace:7\") for NAME.
Parses `cmux list-workspaces' output, which has the form:

  [* ]  workspace:N  <name>  [selected]

The heading title is the cmux/emacs protocol for workspace identity:
cmux persists workspaces by name across restarts while UUIDs and short
refs are regenerated.  Returns nil if no workspace matches NAME."
  (when (and name (not (string-empty-p name)))
    (condition-case nil
        (let ((lines (split-string
                      (code-agent-org-cmux--call "list-workspaces")
                      "\n" t)))
          (catch 'found
            (dolist (line lines)
              ;; Strip optional "* " selected marker and leading whitespace.
              (let* ((stripped (replace-regexp-in-string
                                "\\`[ \t]*\\*?[ \t]*" "" line))

                        (ws-name (match-string 2 cleaned)))

                      (throw 'found ref))))))))
      (error nil))))

** Cross-restart routing recovery (via claude =--name= slug)
:PROPERTIES:
:CUSTOM_ID: cmux-cross-restart-routing-recovery
:END:

When the cmux app restarts (=Cmd-Q= + relaunch), the per-surface env
=process-environment= we injected at original launch — =WORKSPACE_ORG_FILE=,
=WORKSPACE_SESSION_ID=, =WORKSPACE_CUSTOM_ID=, =CMUX_WORKSPACE= — is
*lost*.  cmux only preserves =CMUX_AGENT_LAUNCH_ARGV_B64= + =CMUX_AGENT_LAUNCH_CWD=
and re-injects =--name <current-cmux-workspace-title>= on every claude
respawn (slug rule lives in =claude_workspace._normalize_story_slug=:
lowercase, non-alphanumeric → =-=, strip edges).

The bridge therefore can no longer trust env vars across restart.  Its
fallback path is to read the live =--name= off claude's argv (via PPID),
mirror the slug rule here, and walk all open org buffers asking "which
cmux-backed session's heading title slugifies to this name?"  When
multiple sessions match (genuinely rare —— heading titles inside one
Emacs are usually unique by construction), =cwd= is the tiebreaker.

#+BEGIN_SRC elisp
(defun code-agent-org-cmux--normalize-name-slug (name)
  "Return the cmux =--name= slug for NAME.

Mirrors `claude_workspace._normalize_story_slug' exactly:
lowercases, collapses runs of non-alphanumeric to single =-=, and
strips leading/trailing dashes.  Any divergence between the two
implementations breaks cross-restart recovery — keep them in sync."
  (if (null name)
      ""
    (let* ((lowered (downcase name))
           (dashed (replace-regexp-in-string "[^a-z0-9]+" "-" lowered)))
      (replace-regexp-in-string "\\`-+\\|-+\\'" "" dashed))))

(defun code-agent-org-cmux--lookup-session-by-agent-name (name &optional cwd)
  "Locate an org session whose heading slug equals NAME.

NAME is the slug claude sees in its =--name= flag (see
`code-agent-org-cmux--normalize-name-slug').  Optional CWD is used as
a tiebreaker when multiple open buffers contain matching headings;
exact match wins, prefix match second, otherwise first found.

Returns a plist =(:org-file F :session-id S :custom-id C :heading H
:project-root R)= or nil when no session matches.

Used by =workspace_bridge.py= to recover the (org-file, session-id)
tuple after a cmux app restart loses the routing env vars — see
=workspace_bridge._resolve_routing=.  Walks =buffer-list= so only
already-loaded org files are considered, matching the
property-cache invariant the rest of the cmux backend relies on."
  ;; Hot-path optimisation: =org-map-entries= on every open org buffer is
  ;; O(headings) including full org-element parsing — easily 10s on a single
  ;; ~200kB notebook with 100+ headings.  Bridge calls this on every Stop
  ;; hook so it must be <100ms.  Instead, regex-scan each org buffer for
  ;; lines matching =:CLAUDE_SESSION_ID:= (cheap), and for each hit jump
  ;; to the surrounding heading + slugify only that one heading.  Bound is
  ;; O(sessions), not O(headings).
  (let ((target-slug (code-agent-org-cmux--normalize-name-slug name))
        candidates)
    (when (and target-slug (not (string-empty-p target-slug)))
      (dolist (buf (buffer-list))
        (with-current-buffer buf
          (when (and (derived-mode-p 'org-mode)
                     (buffer-file-name))
            (save-excursion
              (save-restriction
                (widen)
                (goto-char (point-min))
                (while (re-search-forward
                        "^[ \t]*:CLAUDE_SESSION_ID:[ \t]+\\(\\S-+\\)" nil t)
                  (let ((sid (match-string-no-properties 1))
                        (drawer-pos (match-beginning 0)))
                    (save-excursion
                      (goto-char drawer-pos)
                      (when (ignore-errors (org-back-to-heading t) t)
                        (let* ((heading
                                (substring-no-properties
                                 (or (org-get-heading t t t t) "")))
                               (slug (code-agent-org-cmux--normalize-name-slug
                                      heading)))
                          (when (string= slug target-slug)
                            (push (list :org-file (buffer-file-name)
                                        :session-id sid
                                        :custom-id (or (org-entry-get nil "CUSTOM_ID") "")
                                        :heading heading
                                        :project-root (or (org-entry-get nil "PROJECT_ROOT" t) ""))
                                  candidates))))))))))))
      (cond
       ((null candidates) nil)
       ((null (cdr candidates)) (car candidates))
       ;; Multiple candidates with the same slug — disambiguate by cwd.
       ((and cwd (not (string-empty-p cwd)))
        (or (cl-find-if (lambda (c) (string= (plist-get c :project-root) cwd))
                        candidates)
            (cl-find-if (lambda (c)
                          (let ((pr (plist-get c :project-root)))
                            (and (not (string-empty-p pr))
                                 (string-prefix-p pr cwd))))
                        candidates)
            (car candidates)))
       (t (car candidates))))))

(defun code-agent-org-cmux--lookup-session-by-agent-name-as-string (name cwd)
  "Bridge entry point: same lookup, returned as =\"file\\0sid\\0cid\"=.

Empty string for unmatched / unset fields.  Returns the literal
string =\"\"= when no candidate matches at all — the bridge keys
off that to decide whether to override env or keep it.  NUL is the
field separator because no field can legitimately contain it.

Called from `workspace_bridge._resolve_routing' via
`mcp.eval_elisp'.  Keep the return shape stable; the python

    (if r
        (format "%s\0%s\0%s"
                (or (plist-get r :org-file) "")
                (or (plist-get r :session-id) "")
                (or (plist-get r :custom-id) ""))
      "")))

** Workspace lifecycle (restore + launch + persist)

The workspace lifecycle owns three concerns: bringing an already-running
cmux workspace back under Emacs's hash-table control on Emacs restart,
launching a brand-new workspace + claude pair, and persisting the org
properties cmux relies on for cross-restart workspace identity.

*Sidebar grouping* is an optional fourth aspect of launch.  Set a
=:CMUX_GROUP: <name>= org property (it inherits, so a project-level
heading or a file-level =#+PROPERTY: CMUX_GROUP <name>= covers every
session beneath it) and the freshly-launched workspace is filed under
that named cmux sidebar group.  =--ensure-group-membership= reuses an
existing group (=workspace-group add=) or creates one
(=workspace-group create --name=, which titles the auto-created anchor
header with the group name — no "分组 N" placeholder).  Grouping is
best-effort: an older cmux without the =workspace-group= subcommand, or
any RPC hiccup, is logged and skipped so it can never abort a launch.
No property → ungrouped workspace, exactly as before.

#+BEGIN_SRC elisp

(defun code-agent-org-cmux--restore-workspace (saved-surface workspace-session-id
                                                          tab-title workspace-ref)
  "Restore in-memory state for a cmux workspace that already exists.
SAVED-SURFACE is the surface ref; WORKSPACE-SESSION-ID the org session
identifier; TAB-TITLE the active-story label; WORKSPACE-REF the cmux
workspace ref (resolved by name in `ensure-session').  Rebuilds hash
tables, re-applies color, renames the tab, and starts verbose streaming.
Returns SAVED-SURFACE."
  ;; Restore hash table mappings (lost on Emacs restart or session expiry)
  (when workspace-session-id
    (puthash workspace-session-id (code-agent-org-current-session-key)
             code-agent-org-terminal--workspace-to-session-key)
    (when saved-surface
      (puthash workspace-session-id saved-surface
               code-agent-org-cmux--workspace-to-surface))
    (when workspace-ref
      (let ((ws-uuid (code-agent-org-cmux--resolve-workspace-uuid workspace-ref)))
        (when ws-uuid
          (puthash workspace-session-id ws-uuid
                   code-agent-org-cmux--workspace-to-cmux-id)))))
  ;; Store workspace-session-id for verbose tick lookup
  (code-agent-org-session-put (code-agent-org-current-session-key)
                           :workspace-session-id workspace-session-id)
  (when workspace-ref
    (code-agent-org-cmux--apply-color workspace-ref)
    ;; Rename tab to match active story (Claude Code overrides terminal title)
    (condition-case nil
        (code-agent-org-cmux--call "rename-tab" "--workspace" workspace-ref tab-title)
      (error nil)))
  ;; Start verbose and ensure IDE server (IDE only for agents that support it)
  (code-agent-org-cmux--start-verbose saved-surface (code-agent-org-current-session-key))
  (when workspace-session-id
    (let ((profile (code-agent-org-cmux--get-agent-profile)))
      (when (or (null profile)
                (code-agent-org-cmux--agent-profile-supports-ide profile))
        (code-agent-org-cmux--ensure-ide-server
         (or (code-agent-org-get-project-root) default-directory) workspace-session-id))))
  saved-surface)

(defun code-agent-org-cmux--resolve-workspace-uuid (workspace-ref)
  "Resolve WORKSPACE-REF to a stable UUID via sidebar-state.
UUIDs are stable within a session and work in raw socket --tab= args,
while refs only work via CLI.  Returns the UUID string or WORKSPACE-REF
if resolution fails."
  (or (when (string-prefix-p "workspace:" workspace-ref)
        (condition-case nil
            (let ((state (code-agent-org-cmux--call
                          "sidebar-state"
                          "--workspace" workspace-ref)))
              (when (string-match "^tab=\\([0-9A-F-]+\\)" state)
                (match-string 1 state)))
          (error nil)))
      workspace-ref))

(defun code-agent-org-cmux--persist-workspace-state (workspace-session-id
                                                  workspace-ref surface-id)
  "Save workspace state to in-memory hash tables and session heading.
WORKSPACE-SESSION-ID is the org session identifier, WORKSPACE-REF the
cmux workspace ref (e.g. \"workspace:3\"), SURFACE-ID the terminal
surface ref.  Persists only CMUX_SURFACE_ID as an org property — the
workspace identity is the heading title (stable across cmux restart).
Populates session state and the three mapping hash tables."
  (let ((session-key (code-agent-org-current-session-key))
        (ws-uuid (code-agent-org-cmux--resolve-workspace-uuid workspace-ref)))
    (save-excursion
      (save-restriction
        (code-agent-org-terminal-goto-session-heading)
        (org-set-property "CMUX_SURFACE_ID" surface-id)))
    (code-agent-org-session-put session-key :cmux-surface surface-id)
    (code-agent-org-session-put session-key :workspace-session-id workspace-session-id)
    (puthash workspace-session-id surface-id
             code-agent-org-cmux--workspace-to-surface)
    (puthash workspace-session-id session-key
             code-agent-org-terminal--workspace-to-session-key)
    (when ws-uuid
      (puthash workspace-session-id ws-uuid
               code-agent-org-cmux--workspace-to-cmux-id))
    (save-buffer)))

(defun code-agent-org-cmux--setup-ide-after-ready (surface-id project-root
                                                workspace-session-id)
  "Start IDE server and send /ide command if the agent profile supports it.
SURFACE-ID is the terminal surface, PROJECT-ROOT the working directory,
WORKSPACE-SESSION-ID the org session identifier.  Skips IDE setup for
agent profiles that explicitly disable it (e.g. copilot)."
  (when workspace-session-id
    (let ((profile (code-agent-org-cmux--get-agent-profile)))
      (when (or (null profile)
                (code-agent-org-cmux--agent-profile-supports-ide profile))
        (code-agent-org-cmux--ensure-ide-server project-root workspace-session-id)
        (run-at-time 5 nil
          (lexical-let ((sid surface-id))
            (lambda ()
              (condition-case nil
                  (progn
                    (code-agent-org-cmux--call "send" "--surface" sid "/ide")
                    (code-agent-org-cmux--call "send-key" "--surface" sid "Return"))
                (error nil)))))))))

(defun code-agent-org-cmux--find-group-by-name (name)
  "Return the cmux =workspace_group:N= ref whose group name is NAME, else nil.
Parses =cmux workspace-group list --json=.  Returns nil when no group
matches, the JSON can't be parsed, or the running cmux predates the
=workspace-group= subcommand (older builds error out, which we swallow)."
  (condition-case nil
      (let* ((out (code-agent-org-cmux--call "workspace-group" "list" "--json"))
             (data (json-parse-string out :object-type 'alist :array-type 'list))
             (groups (alist-get 'groups data))
             (hit (seq-find (lambda (g) (equal (alist-get 'name g) name)) groups)))
        (and hit (alist-get 'ref hit)))
    (error nil)))

(defun code-agent-org-cmux--ensure-group-membership (workspace-ref group-name)
  "Place WORKSPACE-REF into the cmux sidebar group named GROUP-NAME.
No-op when GROUP-NAME is nil/blank or WORKSPACE-REF is not a
\"workspace:N\" ref.  An existing group is reused via =workspace-group
add=; otherwise the group is created with =workspace-group create
--name=, which also titles the auto-created anchor header with
GROUP-NAME (so there's no \"分组 N\" placeholder — verified against
cmux 0.64.11).  Best-effort: any failure (e.g. an older cmux without
the subcommand) is logged, never signalled, so a grouping hiccup
cannot abort the workspace launch."
  (when (and (stringp group-name)
             (not (string-empty-p (string-trim group-name)))
             (stringp workspace-ref)
             (string-prefix-p "workspace:" workspace-ref))
    (let ((group (string-trim group-name)))
      (condition-case err
          (let ((group-ref (code-agent-org-cmux--find-group-by-name group)))
            (if group-ref
                (code-agent-org-cmux--call "workspace-group" "add"
                                           "--group" group-ref
                                           "--workspace" workspace-ref)
              (code-agent-org-cmux--call "workspace-group" "create"
                                         "--name" group
                                         "--from" workspace-ref))
            (message "cmux: workspace %s placed in group %S" workspace-ref group))
        (error
         (message "cmux: group %S membership skipped: %s"
                  group (error-message-string err)))))))

(defun code-agent-org-cmux--launch-workspace (workspace-session-id tab-title
                                          workspace-title project-root &optional group-name)
  "Launch a new cmux workspace running Claude Code.
WORKSPACE-SESSION-ID identifies the org session, TAB-TITLE and
WORKSPACE-TITLE name the tab and workspace, PROJECT-ROOT sets the
working directory.  Optional GROUP-NAME places the new workspace in
that named cmux sidebar group (creating the group if absent).  Stores
org properties, mappings, waits for the TUI to become ready, and
returns the surface ref."
  (unless workspace-session-id
    (user-error "No CLAUDE_SESSION_ID found. Create a workspace section first"))
  (let* ((org-file (buffer-file-name))
         (launch-cmd (code-agent-org-cmux--build-launch-command
                      org-file workspace-session-id project-root))
         ;; Create new workspace with launch command (returns "OK workspace:N").
         ;; If all tabs are closed, cmux reports "TabManager not available"
         ;; — create a new window first, then retry.
         (result (condition-case err
                     (code-agent-org-cmux--call
                      "new-workspace"
                      "--cwd" project-root
                      "--command" launch-cmd)
                   (error
                    (if (string-match-p "TabManager" (error-message-string err))
                        (progn
                          (code-agent-org-cmux--call "new-window")
                          (sleep-for 0.5)
                          (code-agent-org-cmux--call
                           "new-workspace"
                           "--cwd" project-root
                           "--command" launch-cmd))
                      (signal (car err) (cdr err))))))
         ;; Parse workspace ref, then get its surface ref
         (workspace-ref (code-agent-org-cmux--parse-surface-ref result))
         (surface-id (if (string-prefix-p "workspace:" workspace-ref)
                         (code-agent-org-cmux--get-workspace-surface workspace-ref)
                       workspace-ref)))
    ;; Rename workspace to heading name, tab to active story
    (when (string-prefix-p "workspace:" workspace-ref)
      (condition-case nil
          (progn
            (code-agent-org-cmux--call "rename-workspace"
              "--workspace" workspace-ref workspace-title)
            (code-agent-org-cmux--call "rename-tab"
              "--workspace" workspace-ref tab-title))
        (error nil)))
    ;; Persist workspace state (org properties + in-memory hash tables)
    (code-agent-org-cmux--persist-workspace-state
     workspace-session-id workspace-ref surface-id)
    ;; Apply color and start verbose BEFORE waiting for agent TUI.
    ;; These are pure cmux sidebar ops that don't need Claude Code running.
    ;; If we wait first, a slow or stuck agent launch means color/verbose
    ;; never get applied (wait-for-ready can time out).
    (when (string-prefix-p "workspace:" workspace-ref)
      (code-agent-org-cmux--apply-color workspace-ref)
      (code-agent-org-cmux--ensure-group-membership workspace-ref group-name))
    (code-agent-org-cmux--start-verbose surface-id (code-agent-org-current-session-key))
    (message "Agent starting in cmux (surface: %s) — waiting for TUI..." surface-id)
    ;; Wait for agent TUI to be ready before returning
    (code-agent-org-cmux--wait-for-ready surface-id)
    ;; IDE server and /ide command DO need the TUI ready.
    (code-agent-org-cmux--setup-ide-after-ready surface-id project-root
                                            workspace-session-id)
    (message "Agent ready in cmux (surface: %s)" surface-id)
    surface-id))

(defun code-agent-org-cmux--ensure-session ()
  "Ensure a cmux workspace/surface exists for the current workspace story.
Returns the cmux surface ref (e.g. \"surface:1\").
Launches if needed, reuses by saved ref.
Auto-starts the Emacs MCP server if not running."
  (code-agent-with-span "cmux-ensure-session"
    (list :session-id (condition-case nil
                          (code-agent-org-terminal-find-session-property "CLAUDE_SESSION_ID")
                        (error nil))) nil
  ;; Best-effort MCP server auto-start
  (when (and (fboundp 'emacs-mcp-server-running-p)
             (not (emacs-mcp-server-running-p))
             (fboundp 'emacs-mcp-server-start))
    (condition-case err
        (progn
          (emacs-mcp-server-start)
          (run-at-time 1 nil
                       (lambda ()
                         (if (emacs-mcp-server-running-p)
                             (message "Started Emacs MCP server for workspace bridge")
                           (message "WARNING: MCP server didn't start")))))
      (error (message "WARNING: MCP server start failed: %s" err))))
  (let* ((saved-surface (code-agent-org-terminal-find-session-property "CMUX_SURFACE_ID"))
         (tab-title (code-agent-org-terminal--tab-title))
         (workspace-title (code-agent-org-cmux--session-workspace-title))
         (workspace-session-id
          (code-agent-org-terminal-find-session-property "CLAUDE_SESSION_ID"))
         (project-root (or (code-agent-org-get-project-root) default-directory))
         ;; Optional sidebar group — inherits from parent headings and
         ;; file-level #+PROPERTY via find-session-property.
         (group-name (code-agent-org-terminal-find-session-property "CMUX_GROUP"))
         ;; Single source of truth: resolve workspace by heading name.
         ;; Names are stable across cmux restart; UUIDs and refs are not.
         (ws-ref (code-agent-org-cmux--find-workspace-by-name workspace-title)))
    (cond
     ;; Workspace exists in cmux (possibly with a fresh surface after a
     ;; cmux restart) — restore in-memory mappings and refresh the
     ;; surface property if the old one went stale.
     (ws-ref
      (let* ((fresh-surface (condition-case nil
                                (code-agent-org-cmux--get-workspace-surface ws-ref)
                              (error nil)))
             (surface-to-use (or fresh-surface saved-surface)))
        (when (and fresh-surface (not (equal fresh-surface saved-surface)))
          (save-excursion
            (save-restriction
              (code-agent-org-terminal-goto-session-heading)
              (org-set-property "CMUX_SURFACE_ID" fresh-surface)))
          (when (buffer-file-name) (save-buffer)))
        (code-agent-org-cmux--restore-workspace
         surface-to-use workspace-session-id tab-title ws-ref)))
     ;; No workspace by this name — launch a fresh one.
     (t
      (code-agent-org-cmux--launch-workspace
       workspace-session-id tab-title workspace-title project-root
       group-name))))))
#+END_SRC

* Status Detection

#+BEGIN_SRC elisp
(defun code-agent-org-cmux--get-status (workspace-session-id surface-id)
  "Get code agent status for WORKSPACE-SESSION-ID and SURFACE-ID.
WORKSPACE-SESSION-ID keys the hook file; SURFACE-ID keys the cmux API.
Uses ready/busy patterns from the active agent profile."
  (let ((hook-status (code-agent-org-terminal--read-hook-status workspace-session-id)))
    (if (member hook-status '("ready" "busy"))
        hook-status
      ;; Fallback: read screen content from cmux using profile patterns
      (condition-case nil
          (let* ((profile (code-agent-org-cmux--get-agent-profile))
                 (ready-re (if profile
                               (mapconcat #'regexp-quote
                                          (code-agent-org-cmux--agent-profile-ready-patterns profile)
                                          "\\|")
                             "-- INSERT --\\|type a message"))
                 (busy-re (if profile
                              (mapconcat #'regexp-quote
                                         (code-agent-org-cmux--agent-profile-busy-patterns profile)
                                         "\\|")
                            "Tool:\\|Thinking"))
                 (screen (code-agent-org-cmux--call "capture-pane"
                           "--surface" surface-id)))
            (cond
             ((string-match-p ready-re screen) "ready")
             ((string-match-p busy-re screen) "busy")
             ((string-empty-p screen) "dead")
             (t "unknown")))
        (error "dead")))))

* Query Completion

Decides when a Claude turn has ended — composite signal of =Stop= hook fire + shell prompt re-appearing in the verbose capture.

#+BEGIN_SRC elisp
(defun code-agent-org-cmux--query-completed (workspace-session-id)
  "Mark the cmux query for WORKSPACE-SESSION-ID as completed.
Unregisters from `code-agent--active-queries'.
When loop state is active, schedules the next iteration.
Wrapped in condition-case: called from Python via MCP evalElisp,
so an unhandled error would leave the session permanently :busy t."
  (condition-case err
      (let* ((session-key (gethash workspace-session-id code-agent-org-terminal--workspace-to-session-key))
             (trace-ctx (when session-key
                          (code-agent-org-session-get session-key :trace-ctx))))
        (code-agent-with-span "cmux-query-completed"
            (list :session-id workspace-session-id) trace-ctx
        (let ((req-id (code-agent-org-terminal--read-request-id workspace-session-id)))
          (when req-id
            (let ((state (code-agent--get-active-query req-id)))
              (when state
                (setf (code-agent--process-state-closed state) t)
                (code-agent--unregister-query req-id)))))
        ;; Check loop continuation
        (let ((surface-id (gethash workspace-session-id code-agent-org-cmux--workspace-to-surface)))
          ;; Workspace mappings persist across queries (workspace outlives stories)
          ;; No pipe-pane streaming to stop (removed — marker was never wired up,
          ;; resulting in every-2s sync `cmux pipe-pane` calls with discarded output).
          ;; No color to re-apply — WORKSPACE_COLOR is static per workspace and
          ;; was already applied at session-creation time.
          ;; Verbose output (separate subsystem) keeps running — user may type
          ;; more queries directly in cmux without going through execute-ai-block.
          (when session-key
            (code-agent-org-session-put session-key :busy nil)
            (let ((loop-current (or (code-agent-org-session-get session-key :loop-current) 1))
                  (loop-max (or (code-agent-org-session-get session-key :loop-max) 1)))
              (if (< loop-current loop-max)
                  ;; More iterations — schedule next
                  (let ((interval (or (code-agent-org-session-get session-key :loop-interval) 0))
                        (prompt (code-agent-org-session-get session-key :original-prompt)))
                    (code-agent-org-session-put session-key :loop-current (1+ loop-current))
                    (if (> interval 0)
                        (run-at-time interval nil
                                     #'code-agent-org-cmux--loop-send
                                     workspace-session-id surface-id prompt session-key)
                      (code-agent-org-cmux--loop-send workspace-session-id surface-id prompt session-key)))
                ;; Loop complete — cleanup
                (code-agent-org-session-put session-key :loop-max nil)
                (code-agent-org-session-put session-key :loop-current nil)))))))
    (error
     ;; Ensure busy state is cleared even on error
     (let ((session-key (gethash workspace-session-id code-agent-org-terminal--workspace-to-session-key)))
       (when session-key
         (code-agent-org-session-put session-key :busy nil)))
     (message "code-agent-org-cmux: error in query-completed: %S" err))))
#+END_SRC

(defun code-agent-org-cmux--loop-send (workspace-session-id surface-id prompt session-key)
  "Send next loop iteration PROMPT to cmux.
WORKSPACE-SESSION-ID and SURFACE-ID identify the session."
  (code-agent-with-span "cmux-loop-send"
      (list :session-id workspace-session-id) nil
  (let ((org-buf (code-agent-org-session-get session-key :loop-org-buffer))
        (marker (code-agent-org-session-get session-key :loop-block-marker)))
    (when (and org-buf (buffer-live-p org-buf) marker (marker-buffer marker))
      (with-current-buffer org-buf

          (save-excursion
            (org-back-to-heading t)
            (when workspace-session-id
              (code-agent-org-terminal-register-query workspace-session-id surface-id)))))))
  (code-agent-org-cmux--send-text surface-id prompt)
  (let ((current (code-agent-org-session-get session-key :loop-current))
        (max (code-agent-org-session-get session-key :loop-max)))
    (message "Sent loop iteration %d/%d to cmux (%d chars)"
             current max (length prompt)))))

* Execution

eight steps; every step has a matching OTel span so the trace tree
mirrors the prose:

2. ensure-session: reuse (capture-pane liveness) or create (new-workspace)

4. wait-for-ready: poll capture-pane for INSERT mode (up to 30 s)
5. write from-emacs flag + custom-id + register query

7. SDD bridge hooks fire (Python → Emacs MCP):
   - handle_prompt: save CLI session, insert prompt (Flow B)

(defun code-agent-org-cmux--prompt-at-point ()
  "Return the trimmed prompt string of the AI block at point, or signal user-error."
  (let* ((element (org-element-at-point))
         (prompt (when (and (eq (org-element-type element) 'src-block)
                            (string= (org-element-property :language element) "ai"))
                   (substring-no-properties
                    (string-trim (org-element-property :value element))))))
    (unless prompt
      (user-error "Point is not inside a #+begin_src ai block"))
    prompt))

(defun code-agent-org-cmux--session-state-seed (sk surface-id)
  "Populate per-query session state for SK / SURFACE-ID before dispatch.

Mirrors the field-write block in `code-agent-org-execute' that the
agent-family backends rely on.  The multiplexer path bypasses
`code-agent-org-execute', so without this seeding cancel-from-org
returns \"No active query\", queueing skips, and `:loop 2+' never
advances past iteration 1."
  (ignore surface-id)
  (code-agent-org-session-put sk :loop-org-buffer (current-buffer))
  (code-agent-org-session-put sk :loop-block-marker (copy-marker (point)))
  (code-agent-org-session-put sk :backend
                               (code-agent-cmux-backend-create :session-key sk))
  ;; Keep `:backend-property' in sync so `code-agent-org--resolve-backend'
  ;; treats this manual install as a fresh cache entry rather than a
  ;; property-change miss on the next dispatch.
  (code-agent-org-session-put sk :backend-property "cmux")
  (let ((instr-num     (code-agent-org--find-instruction-number))
        (custom-id     (code-agent-org--find-instruction-custom-id))
        (section-level (code-agent-org--get-section-level))
        (query-id      (code-agent-org--generate-query-id))
        (block-marker  (copy-marker (point))))
    (code-agent-org-session-put sk :busy t)
    (code-agent-org-session-put sk :query-id query-id)
    (code-agent-org-session-put sk :marker block-marker)
    (code-agent-org-session-put sk :start-time (float-time))
    (code-agent-org-session-put sk :instruction-num instr-num)
    (code-agent-org-session-put sk :custom-id custom-id)
    (code-agent-org-session-put sk :section-level section-level)
    (code-agent-org-session-put sk :recovery-count 0)))

(defun code-agent-org-cmux--dispatch-prompt (sk workspace-session-id surface-id prompt)
  "Register the query, flip the from-emacs flag, type PROMPT, start verbose mirror."
  (ignore sk)
  (save-excursion
    (org-back-to-heading t)
    (when workspace-session-id
      (code-agent-org-terminal-register-query workspace-session-id surface-id)))
  (when workspace-session-id
    (code-agent-org-terminal--write-from-emacs-flag workspace-session-id))
  (code-agent-org-cmux--send-text surface-id prompt)
  (code-agent-org-cmux--start-verbose surface-id sk)
  (message "Sent to cmux (%d chars)" (length prompt)))

(defun code-agent-org-cmux--execute-ai-block ()
  "Execute the AI block at point via the cmux backend.

Five phases:
1. Read the prompt and resolve session/surface/status.
2. Refuse to send when the surface is busy.
3. Auto-update ACTIVE_STORY (so Channel B routing stays in sync).
4. Seed session state for cancel/queue/loop/telemetry paths.
5. Type the prompt, register active query, start verbose mirror —
   all under one `cmux-execute' span that async cmux-query-completed
   callbacks attach to via the cached trace context."
  (let* ((prompt (code-agent-org-cmux--prompt-at-point))
         (surface-id (code-agent-org-cmux--ensure-session))
         (workspace-session-id
          (code-agent-org-terminal-find-session-property "CLAUDE_SESSION_ID"))
         (status (code-agent-org-cmux--get-status workspace-session-id surface-id))
         (sk (code-agent-org-current-session-key)))
    (when (string= status "busy")
      (user-error "Claude Code busy (status: %s). Cancel first?" status))
    ;; Durable fix for the 2026-05-26 "prompt vanishes" failure mode.
    ;; cmux's session-restore strips the launcher's `--settings
    ;; workspace-hooks.json' extras, so the restored claude has no
    ;; bridge hooks and every UserPromptSubmit fires silently.  Check
    ;; the running claude's argv on this surface and auto-relaunch via
    ;; the launcher when hooks are missing.  No-op when claude is
    ;; already correctly wired (the common case after a fresh launch).
    (code-agent-org-cmux--ensure-hooks-wired surface-id)
    (when-let* ((story (code-agent-org--find-story-heading)))
      (code-agent-org--set-active-story (car story)))
    ;; Root trace context: cache BEFORE entering the child span so async
    ;; callbacks join at the root, not under the cmux-execute span itself.
    (when sk
      (code-agent-org-session-put sk :trace-ctx (code-agent-trace-context)))
    (code-agent-with-span "cmux-execute"
        (list :session-id workspace-session-id
              :input prompt
              :surface-id surface-id) nil
      (when workspace-session-id
        (puthash workspace-session-id sk
                 code-agent-org-terminal--workspace-to-session-key))
      (code-agent-org-cmux--session-state-seed sk surface-id)
      (code-agent-org-cmux--dispatch-prompt
       sk workspace-session-id surface-id prompt))))

* Response Delivery

Response text lands in the org buffer via the =Stop= hook →
=workspace_bridge.handle_response= → =code-agent-org-workspace-bridge-insert-response=.
No periodic polling from Emacs is needed.

(Historical note: there used to be a =code-agent-org-cmux--start-streaming= timer
that fired =cmux pipe-pane= every 2 s to mirror terminal output into the org
buffer.  Its insertion marker was never initialised, so every tick did a
200–1500 ms synchronous subprocess call and silently discarded the result —
a persistent Emacs hang for the full duration of every Claude query.  The
subsystem was removed in favour of the =Stop=-hook path, which delivers the
full structured response exactly once.  Live terminal echo is still available
via the async =Verbose Output= mirror below.)

* Verbose Output (Live Output Mirror)

Stream cmux terminal output into a read-only Emacs buffer accessible via
=code-agent-org-menu → v → Verbose output=. The user gets Claude Code's
live thinking — tool calls, file edits, intermediate output — without
having to alt-tab into the cmux app, and the canonical response still
arrives through the =Stop= hook into the org buffer. Both surfaces are
useful: the verbose buffer is for /watching the work happen/; the org
response is for /referring back to the final answer/.

** Data-Source Choice — Why Async Polling Won the First Round

Three data-source options were considered before settling on the
current implementation. The shipped path is the middle of the road —
it works today and the upgrade path is clean.

| Option | Mechanism | Latency | Cost |
|--------+-----------+---------+------|
| 1. cmux =pipe-pane --follow= | persistent socket subscription from cmux side | ~0, event-driven | requires a Swift change in cmux (~30 lines + Ghostty content-update callback) |
| 2. Async =capture-pane= polling (*shipped*) | =start-process= every ~1 s, diff against previous | ~1 s sampling | needs no cmux changes; capture cost grows with scrollback |
| 3. FIFO + =file-notify= | =pipe-pane= writing to a log file, FSEvents on Emacs side | ~100 ms | =pipe-pane= is one-shot (needs re-invocation); log file grows unbounded |

Option 2 ships because it works against the current cmux release; the
Emacs-side buffer infrastructure is data-source-agnostic, so the
=verbose-tick= process filter could be swapped for a
=make-network-process= socket whenever cmux gains =pipe-pane --follow=
without touching the buffer / mode / menu surfaces.

** Two Predecessor Bugs Worth Remembering

The current shape is partly defined by what came before it failing.

*The =call-process= leak (commit =1f016b8=, fixed in =01b4143=).* The
first attempt used =call-process= inside a 1 Hz timer to poll
=capture-pane=. Two compounding bugs: (a) =call-process= is
synchronous, so every tick blocked Emacs's main thread for 200–1500 ms;
(b) the insertion marker was declared but never initialised, so the
guard around the insertion was always nil and the captured text was
silently discarded. The result: a permanent Emacs hang for every
Claude query, doing work no user could observe. The fix replaced
=call-process= with =start-process= + filter + sentinel; the rule
=.claude/rules/minimize-emacs-mcp-calls.md= now forbids periodic
timers that =call-process=.

*The unbounded buffer leak (2026-04-22).* Once the follower /did/
deliver text, it appended forever. A box left overnight accumulated
several megabytes per chatty session — nine live =*cmux: <id>*=
buffers held ~8 MB combined in one inspection, visibly swelling Emacs
RSS. The fix is in the Verbose Buffer Memory Cap subsection further
down: a configurable byte ceiling with whole-line trim from the front,
plus a =kill-buffer-hook= that stops the follower subprocess when the
user dismisses the buffer.

because some TUI frameworks need the raw byte, not a key event."
  (when code-agent-org-cmux--verbose-surface-id

** Buffer and Streaming

Verbose buffer lifecycle + token streaming primitives shared by the cmux follower and the in-band response handler.

#+BEGIN_SRC elisp
(defvar-local code-agent-org-cmux--verbose-prev-text ""
  "Previous capture-pane output for diff-based deduplication.")

(defun code-agent-org-cmux--create-verbose-buffer (session-key surface-id)
  "Create a verbose output buffer for cmux terminal SESSION-KEY.
Registers it so `code-agent-org-show-verbose' can find it.  Derives the
workspace identity from SESSION-KEY itself (format `<file>::<session-id>')
so the buffer name stays stable even if `:workspace-session-id' session
state has been wiped by a module reload — never falls back to the ambient
current-buffer's `CLAUDE_SESSION_ID', which would collide with unrelated
buffers."
  (let* ((workspace-id (or (code-agent-org-session-get session-key :workspace-session-id)
                           (when (and session-key
                                      (string-match "::\\([^:]+\\)\\'" session-key))
                             (match-string 1 session-key))
                           "cmux"))
         (buf-name (format "*cmux: %s*" workspace-id))
         (buf (get-buffer-create buf-name)))
    (with-current-buffer buf
      (unless (eq major-mode 'code-agent-org-cmux-verbose-mode)
        (code-agent-org-cmux-verbose-mode)
        (setq-local code-agent-org-cmux--verbose-prev-text "")
        (setq-local code-agent-org-cmux--verbose-surface-id surface-id)
        ;; Sticky header with story name and keybindings
        (setq-local header-line-format
          (list "  "
                (propertize workspace-id 'face 'bold)
                "  "
                (propertize "[,]menu [G]follow [q]quit" 'face 'shadow))))
      ;; Drop the global registry entry when the buffer dies so
      ;; `code-agent-org-show-verbose' and `--create-verbose-buffer' see the
      ;; buffer as gone.  The follow-process is stopped from
      ;; `--start-verbose' (see `--install-verbose-kill-hook') — it knows
      ;; the process and doesn't need buffer-local session state which is
      ;; unreachable here (we're running inside the dying `vbuf', not the
      ;; file buffer that owns `code-agent-org--sessions').
      (lexical-let ((sk session-key))
        (add-hook 'kill-buffer-hook
                  (lambda ()
                    (remhash sk code-agent--session-verbose-buffers))
                  nil t)))
    ;; Register so code-agent-org-show-verbose finds it
    (puthash session-key buf code-agent--session-verbose-buffers)
    buf))

(defun code-agent-org-cmux--verbose-workspace-uuid (session-key)
  "Return the cmux workspace UUID for SESSION-KEY from the in-memory cache.
Checks `:workspace-session-id' session slot first, then parses the
session-id out of SESSION-KEY (format `<file>::<session-id>'); both feed
into `workspace-to-cmux-id', which is populated by `restore-workspace'
/ `launch-workspace' / `recover-session' when the workspace is resolved
by heading name.  Returns nil on cache miss — callers must skip the
tick; a subsequent `ensure-session' will repopulate the cache."
  (let ((ws-sid (or (code-agent-org-session-get session-key :workspace-session-id)
                    (when (and session-key
                               (string-match "::\\([^:]+\\)\\'" session-key))
                      (match-string 1 session-key)))))
    (when ws-sid
      (gethash ws-sid code-agent-org-cmux--workspace-to-cmux-id))))

** Verbose Buffer Memory Cap

The =--follow= filter appends chunks forever, so without a ceiling
the =*cmux: <id>*= buffer grows unboundedly for as long as the
session produces terminal output.  A box left running overnight
accumulated *several megabytes per chatty session* under the
original 1f016b8 implementation — 9 live buffers held ~8 MB of
raw text in one inspection, visibly swelling Emacs RSS over time.

Cap the buffer with a configurable ceiling and trim whole lines
from the start when it's exceeded.  Whole-line trimming keeps the
display readable (no half-truncated line at =point-min=).  The
default 256 KB ≈ hundreds of scrolled screens — plenty for
debugging, cheap to hold.

The ANSI strip + ceiling defcustom both live in
[[file:../backend/code-agent-multiplexer.org][code-agent-multiplexer.org]] (shared with tmux); this filter
reads from there directly — no cmux-private copies.

#+BEGIN_SRC elisp
(defun code-agent-org-cmux--verbose-follow-filter (proc chunk)
  "Append CHUNK (scrubbed) from `cmux capture-pane --follow' to the verbose buffer.

Trims whole lines from the start when the buffer exceeds
`code-agent-multiplexer-verbose-buffer-max-size' so long-running
sessions don't accumulate unbounded memory.

Auto-scrolls only windows that were already at `point-max' — a user
reading an earlier page keeps their scroll position as new content
lands after the visible window."
  (let ((vbuf (process-get proc 'verbose-buffer)))
    (when (buffer-live-p vbuf)
      (let ((scrubbed (code-agent-multiplexer--strip-ansi chunk)))
        (when (> (length scrubbed) 0)
          (with-current-buffer vbuf
            (let ((win-states nil))
              (dolist (win (get-buffer-window-list vbuf nil t))
                (push (cons win (= (window-point win) (point-max))) win-states))
              (let ((inhibit-read-only t))
                (save-excursion
                  (goto-char (point-max))
                  (insert scrubbed))
                ;; Trim whole lines from the start when over cap.
                (when (and code-agent-multiplexer-verbose-buffer-max-size
                           (> (buffer-size)
                              code-agent-multiplexer-verbose-buffer-max-size))
                  (save-excursion
                    (goto-char (- (point-max)
                                  code-agent-multiplexer-verbose-buffer-max-size))
                    (forward-line 1)
                    (delete-region (point-min) (point)))))
              (dolist (state win-states)
                (let ((win (car state)) (was-at-end (cdr state)))
                  (when (and (window-live-p win) was-at-end)
                    (set-window-point win (point-max))))))))))))

(defun code-agent-org-cmux--verbose-follow-sentinel (proc event)
  "Handle `cmux capture-pane --follow' lifecycle events.

On exit we drop the process reference from the session so a later
`--start-verbose' call can restart it (either manually, or when a
workspace is relaunched).  We deliberately DO NOT auto-restart
here — if cmux is genuinely gone there's no workspace to follow,
and silent reconnect loops would mask real failures."
  (let ((sk (process-get proc 'session-key))
        (vbuf (process-get proc 'verbose-buffer)))
    (when (string-match-p "\\(finished\\|exited\\|killed\\|broken\\)" event)
      (when (and sk (eq proc (code-agent-org-session-get sk :verbose-follow-process)))
        (code-agent-org-session-put sk :verbose-follow-process nil))
      (when (buffer-live-p vbuf)
        (with-current-buffer vbuf
          (let ((inhibit-read-only t))
            (save-excursion
              (goto-char (point-max))
              (insert (format "\n;; cmux stream ended: %s\n"
                              (string-trim event))))))))))

(defun code-agent-org-cmux--start-verbose (surface-id session-key)
  "Start the long-running `cmux capture-pane --follow' stream for SESSION-KEY.

Replaces the earlier polling timer (one `capture-pane' fork per
second per session).  A single subprocess per session reads the
terminal as it changes and its filter appends into
`*cmux: <session>*'.  The subprocess is idle-cheap — it blocks on
read between terminal writes, so zero CPU when nothing is
happening.  Restarts automatically when the surface id changes
(workspace relaunched with a new terminal pane)."
  (let ((existing (code-agent-org-session-get session-key :verbose-follow-process))
        (old-surface (code-agent-org-session-get session-key :verbose-surface-id)))
    ;; Restart if the surface id moved (new workspace pane replaces old).
    (when (and existing (or (not old-surface)
                            (not (equal old-surface surface-id))))
      (code-agent-org-cmux--stop-verbose session-key)
      (setq existing nil))
    (when (and existing (not (process-live-p existing)))
      (code-agent-org-cmux--stop-verbose session-key)
      (setq existing nil))
    (unless existing
      (code-agent-org-session-put session-key :verbose-surface-id surface-id)
      (let* ((ws-uuid (code-agent-org-cmux--verbose-workspace-uuid session-key))
             (vbuf (code-agent-org-cmux--create-verbose-buffer session-key surface-id))
             (sock (or code-agent-org-cmux-socket-path
                       (condition-case nil
                           (code-agent-org-terminal-find-session-property "CMUX_SOCKET_PATH")
                         (error nil)))))
        ;; No workspace resolution yet → nothing to follow.  Leave the
        ;; buffer in place; a later call (after `ensure-session'
        ;; populates the workspace map) will spawn the stream.
        (when (and ws-uuid surface-id (buffer-live-p vbuf))
          (let* ((cli (or code-agent-org-cmux-cli-path "cmux"))
                 (args (append (when sock (list "--socket" sock))
                               (list "capture-pane"
                                     "--workspace" ws-uuid
                                     "--surface" surface-id
                                     "--follow"
                                     "--interval" "0.5")))
                 (proc (apply #'start-process
                              (format "cmux-follow-%s" session-key)
                              nil cli args)))
            (process-put proc 'verbose-buffer vbuf)
            (process-put proc 'session-key session-key)
            (set-process-filter proc #'code-agent-org-cmux--verbose-follow-filter)
            (set-process-sentinel proc #'code-agent-org-cmux--verbose-follow-sentinel)
            (code-agent-org-session-put session-key :verbose-follow-process proc)
            ;; Stop the follower when the user dismisses *cmux: <id>*.
            ;; Installed here (not in --create-verbose-buffer) so the closure
            ;; can capture the process directly.  `code-agent-org--sessions' is
            ;; buffer-local in the FILE buffer, not reachable from inside the
            ;; dying vbuf's kill-buffer-hook — so we also capture the owner
            ;; buffer and clear the session slot there, otherwise the session
            ;; would still claim a process we just deleted.  `lexical-let' is
            ;; required because literate-elisp ignores `lexical-binding'.
            (lexical-let ((captured-proc proc)
                          (owner-buf (current-buffer))
                          (sk session-key))
              (with-current-buffer vbuf
                (add-hook 'kill-buffer-hook
                          (lambda ()
                            (when (process-live-p captured-proc)
                              (delete-process captured-proc))
                            (when (buffer-live-p owner-buf)
                              (with-current-buffer owner-buf
                                (code-agent-org-session-put
                                 sk :verbose-follow-process nil))))
                          nil t)))))))))

(defun code-agent-org-cmux--stop-verbose (session-key)
  "Kill the verbose stream subprocess for SESSION-KEY, if any.

Also clears the legacy `:verbose-timer' slot — older sessions still
carrying a run-at-time timer (before the follow-stream refactor)
get cleaned up the first time this is called."
  (let ((proc (code-agent-org-session-get session-key :verbose-follow-process))
        (timer (code-agent-org-session-get session-key :verbose-timer)))
    (when (and proc (process-live-p proc))
      (delete-process proc))
    (code-agent-org-session-put session-key :verbose-follow-process nil)
    (when timer
      (cancel-timer timer)
      (code-agent-org-session-put session-key :verbose-timer nil))))

(defun code-agent-org-cmux--activate-app ()

  (when (eq system-type 'darwin)
    ;; Tell cmux to mark itself as active
    (condition-case nil
        (code-agent-org-cmux--call "set-app-focus" "active")

(defun code-agent-org-cmux-open-tab ()
  "Open (or focus) the cmux workspace for this workspace session.
Resolves the workspace by heading name.  Launches Claude Code if no
matching workspace exists.  Always re-applies WORKSPACE_COLOR pill
\(status pills are transient in cmux)."
  (interactive)
  (code-agent-org-cmux--ensure-session)
  ;; Re-resolve by name AFTER ensure-session — it may have launched a
  ;; fresh workspace.  The heading title is the stable identity.
  (let ((ws-ref (code-agent-org-cmux--session-workspace-ref))
        (surface-id (code-agent-org-terminal-find-session-property "CMUX_SURFACE_ID")))
    (cond
     (ws-ref
      (condition-case nil
          (progn
            (code-agent-org-cmux--call "select-workspace" "--workspace" ws-ref)
            ;; Re-apply color (pills are lost on cmux restart)
            (code-agent-org-cmux--apply-color ws-ref)
            (code-agent-org-cmux--activate-app)
            (message "cmux workspace focused (%s)" ws-ref))
        (error
         ;; Workspace ref became stale between resolve and call (rare).
         ;; Clear the surface marker and retry via ensure-session.
         (save-excursion
           (save-restriction
             (code-agent-org-terminal-goto-session-heading)
             (org-delete-property "CMUX_SURFACE_ID")
             (save-buffer)))
         (code-agent-org-cmux--ensure-session)
         (let ((fresh-ref (code-agent-org-cmux--session-workspace-ref)))
           (when fresh-ref
             (code-agent-org-cmux--call "select-workspace" "--workspace" fresh-ref)
             (code-agent-org-cmux--apply-color fresh-ref))
           (code-agent-org-cmux--activate-app)
           (message "cmux workspace recreated and focused")))))
     (surface-id
      (code-agent-org-cmux--activate-app)
      (message "cmux surface: %s (focused app)" surface-id))
     (t (user-error "No cmux session for this story")))))

(defun code-agent-org-cmux--capture-screen (surface-id lines)
  "Capture LINES of SURFACE-ID's screen as a string, or empty on failure.

The plain ``capture-pane --surface'' form fails with ``Surface is not
a terminal'' when the caller is outside cmux (Emacs subprocess) and
the target surface lives in a non-current workspace.  Including the
``--workspace'' ref disambiguates the lookup and brings the cross-
workspace case back to life.  Falls back gracefully — every caller
already treats empty string as ``unknown screen state''."
  (let ((ws-ref (code-agent-org-cmux--session-workspace-ref)))
    (or (condition-case nil
            (apply #'code-agent-org-cmux--call
                   "capture-pane"
                   (append
                    (when ws-ref (list "--workspace" ws-ref))
                    (list "--surface" surface-id "--lines" (number-to-string lines))))
          (error nil))
        "")))

(defun code-agent-org-cmux--shell-prompt-p (screen)
  "Return non-nil when SCREEN's last visible character looks like a shell prompt.

Matches the three prompts our developer machines actually produce:
bash/zsh =$=, starship/p10k =❯=, and zsh-with-newline =%=.  The
trailing whitespace class is =\\s-*= (elisp syntax-class for
whitespace), NOT =\\s*= — the latter is a bare backslash-s with no
syntax-class character and never matches anything.  The earlier
restart copy used the broken form, which is why this code path was
silently no-op in production."
  (and screen
       (or (string-match-p "\\$\\s-*$" screen)
           (string-match-p "❯\\s-*$" screen)
           (string-match-p "%\\s-*$" screen))))

(defun code-agent-org-cmux--claude-tui-p (screen)
  "Return non-nil when SCREEN shows the Claude Code TUI is in the foreground.

Positive detection looks for any of Claude Code's stable UI strings —
the input-mode indicator, the permissions status line, or the
distinctive welcome banner.  Negative cases (shell, vim, less, plain
output) lack all three and return nil.

Used by ``restart'' to decide between three states:
  TUI running   → send /exit + wait for shell
  shell prompt  → skip /exit, launch directly
  something else→ neither — log warning, assume TUI to stay safe."
  (and screen
       (or (string-match-p "-- INSERT --" screen)
           (string-match-p "bypass permissions on" screen)
           (string-match-p "shift+tab to cycle" screen)
           (string-match-p "✻ Welcome to Claude" screen))))

(defun code-agent-org-cmux--surface-state (screen)
  "Classify SCREEN content as ='claude=, ='shell=, or ='unknown=.

Order matters: a screen that ends in =$= but also contains
=-- INSERT --= is most likely the *previous* shell line scrolled
above a freshly-started Claude — checking the TUI markers first
catches that case correctly."
  (cond
   ((code-agent-org-cmux--claude-tui-p screen) 'claude)
   ((code-agent-org-cmux--shell-prompt-p screen) 'shell)
   (t 'unknown)))

(defun code-agent-org-cmux--wait-for-shell (surface-id max-seconds)
  "Poll SURFACE-ID once per second until a shell prompt appears or MAX-SECONDS elapse.
Returns t when the prompt was seen, nil on timeout."
  (let ((attempts 0)
        (seen nil))
    (while (and (not seen) (< attempts max-seconds))
      (sleep-for 1)
      (when (code-agent-org-cmux--shell-prompt-p
             (code-agent-org-cmux--capture-screen surface-id 3))
        (setq seen t))
      (cl-incf attempts))
    seen))

(defun code-agent-org-cmux--launch-cmd-without-resume (launch-cmd)
  "Return LAUNCH-CMD with the ``--resume <id>'' pair stripped.

The shell-quoted form produced by ``--build-launch-command'' looks
like ``... -- --resume 12d9...''; rewriting via a single regex is
safer than parsing the shell quoting back to argv, because the env
prefix and quoting style differ across agent profiles."
  (replace-regexp-in-string
   " --resume +[^ ]+"
   ""
   launch-cmd))

(defun code-agent-org-cmux--resume-failed-p (surface-id)
  "Return non-nil when SURFACE-ID shows Claude Code's resume-failure banner.

Claude exits within ~1s of seeing an unknown session id, printing
``No conversation found with session ID: <uuid>'' before returning
control to the shell.  Both the banner line and the resulting shell
prompt are usually still on screen by the time we capture, but we
look for the banner alone — the prompt may have scrolled past the
captured window if the user's prompt occupies multiple lines."
  (let ((screen (code-agent-org-cmux--capture-screen surface-id 15)))
    (and screen (string-match-p "No conversation found" screen))))

(defun code-agent-org-cmux--recover-from-resume-failure (surface-id launch-cmd)
  "When the just-issued LAUNCH-CMD with =--resume= bounced off a stale
session id, drop the stale property and re-send a resume-free command.

SURFACE-ID is the cmux surface to drive.  Only call this after sending
LAUNCH-CMD and waiting long enough for Claude to print its
=No conversation found= banner if applicable (~3s in practice).

Stripping =--resume <id>= from LAUNCH-CMD is deterministic; rebuilding
from scratch via =--build-launch-command= would race a not-yet-visible
property delete in some org versions."
  (when (code-agent-org-cmux--resume-failed-p surface-id)
    (message "Resume failed (stale CLAUDE_CLI_SESSION); relaunching fresh...")
    (condition-case nil
        (save-excursion
          (code-agent-org-terminal-goto-session-heading)
          (org-entry-delete nil "CLAUDE_CLI_SESSION")
          (let ((inhibit-message t)) (save-buffer)))
      (error nil))
    (code-agent-org-cmux--wait-for-shell surface-id 5)
    (let ((fresh-cmd (code-agent-org-cmux--launch-cmd-without-resume
                      launch-cmd)))
      (code-agent-org-cmux--call "send" "--surface" surface-id
                                 (concat fresh-cmd "\n")))))

(defun code-agent-org-cmux--post-restart-ide-setup (surface-id workspace-session-id)
  "Wire the IDE server + send =/ide= to SURFACE-ID after a restart.

Does nothing when WORKSPACE-SESSION-ID is nil (no IDE bridge expected).
The =/ide= send is delayed 10s so Claude finishes booting before it
receives the command.

Extracted from `code-agent-org-cmux-restart' to flatten the restart
function's body — this is one of its larger conceptual phases."
  (when workspace-session-id
    (code-agent-org-cmux--ensure-ide-server
     (or (code-agent-org-get-project-root) default-directory)
     workspace-session-id)
    (run-at-time 10 nil
      (lexical-let ((sid surface-id))
        (lambda ()
          (condition-case nil
              (progn
                (code-agent-org-cmux--call "send" "--surface" sid "/ide")
                (code-agent-org-cmux--call "send-key" "--surface" sid "Return"))
            (error nil)))))))

(defun code-agent-org-cmux-restart ()
  "Restart Claude Code in the current cmux tab.

Sends /exit to quit the running Claude Code, waits for the shell
prompt, then launches a fresh Claude Code in the same tab.  Does not
destroy the workspace or affect other tabs.

Resume-failure recovery: the launch command uses ``--resume <id>''
when ``:CLAUDE_CLI_SESSION:'' is saved on the heading.  If that id
no longer exists in Claude Code's on-disk session store (cross-
contamination, version skew, manual cleanup), Claude prints
``No conversation found with session ID'' and exits immediately.
We detect that within ~2s of launch, drop the stale property, and
re-launch without ``--resume'' so the user gets a fresh session
rather than being stranded at a bare shell prompt.

Calls ``code-agent-org-cmux--ensure-session'' first so stale surface
/ workspace IDs are refreshed after a cmux restart: the saved UUID
may be gone but cmux restores the workspace by name, and restart
must drive the fresh surface rather than the stale one."
  (interactive)
  (let* ((surface-id (code-agent-org-cmux--ensure-session))
         (workspace-session-id (code-agent-org-terminal-find-session-property "CLAUDE_SESSION_ID")))
    (unless surface-id
      (user-error "No cmux session for this story"))
    (let* ((launch-cmd (code-agent-org-cmux--build-launch-command
                        (buffer-file-name)
                        workspace-session-id
                        (or (code-agent-org-get-project-root) default-directory)))
           (screen (code-agent-org-cmux--capture-screen surface-id 8))
           (state  (code-agent-org-cmux--surface-state screen)))
      ;; 1. Classify the surface — claude TUI, shell prompt, or
      ;; unknown.  Only the shell-prompt case skips the /exit step.
      ;; Unknown defaults to "treat as claude" so we err toward
      ;; cleanly closing whatever's there (Claude swallows a stray
      ;; /exit harmlessly; sending nothing risks stacking processes).
      (message "Surface %s state before restart: %S" surface-id state)
      (unless (eq state 'shell)
        (when (eq state 'unknown)
          (message
           "Surface %s shows neither a Claude TUI nor a shell prompt — \
sending /exit as a conservative default.  If something else is in the \
foreground (vim, less, …) this may be a no-op."
           surface-id))
        ;; Claude Code (or unknown) — send /exit and wait
        (message "Sending /exit to Claude Code...")
        (condition-case nil
            (progn
              (code-agent-org-cmux--call "send" "--surface" surface-id "/exit")
              (code-agent-org-cmux--call "send-key" "--surface" surface-id "Return"))
          (error nil))
        (code-agent-org-cmux--wait-for-shell surface-id 15))
      ;; 2. Launch new Claude Code in the same tab
      (message "Launching fresh Claude Code...")
      (code-agent-org-cmux--call "send" "--surface" surface-id
                             (concat launch-cmd "\n"))
      ;; 2a. Resume-failure recovery — see helper docstring.  Claude
      ;; exits within ~1s on a bad session id, so a 2-3s settle is
      ;; enough for the banner.  Only kick the recovery path when we
      ;; actually used --resume; otherwise skip the round trip.
      (when (string-match-p " --resume " launch-cmd)
        (sleep-for 3)
        (code-agent-org-cmux--recover-from-resume-failure surface-id launch-cmd))
      ;; 3. Rename tab to active story (cmux may reset title on relaunch)
      (let ((ws-ref (code-agent-org-cmux--session-workspace-ref))
            (tab-title (code-agent-org-terminal--tab-title)))
        (when ws-ref
          (condition-case nil
              (code-agent-org-cmux--call "rename-tab" "--workspace" ws-ref tab-title)
            (error nil))
          ;; 4. Re-apply color
          (code-agent-org-cmux--apply-color ws-ref)))
      (let ((sk (code-agent-org-current-session-key)))
        (code-agent-org-cmux--stop-verbose sk)
        (code-agent-org-session-put sk :verbose-surface-id nil)
        (code-agent-org-cmux--start-verbose surface-id sk))
      ;; 5. Ensure IDE server and send /ide after ready
      (code-agent-org-cmux--post-restart-ide-setup surface-id workspace-session-id)
      (message "Claude Code restarting in surface %s" surface-id))))

(defun code-agent-org-cmux-cancel ()
  "Cancel the current code agent operation in cmux.
Uses cancel keys from the active agent profile (Escape for Claude Code,
C-c for GitHub Copilot CLI)."
  (interactive)
  (code-agent-with-span "cmux-cancel" nil nil

* Sidebar Feedback

cmux-specific rich feedback via the sidebar API. The wrappers below
expose =set-status= / =clear-status= / =set-progress= / =notify= /
=set-app-focus=; the design question of /what/ to put on the sidebar
splits across two coexisting hook handlers.

cmux ships its own =cmux claude-hook= subcommand that manages the
sidebar natively. Our =sdd-bridge= runs in parallel — both fire on
every event, registered in cmux's global settings and this plugin's
=hooks.json= respectively. They overlap but do not conflict:

| Event | cmux =claude-hook= | Our =sdd-bridge= |
|-------+--------------------+------------------|
| =SessionStart= | Set agent PID, upsert session | (not handled) |
| =UserPromptSubmit= | Clear notifications, "Running" status | Write busy status, save CLI session |
| =PreToolUse= | Verbose tool description ("Reading main.py") | Permission notification to Emacs |
| =Notification= | "Needs input" status, rich notification body | (not handled) |
| =Stop= | "Idle" status, transcript-derived notification | Write ready, insert response |
| =SessionEnd= | Clear all state | (not handled) |

cmux's =claudeCodeVerboseStatus= setting drives the per-tool sidebar
status ("Running git status", "Editing config.yaml", "Reading main.py")
without any code from us — we just leave it on. Port detection works
the same way: cmux's =PortScanner= batches =ps= + =lsof= over a ~10 s
window, so Phoenix (=:6006=) and our MCP server (=:9999=) appear in
the sidebar within ~500 ms of starting without any per-port wiring.

** Future: log query state through cmux's sidebar

We currently duplicate "Running / Idle" status in Emacs's mode-line
and via =write_status=. cmux's sidebar can also carry a richer
per-query record without extra Emacs work. Three small upgrades on
the Python side would land it:

- =sdd_bridge.handle_prompt= → =cmux log --source emacs --workspace <id>=
  with the prompt summary; the user gets a per-query line in the
  sidebar's log panel, attributed to Emacs.
- =sdd_bridge.handle_response= → same shape, summarising response
  length and status.
- =report_meta_block "current_query"= with markdown for richer
  presentation — supports prompt/status/timing in one card.

** Future: open the current story's design notes in the sidebar

=cmux markdown open <path>= raises a live-reloading markdown panel
with H1–H6 / code blocks / tables / blockquotes and atomic-rename-safe
auto-reload. Wiring it to the current SDD story would surface the
relevant design context next to the terminal:

* Permission Handling

Claude Code raises a permission event through the =PreToolUse= hook for
=AskUserQuestion= / =ExitPlanMode= (the two interactive tools — see
=.claude/rules/minimize-emacs-mcp-calls.md= for why everything else is
filtered out at the matcher). The Python =sdd-bridge= side returns
=ask= and calls back into Emacs via MCP; the handlers below register a
mode-line alert through =code-agent-add-alert=, focus the cmux
workspace, activate the cmux app, and post a macOS notification.
=PostToolUse= clears the alert.

The dispatch is keyed by backend: =code-agent-org--terminal-permission-needed=
in [[file:code-agent-org.org][code-agent-org.org]] routes to either cmux or another terminal based
on =CLAUDE_BACKEND=; the cmux variant lives below.

** Future: Pre-cache =AskUserQuestion= text for richer alerts

Today the notification body is the *tool name* — "sdd-2026… needs
approval for AskUserQuestion" — which is uninformative when the
actual question (e.g. "Which database should I use?") sits unread
inside =tool_input.question=. cmux's own =claude-hook pre-tool-use=
handler at =CLI/cmux.swift:8670-8691= already caches this text into
its session store as =lastSubtitle= / =lastBody= and uses it when the
=Notification= hook fires. We should do the same on the bridge side
and on Emacs.

The shape: in =workspace_bridge.py handle_permission=, when =tool_name= is
=AskUserQuestion=, extract =tool_input.question= and either write it
into the status directory (=code-agent-org-terminal-status-dir=) as a
=<session-id>.question= file, or pass it straight through to Emacs's
permission-needed call. =PostToolUse= clears the cache. On the Emacs
side, =--permission-needed= already puts =tool-name= in the tooltip
and notification; the change is a single string substitution.
=ExitPlanMode= is the second tool worth caching by the same path.

End-user effect:

#+begin_example
Before: "sdd-20260316 needs approval for AskUserQuestion"
After:  "sdd-20260316 asks: Which database should I use?"
#+end_example

The =permissionDecision= flow is untouched — the handler still returns
=ask=; only the display text gets richer.

#+BEGIN_SRC elisp
(defun code-agent-org-cmux--permission-needed (workspace-session-id tool-name)
  "Handle permission notification for a cmux session.
Registers a mode-line alert, focuses the cmux workspace, and notifies user.
Also ensures the session is marked busy (self-healing: if the Prompt hook
was skipped, the permission event proves a query is active)."
  (code-agent-with-span "cmux-permission-needed"
      (list :session-id workspace-session-id :tool-name tool-name) nil
  ;; Self-healing: ensure session is marked busy if not already.
  ;; The Prompt hook may have been skipped (e.g., retry/continue in Claude Code).
  (let ((session-key (gethash workspace-session-id code-agent-org-terminal--workspace-to-session-key)))
    (when (and session-key (not (code-agent-org-session-get session-key :busy)))
      (code-agent-org-session-put session-key :busy t)
      ;; Best-effort: register a query so response hook has a request-id.
      ;; Point in source-buffer may not be at the AI block heading, so
      ;; CUSTOM_ID/instruction-num in the query context may be wrong.
      ;; That's acceptable — the alternative is no query registration at all.
      (unless (code-agent-org-terminal--read-request-id workspace-session-id)
        (condition-case nil
            (let ((buf (code-agent-org-session-get session-key :source-buffer)))
              (when (and buf (buffer-live-p buf))
                (with-current-buffer buf
                  (code-agent-org-terminal-register-query workspace-session-id nil))))
          (error nil)))))
  ;; Register mode-line alert
  (code-agent-add-alert
   (intern workspace-session-id)
   :label (code-agent--permission-label workspace-session-id)
   :tooltip (format "Permission needed: %s\nClick to focus cmux workspace" tool-name)
   :face '(:foreground "orange" :weight bold)
   :action (lexical-let ((sid workspace-session-id))
             (lambda ()
               (code-agent-remove-alert (intern sid))
               (code-agent-org-cmux--focus-workspace-by-session sid))))
  ;; Focus cmux workspace (best-effort)
  (code-agent-org-cmux--focus-workspace-by-session workspace-session-id)
  ;; Activate cmux app + Emacs (best-effort, macOS only)
  (code-agent-org-cmux--activate-app)
  ;; macOS notification
  (code-agent-org--notify "Claude: Permission Needed"
                      (format "%s needs approval for %s"
                              (code-agent--permission-label workspace-session-id)
                              tool-name))
  "ok"))

(defun code-agent-org-cmux--permission-resolved (workspace-session-id)
  "Clear pending permission for a cmux session."
  (code-agent-with-span "cmux-permission-resolved"
      (list :session-id workspace-session-id) nil
  (code-agent-remove-alert (intern workspace-session-id))
  "ok"))

(defun code-agent-org-cmux--focus-workspace-by-session (workspace-session-id)

      (ignore-errors
        (code-agent-org-cmux--call "select-workspace" "--workspace" ws-id)))))

* Session Recovery

Cross-restart recovery path — reloads session state from the org buffer when cmux restored a pane whose backend Emacs forgot about.

#+BEGIN_SRC elisp
(defun code-agent-org-cmux--recover-session (workspace-session-id)
  "Try to recover session mapping by scanning org buffers.
Called when WORKSPACE-SESSION-ID is not found in the hash tables after
Emacs restart.  Finds the heading via `CLAUDE_SESSION_ID' property,
resolves the current cmux workspace ref by heading name (the stable
cmux/emacs identity), and repopulates hash tables.  Returns the
session-key if found, nil otherwise."
  (code-agent-with-span "cmux-recover-session"
      (list :session-id workspace-session-id) nil
  (cl-block recover
    (dolist (buf (buffer-list))
      (when (and (buffer-file-name buf)
                 (with-current-buffer buf (bound-and-true-p code-agent-org-mode)))
        (with-current-buffer buf
          (save-excursion
            (save-restriction
              (widen)
              (goto-char (point-min))
              (when (re-search-forward
                     (format ":CLAUDE_SESSION_ID: %s"
                             (regexp-quote workspace-session-id))
                     nil t)
                (org-back-to-heading t)
                (let* ((surface (org-entry-get nil "CMUX_SURFACE_ID" nil))
                       (title (truncate-string-to-width
                               (or (org-get-heading t t t t) "") 50))
                       (ws-ref (and (not (string-empty-p title))
                                    (code-agent-org-cmux--find-workspace-by-name title)))
                       (ws-uuid (and ws-ref
                                     (code-agent-org-cmux--resolve-workspace-uuid ws-ref)))
                       (session-key (code-agent-org-current-session-key)))
                  (when (and surface session-key)
                    (puthash workspace-session-id session-key
                             code-agent-org-terminal--workspace-to-session-key)
                    (puthash workspace-session-id surface
                             code-agent-org-cmux--workspace-to-surface)
                    (when ws-uuid
                      (puthash workspace-session-id ws-uuid
                               code-agent-org-cmux--workspace-to-cmux-id))
                    (cl-return-from recover session-key))))))))))))
#+END_SRC
