* Overview
:PROPERTIES:
:CUSTOM_ID: org-session-overview
:END:

Earlier versions kept session state in a 600+-call-site plist — every
mutation reached in by keyword, every reader did the same, and there
was no static check that =--session-put :start-time ...= matched a
field anyone ever read.  This module replaces the plist with a
typed =cl-defstruct=, but it keeps the keyword API
=--session-get= / =--session-put= as the *sole* read/write surface so
the 600+ call sites need no change while gaining slot-level checking.

Invariant: the four sub-structs (=lifecycle=, =render=, =loop=,
=identity=) cover every typed slot; anything not yet promoted to a
sub-struct lives in =extras= (a plist hatch).  Slot reads MUST go
through =--session-get= — direct accessor calls (e.g.
=(code-agent-org--session-lifecycle-busy state)=) are reserved for
the module itself and bypass the keyword API's normalisation.

* Claude Org Session
:PROPERTIES:
:LITERATE_ORG_BLOCK_KIND: atomic
:header-args:elisp: :tangle yes
:END:

Per-buffer session state for a Claude query in an org-mode AI block.
A session-state is a =cl-defstruct= composed of four sub-structs —
=lifecycle=, =render=, =loop=, =identity= — plus an =extras= plist
for properties that have not (yet) earned a typed slot. Callers reach
slots through the keyword API =--session-get= / =--session-put= so
the receiver-only typed shape stays decoupled from the 600+ call sites.

*** Sub-Structs

*** Lifecycle Sub-Struct

Lifecycle slots — busy / recovering / start-time / pending-queue / backend handle.

#+BEGIN_SRC elisp
(cl-defstruct (code-agent-org--session-lifecycle
               (:constructor code-agent-org--make-session-lifecycle)
               (:copier nil))
  "Query lifecycle state."
  busy                    ; Boolean: query in progress
  recovering              ; Non-nil during session recovery
  start-time              ; float-time of request start
  original-prompt         ; Original prompt for recovery context
  recovery-count          ; Count of recovery attempts
  query-handle            ; Opaque handle from backend-query (for cancellation)
  backend                 ; code-agent-backend struct (dispatches protocol)
  pending-queue)          ; List of queued blocks awaiting execution
#+END_SRC

*** Render Sub-Struct

Render slots — section-level / response-has-content / current-line-length / marker / spinner.  Owns the response-side mutable state.

(cl-defstruct (code-agent-org--session-render

               (:copier nil))

  marker                  ; Insertion point marker

*** Composed Session State

The umbrella =cl-defstruct= composing all sub-structs.  =--session-get/put= dispatches to the sub-struct via the field-spec.

#+BEGIN_SRC elisp
(cl-defstruct (code-agent-org--session-state
               (:constructor code-agent-org--make-session-state--internal)
               (:copier nil))
  "Typed session state for an org-mode Claude session.
Composed of sub-structs: lifecycle, render, loop, identity."
  (lifecycle (code-agent-org--make-session-lifecycle) :documentation "Lifecycle sub-struct")
  (render (code-agent-org--make-session-render) :documentation "Render sub-struct")
  (loop (code-agent-org--make-session-loop) :documentation "Loop sub-struct")
  (identity (code-agent-org--make-session-identity) :documentation "Identity sub-struct")
  extras)                 ; Plist for arbitrary additional properties

(defun code-agent-org--make-session-state (&rest args)
  "Create a new session-state, applying keyword ARGS to sub-struct fields.
ARGS is a flat property list (e.g. :spinner 0 :section-level nil);
each key is routed to its sub-struct via `code-agent-org--session-state-set'."
  (let ((state (code-agent-org--make-session-state--internal)))
    (cl-loop for (key val) on args by #'cddr
             do (code-agent-org--session-state-set state key val))
    state))
#+END_SRC

*** Generated Routing Tables

Two alists, generated from =code-agent-org--session-field-specs= by a
shared helper. Each entry is =(KEYWORD . FUNCTION)= so callers
(including structural tests that introspect the tables) can use
=(funcall (cdr entry) ...)= without knowing which sub-struct the slot
lives in. The previous revision inlined =mapcar= twice with two
near-identical =eval `(lambda ...)=  closures; folding the shared
spec→symbols step into =--make-field-entry= cuts the boilerplate in
half.

#+BEGIN_SRC elisp
(defun code-agent-org--session--make-field-entry (spec build-fn)
  "Build a (KEYWORD . CLOSURE) entry for one field SPEC.
SPEC is (FIELD-NAME . SUB-STRUCT-NAME); BUILD-FN receives the two
resolved accessor symbols and returns the lambda to store."
  (let* ((field (car spec))
         (sub (cdr spec))
         (sub-acc (intern (format "code-agent-org--session-state-%s" sub)))
         (field-acc (intern (format "code-agent-org--session-%s-%s" sub field))))
    (cons (intern (format ":%s" field))
          (funcall build-fn sub-acc field-acc))))

(defconst code-agent-org--session-field-accessors
  (mapcar
   (lambda (spec)
     (code-agent-org--session--make-field-entry
      spec
      (lambda (sub-acc field-acc)
        (eval `(lambda (s) (,field-acc (,sub-acc s))) t))))
   code-agent-org--session-field-specs)
  "Alist mapping keyword properties to session-state getter closures.
Each entry is (KEYWORD . GETTER-FN) where GETTER-FN routes through sub-structs.
Generated from `code-agent-org--session-field-specs'.")

(defconst code-agent-org--session-field-setters
  (mapcar
   (lambda (spec)
     (code-agent-org--session--make-field-entry
      spec
      (lambda (sub-acc field-acc)
        (eval `(lambda (s v) (setf (,field-acc (,sub-acc s)) v)) t))))
   code-agent-org--session-field-specs)
  "Alist mapping keyword properties to session-state setter closures.
Each entry is (KEYWORD . SETTER-FN) where SETTER-FN routes through sub-structs.
Generated from `code-agent-org--session-field-specs'.")
#+END_SRC

*** Session State Accessors

Generated keyword API (=--session-get= / =--session-put=).  Single-source-of-truth routing tables built from the field spec.

#+BEGIN_SRC elisp
(defun code-agent-org--get-session (session-key)
  "Get or create session state for SESSION-KEY.
Returns a `code-agent-org--session-state' struct.
Replaces stale non-struct entries (e.g. plists from pre-refactor code)."
  ;; Ensure hash table exists (lazy initialization per buffer)
  ;; Must use setq-local to create buffer-local binding
  (unless (local-variable-p 'code-agent-org--sessions)
    (setq-local code-agent-org--sessions (make-hash-table :test 'equal)))
  (let ((existing (gethash session-key code-agent-org--sessions)))
    (if (code-agent-org--session-state-p existing)
        existing
      (let ((state (code-agent-org--make-session-state
                    :spinner 0
                    :section-level nil
                    :current-line-length 0)))
        (puthash session-key state code-agent-org--sessions)
        state))))

(defun code-agent-org--session-state-set (state prop value)
  "Set PROP to VALUE on session STATE struct.
PROP is a keyword like :busy, :query-id, etc.; unknown keywords fall
through to the extras plist."
  (let ((entry (assq prop code-agent-org--session-field-setters)))
    (if entry
        (funcall (cdr entry) state value)
      (setf (code-agent-org--session-state-extras state)
            (plist-put (code-agent-org--session-state-extras state) prop value))))
  value)

(defun code-agent-org-session-put (session-key prop value)
  "Set PROP to VALUE in session SESSION-KEY.
PROP is a keyword like :busy, :query-id, etc."
  (let ((state (code-agent-org--get-session session-key)))
    (code-agent-org--session-state-set state prop value)
    state))

(defun code-agent-org--session-state-get (state prop)
  "Get PROP from session STATE struct.
PROP is a keyword like :busy, :query-id, etc.; unknown keywords fall
through to the extras plist."
  (let ((entry (assq prop code-agent-org--session-field-accessors)))
    (if entry
        (funcall (cdr entry) state)
      (plist-get (code-agent-org--session-state-extras state) prop))))

(defun code-agent-org-session-get (session-key prop)
  "Get PROP from session SESSION-KEY.
PROP is a keyword like :busy, :query-id, etc.
Unknown properties fall through to the extras plist."
  (let ((state (code-agent-org--get-session session-key)))
    (code-agent-org--session-state-get state prop)))

(defun code-agent-org--reset-session-state (session-key)
  "Reset transient session state flags for SESSION-KEY.
Clears :busy, :recovering, and :last-assistant-query-id.
Used after query completion, error handling, and recovery failure."
  (code-agent-org-session-put session-key :busy nil)
  (code-agent-org-session-put session-key :recovering nil)
  (code-agent-org-session-put session-key :last-assistant-query-id nil))

(defun code-agent-org--find-heading-by-property (property value &optional buffer)
  "Find heading with PROPERTY matching VALUE in BUFFER.
Return point at heading start, or nil if not found.
BUFFER defaults to current buffer."
  (with-current-buffer (or buffer (current-buffer))
    (save-excursion
      (goto-char (point-min))
      (when (re-search-forward
             (format ":%s: +%s"
                     (regexp-quote property)
                     (regexp-quote value))
             nil t)
        (org-back-to-heading t)
        (point)))))

(defun code-agent-org--active-session-count ()
  "Return count of sessions with :busy t."
  (let ((count 0))
    (when (hash-table-p code-agent-org--sessions)
      (maphash (lambda (_id state)
                 (when (and (code-agent-org--session-state-p state)
                            (code-agent-org--session-state-get state :busy))
                   (cl-incf count)))
               code-agent-org--sessions))
    count))

(defun code-agent-org--session-display-name (session-key)
  "Extract display name from SESSION-KEY.
Returns just the custom part after :: or a shortened file path."
  (if (string-match "::\\(.+\\)$" session-key)
      (match-string 1 session-key)
    ;; No custom ID, show abbreviated file name
    (file-name-nondirectory session-key)))

(defun code-agent-org--format-elapsed (start-time)
  "Format elapsed time since START-TIME as human-readable string.
Uses verbose format for header-line display."
  (code-agent-format-elapsed-time start-time 'verbose))
#+END_SRC

*** Section Level Helpers

Detect the depth of the AI block's enclosing heading — drives the response-section level so children nest correctly.

#+BEGIN_SRC elisp
(defun code-agent-org--ensure-positive-level (raw-level)
  "Ensure RAW-LEVEL is a positive integer, defaulting to 1.
Returns RAW-LEVEL unchanged if it is a number greater than 0,
otherwise returns 1.  Handles nil, zero, and negative inputs."
  (if (and raw-level (> raw-level 0)) raw-level 1))

(defun code-agent-org--effective-section-level (session-key)
  "Return the effective section level for SESSION-KEY, defaulting to 1.
Reads :section-level from the session state and ensures it is positive
via `code-agent-org--ensure-positive-level'."
  (code-agent-org--ensure-positive-level
   (code-agent-org-session-get session-key :section-level)))
