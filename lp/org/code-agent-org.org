* Overview
:PROPERTIES:
:CUSTOM_ID: org-overview
:END:

This module owns the =code-agent-org-mode= minor mode — the public face
of =code-agent-org= that users enable in org buffers.  It wires together
the workspace-management infrastructure: cmux workspace lifecycle
(launch, restart, cancel, open tab), backend/profile selection, IDE
server management, and permission mode settings, all surfaced through a
=transient= menu (=C-c C-/=).

This file is the integration point — it loads the sub-modules
(customize, session, session-context, env-permission, project-prompts,
workspace, process) and provides the interactive surface.  The actual
workspace orchestration lives in those sub-modules under =lp/org/=.

Invariant: =code-agent-org-mode= turns on iff this module is loaded; no
other module activates the minor mode.  Cross-buffer state (session
table, active queries, mode-line counters) is owned by this file or by
sub-modules whose functions are called through the single-dash public
API surface exported here.

* Mode Definition

** Terminal Dispatchers

Three events arrive here from =workspace_bridge.py= over MCP carrying
nothing but a workspace-session-id, and each has to reach the backend
that owns that session.

Resolving the owner is the whole job, and it happens once, in
=--terminal-backend= below.  Previously each dispatcher open-coded a
=cond= over =(fboundp 'code-agent-org-cmux--…)= — which made cmux the
only reachable multiplexer no matter what any other backend
implemented.  The =fboundp= arms are gone; the three dispatchers now
send a Protocol 3 message and let dispatch decide.

#+BEGIN_SRC elisp
(defun code-agent-org--terminal-backend (workspace-session-id)
  "Return the backend owning WORKSPACE-SESSION-ID, or nil.

Three sources, cheapest first.  The cached =:backend= slot is
authoritative — the launch path put it there — so the common case
costs one hash lookup.  When the hash is empty because Emacs
restarted, `code-agent-org-backend-recover-session' rebuilds the
mapping from the org buffer, which is the authoritative record.  Only
then does the request-id file act as a last-resort proof that the
session existed at all.

Recovery must precede the request-id fallback: that path re-enters
with the hash still empty, so the session stays out of sync — busy
never clears, the loop never continues — unless the mapping is
rebuilt from the org section first."
  (let ((session-key (gethash workspace-session-id
                              code-agent-org-terminal--workspace-to-session-key)))
    (or (and session-key (code-agent-org-session-get session-key :backend))
        ;; Hash cold.  One scan of the loaded org buffers finds the
        ;; heading that owns this session; standing on it, the
        ;; CLAUDE_BACKEND property says which backend to build, and the
        ;; backend reads its own identity properties back.
        (let (found)
          (when (code-agent-org-terminal--recover-session
                 workspace-session-id
                 (lambda ()
                   (setq found (code-agent-org--resolve-backend
                                (code-agent-org-current-session-key)
                                (list :cwd default-directory)))
                   (when found
                     (ignore-errors (code-agent-org-backend-adopt-identity found)))))
            found))
        ;; Module reload / race: no org buffer is loaded, but the
        ;; request-id file proves a session is live.  Fall back to the
        ;; configured default so the query still gets unregistered
        ;; rather than leaking as permanently in-flight.
        (and (code-agent-org-terminal--read-request-id workspace-session-id)
             (when-let* ((ctor (cdr (assoc code-agent-org-default-backend
                                           code-agent-org-backend-registry))))
               (funcall ctor (or session-key workspace-session-id) nil))))))

(defun code-agent-org--terminal-query-completed (workspace-session-id)
  "Route query-completion for WORKSPACE-SESSION-ID to its backend."
  (if-let* ((backend (code-agent-org--terminal-backend workspace-session-id)))
      (code-agent-org-backend-query-completed backend workspace-session-id)
    (message "code-agent-org: no backend owns session %s (query-completed)"
             workspace-session-id)))

(defun code-agent-org--terminal-permission-needed (workspace-session-id tool-name)
  "Route a permission request for WORKSPACE-SESSION-ID to its backend."
  (if-let* ((backend (code-agent-org--terminal-backend workspace-session-id)))
      (code-agent-org-backend-permission-needed backend workspace-session-id tool-name)
    (message "code-agent-org: no backend owns session %s (permission-needed)"
             workspace-session-id)))

(defun code-agent-org--terminal-permission-resolved (workspace-session-id)
  "Route a permission resolution for WORKSPACE-SESSION-ID to its backend."
  (if-let* ((backend (code-agent-org--terminal-backend workspace-session-id)))
      (code-agent-org-backend-permission-resolved backend workspace-session-id)
    (message "code-agent-org: no backend owns session %s (permission-resolved)"
             workspace-session-id)))

** with-backend macro

Three things every "dispatch on the backend for point's session"
callsite repeats: read =current-session-key=, build the resolve
=options= plist with =:cwd=, and call =--resolve-backend=.  Lifting
that triple into one macro keeps callers focused on the verb they
actually want.

#+BEGIN_SRC elisp
(defmacro code-agent-org-with-backend (backend-var &rest body)
  "Bind BACKEND-VAR to the resolved backend for the current org
session and run BODY.  Resolve uses =current-session-key= +
=(:cwd default-directory)= options, the canonical preamble for
interactive callers.

Callers that already hold a session-key (e.g. =--send-request=
which receives one as a parameter) should NOT use this macro —
call =--resolve-backend= directly so the session-key flows through
explicitly."
  (declare (indent 1) (debug (symbolp body)))
  `(let* ((session-key (code-agent-org-current-session-key))
          (options (list :cwd default-directory))
          (,backend-var (code-agent-org--resolve-backend session-key options)))
     ,@body))
#+END_SRC

** New Workspace

Insert a new workspace heading with the standard properties for cmux session management.

A workspace heading is the binding between an org section and a
checkout: =:CLAUDE_SESSION_ID:= names the session for hook routing,
=:PROJECT_ROOT:= names the directory it works in.  The root is stamped
explicitly rather than left to the file-level =#+PROPERTY:= default —
the moment a second worktree exists, an inherited root can no longer
say which one a heading means, and the multiplexer resolves the
worktree from exactly this value.

=:CMUX_WORKSPACE:= is stamped only by backends that read it back;
asking the backend keeps that knowledge in the one module that owns
the property instead of a string test at the call site.

#+BEGIN_SRC elisp
(cl-defgeneric code-agent-org-backend-workspace-properties (backend name)
  "Return extra org properties to stamp on a new workspace heading NAME.
An alist of (PROPERTY . VALUE); the base method stamps nothing."
  (ignore backend name)
  nil)

(defun code-agent-org--session-id-taken-p (session-id)
  "Return non-nil when SESSION-ID is already stamped in this buffer."
  (save-excursion
    (save-restriction
      (widen)
      (goto-char (point-min))
      (re-search-forward
       (concat "^[ \t]*:CLAUDE_SESSION_ID:[ \t]*" (regexp-quote session-id) "[ \t]*$")
       nil t))))

(defun code-agent-org--new-session-id ()
  "Return a workspace session id no heading in this buffer uses yet.
The timestamp has second resolution, so importing several worktrees in
one command would otherwise stamp them all with the same id — and the
id is what every hook routes on."
  (let* ((base (format "sdd-%s" (format-time-string "%Y%m%d-%H%M%S")))
         (candidate base)
         (n 1))
    (while (code-agent-org--session-id-taken-p candidate)
      (setq n (1+ n)
            candidate (format "%s-%d" base n)))
    candidate))

(defun code-agent-org-insert-workspace-heading (name project-root &optional level)
  "Insert a workspace heading NAME bound to PROJECT-ROOT, and return its session id.
The heading lands after the current subtree at LEVEL (default: the
level of the heading at point, or 1), so a new workspace is a sibling
of the one it was created from — nesting would re-parent every ai
block written under the old heading."
  (let* ((session-id (code-agent-org--new-session-id))
         (lvl (or level
                  (save-excursion
                    (if (ignore-errors (org-back-to-heading t))
                        (org-current-level)
                      1))))
         (extra (ignore-errors
                  (code-agent-org-backend-workspace-properties
                   (code-agent-org--make-default-backend session-id nil) name))))
    (if (ignore-errors (org-back-to-heading t))
        (org-end-of-subtree t t)
      (goto-char (point-max)))
    (unless (bolp) (insert "\n"))
    (insert "\n" (make-string lvl ?*) " " name "\n")
    (insert ":PROPERTIES:\n")
    (dolist (cell extra)
      (insert ":" (car cell) ": " (cdr cell) "\n"))
    (insert ":CLAUDE_SESSION_ID: " session-id "\n")
    (insert ":PROJECT_ROOT: " (directory-file-name (expand-file-name project-root)) "\n")
    (insert ":END:\n")
    session-id))

(defun code-agent-org-new-workspace (name)
  "Create a workspace heading named NAME in the current worktree.
The new heading is a sibling of the one at point and inherits its
=:PROJECT_ROOT:=, so this is how a second agent joins a checkout that
already has one.  Use `code-agent-org-orca-new-worktree' when the work
needs its own checkout."
  (interactive "sWorkspace name: ")
  (let ((root (or (code-agent-org-get-project-root) default-directory)))
    (save-excursion
      (code-agent-org-insert-workspace-heading name root))
    (message "Workspace '%s' created in %s. Use C-c C-/ r to launch."
             name (abbreviate-file-name root))))
#+END_SRC

** IDE Server Wrappers

Interactive wrappers for IDE server lifecycle functions that need
session-level context (workspace-session-id, claude-ide-key) that a
bare transient binding cannot provide directly.

#+BEGIN_SRC elisp
(defun code-agent-org-ide-start ()
  "Start the IDE server for the current workspace."
  (interactive)
  (let* ((session-key (code-agent-org-current-session-key))
         (workspace-id (code-agent-org-session-get session-key :workspace-session-id))
         (project-root (code-agent-org-get-project-root)))
    (if (and workspace-id project-root)
        (progn
          (code-agent-org-cmux--ensure-ide-server project-root workspace-id)
          (message "IDE server started for workspace %s" workspace-id))
      (message "No active workspace or project root"))))

(defun code-agent-org-ide-stop ()
  "Stop the IDE server for the current workspace."
  (interactive)
  (let* ((session-key (code-agent-org-current-session-key))
         (claude-ide-key (code-agent-org-session-get session-key :claude-ide-key)))
    (if claude-ide-key
        (progn
          (claude-ide-stop-server claude-ide-key)
          (message "IDE server stopped"))
      (message "No active IDE server for this session"))))
#+END_SRC

;;;###autoload
(define-minor-mode code-agent-org-mode
  "Minor mode for Claude Code workspace management in org-mode.

Key bindings:
  \\[code-agent-org-menu]     Open transient command menu

\\{code-agent-org-mode-map}"
  :lighter " ClaudeOrg"
  :keymap code-agent-org-mode-map
  :group 'code-agent-org
  (if code-agent-org-mode
      (progn
        ;; Save original header line
        (setq code-agent-org--original-header-line header-line-format)
        ;; Save and disable line truncation (so long lines wrap)
        (setq code-agent-org--original-truncate-lines truncate-lines)
        (setq truncate-lines nil)
        ;; Set up header line
        (code-agent-org-refresh-header-line)
        ;; Track cursor position for workspace badge
        (add-hook 'post-command-hook
                  #'code-agent-org--schedule-cursor-header-update nil t)
        ;; Register exclusion from IDE context
        (code-agent-org--register-exclusion)
        ;; Auto-start MCP server
        (code-agent-org--ensure-mcp-server)
        ;; Proactively start the OTel trace bridge so spans flow from the
        ;; first session rather than only lazily on the first Emacs-side
        ;; traced span — a cmux-only workflow may never emit one, leaving
        ;; the bridge dead (and Phoenix silent) until a manual restart.
        ;; `--ensure-bridge' is idempotent and self-gates on
        ;; `code-agent-trace-enabled'.
        (when (fboundp 'code-agent-trace--ensure-bridge)
          (ignore-errors (code-agent-trace--ensure-bridge)))
        ;; Add buffer kill hook to clean up resources
        (add-hook 'kill-buffer-hook #'code-agent-org--on-buffer-kill nil t))
    ;; Restore original header line
    (setq header-line-format code-agent-org--original-header-line)
    ;; Restore original truncate-lines
    (setq truncate-lines code-agent-org--original-truncate-lines)
    ;; Disconnect persistent clients for this buffer
    (code-agent-org-persistent-registry-disconnect-buffer
     code-agent-org--persistent-registry (current-buffer))
    ;; Stop header timer if no more code-agent-org buffers
    (code-agent-org--stop-header-timer)
    ;; Cancel cursor-position debounce timer
    (when code-agent-org--header-cursor-timer
      (cancel-timer code-agent-org--header-cursor-timer)
      (setq code-agent-org--header-cursor-timer nil))
    (remove-hook 'post-command-hook
                 #'code-agent-org--schedule-cursor-header-update t)
    ;; Remove buffer-local hooks
    (remove-hook 'kill-buffer-hook #'code-agent-org--on-buffer-kill t)))

;;;###autoload
(defun code-agent-org-cleanup ()
  "Clean up code-agent-org resources."
  (interactive)
  (clrhash code-agent-org--sessions))
