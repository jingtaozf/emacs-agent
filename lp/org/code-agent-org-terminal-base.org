* Overview
:PROPERTIES:
:CUSTOM_ID: org-terminal-base-overview
:END:

cmux and tmux backends both need the same handful of cross-cutting
primitives: a =/tmp/code-agent-status= file the Python bridge can
poll, a workspace-id-to-session-key hash table, session heading
navigation, request-id registration in =code-agent--active-queries=,
and tab-title formatting.  Without this base module, every backend
duplicates the same five functions and the duplicates drift apart.

Invariant: every helper here is named with a =code-agent-org-terminal--=
prefix and is purely data-shaping — no backend-specific RPCs.  The
shared workspace-to-session-key hash table is the single source of
truth for which org buffer owns each terminal session; both cmux and
tmux register through =code-agent-org-terminal--register-workspace=
and look up through =code-agent-org-terminal--lookup-session-key=.

* Claude Org Terminal Base

Shared utilities for terminal backends — status file I/O in
=/tmp/code-agent-status=, session heading navigation, query
registration in =code-agent--active-queries=, shared hash tables,
and tab-title generation. Extracted with a =code-agent-org-terminal--=
prefix so both cmux and tmux backends reuse the same logic.

*** Shared Session-Key Table

The single source of truth for which org buffer owns each terminal
session — mapped as workspace session ID → org session-key.  Owned
here (not in a backend module) because both cmux and tmux register
into it and look up through it; a =code-agent-org-terminal--= prefix
keeps the ownership explicit.  =code-agent-org.org= carries only a
valueless forward =defvar= for byte-compilation; this block holds the
live hash table.

#+BEGIN_SRC elisp
(defvar code-agent-org-terminal--workspace-to-session-key
  (make-hash-table :test 'equal)
  "Map workspace session ID → org session-key.
Single source of truth shared by the cmux and tmux terminal backends.")
#+END_SRC

** Org Navigation

Heading walk + property lookup primitives + tab-title
formatting — used by both cmux and tmux backends.

*** Navigation Helpers

Find the workspace session heading and read properties from the session scope.
These are identical across terminal backends.

#+BEGIN_SRC elisp
(defun code-agent-org-terminal-goto-session-heading ()
  "Move point to the nearest ancestor heading with CLAUDE_SESSION_ID.
Starts at current heading, walks up. Returns the session ID string, or nil."
  (widen)
  (condition-case nil (org-back-to-heading t) (error nil))
  (or (org-entry-get nil "CLAUDE_SESSION_ID")
      (let ((found nil))
        (while (and (not found) (org-up-heading-safe))
          (setq found (org-entry-get nil "CLAUDE_SESSION_ID")))
        found)))

(defun code-agent-org-terminal-find-session-property (prop)
  "Find PROP in the workspace session scope.
Searches up from point for org property PROP using inheritance.
Also checks file-level #+PROPERTY settings (org-keyword-properties)
which `org-entry-get' does not include.
Returns the value string, or nil if not found."
  (save-excursion
    (save-restriction
      (widen)
      (or (org-entry-get nil prop t)
          ;; File-level #+PROPERTY values live in org-keyword-properties
          (cdr (assoc prop org-keyword-properties))))))
#+END_SRC

*** Tab Title

Generate a tab/workspace title from the workspace session heading — used by both
terminal tab naming and cmux workspace naming.

#+BEGIN_SRC elisp
(defun code-agent-org-terminal--workspace-heading-name ()
  "Return the workspace heading name truncated to 50 chars.
Point must be inside the workspace subtree."
  (save-excursion
    (save-restriction
      (code-agent-org-terminal-goto-session-heading)
      (truncate-string-to-width
       (or (org-get-heading t t t t) "untitled") 50))))

(defun code-agent-org-terminal--tab-title ()
  "Generate terminal tab title for current workspace session."
  (code-agent-org-terminal--workspace-heading-name))
#+END_SRC

** Status + Registration

Status file read/write + the per-query registration that ties
a workspace-session-id to its in-flight request-id.

*** Status File I/O

Read and write status files in =code-agent-org-terminal-status-dir=. The Python
Workspace bridge hooks write status (ready/busy), and Emacs reads them for fast
polling without API calls.

#+BEGIN_SRC elisp
(defun code-agent-org-terminal--save-request-id (workspace-session-id request-id)
  "Save REQUEST-ID to status file for WORKSPACE-SESSION-ID."
  (let ((dir code-agent-org-terminal-status-dir))
    (make-directory dir t)
    (with-temp-file (expand-file-name
                     (concat workspace-session-id ".request-id") dir)
      (insert request-id))))

(defun code-agent-org-terminal--read-request-id (workspace-session-id)
  "Read the request-id for WORKSPACE-SESSION-ID, or nil if not set."
  (let ((path (expand-file-name
               (concat workspace-session-id ".request-id")
               code-agent-org-terminal-status-dir)))
    (when (file-exists-p path)
      (let ((val (string-trim (with-temp-buffer
                                (insert-file-contents path)
                                (buffer-string)))))
        (unless (string-empty-p val) val)))))

(defun code-agent-org-terminal--read-hook-status (workspace-session-id)
  "Read Claude Code status from hook-written file. Fast, no API call."
  (let ((file (expand-file-name (or workspace-session-id "unknown")
                                code-agent-org-terminal-status-dir)))
    (if (file-exists-p file)
        (string-trim (with-temp-buffer
                       (insert-file-contents file)
                       (buffer-string)))
      "unknown")))

(defun code-agent-org-terminal--write-from-emacs-flag (workspace-session-id)
  "Write flag file indicating the next prompt was sent from Emacs.
workspace-bridge.sh checks this to skip duplicate instruction insertion."
  (let ((dir code-agent-org-terminal-status-dir))
    (make-directory dir t)
    (with-temp-file (expand-file-name
                     (concat workspace-session-id ".from-emacs") dir)
      (insert "1"))
    (let ((custom-id (org-entry-get nil "CUSTOM_ID")))
      (when custom-id
        (with-temp-file (expand-file-name
                         (concat workspace-session-id ".custom-id") dir)
          (insert custom-id))))))
#+END_SRC

*** Query Registration

Register an AI block execution as an active query in =code-agent--active-queries=.
Both backends create identical process-state structs and save the request-id
to a status file for the Python response hook.

#+BEGIN_SRC elisp
(defun code-agent-org-terminal-register-query (workspace-session-id _terminal-id)
  "Register the current AI block as an active query.
WORKSPACE-SESSION-ID is the workspace session, _TERMINAL-ID is the backend-specific ID (ignored).
Creates a process-state, registers in `code-agent--active-queries',
and saves the request-id to a status file for the Python hook."
  (let* ((custom-id (org-entry-get nil "CUSTOM_ID"))
         (heading (org-get-heading t t t t))
         (instr-num (when (and heading
                               (string-match "\\bInstruction \\([0-9]+\\)" heading))
                      (string-to-number (match-string 1 heading))))
         (req-id (code-agent--generate-request-id))
         (ctx (code-agent-make-query-context
               :instruction-num instr-num
               :custom-id custom-id))
         (state (code-agent--make-process-state
                 :request-id req-id
                 :start-time (float-time)
                 :source-buffer (current-buffer)
                 :query-context ctx
                 :source-location-fn (when custom-id #'code-agent-org-goto-custom-id)
                 :source-location-args (when custom-id (list custom-id)))))
    (code-agent--register-query req-id state)
    (code-agent-org-terminal--save-request-id workspace-session-id req-id)))
#+END_SRC

** Hook Routing — backend-neutral bodies

The three events the Python bridge pushes over MCP — turn finished,
permission opened, permission closed — plus the cross-restart mapping
rebuild they depend on.  cmux answers the matching Protocol 3 generics
from its own legacy body; every *other* multiplexer answers them with
the functions here, so a new backend inherits the whole behaviour by
writing four one-line methods.

Everything below reaches the multiplexer only through Protocol 2b
generics, never through a named CLI.

*** Turn completion

Unregisters the in-flight query, clears the session's busy flag, and
continues a =:LOOP_MAX:= run when one is active.  The =condition-case=
is load-bearing rather than defensive: this runs from Python over MCP,
where an unhandled error would leave the session wedged at =:busy t=
forever with no user-visible cause.

#+BEGIN_SRC elisp
(declare-function code-agent-org-session-get "code-agent-org-session" (key prop))
(declare-function code-agent-org-session-put "code-agent-org-session" (key prop value))
(declare-function code-agent--get-active-query "code-agent-backend" (request-id))
(declare-function code-agent--unregister-query "code-agent-backend" (request-id))
(declare-function code-agent-mux-send-text "code-agent-multiplexer" (backend text))
(declare-function code-agent-mux-send-key "code-agent-multiplexer" (backend key))
(declare-function code-agent-mux-focus "code-agent-multiplexer" (backend))
(declare-function code-agent-add-alert "code-agent" (id &rest args))
(declare-function code-agent-remove-alert "code-agent" (id))
(declare-function code-agent--permission-label "code-agent-org-cmux" (session-id))
(declare-function code-agent-org-current-session-key "code-agent-org-session" ())

(defun code-agent-org-terminal--submit-prompt (backend prompt)
  "Type PROMPT into BACKEND's terminal and submit it."
  (code-agent-mux-send-text backend prompt)
  (code-agent-mux-send-key backend :enter))

(defun code-agent-org-terminal--continue-loop (backend session-key workspace-session-id)
  "Schedule the next `:LOOP_MAX:' iteration for SESSION-KEY, if any."
  (let ((current (or (code-agent-org-session-get session-key :loop-current) 1))
        (max     (or (code-agent-org-session-get session-key :loop-max) 1)))
    (if (< current max)
        (let ((interval (or (code-agent-org-session-get session-key :loop-interval) 0))
              (prompt   (code-agent-org-session-get session-key :original-prompt)))
          (code-agent-org-session-put session-key :loop-current (1+ current))
          (code-agent-org-terminal--save-request-id
           workspace-session-id (code-agent--generate-request-id))
          (if (> interval 0)
              (run-at-time interval nil
                           #'code-agent-org-terminal--submit-prompt backend prompt)
            (code-agent-org-terminal--submit-prompt backend prompt)))
      (code-agent-org-session-put session-key :loop-max nil)
      (code-agent-org-session-put session-key :loop-current nil))))

(defun code-agent-org-terminal--query-completed (backend workspace-session-id)
  "Backend-neutral handler for WORKSPACE-SESSION-ID's turn finishing."
  (condition-case err
      (let ((session-key (gethash workspace-session-id
                                  code-agent-org-terminal--workspace-to-session-key)))
        (when-let* ((req-id (code-agent-org-terminal--read-request-id
                             workspace-session-id))
                    (state (code-agent--get-active-query req-id)))
          (setf (code-agent--process-state-closed state) t)
          (code-agent--unregister-query req-id))
        (when session-key
          (code-agent-org-session-put session-key :busy nil)
          (code-agent-org-terminal--continue-loop
           backend session-key workspace-session-id)))
    (error
     (when-let* ((sk (gethash workspace-session-id
                              code-agent-org-terminal--workspace-to-session-key)))
       (code-agent-org-session-put sk :busy nil))
     (message "code-agent-org-terminal: query-completed failed: %S" err))))
#+END_SRC

*** Permission alerts

Registers a mode-line alert whose action focuses the agent's terminal,
then focuses it immediately.  Focus goes through =code-agent-mux-focus=
— the Protocol 2b generic that shipped with a no-op default and no
callers until this call site.

The self-healing =:busy= write is not bookkeeping tidiness: Claude Code
skips the prompt hook on a retry or a =/continue=, and a permission
event is proof a turn is in flight, so this is the only signal that a
skipped-hook session is actually running.

#+BEGIN_SRC elisp
(defun code-agent-org-terminal--permission-needed (backend workspace-session-id tool-name)
  "Backend-neutral permission-needed alert for WORKSPACE-SESSION-ID."
  (let ((session-key (gethash workspace-session-id
                              code-agent-org-terminal--workspace-to-session-key)))
    (when (and session-key (not (code-agent-org-session-get session-key :busy)))
      (code-agent-org-session-put session-key :busy t)
      (unless (code-agent-org-terminal--read-request-id workspace-session-id)
        (condition-case nil
            (let ((buf (code-agent-org-session-get session-key :source-buffer)))
              (when (and buf (buffer-live-p buf))
                (with-current-buffer buf
                  (code-agent-org-terminal-register-query workspace-session-id nil))))
          (error nil)))))
  (code-agent-add-alert
   (intern workspace-session-id)
   :label (code-agent--permission-label workspace-session-id)
   :tooltip (format "Permission needed: %s\nClick to focus the agent terminal" tool-name)
   :face '(:foreground "orange" :weight bold)
   :action (lambda ()
             (code-agent-remove-alert (intern workspace-session-id))
             (ignore-errors (code-agent-mux-focus backend))))
  (ignore-errors (code-agent-mux-focus backend))
  "ok")

(defun code-agent-org-terminal--permission-resolved (_backend workspace-session-id)
  "Backend-neutral permission-resolved handler for WORKSPACE-SESSION-ID."
  (code-agent-remove-alert (intern workspace-session-id))
  "ok")
#+END_SRC

*** Cross-restart recovery

Finds the org heading whose =CLAUDE_SESSION_ID= matches and re-registers
the workspace-to-session-key mapping the rest of the routing depends
on.  =AT-HEADING-FN= runs with point on that heading so a backend can
read its own identity properties back into its slots — the hook that
replaces cmux's title lookup, which cannot work on a multiplexer that
regenerates tab titles from agent activity.

#+BEGIN_SRC elisp
(defun code-agent-org-terminal--recover-session (workspace-session-id &optional at-heading-fn)
  "Rebuild the session-key mapping for WORKSPACE-SESSION-ID from org buffers.
Calls AT-HEADING-FN with point on the matching heading when supplied.
Returns the session-key, or nil when no buffer carries that session."
  (cl-block recover
    (dolist (buf (buffer-list))
      (when (and (buffer-file-name buf)
                 (with-current-buffer buf (bound-and-true-p code-agent-org-mode)))
        (with-current-buffer buf
          (save-excursion
            (save-restriction
              (widen)
              (goto-char (point-min))
              (when (re-search-forward
                     (format ":CLAUDE_SESSION_ID: %s"
                             (regexp-quote workspace-session-id))
                     nil t)
                (org-back-to-heading t)
                (let ((session-key (code-agent-org-current-session-key)))
                  (when session-key
                    (puthash workspace-session-id session-key
                             code-agent-org-terminal--workspace-to-session-key)
                    (when at-heading-fn (funcall at-heading-fn))
                    (cl-return-from recover session-key)))))))))))
#+END_SRC
