#+TITLE: Code Agent Org — Living Workspace
#+PROPERTY: literate-load yes

* Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:

Implements the "Living Workspace" model: the org file is a
persistent REPL where a top-level workspace heading hosts a
long-lived Claude Code session. Owns workspace-root detection,
=CUSTOM_ID= generation for both workspaces and the ai blocks
that live under them, and inline context collection for prompts.

** Concerns owned

| Concern | Functions |
|---------+-----------|
| Workspace detection | =--find-workspace-heading= / =--find-workspace-root= |
| =CUSTOM_ID= generation | =--generate-custom-id= / =--generate-instruction-custom-id= |
| Inline context for prompts | =--collect-current-context= (the file-position summariser sent with every query) |

** The Living Workspace mental model

The org file is a *Lisp image*. A workspace is a persistent
process; =C-c C-c= is the REPL =eval=, always available.

#+begin_example
,* code-agent-dev                        ← workspace heading
:PROPERTIES:
:CMUX_WORKSPACE: code-agent-dev          ← user-set: human-readable name
:CLAUDE_SESSION_ID: sdd-20260326-dev       ← session identity
:CLAUDE_CLI_SESSION: abc-def-123           ← auto-set: for --resume
:CMUX_SURFACE_ID: surface:5                ← auto: cached surface ref
:END:

,** System Prompt :system_prompt:         ← project context
,** Workflow :sdd:                        ← all prompts + responses go here
,*** Instruction 1 :claude_chat:
,#+begin_src ai
…
,#+end_src
#+end_example

| Property | Who Sets | Purpose |
|----------+----------+---------|
| =CMUX_WORKSPACE= | User | Human-readable workspace name; binds to the cmux pane |
| =CLAUDE_SESSION_ID= | User or auto | Session identity for routing and inheritance |
| =CLAUDE_CLI_SESSION= | Auto | Claude Code SDK UUID for =--resume= |
| =CMUX_SURFACE_ID= | Auto | Cached surface ID, avoids re-detection |

** Two Channels, Same Session

Both routes through the same workspace's Claude Code:

| Channel | Trigger | Routing |
|---------+---------+---------|
| A — ai block | =C-c C-c= inside an =ai= block | Auto-selects nearest ancestor =CMUX_WORKSPACE=; per-session =:marker= identifies insert point |
| B — direct cmux input | User types in the cmux terminal directly | =workspace-bridge= navigates to the workspace's =Workflow= subsection, inserts at end |

* Workspace Root Detection

Recognises workspace root from the runtime signals available — gates the branch that depends on the result.

#+BEGIN_SRC elisp
(defun code-agent-org--find-workspace-root ()
  "Find the root workspace name for current position.
Returns the heading text of the workspace heading (with CMUX_WORKSPACE
property), or falls back to the grandparent of the :sdd: Workflow section."
  (save-excursion
    ;; Prefer CMUX_WORKSPACE-based lookup (new workspace layout)
    (let ((ws (code-agent-org--find-workspace-heading)))
      (if ws
          (car ws)
        ;; Fallback for old layout: walk up from :sdd: tag
        (when (member "sdd" (code-agent-org--get-current-tags))
          (while (and (org-up-heading-safe)
                      (not (member "sdd" (org-get-tags nil t)))))
          (when (org-up-heading-safe)
            (org-get-heading t t t t)))))))
#+END_SRC

** Workspace Heading Navigation

Movement primitives for workspace heading — wraps =org-goto-*= so callers express intent, not point arithmetic.

A workspace root is recognised by its *own* (non-inherited) =CMUX_WORKSPACE=
or =CLAUDE_SESSION_ID= property. =CMUX_WORKSPACE= is the human-readable name
=code-agent-org-insert-workspace= stamps, but the SDD/cmux creation paths
stamp only =CLAUDE_SESSION_ID= — the universal marker every backend (cmux
launch, the Python bridge) already keys on. Both reads are non-inherited so
a sub-section — which merely *inherits* the session id — is never mistaken
for a workspace root.

#+BEGIN_SRC elisp
(defun code-agent-org--workspace-heading-p ()
  "Non-nil if the heading at point is a workspace root.
Matches a heading carrying its OWN `CMUX_WORKSPACE' (named layout) or
`CLAUDE_SESSION_ID' (the session marker every backend keys on), read
non-inherited so a sub-section that only inherits the session id is
not counted as a workspace."
  (or (org-entry-get nil "CMUX_WORKSPACE")
      (org-entry-get nil "CLAUDE_SESSION_ID")))
#+END_SRC

#+BEGIN_SRC elisp
(defun code-agent-org--find-workspace-heading ()
  "Find nearest ancestor workspace heading (see
`code-agent-org--workspace-heading-p').
Returns (name . position) or nil. Works from any point inside a workspace."
  (save-excursion
    (save-restriction
      (widen)
      (condition-case nil
          (progn
            (unless (org-at-heading-p) (org-back-to-heading t))
            ;; Check current heading and walk up until found or at top
            (cl-block nil
              (while t
                (when (code-agent-org--workspace-heading-p)
                  (cl-return (cons (org-get-heading t t t t) (point))))
                (unless (org-up-heading-safe)
                  (cl-return nil)))))
        (error nil)))))

#+END_SRC

** Workspace Collection

Collects all workspace headings in the buffer.

#+BEGIN_SRC elisp
(defun code-agent-org--collect-workspaces ()
  "Collect all workspace headings in current buffer (see
`code-agent-org--workspace-heading-p').
Returns list of (NAME POS SESSION-ID) ordered by position."
  (save-excursion
    (save-restriction
      (widen)
      (goto-char (point-min))
      (let (result)
        (while (re-search-forward "^\\*+ " nil t)
          (when (code-agent-org--workspace-heading-p)
            (push (list (org-get-heading t t t t)
                        (line-beginning-position)
                        (or (org-entry-get nil "CLAUDE_SESSION_ID") ""))
                  result)))
        (nreverse result)))))

#+END_SRC

** CUSTOM_ID Utilities

Generation + sanitisation helpers for =:CUSTOM_ID:= slugs — kebab-case + ASCII-safe so the slug round-trips through cross-file links.

#+BEGIN_SRC elisp
(defun code-agent-org--goto-block-by-custom-id (custom-id)
  "Navigate to heading with CUSTOM_ID using org-link-search.
Returns t if navigation succeeded, nil otherwise."
  (condition-case nil
      (progn
        (org-link-search (format "#%s" custom-id))
        t)
    (error nil)))

(defun code-agent-org--custom-id-exists-p (custom-id)
  "Check if CUSTOM_ID exists in the current buffer."
  (when custom-id
    (save-excursion
      (save-restriction
        (widen)
        (code-agent-org--goto-block-by-custom-id custom-id)))))

(defun code-agent-org-goto-custom-id (custom-id)
  "Navigate to the heading with CUSTOM_ID.
Returns t if found and positioned, nil otherwise."
  (goto-char (point-min))
  (when (re-search-forward
         (format ":CUSTOM_ID: %s" (regexp-quote custom-id)) nil t)
    (org-back-to-heading t)
    t))

(defun code-agent-org--find-instruction-custom-id ()
  "Find the CUSTOM_ID of the instruction heading containing point.
Checks immediate heading, previous siblings, then parent headings."
  (save-excursion
    (let ((custom-id nil))
      (ignore-errors
        (org-back-to-heading t)
        (when (member code-agent-org-heading-tag (org-get-tags nil t))
          (setq custom-id (org-entry-get nil "CUSTOM_ID"))))
      (unless custom-id
        (let ((current-level (org-current-level)))
          (while (and (not custom-id)
                      (org-get-previous-sibling))
            (when (and (= (org-current-level) current-level)
                       (member code-agent-org-heading-tag (org-get-tags nil t)))
              (setq custom-id (org-entry-get nil "CUSTOM_ID"))))))
      (unless custom-id
        (ignore-errors
          (while (and (not custom-id) (org-up-heading-safe))
            (when (member code-agent-org-heading-tag (org-get-tags nil t))
              (setq custom-id (org-entry-get nil "CUSTOM_ID"))))))
      custom-id)))
#+END_SRC

** CUSTOM_ID Generation

Generator helpers producing custom_id — invariants noted in each docstring.

#+BEGIN_SRC elisp
(defun code-agent-org-generate-custom-id (session-id section-name &optional file-base)
  "Generate a CUSTOM_ID for workspace sections.
SESSION-ID is the session identifier (e.g., \"sdd-20251227-180147\").
SECTION-NAME is the heading text (e.g., \"Research Output\").
FILE-BASE is optional file name without extension for cross-file uniqueness.
Returns a slug like \"code-agent-dev-research-output-sdd-20251227-180147\"."
  (when (and session-id section-name)
    (let ((slug (downcase (replace-regexp-in-string "[^[:alnum:]]+" "-" section-name))))
      ;; Remove leading/trailing hyphens
      (setq slug (replace-regexp-in-string "^-+\\|-+$" "" slug))
      (if file-base
          (format "%s-%s-%s" file-base slug session-id)
        (format "%s-%s" session-id slug)))))
#+END_SRC

* Collect Current Context

Gathers the workspace, buffer, file, region, IDE context into one plist — the input to every backend-query call.

#+BEGIN_SRC elisp
(defun code-agent-org--get-heading-tags ()
  "Get list of tag strings from current section headings (inherited).
Uses org-get-tags with LOCAL=nil to include inherited tags from ancestors."
  (when-let* ((tags (org-get-tags nil nil)))  ; nil = include inherited tags
    (mapcar #'downcase tags)))

(defun code-agent-org--get-property-tags ()
  "Get list of tag strings from CLAUDE_TAGS property (with inheritance).
Property value is space-separated list of tag names."
  (when-let* ((prop-value (org-entry-get nil "CLAUDE_TAGS" t)))  ; t = inherit
    (split-string prop-value "[ \t]+" t)))

(defun code-agent-org--get-current-tags ()
  "Get effective list of tag strings for current context.
Merges heading tags with CLAUDE_TAGS property, deduplicating.
Heading tags take priority (appear first in list)."
  (let* ((heading-tags (code-agent-org--get-heading-tags))
         (property-tags (code-agent-org--get-property-tags))
         (all-tags heading-tags))
    ;; Add property tags that aren't already in heading tags
    (dolist (tag property-tags)
      (unless (member (downcase tag) (mapcar #'downcase all-tags))
        (push (downcase tag) all-tags)))
    (nreverse all-tags)))

(defun code-agent-org--get-block-header-args ()
  "Get header arguments from current ai block.
Returns plist of header arguments, e.g. (:phase \"code\" :tests t)."
  (save-excursion
    (let ((case-fold-search t))
      (when (re-search-backward "^[ \t]*#\\+begin_src[ \t]+ai\\b" nil t)
        (let ((line (buffer-substring-no-properties (point) (line-end-position))))
          (when (string-match "#\\+begin_src[ \t]+ai\\b[ \t]*\\(.*\\)" line)
            (let ((args-str (match-string 1 line))
                  (result nil))
              (when (and args-str (not (string-empty-p args-str)))
                ;; Parse header args: :key value :key2 value2
                (with-temp-buffer
                  (insert args-str)
                  (goto-char (point-min))
                  (while (re-search-forward ":\\([a-zA-Z_-]+\\)\\(?:[ \t]+\\([^ \t\n:]+\\)\\)?" nil t)
                    (let ((key (intern (concat ":" (match-string 1))))
                          (val (match-string 2)))
                      ;; Build plist: push value first, then key (reversed later)
                      (push key result)
                      (push (or val t) result)))))
              ;; Result is (val2 key2 val1 key1), reverse to get (key1 val1 key2 val2)
              (nreverse result))))))))
#+END_SRC
