#+TITLE: lp/trace — OpenTelemetry Tracing Primitives

One module: the =code-agent-trace-with-span= macro family that wraps
every meaningful operation in an OTel span.  Spans are exported via
the OTel bridge to Phoenix on localhost:6006.

* Modules

| File | Role |
|------+------|
| [[file:code-agent-trace.org][code-agent-trace.org]] | =cl-defstruct= for tracer / span / attribute, the =code-agent-trace-with-span= macro, the lazy-init that creates the global tracer at first use. |

* Read order

=code-agent-trace.org= is small and self-contained; read top-to-bottom.

* Boundaries

- /trace/ ← everyone: trace macros are imported by /sdk/, /org/,
  /chat/, /backend/ modules.  Load order in =code-agent.el= MUST
  bring /trace/ in early so the macro expansion sees a defined
  symbol when later modules compile.
- /trace/ → nothing: this module has zero outgoing dependencies on
  other =lp/= modules.  External: =opentelemetry-api= (lazy-loaded
  Python through the OTel bridge).

* Caveat

When the =code-agent-trace-with-span= macro changes, EVERY consumer
must reload — the old expansion is baked into compiled function
bodies until the consumer's =.org= file is reloaded.  See the
"Macro re-expansion" caveat in =CLAUDE.md=.
