#+TITLE: emacs-agent — Emacs MCP server + custom in-Emacs agents

An MCP (Model Context Protocol) HTTP server that exposes Emacs itself
as a tool surface to external coding agents — Claude Code, Pi, or any
MCP client — plus the home for custom in-Emacs agents built on top of
it.  Sources are literate org files loaded directly via
[[https://github.com/jingtaozf/literate-elisp][literate-elisp]]; the .org file IS the source.

The repo was deliberately narrowed on 2026-08-13: the previous
generation of features (cmux/tmux/orca terminal backends, org
workspace management, python bridge, IDE bridge) is preserved intact
on the =legacy-2026-08-13= branch.

* Quick start

#+begin_src elisp
;; deps: literate-elisp, web-server
(add-to-list 'load-path "~/projects/emacs-agent")
(require 'code-agent)          ; loads trace + MCP server modules
(emacs-mcp-server-start)       ; HTTP server at localhost:9999
#+end_src

Point an MCP client at =http://localhost:9999/mcp=.  For Claude Code:

#+begin_src bash
claude mcp add --transport http emacs http://localhost:9999/mcp
#+end_src

For Pi, tangle the bundled extension once — it reads =EMACS_MCP_URL=
and gives every Pi session the same Emacs tools:

#+begin_src bash
make tangle-pi-extensions   # → ~/.pi/agent/extensions/{emacs-mcp,doom-loop}.ts
#+end_src
