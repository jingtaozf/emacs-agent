* Codex ACP Profile

Per-agent configuration for OpenAI's Codex CLI.  Codex does NOT speak
ACP natively; it needs the =codex-acp= shim binary from
https://github.com/zed-industries/codex-acp installed separately
(e.g. =npm install -g @zed-industries/codex-acp= or equivalent).

Three auth methods:

| Method          | How                                              |
|-----------------+--------------------------------------------------|
| openai-api-key  | Set OPENAI_API_KEY, sent via authenticate RPC    |
| codex-api-key   | Set CODEX_API_KEY, sent via authenticate RPC     |
| chatgpt         | Interactive ChatGPT login                        |

References:
- https://github.com/zed-industries/codex-acp
- reference/agent-shell/agent-shell-openai.el

** Customization

#+BEGIN_SRC elisp
(defgroup claude-agent-acp-codex nil
  "Codex ACP profile."
  :group 'claude-agent-acp
  :prefix "claude-agent-acp-codex-")

(defcustom claude-agent-acp-codex-command '("codex-acp")
  "Command to launch the codex-acp shim.
The shim is separate from the =codex= CLI: install from
https://github.com/zed-industries/codex-acp."
  :type '(repeat string)
  :group 'claude-agent-acp-codex)

(defcustom claude-agent-acp-codex-auth-method 'openai-api-key
  "Which authenticate method to advertise during the ACP handshake.
- `openai-api-key': sends OPENAI_API_KEY (must be in environment)
- `codex-api-key': sends CODEX_API_KEY (must be in environment)
- `chatgpt': interactive ChatGPT login flow"
  :type '(choice (const openai-api-key)
                 (const codex-api-key)
                 (const chatgpt))
  :group 'claude-agent-acp-codex)

(defcustom claude-agent-acp-codex-environment nil
  "Extra environment variables for the codex-acp subprocess.
List of \"NAME=VALUE\" strings.  Typical entries:
  \"OPENAI_API_KEY=...\" for openai-api-key auth,
  \"CODEX_API_KEY=...\" for codex-api-key auth."
  :type '(repeat string)
  :group 'claude-agent-acp-codex)
#+END_SRC

** Class

The Codex ACP flow runs through the =codex-acp= shim binary rather
than the vendor's native JSON-RPC server; a dedicated subclass keeps
the distinction visible at dispatch time if we ever need to override
shim-specific behaviour.

#+BEGIN_SRC elisp
(cl-defstruct (claude-agent-codex-backend
               (:include claude-agent-acp-backend (type :codex))
               (:constructor claude-agent-codex-backend--create)
               (:copier nil))
  "ACP backend specialised for OpenAI Codex (via codex-acp shim).")
#+END_SRC

** Constructor

#+BEGIN_SRC elisp
(defun claude-agent-acp-codex-create (&rest args)
  "Create an ACP backend configured for OpenAI Codex (via codex-acp shim).
ARGS are forwarded to `claude-agent-codex-backend--create' after the
codex-specific defaults.  Typical usage:

  (claude-agent-acp-codex-create :cwd \"/path\" :session-key \"sdd-...\")

Requires the `codex-acp' binary on PATH; install separately."
  (apply #'claude-agent-acp--make-profile-backend
         #'claude-agent-codex-backend--create
         "codex"
         claude-agent-acp-codex-command
         claude-agent-acp-codex-environment
         'claude-agent-acp-codex-auth-method
         args))
#+END_SRC
